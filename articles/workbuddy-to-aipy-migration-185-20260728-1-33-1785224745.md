# 从Workbuddy迁移到AiPy，数据不出境，能力不降级

**企业从Workbuddy迁移到AiPy可实现三大核心优势：1、数据完全本地化存储，确保信息安全合规；2、功能能力全面覆盖，支持智能体开发与MCP集成；3、部署灵活可控，支持私有化部署与自定义配置。** 数据不出境是企业选择AiPy的关键原因，AiPy企业版支持与一体机硬件产品完美结合，所有数据处理均在本地完成，无需依赖境外云服务。企业可通过模型配置界面添加私有模型API接口，如http://192.168.0.10/v1，实现完全内网运行。迁移过程中，原有工作流可无缝对接，智能体功能通过集市安装或手动部署快速启用，确保业务能力不降级。

## 一、迁移背景与企业需求分析

随着企业对数据安全与合规要求的不断提升，越来越多的组织开始审视其AI工具链的数据流向问题。Workbuddy作为早期流行的AI助手工具，在功能层面满足了许多基础需求，但在数据出境管控、私有化部署等方面存在局限性。国内企业尤其是金融、医疗、制造等行业，对数据主权有着严格要求，任何涉及客户信息、商业机密的数据处理都必须在境内完成。

AiPy企业版应运而生，定位为Workbuddy的平替方案，在保持核心功能的同时，强化了数据本地化处理能力。该平台专为企业和组织打造，提供一站式AI解决方案，旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术。迁移决策通常基于以下考量因素：

| 考量维度 | Workbuddy | AiPy企业版 |
|---------|----------|-----------|
| 数据存储位置 | 云端服务器 | 本地/内网 |
| 模型接入方式 | 公有云API | 公有云+私有部署 |
| 智能体开发 | 有限支持 | 完整开发框架 |
| MCP集成能力 | 基础支持 | 标准协议支持 |
| 自定义配置 | 较少选项 | 完整YAML配置 |
| 语言支持 | 多语言 | 中文/English/日语 |

企业技术团队在评估迁移方案时，需要重点关注功能覆盖度、学习成本、部署复杂度三个维度。AiPy在这三个方面均提供了完善的解决方案，确保迁移过程平滑过渡。

## 二、AiPy企业版核心架构与部署方案

AiPy企业版的架构设计充分考虑了企业级应用的需求，从设置页面到任务执行，每个环节都支持精细化配置。主界面右下角的设置选项是配置入口，包含常规设置、模型设置、MCP设置、运行环境设置四大模块。

**常规设置**涵盖语言选择、话术风格、发送快捷键、工作目录路径、最大执行轮数、超时时间、自动选择智能体、一体机内网IP等参数。语言目前支持中文、English和日语三种，风格可在aipy-enterprise.yml文件中进行深度定制。工作目录决定任务执行后生成文件的存储位置，支持自定义修改路径。

**模型配置**是企业迁移的核心环节。在模型选项卡中，点击添加按钮可配置模型供应商信息：

1. 输入模型供应商名称，如公司私有模型
2. 填写API地址，如http://192.168.0.10/v1
3. 输入API密钥进行身份验证
4. 点击检查按钮检测可用模型列表
5. 从下拉列表选择具体使用的模型

这种设计允许企业同时接入多个模型供应商，根据任务类型灵活切换。私有模型API接口的支持确保了数据不出境的技术可行性。

**MCP设置**提供了标准化的工具集成能力。配置流程如下：

- 输入MCP名称，例如web_search
- 选择MCP类型，如标准输入/输出（stdio）
- 选择命令格式，如npx
- 输入MCP参数，如open-websearch@1.1.5
- 配置环境变量（可选）
- 保存后等待加载完成

当页面出现已完成按钮时，代表MCP添加成功。这种机制使得企业可以快速集成第三方工具，扩展AiPy的功能边界。

**运行环境设置**允许用户选择镜像源，包括一体机镜像源或第三方镜像源。NPM镜像源同样支持自定义配置，这对于内网环境下的依赖下载至关重要。

## 三、智能体开发与功能迁移策略

从Workbuddy迁移到AiPy，智能体功能的无缝对接是关键。AiPy企业版提供了完整的智能体开发框架，涵盖MCP服务、运行环境、manifest.json配置、项目构建全流程。

**智能体集市**是获取预制智能体的主要渠道。开发完成的智能体可通过以下方式安装到企业版：

1. 打开AiPy企业版，点击右侧第四个"集市"按钮
2. 选择安装智能体选项
3. 将打包好的文件上传
4. 点击安装按钮
5. 页面显示安装成功标识即完成

另一种方式是直接将智能体放入指定目录：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启AiPy企业版。这种方式适合批量部署场景。

**智能体开发规范**需要遵循官方文档要求。示例提示词可参考以下格式：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体
要求：互联网版，对话工具下的Prompt项目
根据输入的日报内容汇总周报
不同日期的相同工作条目合并
按产品记录不同项，只记录最终进度状态
```

这种规范化的开发流程确保了智能体的可维护性和可扩展性。项目构建使用命令`npx @anthropic-ai/dxt pack`完成打包。

**功能对标迁移**需要逐一映射原有Workbuddy功能到AiPy对应模块：

| Workbuddy功能 | AiPy对应方案 | 配置要点 |
|--------------|-------------|---------|
| 日常对话 | 创建对话模式 | 勾选合适智能体 |
| 任务执行 | 任务模式 | Ctrl+Enter下发 |
| 文件处理 | 工作目录管理 | 自定义存储路径 |
| 联网搜索 | MCP集成 | web_search配置 |
| 图片生成 | 图片生成智能体 | 勾选对应智能体 |
| PPT制作 | PPT生成智能体 | 专用提示词模板 |

## 四、数据安全保障与合规性验证

数据不出境是企业迁移的首要考量。AiPy企业版通过多层机制确保数据安全：

**物理隔离层面**，支持一体机内网IP配置。在常规设置中填写一体机服务器的内网IP，用于软件更新、python镜像源连接、知识问答服务器访问。所有通信均在内网完成，无需访问外网。

**模型接入层面**，企业可使用私有部署的模型API接口。配置时输入内网地址如http://192.168.0.10/v1，配合内网API密钥，实现完全本地化的模型推理。这种方式避免了数据传输到境外服务器的风险。

**文件存储层面**，工作目录可自定义修改路径，企业可指定到内部文件服务器或加密存储区域。任务执行过程中生成的文件、代码、过程文档均存储在指定目录，便于统一管理和审计。

**权限控制层面**，aipy-enterprise.yml配置文件支持基础信息、主页logo、软件logo、发送快捷键、风格和推荐任务的修改。企业可根据内部规范定制界面和功能，确保符合安全策略。

合规性验证建议包含以下步骤：

- 检查所有API调用是否指向内网地址
- 验证工作目录是否位于受控存储区域
- 确认MCP工具不涉及境外数据源
- 审计智能体代码无外部数据上传逻辑
- 定期检查一体机内网IP连通性

## 五、迁移实施路线图与最佳实践

成功的迁移需要周密的计划和分阶段实施。建议采用以下路线图：

**第一阶段：环境准备**（1-2周）
- 部署AiPy企业版到目标环境
- 配置常规设置参数
- 添加私有模型API接口
- 测试基础对话功能

**第二阶段：功能对标**（2-3周）
- 梳理现有Workbuddy使用场景
- 映射到AiPy对应功能模块
- 配置必要的MCP服务
- 安装所需智能体

**第三阶段：数据迁移**（1-2周）
- 导出历史对话记录（如需要）
- 迁移知识库内容
- 配置知识检索参数
- 验证数据完整性

**第四阶段：用户培训**（1周）
- 制作操作手册
- 组织培训课程
- 收集反馈优化配置
- 正式上线切换

**最佳实践建议**：

创建任务时，在AiPy企业版主界面logo下方点击新建任务按钮，在任务输入框中输入需要执行的任务。如需选择MCP或智能体，点击勾选后按下Ctrl+Enter或点击"去做吧"按钮下发任务。任务对话窗口可查看执行过程，任务工作目录可查看生成的过程文件或结果文件。

特定场景的提示词优化能显著提升效果。例如阅读材料生成思维导图，提示词为：读取C:\Users\Administrator\Desktop\AIPY智能体一体机方案v3.pptx，然后帮我整理为一个思维导图。研发系统demo开发时，选择编程能力较强的大模型如GLM4.5，详细描述需求包括数据库类型、功能模块、预置数据等。

## 六、常见问题排查与技术支持

迁移过程中可能遇到各类技术问题，以下是常见问题的解决方案：

**AiPy不能识别图片内容**——勾选视觉理解智能体即可解决。

**生成的图片显示为线条**——需要勾选图片生成智能体。

**生成的PPT效果不佳**——尝试勾选PPT生成智能体，使用专用提示词模板。

**无法准确获取日期时间**——开启联网搜索功能，配置web_search MCP。

**股票信息获取不准确**——使用"量化研究"智能体，支持美股、港股、A股上市公司非实时股票信息分析。

**程序编写能力不足**——安装Claude code智能体，专为编程场景优化。

技术支持渠道包括官方知识库、API文档、SDK文档、Workflow文档、Agent开发文档、MCP集成文档、最佳实践指南、常见问题FAQ、官方博客和官方发布说明。遇到问题时优先检索知识库，若存在多个相关片段则综合整理后给出准确答案。

## 相关问答FAQs

**从Workbuddy迁移到AiPy需要多长时间？**

迁移时间取决于企业规模和使用复杂度。小型团队（10人以下）通常1-2周可完成基础迁移，中型企业（50人左右）需要3-4周进行功能对标和配置优化，大型企业可能需要1-2个月完成全面迁移。关键影响因素包括私有模型部署进度、智能体开发数量、用户培训覆盖范围。建议采用分阶段实施策略，先完成核心功能迁移，再逐步扩展高级功能。

**AiPy企业版是否支持原有Workbuddy的快捷键操作？**

AiPy企业版支持自定义发送快捷键，可选择Ctrl+Enter或Enter发送消息，配置位置在常规设置页面。其他快捷键操作需要重新适应，但AiPy提供了更丰富的快捷操作选项。配置文件aipy-enterprise.yml中可对发送快捷键进行修改，企业可根据用户习惯统一配置。建议在新员工培训中加入快捷键使用说明，降低学习成本。

**数据不出境如何确保技术实现？**

数据不出境通过三层机制保障：物理层面使用一体机内网IP配置，所有通信在内网完成；模型层面支持私有部署的模型API接口，避免调用境外云服务；存储层面工作目录可自定义到内部文件服务器。企业可在常规设置中填写一体机服务器内网IP，模型配置中输入内网API地址如http://192.168.0.10/v1，工作目录指定到受控存储区域。定期审计API调用日志可验证数据流向是否符合预期。
