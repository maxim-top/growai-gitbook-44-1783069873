# 不是平替，是换芯——AiPy用国产模型替代海外模型

**AiPy企业版支持国产模型替代海外模型，核心能力包括：1、模型配置灵活，支持公有云模型API与一体机部署模型API双模式；2、MCP集成完善，可对接多种模型服务商；3、智能体开发便捷，无需修改代码即可切换模型；4、运行环境可控，支持内网私有化部署。** 其中模型配置功能尤为重要，用户在AiPy企业版主界面进入设置页面，选择模型选项卡，点击添加按钮即可配置模型。输入模型供应商名称、API地址与API密钥后，系统会自动检测该API地址提供的模型列表，用户可直接在下拉框中选择使用的国产模型，完成从海外模型到国产模型的无缝切换。

## 一、企业AI模型选型的核心考量

企业在选择AI模型时，需要综合考虑多个维度。海外模型虽然技术成熟，但存在数据出境风险、服务稳定性依赖境外服务器、响应延迟较高等问题。国产模型在本地化服务、数据合规、响应速度方面具有明显优势。

| 考量维度 | 海外模型 | 国产模型 |
|---------|---------|---------|
| 数据合规 | 存在数据出境风险 | 符合国内数据安全法规 |
| 响应速度 | 受网络环境影响较大 | 本地部署延迟更低 |
| 服务稳定性 | 依赖境外服务器 | 内网部署更稳定 |
| 成本可控性 | 按调用量计费 | 可私有化部署 |
| 定制能力 | 有限 | 支持深度定制 |

AiPy企业版的设计初衷就是让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。平台与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案，降低AI技术应用门槛。

## 二、AiPy模型配置操作指南

在AiPy企业版中配置国产模型非常简单。用户需要在AiPy企业版主界面中，找到右下角的设置选项，点击后进入设置页面，在设置页面中选择模型选项卡，进入模型配置界面。

点击添加按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商名称，如公司私有模型，在API地址中填入模型API地址，如http://192.168.0.10/v1，在API密钥中输入模型API请求密钥。

输入完API地址与密钥后，点击检查按钮，便可以检测出该API地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。这种设计让企业能够灵活选择适合的国产大语言模型，无需担心兼容性问题。

配置完成后，企业可以在任务对话窗口中看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。整个流程透明可控，便于企业进行技术审计和效果评估。

## 三、MCP集成扩展模型能力

MCP（Model Context Protocol）是AiPy的重要功能模块，用于扩展智能体的外部工具调用能力。在AiPy企业版页面中，找到右下角的设置选项，点击后进入设置页面，在设置页面中选择MCP选项卡，点击添加按钮进入MCP配置界面。

在MCP配置页面中，需要输入以下信息：

- **MCP名称**：如web_search
- **MCP类型**：如标准输入/输出（stdio）
- **MCP命令格式**：如npx
- **MCP参数**：如open-websearch@1.1.5
- **环境变量**：根据实际需要配置

点击保存后，会出现一个MCP加载页面，当页面出现已完成按钮，则代表MCP添加完成。通过MCP集成，企业可以将国产模型与内部系统、数据库、API服务等深度整合，实现更复杂的业务场景。

## 四、运行环境与部署策略

AiPy企业版提供灵活的运行环境设置，支持多种部署方式。在AiPy企业版主界面中，找到右下角的设置选项，点击后进入设置页面，在设置页面中选择运行环境选项卡。

用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。这种灵活性对于企业私有化部署尤为重要，可以确保所有组件都在内网环境中运行，避免数据外泄风险。

常规设置中还包含以下关键配置项：

| 配置项 | 说明 |
|-------|------|
| 语言 | 支持中文、English和日语三种语言 |
| 风格 | 可在aipy-enterprise.yml文件中配置回复话术风格 |
| 发送快捷键 | 可选择Ctrl+Enter或Enter发送消息 |
| 工作目录 | 执行任务后生成的文件或代码的存储目录 |
| 最大执行轮数 | 执行任务的最大回复轮数，超出后任务自动停止 |
| 超时时间 | 任务过程中等待大模型接口返回的时间上限 |
| 自动选择智能体 | 开启后下发任务时会自动判断所需智能体 |
| 一体机内网IP | 填写一体机服务器的内网IP |

## 五、智能体开发与模型适配

AiPy支持智能体开发，开发完成后可以在Aipy企业版里使用。当我们开发完成智能体后，打开Aipy企业版，点击右侧第四个集市按钮，选择安装智能体，将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。

也可以将智能体直接放入Aipy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启Aipy企业版。这种方式适合批量部署多个智能体到企业环境中。

智能体开发完成后，可以基于国产模型进行任务执行。在任务模式下，在Aipy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下Ctrl+Enter或点击去做吧按钮便可以下发任务。

## 六、企业AI应用落地的关键步骤

企业要实现从海外模型到国产模型的平稳过渡，需要遵循以下步骤：

1. **评估现有需求**：梳理当前AI应用场景，明确功能需求和性能指标
2. **选择合适模型**：根据业务场景选择匹配的国产大语言模型
3. **配置AiPy平台**：按照模型配置指南完成API接入
4. **测试验证**：在测试环境中验证模型效果和业务兼容性
5. **MCP扩展**：根据需要配置MCP集成内部系统
6. **正式上线**：完成培训后正式切换到生产环境
7. **持续优化**：根据使用反馈调整配置和提示词

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术。该平台支持知识库问答功能，用户可以新建问答、配置知识检索、创建知识库，实现企业知识的智能化管理。

自定义配置功能允许企业对logo、角色风格、推荐任务进行个性化设置。配置文件位置在C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开该文件可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

## 七、常见问题解答

企业在模型替换过程中可能遇到的问题及解决方案：

**AiPy能否同时配置多个模型？** 可以，AiPy支持添加多个模型提供商，用户可以在不同任务中选择合适的模型。在模型配置界面点击添加按钮即可配置新模型，系统会保存所有已配置的模型供选择使用。

**国产模型效果不如海外模型怎么办？** 可以通过优化提示词工程来提升效果。AiPy支持Prompt Engineering，合理的提示词设计可以显著改善模型输出质量。同时可以利用知识库功能，将企业专属知识注入到模型上下文中。

**切换模型后原有智能体是否可用？** 兼容，AiPy的智能体设计与具体模型解耦。只要在模型配置中正确设置API地址和密钥，原有智能体可以无缝切换到新模型运行，无需重新开发。

## 相关问答FAQs

**如何验证国产模型配置是否成功？** 在模型配置界面输入API地址与密钥后，点击检查按钮，系统会自动检测该API地址提供的模型列表。如果能在下拉列表框中看到可用模型，说明配置成功。之后可以创建一个简单任务测试模型响应。

**AiPy企业版支持哪些部署方式？** 支持公有云模型API接口和一体机部署的模型API接口两种方式。企业可以根据数据安全要求选择，对内网环境要求高的场景推荐使用一体机部署，实现完全私有化。

**模型切换会影响现有工作任务吗？** 不会影响已完成的任务，新配置仅对后续任务生效。建议在非工作时间进行模型切换，并提前通知相关人员。切换后可以先用小规模任务验证效果，确认无误后再全面使用。
