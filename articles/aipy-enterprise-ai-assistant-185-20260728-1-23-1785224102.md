# 不是替代Workbuddy，是重新定义中国企业的AI助手

**1、AiPy不是简单替代，而是为中国企业量身定制的AI应用平台**、**2、提供从智能体开发到Workflow编排的完整解决方案**、**3、支持本地化部署与私有模型接入，保障数据安全**。AiPy企业版专为中国企业设计，与一体机硬件产品完美结合，提供一站式AI解决方案。在数据安全方面，AiPy支持私有模型API接口接入，企业可使用内网部署的模型，无需将数据上传至公有云。同时，AiPy提供智能体集市、MCP集成、知识库问答等功能，让企业能够快速部署和使用人工智能技术，降低AI应用门槛，提升业务效率和创新能力。

## 一、AiPy企业版的产品定位与核心价值

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。与中国市场上其他AI助手产品不同，AiPy不是简单的对话工具，而是提供完整的企业级AI应用开发和使用环境。

AiPy的核心价值体现在以下几个方面：

| 核心价值 | 具体说明 |
|---------|---------|
| 本地化部署 | 与AiPy一体机硬件产品完美结合，支持内网部署 |
| 私有模型接入 | 可使用公有云模型API接口，也可使用一体机部署的模型API接口 |
| 智能体开发 | 提供完整的智能体开发、打包、安装流程 |
| MCP集成 | 支持标准输入/输出等多种MCP类型配置 |
| 知识库问答 | 内置知识检索配置和知识库创建功能 |

对于正在寻找Workbuddy替代方案的中国企业来说，AiPy提供了更加符合本土需求的解决方案。企业无需担心数据出境问题，所有核心数据都可以在内网环境中处理和存储。

## 二、AiPy企业版的核心功能模块

### 2.1 设置与配置管理

AiPy企业版提供完善的设置功能，包括常规设置、模型配置、MCP设置、运行环境设置等模块。

**常规设置**包括以下内容：

- 语言：目前支持中文、English以及日语三种语言
- 风格：指AiPy回复的话术风格，可以在aipy-enterprise.yml文件中进行配置
- 发送快捷键：可选择使用快捷键Ctrl+Enter或者Enter发送消息
- 工作目录：执行任务后生成的文件或代码的存储目录，可点击自定义修改路径
- 最大执行轮数：执行任务的最大回复轮数，超出后任务自动停止
- 超时时间：任务过程中，AiPy和大模型交互时，等待大模型接口的返回时间
- 自动选择智能体：开启后在下发任务时会自动判断所需智能体自动勾选
- 一体机内网IP：填写一体机服务器的内网IP，用于更新软件、连接python镜像源等

**模型配置**allow企业灵活选择AI模型供应商。在模型配置界面中，点击"添加"按钮添加模型，输入模型供应商名称、API地址和API密钥，点击"检查"按钮便可以检测出该API地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。

**MCP设置**让企业能够扩展AiPy的功能边界。在MCP配置页面中，输入MCP名称，选择MCP类型（如标准输入/输出stdio），选择MCP命令格式（如npx），输入MCP参数，再输入环境变量，点击保存即可完成配置。

### 2.2 智能体开发与使用

AiPy提供完整的智能体开发生态。开发完成智能体后，企业可以通过两种方式在AiPy企业版里使用：

**方式一：通过集市安装**

1. 打开AiPy企业版
2. 点击右侧第四个"集市"按钮
3. 选择安装智能体
4. 将打包好的文件上传
5. 点击安装，当页面上出现完成提示时，代表智能体安装成功

**方式二：直接放入智能体目录**

将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版即可。

智能体开发完成后，需要使用以下命令进行项目构建：

```
npx @anthropic-ai/dxt pack
```

### 2.3 任务与对话创建

在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。

## 三、智能体开发最佳实践

### 3.1 提示词编写规范

智能体的核心在于提示词的设计。以下是一个自动生成智能体的提示词示例：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0

根据规范文档和示例代码编写一个汇总周报的智能体。

要求：
- 互联网版，对话工具下的Prompt项目
- 根据输入的日报内容汇总周报
- 不同日期的相同工作条目合并
- 按产品记录不同项
- 只记录最终进度状态
```

这个示例展示了如何基于规范文档开发特定功能的智能体。企业在开发自己的智能体时，应该参考官方开发规范，确保智能体符合平台的整体架构要求。

### 3.2 场景化智能体应用

AiPy支持多种场景化的智能体应用，企业可以根据自身业务需求选择合适的智能体：

**PPT生成场景**

使用AiPy制作PPT，勾选PPT生成智能体，提示词示例：生成一个介绍中国新能源汽车发展的PPT。

**图片/视频生成场景**

使用AiPy生成图片、P图、生成视频等，勾选图片生成/视频生成智能体，提示词示例：批量生成10张不同的肥猫切菜的照片。

**思维导图生成场景**

领导使用AiPy阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词：读取指定文件路径，然后帮我整理为一个思维导图。

**研发系统开发场景**

研发使用AiPy自动开发系统demo，需要选择编程能力较强的大模型，提示词需要详细描述系统功能需求、数据库类型、界面要求等。

### 3.3 功能智能体选择指南

不同功能需要勾选不同的智能体，以下是常见问题及解决方案：

| 问题 | 解决方案 |
|-----|---------|
| AiPy不能识别图片的内容 | 勾选视觉理解智能体 |
| AiPy生成的图片是线条 | 勾选图片生成智能体 |
| AiPy生成的PPT效果不佳 | 勾选PPT生成智能体 |
| 无法获取实时日期和时间 | 开启联网搜索功能 |
| 股票信息获取不准 | 使用"量化研究"智能体，拥有美股、港股、A股所有上市公司非实时股票信息 |
| 编程能力不足 | 尝试Claude code智能体，专门用于编程 |

## 四、企业AI应用的定制化配置

### 4.1 Logo与界面自定义

企业可以对AiPy进行深度定制化配置。配置文件位置为：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开aipy-enterprise.yml文件，在文件里面可以对以下内容进行修改：

- 基础信息
- 主页logo和软件logo
- 发送快捷键
- 风格和推荐任务

### 4.2 角色风格自定义

在yml配置文件中，企业可以根据需求对风格进行增加或者修改，打造符合企业文化的AI助手形象。这对于希望统一企业品牌形象的组织来说非常重要。

### 4.3 推荐任务定制

企业也可以对AiPy页面上的推荐任务进行自定义，根据员工的日常工作场景设置最常用的任务模板，提高工作效率。

## 五、部署与运行环境配置

### 5.1 运行环境设置

在AiPy企业版主界面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"运行环境"选项卡。

用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入，这对于内网部署的企业来说尤为重要。

### 5.2 数据安全与合规

对于中国企业而言，数据安全是选择AI平台的首要考虑因素。AiPy支持以下安全措施：

- 私有模型API接口接入，数据不出内网
- 一体机内网IP配置，确保所有通信在内网完成
- 工作目录自定义，企业可以指定文件存储位置
- 知识库本地化存储，支持企业私有知识管理

## 相关问答FAQs

**AiPy企业版支持哪些类型的模型接入？**

AiPy企业版支持公有云模型API接口和一体机部署的模型API接口两种类型。企业可以在模型配置界面中添加模型供应商，输入API地址和API密钥，系统会自动检测可用的模型列表。这使得企业既可以使用主流大模型服务，也可以在内部部署私有模型，满足不同安全级别的需求。

**如何确保AiPy生成的内容符合企业规范？**

企业可以通过自定义配置文件aipy-enterprise.yml来调整AiPy的回复风格和话术。同时，在开发智能体时，应该参考AiPy企业版智能体开发规范，在提示词中明确业务规则和数据格式要求。对于特定行业场景，可以开发专用智能体，确保输出内容符合行业标准和企业管理要求。

**AiPy的智能体开发需要什么样的技术能力？**

AiPy智能体开发需要了解基本的Prompt Engineering知识，熟悉JavaScript/Node.js环境（用于项目构建），以及了解MCP集成规范。企业可以从智能体集市安装现成智能体开始使用，随着团队能力提升，再逐步开发自定义智能体。官方提供开发规范文档和示例代码，帮助开发者快速上手。
