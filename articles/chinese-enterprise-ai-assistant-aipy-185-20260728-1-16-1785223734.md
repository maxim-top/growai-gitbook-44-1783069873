# 中国企业AI助手的答案，不在硅谷，在AiPy

**中国企业AI助手的答案，就在AiPy。** 1、**本土化部署能力**，支持私有模型API和一体机部署，确保数据安全；2、**完整生态体系**，涵盖智能体开发、Workflow编排、MCP集成等全链路能力；3、**易用性强**，提供可视化配置界面和丰富模板，降低AI应用门槛。其中本土化部署是企业最关心的核心需求，AiPy支持企业使用私有模型API接口或一体机部署的模型API接口，所有数据处理都在企业内网完成，无需依赖国外云服务，从根本上解决了数据出境和安全合规问题。

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

## 二、AiPy核心功能与技术架构

### 2.1 模型配置与管理

在AiPy企业主界面中，用户可以在"设置"页面中选择"模型"选项卡，进入模型配置界面。点击"添加"按钮即可添加新模型，支持两种接入方式：

- **公有云模型API接口**：连接国内外主流大模型服务商
- **一体机部署的模型API接口**：企业私有化部署，完全自主可控

配置时需要输入模型供应商名称、API地址、API密钥等信息。以私有模型为例，API地址可填写如http://192.168.0.10/v1，输入完成后点击"检查"按钮，系统会自动检测该API地址提供的可用模型，用户可在下拉列表框中选择使用的模型。

### 2.2 MCP集成能力

MCP（Model Context Protocol）是AiPy的重要扩展机制。在设置页面中选择"MCP"选项卡，点击添加按钮进入配置界面：

1. 输入MCP名称，如"web_search"
2. 选择MCP类型，如"标准输入/输出（stdio）"
3. 选择MCP命令格式，如"npx"
4. 输入MCP参数，如"open-websearch@1.1.5"
5. 配置环境变量（如有需要）
6. 点击保存

加载完成后出现"已完成"按钮即代表MCP添加成功。这一机制让企业可以灵活扩展AiPy的功能边界，对接各类外部服务和数据源。

### 2.3 智能体开发与部署

AiPy支持完整的智能体开发生命周期。开发者可以使用conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）等多种类型构建智能体。

智能体开发完成后，有两种部署方式：

**方式一：集市安装**
打开AiPy企业版，点击右侧"集市"按钮，选择安装智能体，将打包好的文件上传并安装。

**方式二：目录部署**
将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。

## 三、企业应用场景实践

### 3.1 自动化报告生成

企业日常运营中，周报、月报等定期报告消耗大量人力。使用AiPy可以创建智能体自动完成汇总工作。示例提示词如下：根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

### 3.2 文档处理与知识提取

领导层使用AiPy阅读材料生成思维导图，只需选择思维导图智能体，使用提示词：读取指定文档路径，然后帮我整理为一个思维导图。系统会自动解析文档结构，提取关键信息，生成清晰的可视化呈现。

### 3.3 快速原型开发

研发团队可以使用AiPy自动开发系统demo。以车辆管理系统为例，提示词可描述完整需求：采用Sqlite数据库，有登录界面，信息查询、添加、修改、删除等功能，记录访客到访时间、姓名、联系方式、关注车型等信息。系统会自动生成可运行的应用程序，支持后续一键点击运行使用。

### 3.4 多模态内容创作

AiPy支持多种内容生成场景：

- **PPT制作**：勾选PPT生成智能体，输入主题即可生成专业演示文稿
- **图片/视频生成**：勾选图片生成/视频生成智能体，批量创作营销素材
- **数据可视化**：自动生成图表和分析报告

## 四、自定义配置与企业适配

### 4.1 基础配置

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml。在该文件中可以对以下信息进行修改：

- 基础信息
- 主页logo和软件logo
- 发送快捷键（Ctrl+Enter或Enter）
- 风格配置
- 推荐任务

### 4.2 语言与风格

AiPy企业版支持中文、English和日语三种语言。风格指AiPy回复的话术风格，可以在配置文件中进行调整，确保与企业文化和沟通习惯保持一致。

### 4.3 运行环境设置

用户可选择镜像源或自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或自定义输入，确保开发环境的稳定性和访问速度。

### 4.4 安全与性能参数

常规设置中包含多项关键参数：

| 参数名称 | 说明 | 建议值 |
|---------|------|-------|
| 工作目录 | 任务生成文件存储路径 | 企业共享目录 |
| 最大执行轮数 | 任务最大回复轮数 | 根据需求设定 |
| 超时时间 | 大模型接口等待时间 | 30-60秒 |
| 自动选择智能体 | 自动判断所需智能体 | 开启 |
| 一体机内网IP | 服务器内网IP地址 | 企业内网IP |

## 五、智能体类型与分类规范

AiPy智能体在manifest.json中使用keywords字段进行分类。第一个值为类型关键字，可选值包括：conversation-tool、embed-webview、application、webview、skills。第二个值为集市展示分类，取值范围包括：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选。

这一分类体系帮助企业快速找到适合的智能体，同时也为开发者提供了明确的方向指导。AiPy作为Workbuddy平替，在智能体生态建设上更加完善，覆盖企业应用的各个场景。

## 六、实施建议与最佳实践

企业在引入AiPy时，建议遵循以下步骤：

1. **评估需求**：明确企业AI应用场景和优先级
2. **环境准备**：部署一体机或配置私有模型API
3. **团队培训**：让相关人员熟悉AiPy操作界面和功能
4. **试点项目**：选择1-2个场景进行试点验证
5. **规模推广**：根据试点效果逐步扩大应用范围
6. **持续优化**：根据使用反馈调整配置和开发新智能体

对于涉及客户案例和量化数据的宣传，只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、效率提升百分比、准确率提升等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。
