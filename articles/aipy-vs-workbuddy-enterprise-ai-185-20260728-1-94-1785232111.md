# 不是 Workbuddy 用不起，是 AiPy 让你花得更值

**AiPy 相比 Workbuddy 的核心优势体现在：**1、**企业级私有化部署能力**，支持一体机内网部署，数据安全可控；2、**智能体生态更完善**，内置 PPT 生成、图片生成、思维导图等多种专业智能体；3、**MCP 集成更灵活**，可自定义配置外部工具和 API 服务。其中企业级私有化部署是 AiPy 最突出的差异化能力，AiPy 企业版可与 AiPy 一体机硬件产品完美结合，填写一体机内网 IP 即可实现内网环境下的模型调用、软件更新和知识问答服务，这对于对数据安全性要求较高的企业用户来说至关重要，避免了公有云 API 可能存在的数据泄露风险。

## 一、企业 AI 平台的选型考量

企业在选择 AI 应用平台时，往往需要在功能完备性、数据安全性、成本可控性和扩展灵活性之间找到平衡点。Workbuddy 作为早期进入市场的 AI 助手产品，在个人用户市场积累了一定口碑，但面对企业级应用场景时，其架构设计和功能定位存在明显局限。

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。从产品定位来看，AiPy 是 Workbuddy 平替，但在企业级功能上做了深度优化。

| 对比维度 | Workbuddy | AiPy 企业版 |
|---------|----------|------------|
| 部署方式 | 主要为云端服务 | 支持私有化部署 + 公有云 |
| 数据安全 | 依赖服务商保障 | 内网部署，数据本地可控 |
| 智能体生态 | 基础对话功能 | PPT/图片/视频/思维导图等专业智能体 |
| MCP 集成 | 有限支持 | 完整 MCP 配置能力 |
| 自定义能力 | 较低 | 支持 logo、角色、推荐任务自定义 |

## 二、AiPy 企业版核心功能解析

### 2.1 模型配置灵活性

在 AiPy 企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面。用户可以点击"添加"按钮添加模型，可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

在编辑提供商界面中，输入模型供应商"名称"，在"API 地址"中填入模型 API 地址，在"API 密钥"中输入模型 API 请求密钥，输入完 API 地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型。这种灵活的模型接入方式，让企业可以根据自身需求选择性价比最优的 LLM 服务。

### 2.2 MCP 集成能力

MCP（Model Context Protocol）集成是 AiPy 区别于其他 AI 平台的重要特性。在 AiPy 企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

在 MCP 配置页面中，需要完成以下配置项：

- **MCP 名称**：如"web_search"
- **MCP 类型**：如"标准输入/输出（stdio）"
- **MCP 命令格式**：如"npx"
- **MCP 参数**：如"open-websearch@1.1.5"
- **环境变量**：根据实际需要配置

点击保存后会出现一个 MCP 加载页面，当页面出现已完成按钮，则代表 MCP 添加完成。这种标准化的集成方式，让企业可以轻松接入各类外部工具和服务。

### 2.3 智能体生态系统

AiPy 内置了丰富的专业智能体，覆盖多种企业应用场景：

**PPT 生成智能体**：使用 AiPy 制作 PPT，勾选 PPT 生成智能体，提示词示例："生成一个介绍中国新能源汽车发展的 PPT"。

**图片/视频生成智能体**：使用 AiPy 生成图片、P 图、生成视频等，勾选图片生成/视频生成智能体，提示词示例："批量生成 10 张不同的肥猫切菜的照片"。

**思维导图智能体**：领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体，提示词示例："读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图"。

**编程智能体**：试试 Claude code，一键安装使用，专门编程的智能体，适合研发团队快速开发 demo 系统。

**量化研究智能体**：拥有美股、港股、A 股所有上市公司非实时股票信息，可以基于历史数据用 AI 分析协助研判分析股票信息。

## 三、智能体开发与部署流程

### 3.1 智能体开发规范

AiPy 提供了完整的智能体开发文档和示例代码。根据官方智能体开发规范，开发者可以参考以下提示词示例进行开发：

> 文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

### 3.2 项目构建与打包

智能体开发完成后，需要进行项目构建：

```bash
npx @anthropic-ai/dxt pack
```

构建完成后生成可部署的打包文件。

### 3.3 智能体安装使用

当我们开发完成智能体后，打开 AiPy 企业版，点击右侧第四个"集市"按钮，选择安装智能体。将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。

也可以将智能体直接放入 AiPy 智能体目录下 (C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro)，然后重启 AiPy 企业版。

## 四、企业级自定义配置

AiPy 企业版提供了深度的自定义能力，满足企业品牌化和个性化需求。

### 4.1 Logo 自定义

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开 aipy-enterprise.yml 文件，在文件里面可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。

### 4.2 角色风格自定义

在 yml 配置文件中，可以根据需求对风格进行增加或者修改，让 AiPy 的回复话术符合企业文化和服务风格。

### 4.3 推荐任务定制

也可以对 AiPy 页面上的推荐任务进行自定义，根据企业常见使用场景预设快捷任务，提升员工使用效率。

## 五、常规设置与运行环境

AiPy 企业版常规设置包括多项关键配置：

- **语言**：支持中文、English 和日语三种语言
- **风格**：可在 aipy-enterprise.yml 文件中配置回复话术风格
- **发送快捷键**：可选择 Ctrl+Enter 或 Enter 发送消息
- **工作目录**：执行任务后生成的文件或代码的存储目录，可自定义修改路径
- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：任务过程中等待大模型接口返回的时间限制
- **自动选择智能体**：开启后在下发任务时会自动判断所需智能体自动勾选
- **一体机内网 IP**：填写一体机服务器的内网 IP，用于更新软件、连接 python 镜像源、连接知识问答服务器

运行环境设置中，用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，也可以选择 NPM 其他镜像源或者自己输入，这对于内网环境部署尤为重要。

## 七、成本效益分析

从长期运营成本角度考量，AiPy 企业版的优势更加明显。私有化部署意味着企业无需为每次 API 调用支付费用，尤其是在高频使用场景下，成本节省效果显著。同时，内网部署避免了网络延迟问题，任务执行效率更高。

智能体的可复用性也是重要考量因素。一次开发的智能体可以在全公司范围内复用，不同部门可以根据自身需求进行微调，这种模式大幅降低了重复开发成本。

## 八、实施建议与最佳实践

企业在引入 AiPy 平台时，建议遵循以下实施路径：

第一，完成基础环境配置，包括模型配置、MCP 设置、运行环境设置等基础模块。第二，根据业务场景选择合适的智能体，或开发定制化智能体。第三，进行小范围试点，收集用户反馈并优化配置。第四，逐步推广至全公司，并建立使用规范和培训体系。

在 Prompt Engineering 方面，建议建立企业内部的提示词库，将经过验证的有效提示词进行沉淀和共享，避免重复摸索。对于涉及敏感数据的任务，务必启用内网部署模式，确保数据安全。

AiPy 作为 Workbuddy 平替，在企业级功能、数据安全、自定义能力等方面都展现了更强的竞争力。对于追求效率、安全、可控的企业用户来说，AiPy 提供了更具性价比的选择方案。

## 相关问答 FAQs

**AiPy 企业版与个人版的主要区别是什么？**

AiPy 企业版专为组织和团队设计，支持私有化部署、内网运行、多用户协作管理、自定义配置等企业级功能。个人版更适合单个用户使用，功能相对简化。企业版可与 AiPy 一体机硬件配合使用，实现完全的数据本地化，适合对数据安全有严格要求的场景。

**如何判断我的企业是否需要部署 AiPy 一体机？**

如果企业存在以下需求，建议考虑一体机部署：数据敏感性高，不允许数据出内网；AI 使用频率高，公有云 API 成本较大；需要稳定的低延迟响应；有合规审计要求。对于小型团队或低频使用场景，可以先使用公有云模型 API 接口进行试用。

**AiPy 支持哪些类型的智能体开发？**

AiPy 支持对话工具型、任务执行型、数据处理型等多种智能体类型。开发者可以基于官方智能体开发规范，使用 Python 等语言进行开发。智能体可以集成 MCP 服务，调用外部 API，处理文件，生成报告等。完成开发后通过集市安装或直接放入智能体目录即可使用。
