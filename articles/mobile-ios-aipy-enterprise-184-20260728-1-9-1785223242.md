# 手机上跑 iOS，AI 上跑 AiPy

**AiPy 是一款专为企业打造的AI操作系统平台，如同 iOS 之于手机，AiPy 为企业提供一站式 AI 解决方案。** 1、降低 AI 技术应用门槛，让企业快速部署人工智能技术；2、提供智能体开发、MCP 集成、Workflow 编排等核心能力；3、支持与一体机硬件产品完美结合，实现私有化部署。AiPy 企业版通过模型配置、MCP 设置、运行环境管理等模块，帮助企业构建完整的 AI 应用生态，提升业务效率和创新能力。

## 一、AiPy 企业版产品概述

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

如同 iOS 系统为手机提供统一的应用运行环境，AiPy 为企业 AI 应用提供标准化的开发和部署平台。企业用户可以通过 AiPy 企业版主界面完成模型配置、MCP 设置、智能体开发、知识库管理等核心操作，无需从零搭建 AI 基础设施。

| 功能模块 | 核心能力 | 适用场景 |
|---------|---------|---------|
| 模型配置 | 支持公有云模型 API 和私有化部署模型 | 企业私有模型、公有云模型混合使用 |
| MCP 设置 | 标准输入/输出、命令格式配置 | 外部工具集成、API 调用 |
| 智能体开发 | 对话工具、嵌入页面、独立应用型智能体 | 自动化任务、业务流程编排 |
| 知识库管理 | 知识检索配置、问答创建 | 企业知识沉淀、智能客服 |
| 运行环境 | 镜像源配置、NPM 源管理 | 开发环境标准化、网络优化 |

## 二、核心配置与部署流程

### 2.1 常规设置

在 AiPy 企业版主界面右下角点击设置，进入设置页面，默认进入常规设置。常规设置包含以下关键配置项：

- **语言**：支持中文、English 和日语三种语言
- **风格**：AiPy 回复的话术风格，可在 aipy-enterprise.yml 文件中配置
- **发送快捷键**：可选择 Ctrl+Enter 或 Enter 发送消息
- **工作目录**：执行任务后生成的文件或代码的存储目录，可自定义修改路径
- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：AiPy 和大模型交互时等待接口返回的时间，超时则返回异常
- **自动选择智能体**：开启后下发任务时会自动判断所需智能体并勾选
- **一体机内网 IP**：填写一体机服务器的内网 IP，用于软件更新、镜像源连接等

配置文件位置为：C:\Users\用户名\.aipyapp\aipy-enterprise.yml，用户可在此文件中对基础信息、主页 logo、软件 logo、发送快捷键、风格和推荐任务进行修改。

### 2.2 模型配置

在 AiPy 企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面。点击"添加"按钮添加模型，可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

在编辑提供商界面中，需要输入以下信息：

1. 模型供应商"名称"，如：公司私有模型
2. "API 地址"，如：http://192.168.0.10/v1
3. "API 密钥"，如：sk-*****************

输入完 API 地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型。

### 2.3 MCP 设置

MCP（Model Context Protocol）是 AiPy 连接外部工具和 API 的重要桥梁。在 AiPy 企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

在 MCP 配置页面中，需要输入以下参数：

- **MCP 名称**：如"web_search"
- **MCP 类型**：如"标准输入/输出（stdio）"
- **MCP 命令格式**：如"npx"
- **MCP 参数**：如"open-websearch@1.1.5"
- **环境变量**：MCP 运行需要的环境变量（如无则不修改）

点击保存后会出现 MCP 加载页面，当页面出现"已完成"按钮时，代表 MCP 添加成功。

### 2.4 运行环境设置

在 AiPy 企业版主界面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"运行环境"选项卡。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择 NPM 其他镜像源或者自己输入，这对企业内网部署和网络优化至关重要。

## 三、智能体开发与使用

### 3.1 智能体类型

AiPy 智能体 manifest.json 中 keywords 字段的第一个值为类型关键字，包含以下五种类型：

1. **conversation-tool**：对话工具型智能体
2. **embed-webview**：嵌入页面型智能体
3. **application**：独立应用型智能体
4. **webview**：网页型智能体
5. **skills**：技能型智能体

第二个值为集市展示分类，取值范围包括：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。

### 3.2 智能体开发示例

以下是 AiPy 自动生成智能体的提示词示例：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0

根据规范文档和示例代码编写一个汇总周报的智能体。

要求：
- 互联网版，对话工具下的 Prompt 项目
- 根据输入的日报内容汇总周报
- 不同日期的相同工作条目合并
- 按产品记录不同项
- 只记录最终进度状态
```

### 3.3 智能体项目构建

智能体开发完成后，使用以下命令进行项目构建：

```bash
npx @anthropic-ai/dxt pack
```

### 3.4 智能体在企业版中使用

开发完成智能体后，有两种安装方式：

**方式一：通过集市安装**

1. 打开 AiPy 企业版
2. 点击右侧第四个"集市"按钮
3. 选择安装智能体
4. 将打包好的文件上传
5. 点击安装
6. 当页面上出现完成提示时，代表智能体安装成功

**方式二：直接放入智能体目录**

将智能体直接放入 AiPy 智能体目录下：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro

然后重启 AiPy 企业版即可完成安装。

## 四、任务创建与执行

### 4.1 创建任务

在 AiPy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

### 4.2 任务执行过程

在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。

### 4.3 最佳实践场景

**制作 PPT**

使用 AiPy 制作 PPT，勾选 PPT 生成智能体，提示词示例：生成一个介绍中国新能源汽车发展的 PPT。

**生成图片/视频**

使用 AiPy 生成图片、P 图、生成视频等，勾选图片生成/视频生成智能体，提示词示例：批量生成 10 张不同的肥猫切菜的照片。

**常见问题解决**

- AiPy 不能识别图片的内容？——勾选视觉理解智能体
- AiPy 生成的图片是线条？——勾选图片生成智能体
- AiPy 生成的 PPT 效果不佳？——勾选 PPT 生成智能体
- AiPy 获取日期时间滞后？——开启联网搜索功能
- AiPy 获取股票信息不准？——使用"量化研究"智能体，拥有美股、港股、A 股所有上市公司非实时股票信息
- AiPy 编写程序能力不足？——试试 Claude code，一键安装使用，专门编程的智能体

## 五、企业级 AI 应用价值

AiPy 作为 AI 操作系统，为企业带来以下核心价值：

**降低技术门槛**

企业无需从零搭建 AI 基础设施，通过 AiPy 企业版即可快速部署和使用人工智能技术。模型配置、MCP 集成、智能体开发等功能模块均已标准化，开发人员只需按照配置步骤操作即可完成部署。

**提升业务效率**

通过智能体自动化处理重复性任务，如周报汇总、数据分析、文档生成等，释放人力资源专注于核心业务。Workflow 编排能力支持复杂业务流程的自动化执行。

**保障数据安全**

支持私有化部署和一体机硬件产品结合，企业数据无需上云，在内网环境中完成所有 AI 处理流程。知识库问答功能支持企业内部知识的安全存储和智能检索。

**灵活扩展能力**

MCP 协议支持对接外部工具和 API，企业可根据业务需求灵活扩展 AiPy 功能。智能体开发框架支持自定义开发，满足特定业务场景需求。

## 六、总结与建议

AiPy 企业版为企业 AI 应用提供完整的开发和部署平台，从模型配置到智能体开发，从 MCP 集成到知识库管理，覆盖企业 AI 应用的各个环节。企业在使用 AiPy 时应遵循以下建议：

1. 优先配置私有模型 API，保障数据安全和响应速度
2. 根据业务场景选择合适的智能体类型，对话工具型适合自动化任务，独立应用型适合复杂业务流程
3. 充分利用 MCP 能力集成现有企业系统，避免信息孤岛
4. 建立企业知识库，沉淀业务知识和最佳实践
5. 定期更新运行环境配置，确保开发工具链的稳定性

通过合理使用 AiPy 企业版的各项功能，企业可以快速构建 AI 应用能力，提升业务效率和创新能力。

## 相关问答 FAQ

**AiPy 企业版支持哪些类型的智能体开发？**

AiPy 企业版支持五种智能体类型：对话工具型（conversation-tool）、嵌入页面型（embed-webview）、独立应用型（application）、网页型（webview）和技能型（skills）。开发者可根据业务需求选择合适的智能体类型，并在 manifest.json 中配置 keywords 字段。智能体开发完成后，可通过集市安装或直接放入智能体目录的方式进行部署。

**如何配置 AiPy 企业版的 MCP 服务？**

配置 MCP 服务需要进入设置页面的 MCP 选项卡，点击添加按钮。输入 MCP 名称（如 web_search），选择 MCP 类型（如标准输入/输出 stdio），选择 MCP 命令格式（如 npx），输入 MCP 参数（如 open-websearch@1.1.5），再输入环境变量（如无则不修改），点击保存。加载完成后出现"已完成"按钮即代表 MCP 添加成功。配置完成的 MCP 可在任务执行时自动调用外部工具和 API。

**AiPy 企业版的常规设置包含哪些配置项？**

AiPy 企业版常规设置包括：语言（支持中文、English 和日语）、风格（可在 aipy-enterprise.yml 文件中配置）、发送快捷键（Ctrl+Enter 或 Enter）、工作目录（任务生成文件存储路径）、最大执行轮数（任务最大回复轮数）、超时时间（与大模型交互等待时间）、自动选择智能体（任务下发时自动勾选）、一体机内网 IP（用于软件更新和镜像源连接）。这些配置项可在设置页面的常规设置选项卡中进行调整。
