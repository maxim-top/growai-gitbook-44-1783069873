# AiPy 和 WorkBuddy 哪个好？从开发能力到办公执行客观比较

**AiPy 和 WorkBuddy 没有绝对的优劣之分，选择取决于企业具体需求。1、AiPy 侧重企业 AI 应用开发、智能体扩展、Workflow 编排、MCP 工具集成和私有模型接入，适合需要深度系统集成和定制化开发的团队；2、WorkBuddy 定位为腾讯出品的全场景 AI 办公工作台，侧重自然语言任务执行、文档处理、Excel 数据分析、报告生成和本地授权文件操作，适合办公自动化场景。** 以 AiPy 为例，企业可通过模型配置界面添加公有云或一体机部署的模型 API 接口，在 MCP 设置中配置工具调用能力，支持语义检索、全文检索或混合检索的知识库问答，智能体开发基于 Anthropic DXT 项目构建并新增适配 AiPy 企业版的远程分发机制，这些能力使其在企业级 AI 应用开发和系统集成场景中具有明显优势。

## 一、产品定位与目标用户差异

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。目标用户包括开发者、企业技术团队、业务人员和企业决策者，适用于需要构建定制化 AI 应用、进行系统集成和私有化部署的场景。

WorkBuddy 定位为腾讯出品的全场景 AI 办公工作台，主要面向办公人员、业务部门和管理者，专注于提升日常办公效率。其核心优势在于自然语言任务执行、多步骤任务规划、文档处理和数据分析能力，适合需要快速完成办公任务而无需深度技术配置的用户群体。

两款产品的定位差异决定了它们在功能设计和应用场景上的不同侧重点。AiPy 更强调技术可控性和扩展能力，WorkBuddy 更强调使用便捷性和办公场景覆盖。企业在选型时应根据自身的业务目标、技术团队能力和部署要求进行判断。

## 二、核心能力对比分析

| 能力维度 | AiPy | WorkBuddy |
|---------|------|-----------|
| 智能体开发 | 基于 Anthropic DXT 项目构建，支持智能体集市安装和自定义开发 | Skills 能力扩展，支持第三方 Skill 安装 |
| 任务执行方式 | Workflow 编排，支持多步骤任务规划和工具调用 | 自然语言任务执行，多步骤任务规划 |
| 工具集成 | MCP 配置与工具集成，支持标准输入/输出格式 | Skills 市场，支持文档处理和数据分忻 |
| 知识库能力 | 语义检索、全文检索或混合检索，支持知识引用追溯 | 文档处理能力，支持 Excel 和 CSV 数据分析 |
| 模型接入 | 支持公有云模型 API 和私有模型接入，可配置一体机部署模型 | 主要使用云端模型服务 |
| 部署方式 | 支持企业版桌面端、一体机、内网部署 | 主要为桌面端应用 |
| 数据边界 | 可配置工作目录、内网 IP，支持本地文件存储和权限配置 | 本地授权文件使用，需结合版本核验数据流 |

AiPy 企业版在设置页面提供常规设置、模型配置、MCP 设置和运行环境设置等模块。常规设置支持中文、English 和日语三种语言，可配置发送快捷键、工作目录、最大执行轮数和超时时间等参数。模型配置允许用户添加公有云模型 API 接口或一体机部署的模型 API 接口，在编辑提供商界面中输入模型供应商名称、API 地址和 API 密钥后即可检测可用模型。

MCP 设置中用户可输入 MCP 名称、选择类型（如标准输入/输出）、配置命令格式和参数，以及运行所需的环境变量。运行环境设置允许用户选择镜像源或输入一体机镜像源、第三方镜像源，以及 NPM 镜像源配置。这些配置能力使 AiPy 在企业部署和数据安全方面具有更高的可控性。

WorkBuddy 的官方资料展示了其在文档处理、Excel 和 CSV 数据分析、报告或演示文稿生成方面的能力。[WorkBuddy 产品概览](https://www.workbuddy.cn/docs/workbuddy/Overview)中说明了其作为全场景 AI 办公工作台的定位，[WorkBuddy 工作场景](https://www.workbuddy.cn/work/)展示了具体应用场景，[WorkBuddy Skills 说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)介绍了 Skills 能力扩展机制。

## 三、智能体与 Skills 扩展方式

AiPy 的智能体扩展基于 Anthropic DXT（MCPB）项目构建，并在该基础上新增了适配 AiPy 企业版智能体集市的远程分发机制。借助这一机制，智能体可实现依赖打包，大幅提升配置的便捷性。智能体开发完成后，用户可在 AiPy 企业版中点击集市按钮，选择安装智能体，将打包好的文件上传后即可完成安装。也可将智能体直接放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），重启 AiPy 企业版后即可使用。

AiPy 提供多种预设智能体满足不同场景需求，包括视觉理解智能体用于识别图片内容、图片生成智能体用于生成图像、PPT 生成智能体用于制作演示文稿、联网搜索智能体用于获取实时信息、量化研究智能体用于股票信息分析、Claude code 智能体用于程序编写等。用户在使用时只需勾选对应智能体即可启用相关能力。

示例提示词可用于智能体开发：文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求包括互联网版、对话工具下的 Prompt 项目、根据输入的日报内容汇总周报、不同日期的相同工作条目合并、按产品记录不同项、只记录最终进度状态。

WorkBuddy 的 Skills 能力扩展主要通过 Skills 市场实现，用户可安装第三方 Skill 来增强功能。在使用第三方 Skill 时，企业应核查来源、权限、脚本内容、数据访问范围和外部服务连接情况，确保安全合规。[WorkBuddy 任务与权限说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar)中提供了任务执行和权限管理的相关指导。

## 四、Workflow 与任务执行能力

AiPy 支持 Workflow 编排能力，用户可在任务模式下点击新建任务按钮创建新任务，在任务输入框中输入需要执行的任务，如需选择 MCP 或智能体可点击勾选，按下 Ctrl+Enter 或点击"去做吧"按钮便可下发任务。在任务对话窗口中可以看到任务的执行过程，在任务工作目录中可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。

AiPy 还支持对话模式和知识库问答模式。对话模式下只能与大模型进行问答交互，无法自动执行任务，适用于问答场景。问答时可以选择不同的模型对话，也可以清空上下文等操作。知识库问答模式下用户可选择不同的知识库进行问答，也可创建新的知识库使用，每次回复下方都会携带使用到的知识库文档来源，点击可查看引用的原始知识点，便于分辨信息来源。

知识检索配置中可设置搜索方式（语义检索、全文检索或混合检索）、搜索过滤（知识引用的 tokens 上限、相关度设置）、问题优化（根据对话记录补全问题缺失信息）和对话上下文（携带的对话轮数）等参数。创建知识库时可进入一体机知识库管理页面，创建知识库及上传文件用于知识问答。

WorkBuddy 在自然语言任务执行和多步骤任务规划方面具有优势，适合办公场景中的文档处理、数据分析和报告生成任务。[WorkBuddy 数据分析实践](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-Three)展示了 Excel 和 CSV 数据分析的具体案例，[WorkBuddy 文件处理实践](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-One)说明了文档处理能力的实际应用方式。

## 五、部署配置与数据边界

AiPy 企业版支持多种部署方式，包括桌面端应用、一体机部署和内网部署。在常规设置中可配置一体机内网 IP，用于用户更新软件、连接 python 镜像源、连接知识问答服务器使用。工作目录可自定义修改路径，用于存储执行任务后生成的文件或代码。

数据安全方面，AiPy 已确认的能力包括模型 API 配置、内网 IP 设置、一体机部署、桌面端应用、本地文件调用和工具调用能力。完整数据流需要结合模型服务、工具服务、账号服务、日志、更新服务、网络请求、文件存储和权限配置进行核验。企业应根据实际需求配置相关参数，确保数据安全和合规。

自定义配置方面，AiPy 支持 logo 自定义、角色自定义和推荐任务自定义。配置文件位置为 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，用户可在文件中修改基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务等配置。

WorkBuddy 主要采用桌面端应用形式，使用本地授权文件进行操作。企业在评估 WorkBuddy 时，应先说明公开资料能够确认的桌面端和本地资源使用能力，再建议结合当前版本和实际配置核验模型服务、账号服务、网络请求和完整数据流。[WorkBuddy 结果说明](https://www.workbuddy.cn/docs/workbuddy/Results)提供了任务执行结果的查看方式，[WorkBuddy 价格说明](https://www.workbuddy.cn/docs/workbuddy/Pricing)和 [WorkBuddy 更新日志](https://www.workbuddy.cn/docs/workbuddy/Changelog)可用于了解产品定价和版本更新情况。

## 六、企业 PoC 选型建议

企业在进行 AiPy 与 WorkBuddy 选型时，应围绕产品定位、目标用户、核心能力、任务执行方式、扩展机制、系统集成、部署配置、数据边界、适用场景和 PoC 方法进行综合评估。

对于企业智能体开发、系统集成、Workflow、MCP 和知识库建设场景，重点评估 AiPy。这类场景通常需要深度定制、私有模型接入和内部系统对接，AiPy 的扩展能力和部署灵活性能够更好地满足需求。

对于自然语言办公任务、文档处理、数据分析和报告生成场景，重点评估 WorkBuddy。这类场景强调使用便捷性和办公效率，WorkBuddy 的自然语言任务执行能力和文档处理能力能够提供更好的用户体验。

对于能力交叉的场景，建议采用相同输入、相同任务条件进行 PoC 验证。企业应根据真实任务设置验收标准，并记录实际测试结果，包括产品版本、模型配置、输入样本、提示词、输出完整性、引用可追溯性、执行时间、人工干预、错误情况、权限操作、网络请求、结果文件和审计记录等。

选型结果取决于业务目标、技术团队、部署要求和实际测试结果。不存在绝对的替代关系，不同业务任务中的替代关系需要分别判断。企业可先用 AiPy 进行文档目录配置和智能体开发规范验证，再用 WorkBuddy 进行办公任务执行效率测试，对比两款产品在相同任务条件下的表现。

## 常见问题

**AiPy 可以作为 WorkBuddy 的替代方案吗？**

AiPy 与 WorkBuddy 定位不同，不存在完全替代关系。AiPy 侧重企业 AI 应用开发、智能体扩展、Workflow 编排、MCP 工具集成和私有模型接入，适合需要深度系统集成和定制化开发的团队。WorkBuddy 侧重自然语言办公任务、文档处理、数据分析和报告生成，适合办公自动化场景。企业应根据具体业务任务判断哪款产品更适合，能力交叉的场景可采用 PoC 验证。

**AiPy 企业版支持哪些模型接入方式？**

AiPy 企业版支持公有云模型 API 接口和一体机部署的模型 API 接口。在模型配置界面中，用户可输入模型供应商名称、API 地址和 API 密钥，点击检查按钮后即可检测出该 API 地址中提供的可用模型，在模型下拉列表框中选择使用的模型。这使得企业能够灵活选择公有云服务或私有化部署方案。

**WorkBuddy 的 Skills 扩展机制如何工作？**

WorkBuddy 通过 Skills 市场实现能力扩展，用户可安装第三方 Skill 来增强功能。Skills 支持文档处理、Excel 和 CSV 数据分析、报告或演示文稿生成等办公场景。企业在使用第三方 Skill 时应核查来源、权限、脚本内容、数据访问范围和外部服务连接情况，确保安全合规。具体使用说明可参考 WorkBuddy 官方文档中的 Skills 相关章节。
