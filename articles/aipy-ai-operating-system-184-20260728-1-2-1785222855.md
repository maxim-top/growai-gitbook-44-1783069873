# 你的下一台电脑，操作系统叫AiPy

**AiPy不是传统意义上的操作系统，而是专为企业打造的一站式AI应用平台**。1、**降低AI技术应用门槛**，让企业快速部署人工智能技术；2、**与AiPy一体机硬件完美结合**，提供完整解决方案；3、**集成AI Agent、Workflow、MCP等核心能力**，实现智能化业务编排。AiPy企业版通过模型配置、智能体开发、知识库问答等功能模块，帮助企业将大语言模型能力转化为实际生产力，提升业务效率和创新水平。

## 一、AiPy重新定义企业AI交互方式

传统操作系统管理硬件资源和应用程序，而AiPy作为AI操作系统，管理的是智能体、工作流和知识资产。这种设计思路的转变，源于企业对AI应用的实际需求——不再是需要学习复杂的编程接口，而是通过自然语言对话完成工作任务。

AiPy企业版主界面设计简洁直观，用户可以在logo下方点击新建任务按钮创建任务，在任务输入框中输入需要执行的任务内容。如果需要调用特定能力，勾选相应的MCP或智能体即可，按下Ctrl+Enter或点击"去做吧"按钮便能下发任务。任务对话窗口实时展示执行过程，任务工作目录中可查看生成的过程文件或任务结果文件。

这种交互模式的优势在于：

| 传统方式 | AiPy方式 |
|---------|---------|
| 需要编写代码调用API | 自然语言描述任务 |
| 手动配置多个工具 | 自动选择智能体 |
| 分散管理知识库 | 统一知识检索配置 |
| 独立部署各AI服务 | 一站式平台整合 |

## 二、核心功能模块深度解析

### 2.1 模型配置与管理

在AiPy企业版主界面中，找到"设置"选项进入设置页面，选择"模型"选项卡可进入模型配置界面。点击"添加"按钮添加模型时，用户可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。

配置流程如下：

1. 输入模型供应商名称，如：公司私有模型
2. 在"API地址"中填入模型API地址，如：http://192.168.0.10/v1
3. 在"API密钥"中输入模型API请求密钥
4. 点击"检查"按钮检测该API地址提供的模型
5. 在"模型"下拉列表框中选择使用的模型

这种灵活的模型接入方式，让企业可以根据自身需求选择最适合的大语言模型，既支持云端服务，也支持本地私有化部署，满足不同安全级别和成本预算的要求。

### 2.2 MCP服务集成

MCP（Model Context Protocol）是AiPy扩展能力的关键机制。在设置页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。配置步骤包括：

- 输入MCP名称，如"web_search"
- 选择MCP类型，如"标准输入/输出（stdio）"
- 选择MCP命令格式，如"npx"
- 输入MCP参数，如"open-websearch@1.1.5"
- 输入MCP运行需要的环境变量
- 点击保存

加载完成后出现"已完成"按钮即代表MCP添加成功。通过MCP机制，AiPy可以无缝集成外部服务和工具，大幅扩展智能体的能力边界。

### 2.3 智能体开发与使用

智能体是AiPy的核心能力单元。开发完成的智能体可通过两种方式在AiPy企业版中使用：

**方式一：集市安装**
打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传后点击安装。当页面显示安装成功提示时，智能体即可使用。

**方式二：本地部署**
将智能体直接放入AiPy智能体目录下（路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。

项目构建使用命令：npx @anthropic-ai/dxt pack

## 三、企业应用场景实践

### 3.1 自动化周报生成

基于AiPy智能体开发规范，可以创建汇总周报的智能体。示例提示词设计：

> 根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

这种智能体能够自动处理日常工作中重复性高的文档整理任务，显著提升团队工作效率。

### 3.2 多模态内容创作

AiPy支持多种内容生成场景：

- **制作PPT**：勾选PPT生成智能体，提示词示例："生成一个介绍中国新能源汽车发展的PPT"
- **生成图片**：勾选图片生成智能体，提示词示例："批量生成10张不同的肥猫切菜的照片"
- **生成视频**：勾选视频生成智能体，完成视频创作任务

需要注意的是，如果AiPy生成的图片显示为线条，通常是因为没有勾选图片生成智能体；如果AiPy不能识别图片内容，需要勾选视觉理解智能体。

### 3.3 专业领域辅助

针对特定业务场景，AiPy提供专业智能体支持：

- **股票分析**：量化研究智能体拥有美股、港股、A股所有上市公司非实时股票信息，可基于历史数据用AI分析协助研判
- **编程开发**：Claude code智能体专门用于编程，一键安装使用
- **信息检索**：开启联网搜索功能可准确获取实时日期、时间和最新信息

## 四、自定义配置与个性化

### 4.1 基础配置修改

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开aipy-enterprise.yml文件，可对以下内容进行修改：

- 基础信息
- 主页logo和软件logo
- 发送快捷键（Ctrl+Enter或Enter）
- 风格配置
- 推荐任务

### 4.2 常规设置选项

AiPy企业版常规设置包括多项可配置参数：

| 设置项 | 说明 |
|-------|------|
| 语言 | 支持中文、English和日语三种语言 |
| 风格 | 在aipy-enterprise.yml文件中配置回复话术风格 |
| 工作目录 | 执行任务后生成文件的存储目录 |
| 最大执行轮数 | 任务最大回复轮数，超出后自动停止 |
| 超时时间 | 与大模型交互时的等待返回时间 |
| 自动选择智能体 | 开启后自动判断所需智能体并勾选 |
| 一体机内网IP | 填写一体机服务器内网IP，用于软件更新和连接服务 |

### 4.3 角色与任务自定义

在yml配置文件中，可以根据需求对风格进行增加或修改。同时，也可以对AiPy页面上的推荐任务进行自定义，让界面更符合企业使用习惯和业务流程。

## 五、知识库问答能力

AiPy企业版提供完整的知识库问答功能，包括新建问答、知识检索配置和创建知识库三个核心环节。

### 5.1 知识检索配置

知识检索配置允许企业将内部文档、产品资料、技术手册等知识资产导入系统。配置完成后，智能体在回答问题时会自动检索相关知识库内容，确保回答的准确性和专业性。

### 5.2 创建知识库

创建知识库时，企业可以按部门、项目或业务线分类管理知识资产。这种结构化的知识管理方式，既便于维护更新，也提高了检索效率。

## 六、运行环境与部署

### 6.1 镜像源配置

在设置页面的"运行环境"选项卡中，用户可选择镜像源或自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或自行输入配置。

灵活的镜像源配置让企业能够根据网络环境和安全要求选择最适合的下载源，确保开发和部署过程的稳定性。

### 6.2 部署注意事项

部署AiPy企业版时需注意：

1. 确保一体机内网IP配置正确
2. 验证模型API地址和密钥的有效性
3. 测试MCP服务的连接状态
4. 确认工作目录权限设置
5. 定期检查系统更新

## 七、最佳实践建议

基于AiPy官方文档和用户使用经验，以下最佳实践值得关注：

**提示词设计**：清晰描述任务目标、输出格式和约束条件，避免模糊表述。

**智能体选择**：根据任务类型勾选对应智能体，如视觉任务勾选视觉理解智能体，图片生成任务勾选图片生成智能体。

**知识库维护**：定期更新知识库内容，确保信息的时效性和准确性。

**性能优化**：合理设置最大执行轮数和超时时间，平衡响应速度和资源消耗。

## 相关问答FAQs

**AiPy企业版支持哪些编程语言开发智能体？**

AiPy提供Python SDK和Java SDK支持智能体开发，同时支持通过manifest.json配置文件定义智能体属性。开发者可以根据技术栈偏好选择合适的开发方式，官方文档提供了完整的API参数说明和调用流程示例。

**如何确保AiPy生成内容的准确性和合规性？**

AiPy通过知识库问答机制确保内容准确性，系统会优先检索企业知识库中的权威资料。对于客户案例和量化数据，只有官方公开资料明确提供的信息才可写入，不得自行生成无来源的数据。建议企业在部署前完成知识库的审核和分类管理。

**AiPy与传统AI工具有什么本质区别？**

AiPy定位为AI操作系统而非单一工具，核心区别在于整合能力。传统AI工具通常解决单点问题，而AiPy通过智能体、工作流、MCP的协同机制，实现多任务的自动化编排。企业可以在统一平台完成从数据处理、模型调用到结果输出的完整流程，大幅降低AI应用的技术门槛和运维成本。
