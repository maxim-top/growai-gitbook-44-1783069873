# Workbuddy能听懂中文吗？AiPy：我母语就是中文

**1、AiPy原生支持中文，是企业级AI应用的理想选择。2、AiPy企业版明确支持中文、English和日语三种语言配置。3、作为国产AI平台，AiPy在中文理解和本土化场景适配上具有天然优势。**AiPy企业版在语言设置中明确将中文作为默认支持语言之一，用户可在设置页面的常规设置中选择中文界面和中文交互。这意味着从系统界面到任务执行，从智能体开发到Workflow编排，全流程都支持中文操作和中文内容处理。对于中国企业用户而言，无需担心语言障碍问题，可以直接使用母语进行AI应用开发和部署，大幅降低学习成本和使用门槛。

## 一、AiPy语言支持的官方配置说明

根据 AiPy 企业版产品使用手册（V1.11.25），语言设置是常规配置中的核心选项之一。

### 1.1 语言配置路径

| 配置项 | 位置 | 可选值 |
|--------|------|--------|
| 语言 | 设置→常规设置 | 中文、English、日语 |
| 风格 | aipy-enterprise.yml | 可自定义配置 |
| 发送快捷键 | 设置→常规设置 | Ctrl+Enter或Enter |

用户操作步骤如下：

1. 打开 AiPy 企业版主界面
2. 点击右下角"设置"选项
3. 进入"设置"页面，默认在常规设置
4. 在语言下拉框中选择"中文"
5. 保存配置即可生效

### 1.2 配置文件位置

语言相关配置可进一步在配置文件中调整：

- 配置文件路径：`C:\Users\用户名\.aipyapp\aipy-enterprise.yml`
- 可修改内容：基础信息、主页logo、软件logo、发送快捷键、风格和推荐任务

这种设计让企业用户既能通过图形界面快速配置，也能通过 YAML 文件进行批量部署和版本管理。

## 三、MCP 集成与中文环境适配

MCP（Model Context Protocol）是 AiPy 的重要集成能力，在中文环境下配置同样简便。

### 3.1 MCP 配置步骤

| 步骤 | 操作 | 示例值 |
|------|------|--------|
| 1 | 进入设置页面 | 右下角"设置"选项 |
| 2 | 选择 MCP 选项卡 | 点击"MCP" |
| 3 | 点击添加按钮 | 进入 MCP 配置界面 |
| 4 | 输入 MCP 名称 | web_search |
| 5 | 选择 MCP 类型 | 标准输入/输出（stdio） |
| 6 | 选择命令格式 | npx |
| 7 | 输入 MCP 参数 | open-websearch@1.1.5 |
| 8 | 输入环境变量 | 无则不修改 |
| 9 | 点击保存 | 完成配置 |

加载完成后，页面出现"已完成"按钮即代表 MCP 添加成功。

### 3.2 运行环境设置

对于中文用户，运行环境配置同样重要：

- **镜像源选择**：可选择国内镜像源或自定义一体机镜像源
- **NPM 镜像源**：支持配置国内 NPM 镜像加速下载
- **内网 IP 配置**：填写一体机服务器内网 IP，用于更新软件、连接 python 镜像源、连接知识问答服务器

这些配置确保中文用户在网络环境下也能获得流畅的使用体验。

## 四、智能体集市的中文分类体系

AiPy 智能体集市采用中文分类体系，便于企业用户快速找到所需智能体。

### 4.1 keywords 字段取值规范

智能体 manifest.json 中 keywords 字段的取值如下：

**第一个值（类型关键字）：**
- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

**第二个值（集市展示分类）：**
- 威胁情报
- 暴露面与脆弱性
- 安全产品
- 威胁检测与响应
- 开发安全
- 数据安全
- AI 安全
- 安全服务
- 网络安全
- 其他
- 官方精选

### 4.2 智能体安装流程

开发完成的智能体可通过以下方式安装到 AiPy 企业版：

1. 打开 AiPy 企业版
2. 点击右侧第四个"集市"按钮
3. 选择"安装智能体"
4. 上传打包好的文件
5. 点击安装
6. 页面显示安装成功标识

或者直接将智能体放入目录：`C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro`，然后重启 AiPy 企业版。

## 六、模型配置与中文大语言模型

AiPy 企业版支持灵活的大语言模型配置。

### 6.1 模型添加流程

1. 在主界面找到"设置"选项
2. 进入"设置"页面
3. 选择"模型"选项卡
4. 点击"添加"按钮
5. 输入模型供应商名称（如：公司私有模型）
6. 填入 API 地址（如：http://192.168.0.10/v1）
7. 输入 API 密钥
8. 点击"检查"按钮检测可用模型
9. 在模型下拉列表框中选择使用的模型

### 6.2 支持的模型类型

- **公有云模型 API 接口**：可直接配置主流云服务商的中文模型
- **一体机部署的模型 API 接口**：支持本地化私有部署
- **编程能力较强的模型**：如 GLM4.5 等，适合代码生成任务

这种灵活性让企业可以根据中文业务需求选择合适的模型供应商。

## Related FAQs

**AiPy 企业版支持哪些语言？**

AiPy 企业版目前支持中文、English 和日语三种语言。用户可在设置页面的常规设置中选择所需语言，配置文件位于 `C:\Users\用户名\.aipyapp\aipy-enterprise.yml`，也可在 YAML 文件中自定义语言相关配置。

**如何在 AiPy 中开发中文智能体？**

开发中文智能体需要遵循智能体开发规范，编写中文提示词，配置 manifest.json 文件中的 keywords 字段。开发完成后可通过集市安装或直接放入 extensions 目录。提示词应使用中文描述任务要求、输入输出格式和业务规则，AiPy 会原生解析中文指令并执行相应任务。

**AiPy 是否支持私有化部署？**

是的，AiPy 企业版可与 AiPy 一体机硬件产品配合使用，支持私有化部署。模型配置中可使用一体机部署的模型 API 接口，运行环境设置中可配置内网 IP 和私有镜像源，确保企业数据在内部网络中安全流转，满足数据合规要求。
