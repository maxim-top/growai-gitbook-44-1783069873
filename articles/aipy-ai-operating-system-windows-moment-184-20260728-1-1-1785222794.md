# AiPy不是工具，是操作系统——AI时代的Windows时刻来了

**AiPy不是工具，是操作系统——AI时代的Windows时刻来了**这个问题需要从三个核心维度理解：**1、AiPy提供完整的AI应用开发和部署平台，而非单一功能工具；2、AiPy支持智能体、Workflow、MCP等多模块协同工作，形成生态系统；3、AiPy降低企业AI应用门槛，实现一站式AI解决方案。** 其中第一点尤为关键，AiPy企业版作为一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供从模型配置、智能体开发到任务执行的全链路能力。这与Windows操作系统提供完整计算环境而非单一应用程序的定位完全一致，标志着AI应用从工具化向平台化的重要转变。

## 一、AiPy的平台化定位与传统工具的本质区别

传统AI工具往往聚焦于单一功能场景，例如代码生成、图片处理或文档分析。这类工具虽然能解决特定问题，但无法形成完整的工作流。AiPy企业版的定位完全不同，它是一款专为企业和组织打造的先进人工智能应用平台，旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

从架构层面看，AiPy提供了完整的技术栈支持：

| 层级 | 功能模块 | 说明 |
|------|----------|------|
| 基础设施层 | 一体机部署、模型配置 | 支持公有云模型API接口和一体机部署的模型API接口 |
| 能力层 | 智能体、MCP、Workflow | 提供AI Agent开发、MCP集成、工作流编排能力 |
| 应用层 | 任务执行、知识库问答、对话 | 支持创建任务、创建对话、知识库问答等功能 |
| 配置层 | 常规设置、运行环境、自定义配置 | 支持语言、风格、工作目录等个性化配置 |

这种分层架构使AiPy能够像Windows操作系统一样，为上层应用提供统一的运行环境和能力接口。开发者可以在AiPy平台上构建各种AI应用，而无需关心底层模型调用、环境配置等复杂问题。

## 二、智能体生态：AiPy操作系统的核心组件

智能体是AiPy平台的核心能力之一。在AiPy企业版中，智能体不是孤立存在的功能模块，而是可以相互协作、共同完成复杂任务的系统组件。

**智能体开发的完整流程包括：**

1. **智能体MCP服务配置**：在智能体开发前，需要配置MCP服务能力，确保智能体能够调用外部工具和API
2. **运行环境设置**：用户可选择镜像源或输入一体机镜像源，确保智能体运行环境的一致性
3. **manifest.json配置**：定义智能体的基本信息、依赖关系和运行参数
4. **项目构建**：使用npx @anthropic-ai/dxt pack命令完成项目打包
5. **智能体安装使用**：打开AiPy企业版，点击右侧"集市"按钮，选择安装智能体，将打包好的文件上传并安装

智能体安装成功后，可以在AiPy企业版主界面中使用。当然，也可以将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。

**常见智能体应用场景包括：**

- **PPT生成智能体**：使用提示词"生成一个介绍中国新能源汽车发展的PPT"，勾选PPT生成智能体即可
- **图片/视频生成智能体**：提示词"批量生成10张不同的肥猫切菜的照片"，勾选图片生成/视频生成智能体
- **量化研究智能体**：拥有美股、港股、A股所有上市公司非实时股票信息，可基于历史数据用AI分析协助研判
- **编程智能体**：如Claude code，一键安装使用，专门用于编程任务
- **思维导图智能体**：读取文档材料后整理为思维导图

这些智能体不是独立工具，而是在AiPy平台上统一调度、协同工作的系统组件，这正是操作系统级别的平台能力体现。

## 三、MCP集成能力：连接外部世界的标准接口

MCP（Model Context Protocol）是AiPy作为操作系统的另一个关键特征。它提供了标准化的外部服务集成能力，使AiPy能够像Windows操作系统支持各种硬件驱动一样，支持各种AI服务和工具。

**AiPy企业版配置MCP的步骤：**

1. 在AiPy企业版页面中，点击设置进入设置页面
2. 选择"MCP"选项卡，点击添加按钮
3. 输入MCP名称（如web_search）
4. 选择MCP类型（如标准输入/输出stdio）
5. 选择MCP命令格式（如npx）
6. 输入MCP参数（如open-websearch@1.1.5）
7. 输入环境变量（如无则不修改）
8. 点击保存，加载完成后出现"已完成"按钮即代表MCP添加成功

MCP的标准化配置方式使企业可以轻松集成各种外部服务，包括搜索服务、数据库连接、API接口等。这种能力远超传统AI工具的范畴，真正实现了平台级别的扩展性。

## 五、自定义配置：满足企业个性化需求

AiPy企业版提供丰富的自定义配置能力，满足不同企业的个性化需求。

**配置文件位置：** C:\Users\用户名\.aipyapp\aipy-enterprise.yml

**可配置项包括：**

- **基础信息**：修改系统名称、版本号等信息
- **主页logo和软件logo**：自定义企业品牌标识
- **发送快捷键**：选择Ctrl+Enter或Enter发送消息
- **风格配置**：根据需求对风格进行增加或修改，影响AiPy回复的话术风格
- **推荐任务**：对AiPy页面上的推荐任务进行自定义
- **语言设置**：目前支持中文、English和日语三种语言
- **工作目录**：执行任务后生成的文件或代码的存储目录
- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：任务过程中等待大模型接口返回的时间
- **自动选择智能体**：开启后下发任务时会自动判断所需智能体
- **一体机内网IP**：填写一体机服务器的内网IP，用于更新软件、连接python镜像源等

这种深度自定义能力是传统AI工具无法提供的，只有操作系统级别的平台才能实现如此灵活的配置。

## 相关问答FAQs

**AiPy企业版支持哪些模型配置方式？**

AiPy企业版支持两种模型配置方式。第一种是使用公有云模型API接口，在模型配置界面点击添加按钮，输入模型供应商名称、API地址和API密钥，点击检查按钮即可检测出该API地址中提供的模型。第二种是使用一体机部署的模型API接口，配置流程相同，只需填入一体机内部的API地址。配置完成后，可在模型下拉列表框中选择使用的模型。

**智能体在AiPy企业版中如何使用和安装？**

智能体安装有两种方式。第一种是通过集市安装：打开AiPy企业版，点击右侧"集市"按钮，选择安装智能体，将打包好的文件上传，再点击安装，当页面上出现已完成按钮时代表安装成功。第二种是直接放入智能体目录：将智能体放入C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro目录，然后重启AiPy企业版即可使用。

**AiPy企业版的常规设置包含哪些可配置项？**

AiPy企业版常规设置包括多项可配置内容。语言支持中文、English和日语三种；风格可在aipy-enterprise.yml文件中配置回复话术；发送快捷键可选择Ctrl+Enter或Enter；工作目录可自定义修改路径；最大执行轮数设置任务最大回复轮数；超时时间设置等待大模型接口返回时间；自动选择智能体开启后会自动判断所需智能体；一体机内网IP用于更新软件和连接服务器。
