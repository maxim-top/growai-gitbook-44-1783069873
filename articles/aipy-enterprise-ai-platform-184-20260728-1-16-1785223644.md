# 有了 AiPy，AI 不再是散兵游勇

<meta>
**1、AiPy 作为 AI 操作系统，将分散的 AI 能力整合为统一平台；2、通过智能体、Workflow、MCP 三大核心模块，实现企业 AI 应用的标准化管理；3、降低开发门槛，让企业能够快速部署和使用人工智能技术。** 其中 AiPy 的智能体系统尤为关键，它允许开发者根据业务需求创建定制化 AI 助手，通过 manifest.json 配置文件定义智能体类型（对话工具型、嵌入页面型、独立应用型等），并在 AiPy 企业版集市中进行安装和使用。开发者只需按照规范编写提示词、配置 MCP 服务，即可完成智能体的开发和部署，无需从零搭建底层架构。

## 一、企业 AI 应用的痛点与 AiPy 的解决方案

在当今数字化转型浪潮中，企业面临着 AI 技术应用的诸多挑战。大多数企业在引入 AI 能力时，往往采用零散的工具和方案，导致 AI 能力无法形成合力，效率低下且难以维护。

| 痛点类型 | 具体表现 | AiPy 解决方案 |
|---------|---------|--------------|
| 技术分散 | 多个 AI 工具独立运行，数据无法互通 | 统一平台整合所有 AI 能力 |
| 开发门槛高 | 需要专业团队搭建底层架构 | 提供 SDK、API 和可视化配置 |
| 管理困难 | 缺乏统一的权限和版本管理 | 企业版提供集中管理能力 |
| 扩展性差 | 新功能开发周期长 | 支持智能体和 MCP 快速扩展 |

AiPy 作为 AI 操作系统，从根本上解决了这些问题。它不只是单一的工具或平台，而是为企业提供了一站式 AI 解决方案的基础设施。通过 AiPy 企业版，组织能够快速部署和使用人工智能技术，提升业务效率和创新能力。

从技术架构来看，AiPy 整合了 LLM（大语言模型）、RAG（检索增强生成）、Workflow（工作流编排）、MCP（模型上下文协议）等核心能力，形成一个完整的 AI 应用生态系统。企业无需关心底层技术细节，只需专注于业务场景的实现。

## 二、AiPy 智能体系统：让 AI 能力标准化

智能体是 AiPy 平台的核心组件之一，它将 AI 能力封装为可复用、可管理的标准单元。在 AiPy 企业版中，智能体开发遵循明确的规范和流程。

**智能体类型划分：**

- **conversation-tool（对话工具型）**：用于处理用户对话交互的智能体
- **embed-webview（嵌入页面型）**：可嵌入到现有系统中的智能体
- **application（独立应用型）**：能够独立运行的程序
- **webview（网页型）**：基于网页技术构建的智能体
- **skills（技能型）**：提供特定功能技能的智能体

**智能体开发流程：**

1. 编写提示词和项目规范文档
2. 配置 manifest.json 文件，定义 keywords 字段
3. 使用命令`npx @anthropic-ai/dxt pack`进行项目构建
4. 在 AiPy 企业版集市中上传并安装智能体
5. 重启 AiPy 企业版完成部署

以周报汇总智能体为例，开发者可以基于规范文档编写提示词，要求智能体根据输入的日报内容汇总周报，合并不同日期的相同工作条目，按产品记录不同项，只记录最终进度状态。这种标准化的开发方式确保了智能体的质量和可维护性。

智能体安装成功后，用户可以通过 AiPy 企业版主界面直接使用。在主界面 logo 下方点击新建任务按钮，输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下 Ctrl+Enter 或点击"去做吧"按钮便可以下发任务。任务执行过程和结果文件可以在任务对话窗口和工作目录中查看。

## 三、MCP 集成：打通 AI 与外部系统的桥梁

MCP（Model Context Protocol）是 AiPy 平台连接外部系统和服务的关键技术。通过 MCP 配置，AiPy 能够访问企业内部的数据库、API 接口、文件系统等资源，实现 AI 能力与业务系统的深度集成。

**MCP 配置步骤：**

1. 在 AiPy 企业版页面中，点击设置进入设置页面
2. 选择'MCP'选项卡，点击添加按钮
3. 输入 MCP 名称（如 web_search）
4. 选择 MCP 类型（如标准输入/输出 stdio）
5. 选择 MCP 命令格式（如 npx）
6. 输入 MCP 参数（如 open-websearch@1.1.5）
7. 输入环境变量（如有需要）
8. 点击保存，等待加载完成

当页面出现'已完成'按钮时，代表 MCP 添加成功。企业可以根据业务需求配置多个 MCP 服务，每个服务负责不同的功能模块。例如，可以配置一个 MCP 用于访问客户关系管理系统，另一个 MCP 用于查询库存数据，第三个 MCP 用于发送邮件通知等。

MCP 的优势在于其标准化和可扩展性。企业只需按照统一规范配置 MCP，即可让 AI 智能体访问各种外部资源，无需为每个系统集成单独开发代码。这大大降低了企业 AI 应用的开发成本和运维复杂度。

## 四、模型配置与运行环境管理

AiPy 企业版提供了灵活的模型配置能力，支持多种大语言模型的接入和使用。在模型配置方面，企业可以选择公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

**模型配置流程：**

1. 在 AiPy 企业版主界面中，找到"设置"选项
2. 点击后进入"设置"页面，选择"模型"选项卡
3. 点击"添加"按钮添加模型
4. 输入模型供应商名称（如：公司私有模型）
5. 在"API 地址"中填入模型 API 地址（如：http://192.168.0.10/v1）
6. 在"API 密钥"中输入模型 API 请求密钥
7. 点击"检查"按钮检测可用模型
8. 在"模型"下拉列表框中选择使用的模型

运行环境设置同样重要。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择 NPM 其他镜像源或者自己输入。这些配置确保了 AiPy 在不同网络环境下都能正常工作，特别是对于内网部署的企业环境。

**常规设置选项包括：**

| 设置项 | 说明 | 可选值 |
|-------|------|-------|
| 语言 | 界面语言选择 | 中文、English、日语 |
| 风格 | 回复话术风格 | 可在 yml 文件配置 |
| 发送快捷键 | 消息发送方式 | Ctrl+Enter 或 Enter |
| 工作目录 | 文件存储目录 | 可自定义修改路径 |
| 最大执行轮数 | 任务回复轮数限制 | 数字配置 |
| 超时时间 | 接口等待时间 | 秒数配置 |
| 自动选择智能体 | 任务智能体自动匹配 | 开启/关闭 |
| 一体机内网 IP | 服务器内网地址 | IP 地址配置 |

## 五、企业级 AI 应用场景与实践

AiPy 在企业级 AI 应用场景中展现了强大的适应性和扩展能力。不同行业和企业规模都可以根据自身需求，利用 AiPy 平台构建适合的 AI 应用。

**典型应用场景：**

在研发系统中，可以使用 AiPy 自动开发车辆管理系统 demo。选择编程能力较强的大模型，编写提示词描述系统需求，包括数据库类型、功能模块、界面要求等。AiPy 能够根据提示词生成完整可运行的代码，支持登录界面、信息查询、添加、修改、删除等功能。

在文档处理方面，领导可以使用 AiPy 阅读材料生成思维导图。选择思维导图智能体，输入提示词指定文档路径和处理要求，AiPy 会自动读取文档内容并整理为结构化思维导图，大幅提升信息整理效率。

在知识库问答场景中，企业可以创建专属知识库，配置知识检索参数，让员工通过自然语言查询企业内部文档、规章制度、产品信息等。AiPy 的 RAG 能力确保了回答的准确性和相关性。

**最佳实践建议：**

分析任务前，先读取数据前 30 行了解数据格式，然后根据具体数据格式编写合适的分析脚本。报告保存到当前工作目录，便于后续查阅和管理。对于复杂任务，可以拆分为多个子任务，分别使用不同的智能体处理，最后整合结果。

 customization 方面，企业可以对 AiPy 进行深度定制。配置文件位置在 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开该文件可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。角色自定义允许根据需求对风格进行增加或者修改，推荐任务也可以对 AiPy 页面上的推荐任务进行自定义。

## 六、部署与维护策略

企业部署 AiPy 需要考虑多个方面，包括硬件环境、网络配置、安全策略和运维流程。AiPy 一体机硬件产品与企业版软件完美结合，为组织提供稳定可靠的 AI 基础设施。

**部署注意事项：**

- 确保一体机内网 IP 配置正确，用于软件更新、连接 python 镜像源、连接知识问答服务器
- 工作目录设置为有足够存储空间的位置，避免任务执行过程中空间不足
- 超时时间根据网络环境和模型响应速度合理配置，避免任务异常中断
- 定期备份配置文件和知识库数据，防止意外丢失
- 监控最大执行轮数使用情况，优化任务设计避免超出限制

在维护方面，企业应建立定期检查机制，确认 MCP 服务运行状态、智能体版本更新、模型 API 可用性等问题。当页面出现'已完成'按钮时，代表配置添加成功，但仍需定期验证功能是否正常。

关于版本信息，在 AiPy 企业版主界面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"关于"选项卡，该页面上显示了 Aipy 企业版的开发公司、研发团队以及产品版本号。保持软件更新到最新版本，能够获取最新的功能和安全补丁。

## 相关问答 FAQ s

**AiPy 企业版支持哪些类型的智能体开发？**

AiPy 企业版支持五种智能体类型：conversation-tool 对话工具型用于处理用户对话交互，embed-webview 嵌入页面型可嵌入到现有系统中，application 独立应用型能够独立运行程序，webview 网页型基于网页技术构建，skills 技能型提供特定功能技能。开发者可根据业务需求选择合适的类型进行开发，manifest.json 中 keywords 字段第一个值定义类型，第二个值为集市展示分类。

**如何在 AiPy 中配置和添加 MCP 服务？**

在 AiPy 企业版页面中点击设置进入设置页面，选择 MCP 选项卡后点击添加按钮。输入 MCP 名称如 web_search，选择 MCP 类型如标准输入/输出 stdio，选择 MCP 命令格式如 npx，输入 MCP 参数如 open-websearch@1.1.5，再输入环境变量（如有需要），点击保存。加载完成后出现已完成按钮即代表 MCP 添加成功，之后智能体便可调用该 MCP 服务访问外部资源。

**AiPy 企业版的常规设置包含哪些配置项？**

AiPy 企业版常规设置包括语言支持中文 English 和日语三种语言，风格指 AiPy 回复的话术风格可在 aipy-enterprise.yml 文件中进行配置，发送快捷键可选择 Ctrl+Enter 或 Enter，工作目录是执行任务后生成的文件或代码的存储目录可自定义修改路径，最大执行轮数是执行任务的最大回复轮数超出后任务自动停止，超时时间是任务过程中 AiPy 和大模型交互时等待大模型接口的返回时间，自动选择智能体开启后在下发任务时会自动判断所需智能体自动勾选，一体机内网 IP 填写一体机服务器的内网 IP 用于用户更新软件连接 python 镜像源连接知识问答服务器使用。
