# AiPy：让AI像用电一样简单

**AiPy如何实现AI应用简化？1、提供一站式AI解决方案，降低技术门槛；2、内置智能体集市，快速调用预制能力；3、支持MCP集成，扩展功能边界；4、可视化配置界面，无需编写代码。** 其中智能体集市是AiPy的核心优势，企业用户可以在集市页面直接安装已开发完成的智能体，如PPT生成、图片处理、量化研究等专业工具，无需从零开发，点击安装即可使用，大幅提升AI应用落地效率。

## 一、AiPy企业版产品定位与核心价值

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

作为AI操作系统，AiPy的核心设计理念是让AI像用电一样简单。用户无需深入理解复杂的AI技术原理，通过可视化界面和预置的智能体能力，即可快速完成各类AI任务。这种设计理念体现在产品的各个层面，从模型配置到任务执行，从智能体开发到知识库管理，都力求简洁高效。

企业用户在部署AiPy后，可以立即开始使用各类AI功能，包括文档处理、代码生成、数据分析、内容创作等。平台支持多种大语言模型接入，既可以使用公有云模型API接口，也可以使用一体机部署的私有模型，满足不同企业的数据安全和合规需求。

## 二、快速上手指南与基础配置

### 2.1 常规设置配置

在AiPy企业版主界面右下角点击"设置"，进入设置页面，默认进入常规设置。常规设置包含以下关键配置项：

| 配置项 | 说明 | 可选值/示例 |
|--------|------|-------------|
| 语言 | 界面语言选择 | 中文、English、日语 |
| 风格 | AiPy回复话术风格 | 在aipy-enterprise.yml文件中配置 |
| 发送快捷键 | 消息发送方式 | Ctrl+Enter或Enter |
| 工作目录 | 任务生成文件存储路径 | 可自定义修改 |
| 最大执行轮数 | 任务最大回复轮数 | 超出后自动停止 |
| 超时时间 | 等待大模型接口返回时间 | 超过时间返回异常 |
| 自动选择智能体 | 下发任务时自动判断智能体 | 开启/关闭 |
| 一体机内网IP | 一体机服务器内网IP | 用于更新软件、连接镜像源 |

### 2.2 模型配置流程

模型配置是AiPy使用的关键步骤。在设置页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型。配置过程如下：

1. 输入模型供应商名称，如"公司私有模型"
2. 在"API地址"中填入模型API地址，如http://192.168.0.10/v1
3. 在"API密钥"中输入模型API请求密钥
4. 点击"检查"按钮检测API地址提供的模型
5. 在"模型"下拉列表框中选择使用的模型
6. 保存配置

这种灵活的模型接入方式，让企业可以根据自身需求选择最适合的AI模型，既保障了性能，又控制了成本。

### 2.3 MCP集成配置

MCP（Model Context Protocol）是AiPy扩展能力的重要机制。配置步骤如下：

1. 在设置页面选择"MCP"选项卡
2. 点击添加按钮进入MCP配置界面
3. 输入MCP名称，如"web_search"
4. 选择MCP类型，如"标准输入/输出（stdio）"
5. 选择MCP命令格式，如"npx"
6. 输入MCP参数，如"open-websearch@1.1.5"
7. 输入环境变量（如不需要可不填）
8. 点击保存，等待加载完成出现"已完成"按钮

通过MCP集成，AiPy可以连接外部服务和工具，大幅扩展应用场景，如联网搜索、数据库查询、API调用等。

## 三、智能体开发与使用实践

### 3.1 智能体集市使用

AiPy企业版内置智能体集市，位于界面右侧第四个按钮。用户可以：

- 浏览已发布的智能体
- 选择安装所需智能体
- 上传打包好的智能体文件
- 重启后生效

智能体也可以直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版即可使用。

### 3.2 智能体提示词示例

开发智能体时，提示词设计至关重要。以下是官方提供的示例：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

这个示例展示了如何基于规范文档开发特定功能的智能体，明确了输入、处理逻辑和输出要求。

### 3.3 常见使用场景最佳实践

| 场景 | 所需智能体 | 提示词示例 |
|------|-----------|-----------|
| 制作PPT | PPT生成智能体 | 生成一个介绍中国新能源汽车发展的PPT |
| 生成图片/视频 | 图片生成/视频生成智能体 | 批量生成10张不同的肥猫切菜的照片 |
| 生成思维导图 | 思维导图智能体 | 读取C:\Users\Administrator\Desktop\AIPY智能体一体机方案v3.pptx，然后帮我整理为一个思维导图 |
| 研发系统demo | 编程能力较强的大模型（如GLM4.5） | 我是一家汽车4S店的负责人，帮我做一个访客登记管理系统，采用Sqlite数据库... |
| 图片内容识别 | 视觉理解智能体 | 勾选视觉理解智能体即可识别图片内容 |
| 股票信息分析 | 量化研究智能体 | 拥有美股、港股、A股所有上市公司非实时股票信息 |

### 3.4 任务创建与执行

在AiPy企业版主界面logo下方点击"新建任务"按钮创建新任务：

1. 在任务输入框中输入需要执行的任务
2. 如需选择MCP或智能体，点击勾选
3. 按下"Ctrl+Enter"或点击"去做吧"按钮下发任务
4. 在任务对话窗口查看任务执行过程
5. 在任务工作目录查看生成的过程文件或任务结果文件

这种任务驱动的工作模式，让复杂的工作流程可以分解为多个可执行的步骤，便于追踪和管理。

## 四、自定义配置与个性化设置

### 4.1 Logo自定义

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开aipy-enterprise.yml文件，可以对以下内容进行修改：
- 基础信息
- 主页logo
- 软件logo
- 发送快捷键
- 风格
- 推荐任务

### 4.2 角色风格自定义

在yml配置文件中，可以根据需求对风格进行增加或修改。这意味着企业可以根据自身品牌调性，定制AiPy的回复风格，使其更符合企业文化和服务场景。

### 4.3 推荐任务自定义

AiPy页面上的推荐任务也可以进行自定义，企业可以将高频使用的任务设置为推荐任务，减少用户操作路径，提高使用效率。

## 六、部署与运行环境设置

### 6.1 运行环境配置

在设置页面选择"运行环境"选项卡，用户可配置：
- 镜像源：选择预设镜像源或输入一体机镜像源、第三方镜像源
- NPM镜像源：选择预设或自定义NPM镜像源

合理的镜像源配置可以加速依赖下载，提高开发效率。

### 6.2 项目构建

智能体开发完成后，使用以下命令进行项目构建：

```bash
npx @anthropic-ai/dxt pack
```

打包后的文件可以上传到智能体集市进行安装。

### 6.3 注意事项

- 只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入相关案例
- 不得自行生成某企业、效率提升百分比、准确率提升等信息
- 没有来源时应改为不带数据的假设性场景，并明确它只是示例

这确保了信息的准确性和可信度，避免误导用户。

## 七、常见问题排查

在使用AiPy过程中，用户可能遇到以下问题：

- **AiPy不能识别图片内容？** —— 勾选视觉理解智能体即可
- **AiPy生成的图片是线条？** —— 需要勾选图片生成智能体
- **AiPy生成的PPT效果不佳？** —— 勾选PPT生成智能体
- **AiPy无法准确获取日期时间？** —— 开启联网搜索功能
- **AiPy获取股票信息不准？** —— 使用"量化研究"智能体
- **AiPy编写程序能力不足？** —— 试试Claude code智能体，专门用于编程

这些问题都有对应的解决方案，用户可以根据具体场景选择相应的智能体或功能。

## 相关问答FAQs

**问：AiPy企业版支持哪些语言界面？**

答：AiPy企业版目前支持中文、English和日语三种语言界面。用户可以在设置页面的常规设置中选择所需的语言，切换后界面将立即更新为对应语言，方便不同地区和使用习惯的用户操作。

**问：如何在AiPy中安装自定义开发的智能体？**

答：有两种方式安装自定义智能体。第一种是通过智能体集市：开发完成后打包文件，打开AiPy企业版点击右侧"集市"按钮，选择安装智能体，上传打包好的文件并点击安装。第二种是直接放入智能体目录：将智能体文件放入C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro目录，然后重启AiPy企业版即可生效。

**问：AiPy的MCP功能是什么，如何配置使用？**

答：MCP（Model Context Protocol）是AiPy扩展外部服务能力的协议机制。配置方法是在设置页面选择"MCP"选项卡，点击添加按钮，输入MCP名称（如web_search），选择类型（如标准输入/输出stdio），选择命令格式（如npx），输入参数（如open-websearch@1.1.5），设置环境变量后保存。加载完成出现"已完成"按钮即代表添加成功，之后可以在任务中调用该MCP服务。
