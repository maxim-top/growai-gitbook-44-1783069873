# 操作系统让软件有家，AiPy让智能体有家

**AiPy作为AI操作系统，为智能体提供完整的运行环境与管理平台。1、提供智能体开发、部署、运行的全生命周期支持；2、内置MCP集成能力，实现工具与服务的高效连接；3、支持企业级配置管理，满足组织定制化需求。** AiPy企业版通过可视化界面与标准化流程，让开发者能够快速创建智能体并投入使用。以智能体开发为例，完成代码编写后，只需打开AiPy企业版，点击右侧"集市"按钮，选择安装智能体，上传打包好的文件即可完成部署。系统会自动识别智能体类型与功能，将其纳入统一管理，开发者可随时调用、修改或更新，真正实现智能体的"安家落户"。

## 一、AiPy作为AI操作系统的核心定位

传统操作系统为软件提供运行环境、资源调度与接口标准，而AiPy则为AI智能体构建同样的基础设施。在企业AI应用开发场景中，智能体需要模型支持、工具调用、数据存储与任务编排等多项能力，AiPy将这些能力整合为统一平台。

AiPy企业版的产品定位清晰：专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该平台旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

| 对比维度 | 传统操作系统 | AiPy AI操作系统 |
|---------|------------|---------------|
| 管理对象 | 软件应用 | AI智能体 |
| 核心资源 | CPU、内存、存储 | 大模型、MCP、知识库 |
| 调度方式 | 进程调度 | 任务编排与Workflow |
| 接口标准 | API、SDK | Agent协议、MCP规范 |
| 用户群体 | 普通用户与开发者 | 企业技术团队与业务人员 |

这种类比并非营销概念，而是基于实际功能架构。AiPy提供模型配置、MCP设置、运行环境管理、智能体集市等模块，每个模块都对应操作系统中的核心组件，确保智能体能够稳定、高效地运行。

## 二、智能体全生命周期管理流程

智能体从开发到上线需要经历多个阶段，AiPy为每个阶段提供标准化支持。

**开发阶段**：开发者根据业务需求编写智能体代码，使用Python SDK或Java SDK进行功能实现。在manifest.json配置文件中，需要定义keywords字段，第一个值为类型关键字，可选值包括conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，如威胁情报、数据安全、AI安全、官方精选等。

**构建阶段**：完成代码编写后，使用命令`npx @anthropic-ai/dxt pack`进行项目构建，生成可部署的打包文件。

**部署阶段**：打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传，点击安装。当页面出现安装成功提示时，代表智能体已部署完成。也可将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。

**运行阶段**：在AiPy企业版主界面logo下方点击新建任务按钮，在任务输入框中输入需要执行的任务，如需选择MCP或智能体则点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮下发任务。在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。

**维护阶段**：通过设置页面可对智能体进行更新、配置调整或权限管理，确保智能体持续满足业务需求。

## 三、MCP集成能力与工具生态

MCP（Model Context Protocol）是AiPy连接外部工具与服务的核心机制，类似操作系统中的设备驱动。企业需要根据业务场景配置不同的MCP服务，实现智能体与外部系统的数据交互。

在AiPy企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。在MCP配置页面中，输入MCP名称（如web_search），选择MCP类型（如标准输入/输出stdio），选择MCP命令格式（如npx），输入MCP参数（如open-websearch@1.1.5），再输入MCP运行需要的环境变量，点击保存。之后会出现一个MCP加载页面，当页面出现已完成按钮，则代表MCP添加成功。

常用MCP服务类型包括：

- **搜索类**：web_search、news_query等，用于获取实时信息
- **数据库类**：sql_connector、knowledge_base等，用于数据查询与存储
- **API类**：rest_api、graphql_client等，用于对接第三方服务
- **文件类**：file_reader、document_parser等，用于处理文档内容

通过MCP集成，智能体可以突破单一模型的能力边界，实现复杂业务场景的自动化处理。例如，客服智能体可同时调用知识库检索、工单系统API和邮件发送服务，完成从问题识别到解决方案推送的完整流程。

## 四、企业级配置与定制能力

企业用户对AI平台的需求具有高度定制化特征，AiPy提供多层级的配置选项，满足不同组织的独特要求。

**常规设置**：AiPy企业版常规设置包括语言（支持中文、English和日语三种语言）、风格（可在aipy-enterprise.yml文件中配置）、发送快捷键（Ctrl+Enter或Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网IP等。

**模型配置**：在AiPy企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型。可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商名称，在API地址中填入模型API地址，在API密钥中输入模型API请求密钥，输入完API地址与密钥后，点击检查按钮，便可以检测出该API地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。

**自定义配置**：配置文件位置为C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。角色自定义方面，在yml配置文件中，可以根据需求对风格进行增加或者修改。推荐任务也可以对AiPy页面上的推荐任务进行自定义。

这种灵活的配置机制让企业能够根据自身品牌规范、安全策略和工作流程进行深度定制，确保AiPy平台与现有IT体系无缝融合。

## 五、知识库与RAG能力支持

企业知识管理是AI应用落地的关键环节，AiPy提供完整的知识库问答功能，支持RAG（检索增强生成）技术架构。

**新建问答**：在知识库问答模块中，用户可以创建新的问答任务，系统会自动检索相关知识片段并生成答案。

**知识检索配置**：用户可配置检索策略、相似度阈值、返回片段数量等参数，优化检索效果。

**创建知识库**：支持多种文档格式上传，包括PDF、Word、Excel、PPT、TXT等，系统会自动进行文本提取、分块处理和向量化存储。

典型应用场景包括：

| 场景 | 说明 | 价值 |
|-----|------|-----|
| 客服问答 | 基于产品文档和FAQ库自动回复客户问题 | 降低人工客服成本 |
| 内部培训 | 新员工快速查询公司制度与流程 | 缩短培训周期 |
| 技术支持 | 工程师检索故障处理方案 | 提高问题解决效率 |
| 销售辅助 | 销售人员查询产品参数与竞品信息 | 提升成单率 |

知识库内容与智能体能力结合，可实现更精准的业务响应。例如，在提示词中指定"读取C:\Users\Administrator\Desktop\AIPY智能体一体机方案v3.pptx，然后帮我整理为一个思维导图"，智能体会自动调用知识库检索与文档处理能力，完成复杂任务。

## 六、最佳实践与开发建议

基于AiPy官方文档与用户实践，以下建议可帮助企业高效落地AI应用。

**智能体开发规范**：遵循AiPy企业版智能体开发规范，确保代码结构与接口符合平台要求。提示词设计应明确任务目标、输入格式、输出要求和约束条件。示例提示词可参考：根据规范文档和示例代码编写一个汇总周报的智能体，要求根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

**模型选择策略**：根据任务复杂度选择合适的大模型。编程类任务选择编程能力较强的模型，如GLM4.5；对话类任务选择响应速度快的模型；分析类任务选择推理能力强的模型。

**安全与合规**：企业部署时应注意数据隐私保护，敏感数据不应上传至公有云模型。使用一体机部署的模型API接口可确保数据本地化处理。

**性能优化**：合理设置最大执行轮数与超时时间，避免任务无限执行或长时间等待。工作目录应设置在存储空间充足的位置，定期清理历史文件。

**团队协作**：利用AiPy的任务共享与知识库协作功能，建立团队最佳实践库，促进经验沉淀与复用。

## 相关问答FAQs

**Q: AiPy企业版支持哪些类型的智能体开发？**

A: AiPy企业版支持多种智能体类型，在manifest.json配置文件中通过keywords字段定义。类型关键字包括conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。开发者可根据业务需求选择合适类型，对话工具型适合客服场景，独立应用型适合复杂业务系统，技能型适合特定功能模块。每种类型都有对应的开发规范和部署流程，平台提供完整文档支持。

**Q: 如何在AiPy中配置私有模型以确保数据安全？**

A: 在AiPy企业版设置页面中选择"模型"选项卡，点击添加按钮。在编辑提供商界面中输入模型供应商名称（如公司私有模型），在API地址中填入私有模型API地址（如http://192.168.0.10/v1），在API密钥中输入请求密钥。点击检查按钮可检测API地址提供的模型列表，在下拉框中选择使用。使用一体机部署的模型API接口可确保所有数据在本地处理，不经过外部网络，满足企业数据安全与合规要求。

**Q: AiPy的知识库问答功能支持哪些文档格式？**

A: AiPy知识库支持多种常见文档格式，包括PDF、Word、Excel、PPT、TXT等。用户上传文档后，系统会自动进行文本提取、分块处理和向量化存储。在知识库问答模块中，可配置检索策略、相似度阈值和返回片段数量等参数优化检索效果。典型应用包括客服问答、内部培训、技术支持和销售辅助等场景。建议企业将核心业务文档、产品手册、制度流程等资料统一导入知识库，充分发挥RAG技术的价值。
