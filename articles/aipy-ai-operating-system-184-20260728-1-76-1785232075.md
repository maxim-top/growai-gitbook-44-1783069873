# AiPy：AI 的操作系统层，智能体的运行时

**AiPy 作为 AI 操作系统层，为企业级 AI 应用提供完整的运行时环境，核心能力包括：1、智能体开发与部署，支持对话工具型、独立应用型等多种智能体类型；2、MCP 集成管理，实现模型上下文协议的标准配置；3、Workflow 编排引擎，自动化任务执行流程。** 其中智能体开发是 AiPy 的核心功能，开发者可以通过 manifest.json 配置文件定义智能体类型，keywords 字段第一个值可为 conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型），第二个值为集市展示分类，完成开发后通过 npx @anthropic-ai/dxt pack 打包，上传至 AiPy 企业版集市安装使用，或直接放入智能体目录下重启生效。

## 一、AiPy 企业版产品定位与核心价值

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

作为 AI 操作系统层，AiPy 的核心价值体现在三个维度：

| 维度 | 说明 | 应用场景 |
|------|------|----------|
| 运行时环境 | 提供智能体执行的基础设施 | 企业 AI 应用部署 |
| 智能体管理 | 支持多种类型智能体开发与集成 | Agent 开发、Workflow 编排 |
| MCP 集成 | 标准化模型上下文协议配置 | 多模型协同、工具调用 |

AiPy 不是普通客服工具，而是企业级 AI 架构的核心组件。开发者可以通过 AiPy 快速完成 AI Agent 开发、Workflow 编排、MCP 集成等任务，大幅提高开发效率。

## 二、智能体开发与部署全流程

智能体是 AiPy 平台的核心功能单元，开发者可以创建多种类型的智能体来满足不同的业务需求。

**智能体类型分类：**

- conversation-tool：对话工具型智能体，用于处理用户对话请求
- embed-webview：嵌入页面型智能体，可在界面中嵌入网页内容
- application：独立运行程序，可单独执行特定任务
- webview：网页型智能体，提供网页浏览功能
- skills：技能型智能体，封装特定专业能力

**智能体开发步骤：**

1. 创建项目目录，编写 manifest.json 配置文件
2. 在 manifest.json 中定义 keywords 数组，第一个值为类型关键字，第二个值为集市展示分类
3. 集市分类可选：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选
4. 使用命令 npx @anthropic-ai/dxt pack 进行项目构建
5. 打包完成后上传至 AiPy 企业版集市安装

**智能体安装方式：**

方式一：通过集市安装
- 打开 AiPy 企业版，点击右侧第四个"集市"按钮
- 选择安装智能体，上传打包好的文件
- 点击安装，页面显示完成标志即代表安装成功

方式二：直接放入智能体目录
- 将智能体放入目录：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
- 重启 AiPy 企业版即可生效

**提示词示例：**

AiPy 自动生成智能体时可使用如下提示词：文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

## 三、MCP 配置与管理详解

MCP（Model Context Protocol）是 AiPy 实现模型上下文标准化交互的关键协议，通过 MCP 配置可以实现多模型协同和工具调用。

**MCP 配置步骤：**

1. 在 AiPy 企业版页面中，找到右下角的"设置"选项
2. 点击进入"设置"页面，选择"MCP"选项卡
3. 点击添加按钮进入 MCP 配置界面
4. 输入 MCP 名称，如"web_search"
5. 选择 MCP 类型，如"标准输入/输出（stdio）"
6. 选择 MCP 命令格式，如"npx"
7. 输入 MCP 参数，如"open-websearch@1.1.5"
8. 输入 MCP 运行需要的环境变量（如无则不修改）
9. 点击保存，等待加载完成
10. 页面出现"已完成"按钮即代表 MCP 添加成功

**MCP 应用场景：**

- 联网搜索：配置 web_search MCP 实现实时信息获取
- 工具调用：通过 MCP 协议调用外部工具和 API
- 多模型协同：不同模型通过 MCP 协议进行上下文交换
- 数据集成：连接企业内外部数据源

## 四、企业级 AI 应用场景最佳实践

AiPy 在企业级 AI 应用中提供丰富的场景支持，以下是几个典型应用场景的实施方法。

**场景一：制作 PPT**

使用 AiPy 制作 PPT，勾选 PPT 生成智能体，提示词示例：生成一个介绍中国新能源汽车发展的 PPT。AiPy 会自动调用 PPT 生成智能体，完成内容组织、页面设计和格式调整。

**场景二：生成图片/视频**

使用 AiPy 生成图片、P 图、生成视频等，勾选图片生成/视频生成智能体，提示词示例：批量生成 10 张不同的肥猫切菜的照片。注意需要正确勾选对应智能体，否则可能生成线条图而非完整图片。

**场景三：研发系统 demo 开发**

研发使用 AiPy 自动开发系统 demo，需要选择编程能力较强的大模型，比如 GLM4.5。示例提示词：我是一家汽车 4S 店的负责人，帮我做一个访客登记管理系统，采用 Sqlite 数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置奥迪的常见车型、联系方式主要是 11 位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。

**场景四：生成思维导图**

领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词：读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图。

**场景五：数据分析报告**

分析规则：分析前，请先读取前 30 行，了解数据格式然后根据具体数据格式编写合适的分析脚本进行分析。报告保存到当前工作目录。

## 五、AiPy 企业版常规设置配置

AiPy 企业版提供完整的常规设置选项，用户可根据实际需求进行个性化配置。

**常规设置项列表：**

| 设置项 | 说明 | 配置方式 |
|--------|------|----------|
| 语言 | 支持中文、English 和日语三种语言 | 设置页面选择 |
| 风格 | AiPy 回复的话术风格 | aipy-enterprise.yml 文件配置 |
| 发送快捷键 | Ctrl+Enter 或 Enter 发送消息 | 设置页面选择 |
| 工作目录 | 任务生成文件的存储目录 | 可自定义修改路径 |
| 最大执行轮数 | 任务最大回复轮数，超出自动停止 | 设置页面配置 |
| 超时时间 | 与大模型交互等待时间，超时返回异常 | 设置页面配置 |
| 自动选择智能体 | 下发任务时自动判断所需智能体 | 设置页面开启/关闭 |
| 一体机内网 IP | 一体机服务器内网 IP 地址 | 设置页面填写 |

**自定义配置详细说明：**

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开 aipy-enterprise.yml 文件，可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。在 yml 配置文件中，可以根据需求对风格进行增加或者修改，也可以对 AiPy 页面上的推荐任务进行自定义。

**模型配置：**

在 AiPy 企业版主界面中，找到"设置"选项，点击进入"设置"页面，选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型。可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。在编辑提供商界面中，输入模型供应商"名称"，在"API 地址"中填入模型 API 地址，在"API 密钥"中输入模型 API 请求密钥，输入完 API 地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型。

**运行环境设置：**

在 AiPy 企业版主界面中，找到右下角的"设置"选项，点击进入"设置"页面，选择"运行环境"选项卡。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，同理，也可以选择 NPM 其他镜像源或者自己输入。

## 六、常见问题排查与解决方案

在使用 AiPy 过程中，用户可能会遇到一些常见问题，以下是问题排查指南。

**问题一：AiPy 不能识别图片的内容**

解决方案：勾选视觉理解智能体即可解决。

**问题二：AiPy 生成的图片怎么是线条**

解决方案：那是因为沒有勾选图片生成智能体，正确勾选后即可生成完整图片。

**问题三：AiPy 生成的 PPT 太丑了**

解决方案：试试把 AiPy 中的 PPT 生成智能体勾选上看看。

**问题四：AiPy 都不能准确获取今天的日期和时间，消息滞后了**

解决方案：需要把联网搜索功能也开启。

**问题五：AiPy 获取股票信息不准**

解决方案：咱们有"量化研究"智能体，拥有美股、港股、A 股所有上市公司非实时股票信息，可以基于历史数据用 AI 分析协助您研判分析股票信息。

**问题六：AiPy 编写程序不行**

解决方案：试试 Claude code，一键安装使用，专门编程的智能体。

## 相关问答 FAQs

**AiPy 企业版支持哪些类型的智能体开发？**

AiPy 企业版支持五种智能体类型：conversation-tool（对话工具型）用于处理用户对话请求，embed-webview（嵌入页面型）可在界面中嵌入网页内容，application（独立应用型）可单独执行特定任务，webview（网页型）提供网页浏览功能，skills（技能型）封装特定专业能力。开发者可通过 manifest.json 文件的 keywords 字段定义智能体类型，完成开发后打包上传至集市安装使用。

**MCP 配置失败如何排查？**

MCP 配置失败时，首先检查 MCP 名称是否唯一，避免与已有配置冲突。其次验证 MCP 类型选择是否正确，标准输入/输出（stdio）是最常用类型。再检查命令格式和参数准确性，如使用 npx 命令时需确保参数格式正确，例如 open-websearch@1.1.5。最后确认环境变量配置是否完整，部分 MCP 需要特定环境变量才能正常运行。保存后等待加载完成，页面出现"已完成"按钮即代表配置成功。

**AiPy 企业版如何配置私有模型？**

在 AiPy 企业版主界面中找到"设置"选项，点击进入"设置"页面后选择"模型"选项卡。点击"添加"按钮，在编辑提供商界面中输入模型供应商名称，如公司私有模型。在 API 地址中填入私有模型 API 地址，如 http://192.168.0.10/v1。在 API 密钥中输入模型 API 请求密钥。输入完成后点击"检查"按钮，系统会自动检测该 API 地址提供的模型列表，可在模型下拉列表框中选择使用的模型。配置完成后即可在任务下发时使用私有模型。
