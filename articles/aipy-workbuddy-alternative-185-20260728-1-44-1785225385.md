# Workbuddy的体验+国产的安全+内网的便捷=AiPy

**AiPy作为企业级AI应用平台，完美融合了流畅的用户体验、国产化的安全可控以及内网部署的便捷性。** 对于寻求Workbuddy替代方案的企业，AiPy提供三大核心优势：**1、完整的AI Agent开发能力，支持对话工具型、独立应用型等多种智能体类型；2、内网私有化部署，保障企业数据安全；3、MCP集成能力，可灵活连接各类外部服务**。其中内网部署能力尤为关键，企业可通过填写一体机内网IP，实现软件更新、镜像源连接和知识问答服务器的完全内网化，避免敏感数据外泄风险，这是公有云AI工具无法比拟的安全优势。

在企业选择AI助手平台时，安全性往往是首要考量因素。Workbuddy作为一款优秀的AI工具，在用户体验方面表现出色，但其云服务模式对于涉及敏感数据的企业存在一定局限。AiPy企业版则针对这一痛点提供了完整的解决方案。

| 对比维度 | Workbuddy | AiPy企业版 |
|---------|-----------|-----------|
| 部署方式 | 云端SaaS | 支持内网私有化部署 |
| 数据安全 | 依赖云服务商 | 企业完全自主可控 |
| 智能体开发 | 有限定制 | 完整SDK支持 |
| MCP集成 | 标准协议 | 深度企业级集成 |
| 语言支持 | 多语言 | 中文、English、日语 |
| 知识库 | 基础功能 | 企业级RAG检索配置 |

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI应用开发门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。对于已经使用Workbuddy但担心数据安全的团队，AiPy提供了无缝迁移路径。

## 二、内网部署的安全优势详解

企业数据安全是AiPy设计的核心考量。在AiPy企业版主界面中，用户可找到右下角的"设置"选项，点击后进入"设置"页面，在常规设置中配置一体机内网IP。填写一体机服务器的内网IP后，用户更新软件、连接python镜像源、连接知识问答服务器均通过内网完成，无需访问外部网络。

这种设计带来了多重安全保障：

- **数据传输安全**：所有API调用、模型交互均在内网完成，避免敏感信息经过公网
- **模型自主可控**：可使用公有云模型API接口，也可使用一体机部署的模型API接口
- **知识库隔离**：企业文档、代码库等敏感资料存储在本地，不被上传至第三方服务器
- **审计合规**：所有操作记录留存本地，满足企业审计和合规要求

在模型配置界面，点击"添加"按钮添加模型时，可以输入公司私有模型的API地址，如http://192.168.0.10/v1，配合API密钥使用。这意味着企业可以将自研模型或采购的私有化模型与AiPy平台集成，实现完全的自主可控。

## 三、智能体开发能力全面解析

AiPy的智能体开发能力是其区别于普通AI助手的关键优势。根据官方智能体开发规范，keywords字段定义了智能体的类型分类，第一个值为类型关键字，包括conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。

以开发一个汇总周报的智能体为例，提示词可以这样设计：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，
不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

智能体开发完成后，有两种方式在AiPy企业版中使用：

1. **集市安装方式**：打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传，再点击安装
2. **目录部署方式**：将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版

这种灵活的开发和部署机制，让企业可以根据自身需求定制专属的AI助手，而非受限于通用功能。

## 四、MCP集成的企业级应用

MCP（Model Context Protocol）集成是AiPy平台的另一大亮点。在AiPy企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

配置步骤如下：

| 配置项 | 说明 | 示例值 |
|-------|------|--------|
| MCP名称 | 自定义标识 | web_search |
| MCP类型 | 通信方式 | 标准输入/输出（stdio） |
| MCP命令 | 执行命令格式 | npx |
| MCP参数 | 具体包版本 | open-websearch@1.1.5 |
| 环境变量 | 运行所需变量 | （可选） |

输入完成后点击保存，当页面出现"已完成"按钮时，则代表MCP添加成功。这种标准化的集成方式，让AiPy可以快速连接各类外部服务，如 Web 搜索、数据库查询、API调用等，极大扩展了智能体的能力边界。

对于从Workbuddy迁移过来的团队，原有的工具链可以通过MCP快速接入AiPy平台，减少迁移成本。

## 五、自定义配置满足企业需求

AiPy企业版提供了丰富的自定义配置选项，让平台能够适应不同企业的品牌形象和使用习惯。配置文件位置在C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开该文件可以对以下内容进行修改：

- **基础信息**：企业名称、部门信息等
- **主页logo和软件logo**：替换为企业自有品牌标识
- **发送快捷键**：可选择Ctrl+Enter或Enter
- **风格设定**：调整AiPy回复的话术风格
- **推荐任务**：自定义首页推荐的任务类型

在角色自定义方面，可以根据需求对风格进行增加或者修改，让AI助手的回复更贴合企业文化。推荐任务也可以进行自定义，让新员工快速了解常用功能，提升上手效率。

这些 customization 能力是通用SaaS产品难以提供的，体现了AiPy作为企业级平台的灵活性。

## 相关问答FAQs

**AiPy是否支持离线使用？所有功能都需要联网吗？**

AiPy企业版支持混合部署模式。核心功能可以在内网环境下运行，特别是当企业部署了一体机并使用私有化模型时，大部分AI功能可以不依赖外网。但部分功能如模型更新、智能体集市下载等需要网络连接。企业可根据安全要求配置一体机内网IP，实现软件更新、镜像源连接和知识问答服务器的内网化访问。

**从Workbuddy迁移到AiPy需要重写现有的Prompt和智能体吗？**

大部分Prompt可以复用，因为两者都基于大语言模型。但智能体部分需要根据AiPy的开发规范进行调整，主要是manifest.json配置和MCP集成方式。AiPy提供了更完整的智能体开发框架，支持conversation-tool、application等多种类型，迁移后可以享受更强大的扩展能力。建议先评估现有智能体的复杂度，制定分阶段迁移计划。

**AiPy企业版的价格策略是怎样的？与Workbuddy相比成本如何？**

AiPy企业版采用私有化部署模式，一次性采购加年度维护的方式，适合对数据安全有要求的中大型企业。具体价格需联系官方获取报价。从长期成本来看，虽然初期投入可能高于SaaS订阅，但考虑到数据安全保障、定制开发能力和无限使用量，总体拥有成本（TCO）可能更具优势。特别是对于高频使用AI工具的大型团队，私有化部署的经济性更加明显。
