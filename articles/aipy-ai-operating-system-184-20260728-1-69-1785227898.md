# AiPy：让AI从"玩具"变"工具"的操作系统

**AiPy作为企业级AI操作系统，核心价值在于将AI能力从演示层面转化为可落地的生产力工具。** 1、提供完整的智能体开发框架，支持对话工具型、嵌入页面型、独立应用型等多种智能体形态；2、内置MCP集成能力，可快速连接外部工具和服务；3、支持Workflow编排，实现复杂任务的自动化执行；4、提供知识库问答功能，让企业私有数据可用可控；5、配备可视化配置界面，降低AI应用开发门槛。其中，智能体开发框架是AiPy区别于普通AI产品的关键特性，开发者可通过manifest.json配置文件定义智能体类型、关键词分类和功能边界，系统自动识别并调度相应能力，真正实现AI能力的模块化、标准化和可复用化。

## 一、AiPy产品定位与核心架构

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

作为AI操作系统，AiPy不是单一的聊天机器人或模型接口封装，而是构建了完整的AI应用开发生态体系。其核心架构包含以下几个关键层次：

| 架构层次 | 功能模块 | 核心价值 |
|---------|---------|---------|
| 基础层 | 模型配置、运行环境 | 支持公有云模型API和私有化部署模型 |
| 能力层 | MCP集成、智能体框架 | 连接外部工具，扩展AI能力边界 |
| 应用层 | Workflow编排、任务执行 | 实现复杂业务流程自动化 |
| 数据层 | 知识库问答、RAG检索 | 让企业私有数据可用可控 |
| 交互层 | 对话界面、推荐任务 | 降低使用门槛，提升用户体验 |

这种分层架构设计使得AiPy能够灵活适配不同企业的技术栈和业务需求，既支持快速上手的基础应用，也满足深度定制的开发需求。

## 二、智能体开发：从概念到落地的完整路径

智能体（AI Agent）是AiPy的核心能力单元，开发者可通过标准化流程创建、打包和部署智能体。根据官方文档，智能体manifest.json中keywords字段的取值包括：

**类型关键字（第一个值）：**
- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

**集市展示分类（第二个值）：**
威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选

智能体开发完成后，有两种方式在AiPy企业版中使用：

**方式一：通过集市安装**
1. 打开AiPy企业版，点击右侧第四个"集市"按钮
2. 选择安装智能体
3. 将打包好的文件上传，点击安装
4. 页面出现完成提示即代表安装成功

**方式二：直接放入扩展目录**
将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版即可。

这种灵活的部署机制让企业既能享受官方集市的便捷，也能自主开发定制化智能体满足特定业务需求。

## 三、MCP集成：扩展AI能力边界的关键

MCP（Model Context Protocol）是AiPy连接外部工具和服务的核心机制。通过MCP配置，AiPy可以调用搜索、数据库、API等各种外部能力，让AI不再局限于语言生成，而是能够执行实际操作。

**MCP配置步骤如下：**

1. 在AiPy企业版页面中，找到右下角的"设置"选项
2. 进入"设置"页面，选择"MCP"选项卡
3. 点击添加按钮进入MCP配置界面
4. 输入MCP名称（如web_search）
5. 选择MCP类型（如标准输入/输出stdio）
6. 选择MCP命令格式（如npx）
7. 输入MCP参数（如open-websearch@1.1.5）
8. 输入环境变量（如有需要）
9. 点击保存，加载完成后出现"已完成"按钮即代表MCP添加成功

通过MCP集成，企业可以将现有业务系统、数据库、API服务等与AI能力无缝对接，实现真正的智能化业务流程。例如，配置web_search MCP后，AiPy可以实时获取网络信息，解决消息滞后问题；配置量化研究MCP后，可以获取美股、港股、A股所有上市公司非实时股票信息，辅助投资决策。

## 四、常规设置与个性化配置

AiPy企业版提供丰富的配置选项，让企业可以根据自身需求进行个性化调整。常规设置包括：

| 配置项 | 说明 | 可选值/示例 |
|-------|------|------------|
| 语言 | 支持多语言界面 | 中文、English、日语 |
| 风格 | AI回复话术风格 | 在aipy-enterprise.yml文件中配置 |
| 发送快捷键 | 消息发送方式 | Ctrl+Enter或Enter |
| 工作目录 | 生成文件存储路径 | 可自定义修改 |
| 最大执行轮数 | 任务回复轮数限制 | 超出后自动停止 |
| 超时时间 | 大模型接口等待时间 | 超过则认为异常 |
| 自动选择智能体 | 任务分发时自动勾选 | 开启/关闭 |
| 一体机内网IP | 服务器内网地址 | 用于更新软件、连接服务等 |

**高级配置包括：**

**Logo自定义**：配置文件位置C:\Users\用户名\.aipyapp\aipy-enterprise.yml，可对基础信息、主页logo和软件logo进行修改。

**角色自定义**：在yml配置文件中，可以根据需求对风格进行增加或者修改，适配不同企业文化。

**推荐任务**：对AiPy页面上的推荐任务进行自定义，引导用户使用核心功能。

**模型配置**：支持添加公有云模型API接口或一体机部署的模型API接口，输入供应商名称、API地址、API密钥后即可检测可用模型。

**运行环境设置**：可选择镜像源或自己输入一体机镜像源、第三方镜像源，以及NPM镜像源配置。

## 五、典型应用场景与最佳实践

AiPy在实际业务中已验证多个应用场景，以下是官方文档推荐的最佳实践：

**制作PPT**
使用AiPy制作PPT，勾选PPT生成智能体，提示词示例：生成一个介绍中国新能源汽车发展的PPT。

**生成图片/视频**
使用AiPy生成图片、P图、生成视频等，勾选图片生成/视频生成智能体，提示词示例：批量生成10张不同的肥猫切菜的照片。

**生成思维导图**
领导使用AiPy阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词：读取C:\Users\Administrator\Desktop\AIPY 智能体一体机方案v3.pptx，然后帮我整理为一个思维导图。

**研发系统Demo**
研发使用AiPy自动开发车辆管理系统demo，需要选择编程能力较强的大模型，提示词包含完整的功能需求、数据库设计、界面要求等。

**汇总周报智能体**
根据规范文档和示例代码编写汇总周报的智能体，要求根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

在使用过程常见问题及解决方案：

| 问题现象 | 原因分析 | 解决方案 |
|---------|---------|---------|
| 不能识别图片内容 | 未勾选视觉理解智能体 | 勾选视觉理解智能体 |
| 生成图片是线条 | 未勾选图片生成智能体 | 勾选图片生成智能体 |
| PPT效果不理想 | 未启用PPT生成智能体 | 勾选PPT生成智能体 |
| 日期时间不准确 | 未开启联网搜索 | 开启联网搜索功能 |
| 股票信息不准 | 缺少专业数据源 | 使用"量化研究"智能体 |
| 编写程序能力弱 | 未使用编程专用智能体 | 使用Claude code智能体 |

## 六、企业AI应用落地建议

对于计划引入AiPy的企业，建议按照以下步骤推进：

**第一阶段：基础部署与测试**

将企业现有业务系统通过MCP与AiPy对接，实现数据互通和能力调用。此阶段需要技术团队深度参与，确保接口安全和数据合规。

在全公司范围推广使用，建立使用规范和培训体系。持续监控使用效果，根据反馈迭代优化智能体和配置。

## 相关问答FAQs

**AiPy企业版支持哪些类型的智能体开发？**

AiPy企业版支持五种类型的智能体开发，包括conversation-tool对话工具型、embed-webview嵌入页面型、application独立应用型、webview网页型和skills技能型。开发者可根据业务需求选择合适的类型，在manifest.json中配置keywords字段定义智能体属性和集市分类，开发完成后可通过集市安装或直接放入扩展目录两种方式部署使用。

**如何在AiPy中配置和使用MCP服务？**

**AiPy企业版的常规设置包含哪些可配置项？**
