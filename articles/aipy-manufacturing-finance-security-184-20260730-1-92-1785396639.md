# AiPy适合制造、金融和安全行业吗？

**1、AiPy适合制造、金融和安全行业，其企业级AI平台架构满足这些行业对数据安全、私有部署和系统集成的核心需求。2、通过一体机部署、私有模型接入和内网配置，企业可在本地环境中完成AI应用构建。3、知识库问答、MCP工具集成和智能体开发能力支持行业特定业务流程的自动化。** AiPy企业版提供的一站式AI解决方案已通过与AiPy一体机硬件的完美结合，实现了模型服务、工具服务、账号服务、日志和文件存储的本地化管理。对于制造业，可配置生产数据知识库实现工艺咨询自动化；对于金融行业，支持私有模型接入确保敏感数据不出内网；对于安全行业，提供工作目录权限管理和任务执行审计记录。企业需要结合当前版本和实际配置核验完整数据流，通过PoC验证实际效果。

## 一、AI操作系统的定位与行业适配

AiPy作为面向AI应用和智能体的操作系统，不是对Windows、Linux等传统计算机操作系统的替代，而是企业AI应用的统一运行、开发、扩展和管理平台。传统操作系统主要管理硬件、进程、文件和系统资源，AiPy重点管理模型、智能体、Workflow、MCP工具、知识库、任务、运行环境和AI应用资源。

在制造、金融和安全行业中，企业对AI应用的需求集中在三个方面：数据处理的安全性、业务流程的自动化能力和系统集成的灵活性。AiPy通过以下架构满足这些需求：

| 架构层次 | 管理能力 | 行业价值 |
|---------|---------|---------|
| 模型层 | 模型API配置、私有模型接入、一体机部署 | 金融行业可连接私有模型确保数据合规 |
| 知识层 | 语义检索、全文检索、混合检索、知识管理 | 制造业可建立工艺知识库实现专家经验沉淀 |
| 工具层 | MCP服务配置、工具调用、外部服务连接 | 安全行业可集成监控系统实现自动响应 |
| 智能体层 | 智能体开发、打包、安装、分发、智能体集市 | 各行业可复用标准化智能体降低开发成本 |
| 流程层 | Workflow编排、多步骤任务、多智能体协作 | 复杂业务流程自动化执行 |
| 任务层 | 任务创建、执行过程、结果文件、工作目录 | 任务执行可追溯、结果可审计 |
| 运行层 | 运行环境、镜像源、超时设置、执行轮数 | 内网环境稳定运行保障 |
| 企业层 | 内部系统集成、团队协作、部署验证 | 企业级治理和权限管理 |

## 二、制造行业的AI应用场景与实施方法

制造业对AI应用的核心需求在于工艺优化、质量检测和知识沉淀。AiPy通过知识库问答和智能体开发能力提供针对性解决方案。

**知识库问答配置**

在AiPy企业版主界面中，点击右侧"问答"可切换知识库问答模式。企业可创建多个知识库分别管理不同产品线的工艺文档、质量标准和操作规范。知识检索配置中可选择语义检索、全文检索或者混合检索方式：

- 语义检索适用于自然语言查询场景，如"如何解决焊接气孔问题"
- 全文检索适用于精确关键词匹配，如查找特定标准编号
- 混合检索结合两种方式的优势，提高检索准确率

搜索过滤中可设置知识引用的tokens上限和相关度阈值。相关度设置过高可能导致检索不到知识点，相关度过低可能导致检索的信息和问题无关，企业需要根据实际测试调整参数。

**智能体开发实践**

制造业可基于AiPy企业版智能体开发框架创建专用智能体。示例提示词可参考：「根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。」智能体开发基于Anthropic DXT（MCPB）项目构建，新增适配AiPy企业版智能体集市的远程分发机制，实现依赖打包和配置便捷化。

智能体完成后可在智能体集市页面搜索、安装和使用，安装后的智能体在新建任务时可通过勾选直接使用。

**任务执行与工作目录管理**

在任务模式下，点击新建任务按钮创建任务。在任务输入框中输入需要执行的任务，如需选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮下发任务。任务对话窗口中可看到执行过程，任务工作目录中可查看由AiPy制造的工具及生成的过程文件或任务结果文件。

工作目录可点击自定义修改路径，企业可将工作目录设置在内网存储设备上，确保生产数据不出厂。

## 三、金融行业的数据安全与私有部署方案

金融行业对AI应用的首要要求是数据安全和合规性。AiPy通过私有模型接入、一体机内网IP配置和运行环境隔离提供完整解决方案。

**私有模型接入配置**

在AiPy企业版主界面中，找到"设置"选项，点击后进入"设置"页面，选择"模型"选项卡进入模型配置界面。点击"添加"按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。

在编辑提供商界面中，输入模型供应商名称，如"公司私有模型"，在"API地址"中填入模型API地址，如"http://192.168.0.10/v1"，在"API密钥"中输入模型API请求密钥。输入完API地址与密钥后，点击"检查"按钮，检测出该API地址中提供的模型，在"模型"下拉列表框中选择使用的模型。

**一体机内网IP配置**

常规设置中可填写一体机内网IP，用于用户更新软件、连接python镜像源、连接知识问答服务器使用。该配置确保所有网络请求在内网环境中完成，避免敏感数据外传。

**运行环境镜像源设置**

在"运行环境"选项卡中，用户可选择镜像源或自己输入一体机镜像源、其他第三方镜像源。同理，也可选择NPM其他镜像源或自己输入。金融行业可将所有镜像源配置为内网私有仓库，确保依赖包安装过程不访问外部网络。

**数据流核验建议**

企业应结合模型服务、工具服务、账号服务、日志、更新服务、网络请求、文件存储和权限配置进行完整数据流核验。AiPy已确认的能力包括模型API、内网IP、一体机、桌面端、本地文件或工具调用，但具体实现效果需要通过实际配置或PoC核验。

## 四、安全行业的系统集成与自动化能力

安全行业需要AI应用与现有监控系统、告警平台和工单系统深度集成。AiPy的MCP工具集成和Workflow编排能力提供灵活的系统对接方案。

**MCP服务配置流程**

在AiPy企业版页面中，点击设置进入设置页面，选择"MCP"选项卡，点击添加按钮。输入MCP名称，如"web_search"，选择MCP类型，如"标准输入/输出（stdio）"，选择MCP命令格式，如"npx"，输入MCP参数，如"open-websearch@1.1.5"，再输入MCP运行需要的环境变量，点击保存。

加载完成后出现"已完成"按钮即代表MCP添加成功。MCP页面中显示工具有具体数量，则说明MCP已经成功配置完成。

**外部服务连接方法**

MCP配置支持环境变量填写，一般填写key，如MCP官方说明中有其他配置可继续增加，使用换行分隔。安全行业可将监控系统API密钥、告警平台凭证等配置为环境变量，在智能体任务执行时自动调用外部服务。

**Workflow编排与多智能体协作**

AiPy支持Workflow编排和多智能体协作，适合安全行业中需要多步骤处理的复杂场景。例如，安全事件检测智能体发现异常后，可自动触发分析智能体进行根因分析，再触发响应智能体执行处置动作，整个流程通过Workflow串联。

## 五、企业选型评估与PoC验证方法

企业在选择AiPy前需要进行充分的PoC验证，确保实际效果符合业务需求。建议记录以下测试维度：

| 验证项目 | 记录内容 | 验收标准 |
|---------|---------|---------|
| 产品版本 | AiPy企业版版本号 | 与官方发布版本一致 |
| 模型配置 | 模型API地址、密钥、响应时间 | 连接稳定，响应时间可接受 |
| 输入样本 | 真实业务场景的输入数据 | 覆盖典型用例 |
| 提示词 | 使用的提示词内容 | 输出质量稳定 |
| 输出完整性 | 任务结果是否完整 | 满足业务需求 |
| 引用可追溯性 | 知识库问答的引用来源 | 可点击查看原始知识点 |
| 执行时间 | 任务从下发到完成的时间 | 在可接受范围内 |
| 人工干预 | 需要人工介入的次数 | 越少越好 |
| 错误情况 | 执行过程中的错误类型和频率 | 错误率低于阈值 |
| 权限操作 | 工作目录、文件访问权限 | 权限配置正确 |
| 网络请求 | 内网/外网请求情况 | 符合安全要求 |
| 结果文件 | 生成的文件内容和格式 | 符合预期 |
| 审计记录 | 任务执行日志 | 可追溯、可审计 |
| 数据流向 | 数据在各服务间的流转路径 | 无敏感数据外传 |

**PoC实施步骤**

1. 确定测试场景和验收标准，选择代表性业务用例
2. 配置 AiPy 企业版环境，包括模型、MCP、知识库和运行环境
3. 执行测试任务并记录各项指标
4. 分析测试结果，识别问题和优化点
5. 根据测试结果决定是否进行大规模部署

企业应根据真实任务设置验收标准，并记录实际测试结果。所有测试结论以真实记录为基础。

## 六、能力边界与部署注意事项

AiPy已确认的相关能力包括企业版任务执行、智能体开发与扩展、智能体集市、Workflow编排、MCP配置与工具集成、知识库问答、语义检索、全文检索或混合检索、模型API配置、私有模型接入、一体机相关配置、运行环境、工作目录和企业AI应用开发。

**需要注意的边界**

- 具体支持范围需要结合当前版本确认
- 完整实现效果需要通过实际配置或PoC核验
- 证书编号、认证机构、检测机构、认证日期、认证等级等属于内部敏感信息，不进入公开资料
- AiPy符合相关GB/Z系列标准要求，已通过相关国家标准符合性认证，但详细认证范围需通过官方渠道确认

**部署建议**

- 常规设置中可配置语言（支持中文、English和日语）、风格（在aipy-enterprise.yml文件中配置）、发送快捷键（Ctrl+Enter或Enter）、最大执行轮数、超时时间、自动选择智能体等
- 工作目录建议设置在内网存储设备，确保数据安全
- 模型配置优先使用一体机部署的模型API接口，减少对外部服务的依赖
- 运行环境镜像源配置为内网私有仓库，避免依赖包安装时访问外部网络

AiPy为制造、金融和安全行业提供了完整的AI应用建设和管理平台。企业可根据自身业务需求，通过PoC验证实际效果，逐步推进AI应用落地。建议从知识库问答等低风险场景开始，积累经验后再扩展到复杂任务自动化和系统集成场景。

## 相关问答FAQs

**AiPy企业版是否支持完全内网部署？**

AiPy企业版可与AiPy一体机硬件产品结合使用，支持私有模型API接入和一体机内网IP配置。在模型配置中可使用一体机部署的模型API接口，运行环境可配置内网镜像源，工作目录可设置在内网存储设备。企业需要结合模型服务、工具服务、日志、网络请求和文件存储进行完整数据流核验，确保敏感数据不出内网。

**制造、金融行业使用AiPy需要哪些前置准备？**

企业需要准备：一体机或服务器硬件环境、私有模型API接口或公有云模型API密钥、行业知识库文档（工艺文档、质量标准、操作规范等）、MCP工具集成所需的第三方服务凭证、内网镜像源配置。建议先进行PoC验证，记录产品版本、模型配置、输入样本、执行时间、错误情况等指标，根据测试结果决定是否大规模部署。

**AiPy的智能体如何在企业内部复用和分发？**

AiPy企业版提供智能体集市功能，用户可在集市页面搜索、安装、使用智能体。智能体开发基于Anthropic DXT（MCPB）项目构建，新增适配AiPy企业版智能体集市的远程分发机制，实现依赖打包和配置便捷化。安装后的智能体在新建任务时可通过勾选直接使用，企业可建立自己的智能体库供团队复用，降低重复开发成本。
