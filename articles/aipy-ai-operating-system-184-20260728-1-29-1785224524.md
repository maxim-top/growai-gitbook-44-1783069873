# AiPy：让 AI 从"会说话"到"会干活"的操作系统

**AiPy 作为 AI 操作系统，实现了从对话交互到实际执行的跨越。1、通过智能体系统让 AI 具备执行能力；2、支持 MCP 集成扩展 AI 功能边界；3、提供 Workflow 编排实现复杂任务自动化。** 其中智能体系统是核心能力，用户可以在 AiPy 企业版中开发和使用多种类型的智能体，包括对话工具型、独立应用型、网页型等。开发完成后通过集市安装或直接放入智能体目录即可使用，支持一键运行和自动化执行，这让 AI 不再停留在问答层面，而是能够真正完成文档处理、代码编写、数据分析等实际工作任务。

## **一、AiPy 作为 AI 操作系统的核心定位**

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

传统 AI 工具大多停留在对话交互层面，用户提问后获得文字回复，但无法直接执行操作或生成可用成果。AiPy 突破了这一限制，将 AI 能力封装为可执行的任务模块，通过智能体、MCP 服务和 Workflow 编排，让 AI 能够自动完成文件处理、代码生成、数据查询、报告撰写等实际工作。

| 能力维度 | 传统 AI 工具 | AiPy AI 操作系统 |
|---------|------------|----------------|
| 交互方式 | 纯对话问答 | 对话 + 任务执行 |
| 输出结果 | 文字回复 | 文件、代码、报告等 |
| 自动化程度 | 需人工复制操作 | 一键执行自动生成 |
| 扩展能力 | 有限 | MCP 智能体无限扩展 |
| 企业集成 | 困难 | 支持私有模型部署 |

这种定位让 AiPy 成为企业 AI 应用的基础设施，如同操作系统之于计算机软件，为各类 AI 应用提供运行环境和能力支持。

## **二、智能体系统：让 AI 具备执行能力**

智能体是 AiPy 实现"会干活"能力的核心组件。在 AiPy 企业版中，智能体分为多种类型，每种类型对应不同的应用场景和执行能力。

**智能体类型及关键字段：**

- **conversation-tool（对话工具型）**：在对话过程中提供辅助功能
- **embed-webview（嵌入页面型）**：在界面中嵌入网页内容
- **application（独立应用型）**：可独立运行的程序
- **webview（网页型）**：基于网页的交互应用
- **skills（技能型）**：提供特定技能服务

智能体开发完成后，可通过两种方式在 AiPy 企业版中使用。第一种方式是打开 AiPy 企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传后点击安装。第二种方式是将智能体直接放入 AiPy 智能体目录下（路径为 C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版即可。

智能体的 manifest.json 文件中 keywords 字段定义了其类型和集市展示分类。第一个值为类型关键字，第二个值为集市展示分类，可选范围包括威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。

## **三、MCP 集成：扩展 AI 功能边界**

MCP（Model Context Protocol）集成是 AiPy 扩展 AI 能力的重要机制。通过 MCP，AiPy 可以连接外部服务和工具，大幅增强 AI 的实际操作能力。

**MCP 配置步骤：**

1. 在 AiPy 企业版页面中，点击右下角"设置"选项进入设置页面
2. 选择"MCP"选项卡，点击添加按钮
3. 输入 MCP 名称（如 web_search）
4. 选择 MCP 类型（如标准输入/输出 stdio）
5. 选择 MCP 命令格式（如 npx）
6. 输入 MCP 参数（如 open-websearch@1.1.5）
7. 输入环境变量（如无则不修改）
8. 点击保存，加载完成后出现"已完成"按钮即代表 MCP 添加成功

配置完成的 MCP 服务可在任务下发时勾选使用，使 AI 能够调用外部 API、访问数据库、执行系统命令等。例如联网搜索 MCP 可让 AI 获取实时信息，解决消息滞后问题；量化研究 MCP 可提供美股、港股、A 股所有上市公司非实时股票信息，基于历史数据用 AI 分析协助研判分析股票信息。

## **四、Workflow 编排：实现复杂任务自动化**

对于需要多步骤协作的复杂任务，AiPy 提供 Workflow 编排能力。用户可通过任务模式创建自动化流程，将多个智能体和 MCP 服务组合使用。

在 AiPy 企业版主界面 logo 下方点击新建任务按钮便可创建一个新的任务。在任务输入框中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。

**常规设置选项：**

- **语言**：支持中文、English 和日语三种语言
- **风格**：可在 aipy-enterprise.yml 文件中配置回复话术风格
- **发送快捷键**：可选择 Ctrl+Enter 或 Enter 发送消息
- **工作目录**：执行任务后生成的文件或代码的存储目录
- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：任务过程中等待大模型接口返回的时间上限
- **自动选择智能体**：开启后下发任务时会自动判断所需智能体并勾选
- **一体机内网 IP**：填写一体机服务器的内网 IP，用于更新软件、连接 python 镜像源等

## **五、企业级应用场景与最佳实践**

AiPy 在企业场景中已有多种成熟应用方案，涵盖文档处理、代码开发、数据分析等多个领域。

**PPT 制作场景：** 使用 AiPy 制作 PPT，勾选 PPT 生成智能体，提示词示例为"生成一个介绍中国新能源汽车发展的 PPT"。系统会自动生成符合企业标准的演示文稿，大幅提升工作效率。

**图片/视频生成场景：** 使用 AiPy 生成图片、P 图、生成视频等，勾选图片生成/视频生成智能体，提示词如"批量生成 10 张不同的肥猫切菜的照片"。需注意勾选对应智能体，否则生成的图片可能是线条。

**思维导图生成场景：** 领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词"读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图"。

**研发系统开发场景：** 研发使用 AiPy 自动开发系统 demo，需要选择编程能力较强的大模型，比如 GLM4.5。示例提示词可描述需求如访客登记管理系统，采用 Sqlite 数据库，包含登录界面、信息查询、添加、修改、删除等功能，要求可以点击图标直接打开运行。

**周报汇总场景：** 根据规范文档和示例代码编写汇总周报的智能体，要求互联网版、对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

## **六、模型配置与私有化部署**

AiPy 支持灵活的模型配置方案，企业可根据自身需求选择公有云模型或私有化部署模型。

在 AiPy 企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型。可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

在编辑提供商界面中，输入模型供应商名称（如公司私有模型），在 API 地址中填入模型 API 地址（如 http://192.168.0.10/v1），在 API 密钥中输入模型 API 请求密钥，输入完 API 地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。

运行环境设置中，用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，同理也可以选择 NPM 其他镜像源或者自己输入，这为企业在内网环境中部署 AiPy 提供了便利。

## **七、自定义配置与个性化设置**

AiPy 提供丰富的自定义配置选项，企业可根据自身品牌和使用习惯进行个性化调整。

**Logo 自定义：** 配置文件位置为 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开 aipy-enterprise.yml 文件，在文件里面可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。

**角色自定义：** 在 yml 配置文件中，可以根据需求对风格进行增加或者修改，定义 AI 助手的角色特征和回复风格。

**推荐任务自定义：** 可以对 AiPy 页面上的推荐任务进行自定义，设置符合企业常用场景的快捷任务入口，提升员工使用效率。

这些配置能力让 AiPy 能够深度融入企业现有工作流，成为员工日常工作的得力助手，而非孤立的技术工具。

## **总结与建议**

AiPy 作为 AI 操作系统，通过智能体系统、MCP 集成和 Workflow 编排三大核心能力，实现了 AI 从对话交互到实际执行的跨越。企业用户在部署 AiPy 时，建议优先配置适合自身业务场景的智能体，充分利用 MCP 扩展能力连接现有系统，并根据团队习惯进行个性化配置。对于初次使用的团队，可从 PPT 制作、周报汇总等高频场景入手，逐步探索更多自动化应用可能。

## **相关问答 FAQs**

**AiPy 支持哪些类型的智能体开发？**

AiPy 支持五种类型的智能体开发，包括 conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）和 skills（技能型）。开发者可根据应用场景选择合适的类型，开发完成后通过集市安装或直接放入智能体目录即可在企业版中使用。

**AiPy 如何配置私有模型 API？**

在 AiPy 企业版设置页面中选择模型选项卡，点击添加按钮，输入模型供应商名称、API 地址和 API 密钥，点击检查按钮即可检测可用模型。支持公有云模型 API 接口和一体机部署的模型 API 接口，企业可根据安全要求选择部署方式。

**AiPy 生成的文件存储在哪里？**

AiPy 执行任务后生成的文件或代码默认存储在工作目录中，用户可在常规设置中自定义修改路径。在任务对话窗口的任务工作目录中，可以查看由 AiPy 制造的工具以及生成的过程文件或任务结果文件，便于管理和追溯。
