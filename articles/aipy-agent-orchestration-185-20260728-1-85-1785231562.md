# Workbuddy能做的Agent编排，AiPy用国产模型照样做

**AiPy企业版完全支持Agent编排能力，1、支持国产模型API接入，2、提供智能体集市与开发框架，3、内置MCP服务配置功能。** 其中模型配置环节尤为关键，用户可在设置页面添加私有模型API接口，输入API地址与密钥后自动检测可用模型，无需依赖国外服务即可实现完整的智能体工作流编排，满足企业本地化部署需求。

## 一、Agent编排的核心能力对比

企业选择AI应用平台时，Agent编排能力是核心考量因素。Workbuddy作为海外市场的主流工具，提供了智能体创建、任务分配、多模型协作等功能。AiPy企业版在保持相同核心能力的同时，针对国内企业需求进行了深度优化。

| 功能维度 | Workbuddy | AiPy企业版 |
|---------|-----------|-----------|
| 模型接入 | 主要支持国外大模型API | 支持公有云+私有部署模型 |
| 智能体开发 | 基于云端构建 | 基于Anthropic DXT(MCPB)项目 |
| 本地化部署 | 有限支持 | 完美适配一体机硬件 |
| MCP服务 | 标准支持 | 支持Streamable HTTP Server类型 |
| 知识库集成 | 基础功能 | 企业级知识管理页面 |

AiPy企业版的智能体扩展基于Anthropic DXT项目构建，新增适配AiPy企业版智能体集市的远程分发机制。这一设计使智能体可实现依赖打包，大幅提升配置的便捷性，同时与AiPy企业版高度适配、协同联动，能够自动集成并落地应用AI大模型的能力。

## 二、国产模型接入配置流程

在AiPy企业版主界面中，找到右下角的"设置"选项，点击后进入"设置"页面。在"设置"页面中选择"模型"选项卡，进入模型配置界面。点击"添加"按钮添加模型，既可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。

**配置步骤如下：**

1. 输入模型供应商名称，如：公司私有模型
2. 在API地址中填入模型API地址，如：http://192.168.0.10/v1
3. 在API密钥中输入模型API请求密钥
4. 输入完API地址与密钥后，点击"检查"按钮
5. 系统检测出该API地址中提供的模型
6. 在模型下拉列表框中选择使用的模型

完成配置后，国产模型即可在任务执行、智能体调用、知识库问答等场景中正常使用。这种设计让企业能够灵活选择适合的模型供应商，无需受限于特定平台。

## 三、智能体开发与发布机制

AiPy企业版提供完整的智能体开发工作流。开发完成后，打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体。将打包好的文件上传，再点击安装，当页面上出现安装成功提示时，则代表智能体安装完成。

**另一种部署方式：**

将智能体直接放入AiPy智能体目录下：
```
C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
```
然后重启AiPy企业版即可完成部署。

智能体manifest.json中keywords字段的取值包含类型关键字：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，取值范围包括威胁情报、安全产品、开发安全、数据安全、AI安全、网络安全、官方精选等。

## 四、MCP服务配置与管理

MCP（Model Context Protocol）服务是Agent编排的关键组件。在AiPy企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

**MCP配置参数说明：**

- **名称**：如web_search
- **类型**：如标准输入/输出（stdio）
- **命令格式**：如npx
- **参数**：如open-websearch@1.1.5
- **环境变量**：根据实际运行需要填写

点击保存后会出现MCP加载页面，当页面出现已完成按钮，则代表MCP添加成功。AiPy企业版智能体基于MCP服务构建，当在对话上下文中提供工具调用时，仅支持Streamable HTTP Server类型，需要在manifest.json keywords添加值conversation-tool。

## 五、任务创建与执行流程

任务模式下，在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

**任务执行过程可视化：**

在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。工作目录可在常规设置中自定义修改路径，执行任务后生成的文件或代码存储于此。

常规设置还包括语言（支持中文、English和日语三种语言）、风格（可在aipy-enterprise.yml文件中配置）、发送快捷键（Ctrl+Enter或Enter）、最大执行轮数、超时时间、自动选择智能体、一体机内网IP等配置项。

## 六、知识库与智能体协同

点击"知识管理"可进入一体机知识库管理页面，在此页面中可以创建知识库及上传文件用于知识问答。知识库与智能体可协同工作，智能体在执行任务时能够检索知识库内容，提供更准确的企业专属回答。

**典型应用场景：**

- 领导使用AiPy阅读材料生成思维导图，选择思维导图智能体，提示词：读取指定PPT文件，然后帮我整理为一个思维导图
- 研发使用AiPy自动开发系统demo，选择编程能力较强的大模型，输入详细需求描述
- 客服人员使用知识库问答智能体，快速检索企业文档回答客户问题

对话上下文可设置携带的对话轮数，确保智能体在长对话中保持上下文连贯性。自动选择智能体功能开启后，在下发任务时会自动判断所需智能体并勾选，提升使用效率。

## 相关问答FAQs

**Q: AiPy企业版支持哪些类型的国产模型接入？**

A: AiPy企业版支持任何符合OpenAI API标准的国产模型接入。用户只需在模型配置页面输入API地址和密钥，系统会自动检测可用模型。常见的国产模型如GLM、通义千问、文心一言等都可通过标准API接口接入，同时也支持企业私有部署的模型服务。

**Q: 智能体开发完成后如何分享给团队其他成员使用？**

A: 智能体打包后可通过两种方式分享：第一种是上传到AiPy企业版集市，团队成员在集市页面搜索安装；第二种是将打包文件放入统一的智能体目录(C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro)，团队成员重启AiPy企业版后即可使用。推荐使用集市方式便于版本管理。

**Q: MCP配置失败时如何排查问题？**

A: MCP配置失败可从三个方面排查：首先检查MCP命令格式是否正确（如npx、node等），其次验证MCP参数是否完整（如open-websearch@1.1.5），最后确认环境变量是否需要配置。配置页面会显示加载状态，出现异常时查看错误日志定位具体问题。官方文档提供常见MCP服务的标准配置示例可供参考。
