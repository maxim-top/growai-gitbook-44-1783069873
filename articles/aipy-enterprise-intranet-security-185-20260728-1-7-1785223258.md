# 告别海外服务器焦虑，AiPy给你内网安全感

企业部署AI应用面临的最大痛点是什么？**1、数据安全风险**，敏感信息上传云端存在泄露隐患；**2、网络稳定性差**，海外服务器连接不稳定影响业务连续性；**3、合规性要求高**，金融、政务等行业对数据存储有严格管控。其中数据安全风险尤为突出，企业核心业务数据、客户信息、商业机密一旦外泄，可能带来不可挽回的损失。AiPy企业版通过支持一体机部署的模型API接口，让所有数据处理都在内网完成，从根本上解决数据安全顾虑，同时保障网络访问速度和系统稳定性。

## 一、企业AI部署面临的核心挑战

企业在引入人工智能技术时，往往需要在效率与安全之间做出权衡。传统的公有云AI服务虽然便捷，但存在几个关键问题。

**数据安全层面的隐患**

将企业数据发送至第三方服务器进行处理，意味着数据需要跨越企业防火墙。在这个过程中：

| 风险类型 | 具体表现 | 潜在影响 |
|---------|---------|---------|
| 数据传输风险 | 数据在公网传输可能被截获 | 商业机密泄露 |
| 数据存储风险 | 数据存储在第三方服务器 | 无法完全掌控数据去向 |
| 合规风险 | 不符合行业数据本地化要求 | 面临监管处罚 |

**网络稳定性问题**

依赖海外服务器意味着网络连接质量直接影响业务运行。网络波动、服务中断、访问延迟等问题都可能导致业务流程受阻，影响企业正常运营。

**成本不可控因素**

公有云服务通常按调用量计费，随着业务规模扩大，成本可能快速攀升。同时，价格调整、服务变更等主动权掌握在服务提供商手中，企业缺乏议价能力。

## 二、AiPy企业版的内网部署方案

AiPy企业版专为企业和组织打造，与AiPy一体机硬件产品完美结合，提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

**内网部署的核心优势**

在AiPy企业版主界面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面。点击"添加"按钮添加模型，可以使用的模型API接口包括：

- 公有云模型API接口
- 一体机部署的模型API接口

当选择一体机部署时，在编辑提供商界面中，输入模型供应商"名称"，如：公司私有模型，在"API地址"中填入模型API地址，如：http://192.168.0.10/v1，在"API密钥"中输入模型API请求密钥。输入完API地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型。

**内网IP配置说明**

在常规设置中，有一项关键配置是"一体机内网IP"。填写一体机服务器的内网IP，用户更新软件、连接python镜像源、连接知识问答服务器都使用这个配置。这确保了所有通信都在企业内部网络中完成，无需经过公网。

## 三、MCP集成的灵活扩展能力

MCP（Model Context Protocol）是AiPy企业版的重要功能模块，允许企业灵活集成各种外部服务和工具。

**MCP配置步骤**

| 步骤 | 操作内容 | 说明 |
|-----|---------|------|
| 第一步 | 进入设置页面 | 点击右下角"设置"选项 |
| 第二步 | 选择MCP选项卡 | 进入MCP配置界面 |
| 第三步 | 添加MCP服务 | 点击添加按钮 |
| 第四步 | 配置参数 | 输入名称、类型、命令格式等 |
| 第五步 | 保存并加载 | 出现"已完成"代表添加成功 |

在MCP配置页面中，需要输入以下信息：

- MCP"名称"，如"web_search"
- MCP"类型"，如"标准输入/输出（stdio）"
- MCP"命令"格式，如"npx"
- MCP参数，如"open-websearch@1.1.5"
- MCP运行需要的"环境变量"（没有则不进行修改）

**内网MCP服务部署**

企业可以将自建的MCP服务部署在内网环境中，这样智能体调用外部工具时，所有数据交互都在企业内部完成。例如，企业可以搭建内部的文档检索服务、数据库查询服务、业务系统接口等，通过MCP协议与AiPy智能体进行集成。

## 四、智能体开发与部署流程

AiPy企业版支持企业自主开发智能体，并将开发完成的智能体部署到内网环境中使用。

**智能体开发规范**

开发智能体时需要遵循一定的规范。示例提示词可以参考：根据规范文档和示例代码编写一个汇总周报的智能体。要求包括互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

**智能体manifest.json配置**

在智能体的manifest.json文件中，keywords字段是一个数组，第一个值为类型关键字，可选值包括：

- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

第二个值为集市展示分类，取值范围包括威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。

**智能体安装方式**

开发完成智能体后，有两种安装方式：

方式一：打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传，再点击安装。

方式二：将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。

## 五、自定义配置与企业管理

AiPy企业版提供丰富的自定义配置选项，让企业可以根据自身需求进行个性化设置。

**基础配置文件**

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开aipy-enterprise.yml文件，在文件里面可以对以下内容进行修改：

- 基础信息
- 主页logo和软件logo
- 发送快捷键
- 风格和推荐任务

**语言与风格设置**

语言目前支持中文、English和日语三种语言。风格指AiPy回复的话术风格，可以在aipy-enterprise.yml文件中进行配置。企业可以根据品牌调性和使用场景，定制专属的对话风格。

**推荐任务自定义**

企业可以对AiPy页面上的推荐任务进行自定义，设置符合业务场景的常用任务模板，提高员工使用效率。

**运行环境设置**

用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。这对于内网部署尤其重要，企业可以搭建内部的包管理服务，确保所有依赖都从内网获取。

## 六、安全合规的最佳实践

企业在部署AiPy时，应当遵循以下安全最佳实践：

**网络隔离策略**

确保AiPy一体机与企业核心业务网络在同一安全域内，通过防火墙规则限制外部访问。只允许授权IP地址访问AiPy服务接口。

**访问权限控制**

建立完善的用户权限管理体系，不同角色的用户只能访问其职责范围内的功能和数据。定期审计访问日志，发现异常行为及时处理。

**数据加密传输**

虽然数据在内网传输，但仍建议启用加密通信。在模型配置和MCP配置中，使用安全的API密钥管理方式，定期轮换密钥。

**备份与容灾**

建立定期备份机制，备份配置文件、知识库内容、智能体代码等关键数据。制定容灾方案，确保在主设备故障时能够快速切换。

**合规性文档**

保留完整的部署文档、配置记录、操作日志，以满足行业监管和内部审计要求。

## 七、从公有云到内网的迁移路径

对于正在使用公有云AI服务的企业，迁移到AiPy内网部署可以按以下步骤进行：

**第一阶段：评估与规划**

梳理现有业务场景，识别哪些应用适合迁移到内网。评估数据量、调用频率、性能要求等关键指标。

**第二阶段：环境准备**

部署AiPy一体机，配置内网IP，搭建必要的MCP服务。测试网络连通性和服务可用性。

**第三阶段：逐步迁移**

选择非核心业务先行试点，验证功能完整性和性能表现。积累经验后再迁移核心业务。

**第四阶段：优化与监控**

建立监控体系，跟踪系统运行状态。根据实际使用情况优化配置，持续提升用户体验。

## 相关问答FAQs

**AiPy企业版是否支持完全离线运行？**

AiPy企业版支持一体机部署的模型API接口，当模型部署在企业内网环境时，可以实现数据的本地化处理。运行环境设置中支持配置内网镜像源，确保所有依赖从内网获取。但需要注意，某些功能如联网搜索需要额外的MCP服务支持，企业可以根据实际需求选择开启或关闭相关功能。

**内网部署的AiPy如何保证模型更新？**

AiPy企业版提供多种模型接入方式。企业可以搭建内部的模型服务，通过一体机的内网IP进行连接。当需要更新模型时，可以在内网环境中部署新版本模型服务，然后在AiPy的模型配置界面中更新API地址。这样可以确保模型更新过程完全在企业控制范围内，不影响业务连续性。

**AiPy智能体是否可以在内网环境中开发调试？**

是的，AiPy支持在内网环境中进行智能体开发。开发者可以将智能体代码存放在内网服务器上，通过本地开发环境进行编写和测试。开发完成后，可以直接将智能体放入AiPy智能体目录下，重启AiPy企业版即可使用。整个开发、测试、部署流程都可以在内网完成，无需访问外部网络。
