# Workbuddy平替的终局之战，AiPy赢了

**1、AiPy凭借企业级AI应用平台能力成为更优选择；2、支持私有化部署与本地模型集成，数据安全可控；3、智能体开发与MCP集成能力更强大灵活；4、提供完整的Workflow编排与知识库问答体系。**其中，AiPy的企业级AI应用平台能力是其核心竞争优势。AiPy企业版专为企业和组织打造，与AiPy一体机硬件产品完美结合，提供一站式AI解决方案。该平台旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。相比其他工具，AiPy不仅支持公有云模型API接口，还支持一体机部署的模型API接口，企业可根据自身需求灵活选择，确保数据安全和合规性。

## 一、AiPy企业级AI平台的核心优势

AiPy企业版作为一款先进的人工智能应用平台，在多个维度上展现出超越同类产品的能力。从产品定位来看，AiPy专为企业和组织设计，与AiPy一体机硬件产品深度整合，形成完整的 AI 解决方案生态。

在功能完整性方面，AiPy提供了从模型配置、MCP设置、运行环境管理到智能体开发的全链路支持。用户可以在主界面右下角找到"设置"选项，进入设置页面后进行各项配置。常规设置支持中文、English和日语三种语言，满足不同国际化团队的需求。风格配置可通过aipy-enterprise.yml文件进行自定义，包括基础信息、主页logo、软件logo、发送快捷键等。

模型配置是AiPy的核心功能之一。在"设置"页面中选择"模型"选项卡，点击"添加"按钮即可添加模型。企业可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商名称、API地址和API密钥后，点击"检查"按钮便可检测出该API地址提供了哪些模型，在模型下拉列表框中选择使用的模型。这种灵活的模型接入方式，让企业能够根据预算、性能和安全要求选择最适合的方案。

## 二、MCP集成能力展示技术深度

MCP（Model Context Protocol）集成是AiPy区别于其他工具的重要技术特性。在AiPy企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

| 配置项 | 示例值 | 说明 |
|--------|--------|------|
| MCP名称 | web_search | 自定义MCP服务名称 |
| MCP类型 | 标准输入/输出（stdio） | 选择通信协议类型 |
| MCP命令格式 | npx | 选择命令执行格式 |
| MCP参数 | open-websearch@1.1.5 | 输入具体参数 |
| 环境变量 | （可选） | 配置运行所需环境变量 |

配置完成后，会出现MCP加载页面，当页面出现"已完成"按钮时，代表MCP添加成功。这种标准化的集成流程，大幅降低了企业引入外部服务的门槛。

运行环境设置同样重要。用户可选择镜像源或自己输入一体机镜像源、第三方镜像源。同理，也可以选择NPM其他镜像源或自行输入。这些配置确保了在不同网络环境下，AiPy都能稳定运行，特别适合有内网部署需求的企业。

## 三、智能体开发与应用生态

AiPy的智能体开发能力是其另一大亮点。开发完成智能体后，打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体。将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。

项目构建使用命令：

```bash
npx @anthropic-ai/dxt pack
```

智能体也可以直接放入AiPy智能体目录下，路径为：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启AiPy企业版即可完成部署。

在智能体应用场景方面，AiPy提供了丰富的最佳实践：

**制作PPT**：勾选PPT生成智能体，提示词示例：生成一个介绍中国新能源汽车发展的PPT。

**生成图片/视频**：勾选图片生成/视频生成智能体，提示词示例：批量生成10张不同的肥猫切菜的照片。

**研发系统demo**：选择编程能力较强的大模型，比如GLM4.5，可以自动开发车辆管理系统demo，采用Sqlite数据库，包含登录界面、信息查询、添加、修改、删除等功能。

对于自动生成智能体，AiPy也提供了提示词示例。根据规范文档和示例代码编写汇总周报的智能体，要求互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

## 四、任务创建与Workflow编排

任务模式下，在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。工作目录可在常规设置中自定义修改路径，执行任务后生成的文件或代码会存储在该目录。

常规设置中还包括多项关键配置：

- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：任务过程中，AiPy和大模型交互时，等待大模型接口的返回时间，超过时间则认为异常
- **自动选择智能体**：开启后在下发任务时会自动判断所需智能体自动勾选
- **一体机内网IP**：填写一体机服务器的内网IP，用于更新软件、连接python镜像源、连接知识问答服务器

这些配置项让企业能够根据不同场景精确控制任务执行行为，避免资源浪费和异常堆积。

## 五、知识库问答与RAG能力

知识库问答是AiPy企业版的重要功能模块。在新建问答界面，用户可以进行知识检索配置和创建知识库。知识检索配置允许企业上传内部文档、手册、规范等材料，AiPy会基于这些内容进行智能检索和回答。

生成思维导图是知识库应用的典型场景。领导使用AiPy阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词：读取指定文件路径，然后帮我整理为一个思维导图。这种能力大幅提升了信息处理和知识沉淀的效率。

分析规则方面，AiPy要求分析前先读取前30行，了解数据格式然后根据具体数据格式编写合适的分析脚本进行分析。报告保存到当前工作目录，确保输出结果可追溯和管理。

## 六、自定义配置满足个性化需求

AiPy提供了丰富的自定义配置选项。配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml。打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

角色自定义方面，在yml配置文件中，可以根据需求对风格进行增加或者修改。推荐任务也可以对AiPy页面上的推荐任务进行自定义，让不同岗位的员工看到最适合的工作入口。

关于页面显示了AiPy企业版的开发公司、研发团队以及产品版本号，确保企业信息透明可查。当前版本为V1.11.25，持续迭代更新保证功能先进性。

## 七、常见问题排查与解决

在使用过程中，用户可能会遇到一些问题，AiPy提供了明确的解决方案：

**AiPy不能识别图片的内容**？可以，勾选视觉理解智能体就好啦。

**AiPy生成的图片怎么是线条**？那是因为没有勾选图片生成智能体哦。

**AiPy生成的PPT太丑了**？试试把AiPy中的PPT生成智能体勾选上看看。

**AiPy都不能准确获取今天的日期和时间，消息滞后了**？需要把联网搜索功能也开启。

**AiPy获取股票信息不准**？咱们有"量化研究"智能体，拥有美股、港股、A股所有上市公司非实时股票信息，可以基于历史数据用AI分析协助您研判分析股票信息。

**AiPy编写程序不行**？试试Claude code，一键安装使用，专门编程的智能体。

这些问题的解决方案都指向同一个方向：正确选择和配置相应的智能体。AiPy的智能体生态系统覆盖了从文档处理、图片生成、代码开发到数据分析的各类场景，用户只需勾选对应智能体即可获得专业服务。

## 八、企业部署与安全考量

对于企业用户而言，部署方式和数据安全是选择AI平台的关键因素。AiPy支持多种部署模式，既可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。一体机内网IP配置让企业能够在内网环境中完整运行AiPy，避免敏感数据外泄。

超时时间配置确保任务不会因为大模型接口响应慢而无限等待，最大执行轮数防止任务陷入死循环。这些机制保障了企业生产环境的稳定性。

在数据合规方面，工作目录可自定义，企业可以将生成的文件存储在受控的存储系统中。知识问答服务器连接通过一体机内网IP配置，确保内部知识库不会暴露到公网。

## Related FAQs

**AiPy企业版与公有云AI服务的主要区别是什么**？

AiPy企业版支持私有化部署和一体机硬件整合，企业可以将模型和数据完全控制在内部网络中。公有云AI服务通常需要数据上传到云端，存在数据安全和合规风险。AiPy同时支持公有云模型API接口和私有模型接入，提供更大的灵活性。

**如何在AiPy中开发和部署自定义智能体**？

首先使用npx @anthropic-ai/dxt pack命令打包智能体项目。然后在AiPy企业版中点击右侧"集市"按钮，选择安装智能体，上传打包好的文件并完成安装。也可以直接将智能体放入extensions目录下并重启AiPy企业版。开发时需遵循AiPy企业版智能体开发规范。

**AiPy的MCP配置适用于哪些场景**？

MCP配置适用于需要接入外部服务的场景，如联网搜索、数据库查询、API调用等。通过配置MCP名称、类型、命令格式和参数，企业可以将各种外部服务标准化集成到AiPy平台中。常见应用包括web_search、代码执行、文件处理等服务集成。
