## 二、AiPy 企业版核心功能详解

### 2.1 模型配置灵活性

在 AiPy 企业版主界面中，进入"设置"页面选择"模型"选项卡，点击"添加"按钮即可配置模型。企业可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

配置步骤如下：

1. 输入模型供应商名称，如：公司私有模型
2. 在"API 地址"中填入模型 API 地址，如：http://192.168.0.10/v1
3. 在"API 密钥"中输入模型 API 请求密钥
4. 点击"检查"按钮检测该 API 地址中提供的模型
5. 在"模型"下拉列表框中选择使用的模型

这种灵活配置方式使企业能够根据业务场景选择最合适的模型，既可使用高性能公有云模型处理通用任务，也可使用私有部署模型处理敏感数据。

### 2.2 MCP 集成能力

MCP（Model Context Protocol）是 AiPy 的核心扩展机制。在 AiPy 企业版页面中，进入"设置"页面选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

MCP 配置参数包括：

- **名称**：如"web_search"
- **类型**：如"标准输入/输出（stdio）"
- **命令格式**：如"npx"
- **参数**：如"open-websearch@1.1.5"
- **环境变量**：根据 MCP 运行需要配置

当页面出现"已完成"按钮时，代表 MCP 添加成功。通过 MCP 集成，企业可以连接外部数据库、API 服务、内部系统等，实现 AI 助手与现有业务系统的无缝对接。

### 2.3 智能体开发与应用

AiPy 提供完整的智能体开发生态。开发完成后，打开 AiPy 企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传并安装。

智能体安装方式有两种：

**方式一：集市安装**
1. 点击"集市"按钮
2. 上传打包好的智能体文件
3. 点击安装，等待完成提示

**方式二：目录部署**
1. 将智能体直接放入 AiPy 智能体目录下
2. 路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
3. 重启 AiPy 企业版

### 2.4 常规设置选项

AiPy 企业版常规设置涵盖多个维度，满足企业个性化管理需求：

| 设置项 | 说明 |
|-------|------|
| 语言 | 支持中文、English 和日语三种语言 |
| 风格 | 可在 aipy-enterprise.yml 文件中配置回复话术风格 |
| 发送快捷键 | 可选择 Ctrl+Enter 或 Enter 发送消息 |
| 工作目录 | 执行任务后生成的文件或代码的存储目录 |
| 最大执行轮数 | 执行任务的最大回复轮数，超出后任务自动停止 |
| 超时时间 | 等待大模型接口返回的时间阈值 |
| 自动选择智能体 | 开启后下发任务时自动判断所需智能体 |
| 一体机内网 IP | 填写一体机服务器的内网 IP |

## 三、企业应用场景实战

### 3.1 知识库问答

企业可将内部文档、手册、制度等上传至知识库，员工通过自然语言提问快速获取信息。创建知识库后，系统自动进行知识检索配置，支持多格式文档解析。

知识库问答流程：
1. 新建问答任务
2. 配置知识检索参数
3. 创建并上传知识库文档
4. 发起问答请求
5. 获取精准答案及来源引用

### 3.2 智能体自动化任务

AiPy 支持多种智能体协同工作，常见应用场景包括：

**PPT 生成**：勾选 PPT 生成智能体，输入提示词"生成一个介绍中国新能源汽车发展的 PPT"，系统自动完成内容整理、排版设计、图表生成。

**图片/视频生成**：勾选图片生成/视频生成智能体，输入提示词"批量生成 10 张不同的肥猫切菜的照片"，系统调用多模态模型完成创作。

**代码开发**：勾选编程智能体（如 Claude code），输入需求描述，系统自动生成可运行代码，支持一键点击运行使用。

**周报汇总**：根据规范文档和示例代码编写汇总周报的智能体，要求不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

### 3.3 研发系统快速搭建

使用 AiPy 可快速开发企业_demo 系统。以车辆管理系统为例，提示词如下：

"我是一家汽车 4S 店的负责人，帮我做一个访客登记管理系统，采用 Sqlite 数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置奥迪的常见车型、联系方式主要是 11 位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。"

系统自动生成完整可运行的应用程序，大幅降低开发周期和成本。

## 四、部署与运维指南

### 4.1 运行环境配置

在 AiPy 企业主界面中，进入"设置"页面选择"运行环境"选项卡，用户可选择镜像源或自行输入一体机镜像源、其他第三方镜像源。同理，也可以选择 NPM 其他镜像源或自行输入。

合理的镜像源配置可显著提升下载速度和系统稳定性，建议企业根据网络环境选择最优配置。

### 4.2 自定义配置

企业可对 AiPy 进行深度定制，配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

可自定义内容包括：
- 基础信息
- 主页 logo 和软件 logo
- 发送快捷键
- 风格设置
- 推荐任务

打开配置文件后，可根据企业 VI 规范进行品牌化定制，使 AI 助手与企业形象保持一致。

### 4.3 任务创建与执行

在 AiPy 企业版主界面 logo 下方点击新建任务按钮创建新任务。在"任务输入框"中输入需要执行的任务，如需选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮下发任务。

在"任务对话窗口"中可查看任务的执行过程，在"任务工作目录"中可查看由 AiPy 制造的工具以及生成的过程文件或任务结果文件。

## 相关问答 FAQs

**AiPy 企业版与公有云 AI 服务的主要区别是什么？**

AiPy 企业版支持本地部署，数据完全存储在企业内网环境中，无需上传至第三方云服务器。而公有云 AI 服务需要将数据发送至云端处理，存在数据出境和隐私泄露风险。AiPy 同时支持连接公有云模型 API，企业可根据场景灵活选择，兼顾性能与安全。

**企业如何快速上手 AiPy 智能体开发？**

企业开发者可参考官方提供的智能体开发文档和示例代码，从简单的任务型智能体开始实践。AiPy 提供可视化配置界面，大部分功能无需编写代码即可完成配置。对于复杂场景，可使用 Python SDK 或 Java SDK 进行深度开发。官方知识库中包含完整的开发规范和最佳实践指南。

**AiPy 是否支持与企业现有系统集成？**

支持。通过 MCP（Model Context Protocol）集成机制，AiPy 可连接企业现有的数据库、API 服务、业务系统等。配置 MCP 时需指定名称、类型、命令格式和参数，加载完成后即可在任务执行中调用。这对于希望将 AI 能力融入现有业务流程的企业尤为重要，可避免重复建设和系统割裂。
