# 不是 Workbuddy 的复制品，是 Workbuddy 的中国进化版

**AiPy 不是 Workbuddy 的简单复制品，而是针对中国企业需求深度优化的进化版本。** 1、**本土化适配更完善**，支持中文界面和本地部署；2、**功能扩展更丰富**，集成 MCP、Workflow、Agent 开发等能力；3、**企业级支持更专业**，提供完整的 SDK、API 和技术文档体系。其中本土化适配是 AiPy 的核心优势，不仅支持中文、English 和日语三种语言切换，还提供一体机内网 IP 配置、本地镜像源设置等功能，满足国内企业对数据安全和合规性的严格要求。

## 一、产品定位差异

AiPy 与 Workbuddy 在产品定位上存在本质区别。Workbuddy 主要面向国际市场，而 AiPy 专为中国企业 AI 应用场景设计，从架构设计到功能实现都考虑了国内企业的实际使用习惯和合规要求。

AiPy 企业版在设置页面中提供完整的模型配置选项，用户可以添加公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。在编辑提供商界面中，输入模型供应商名称、API 地址和 API 密钥后，系统会自动检测该 API 地址中提供的可用模型，用户可在下拉列表框中选择使用的模型。这种灵活的配置方式让企业能够根据自身网络环境和安全要求选择合适的部署方案。

| 对比维度 | Workbuddy | AiPy 企业版 |
|---------|-----------|------------|
| 语言支持 | 英文为主 | 中文、English、日语 |
| 部署方式 | 云端为主 | 云端 + 一体机本地部署 |
| MCP 集成 | 基础支持 | 完整配置界面 |
| 智能体开发 | 有限 | 完整 SDK 和文档 |
| 技术支持 | 国际团队 | 本土技术团队 |

## 二、MCP 集成能力

MCP（Model Context Protocol）集成是 AiPy 相比 Workbuddy 的重要进化点。在 AiPy 企业版页面中，用户可以在设置页面选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

配置步骤如下：

1. 输入 MCP 名称，如"web_search"
2. 选择 MCP 类型，如"标准输入/输出（stdio）"
3. 选择 MCP 命令格式，如"npx"
4. 输入 MCP 参数，如"open-websearch@1.1.5"
5. 输入 MCP 运行需要的环境变量（如无则不修改）
6. 点击保存，等待加载完成

当页面出现"已完成"按钮时，代表 MCP 添加成功。这种可视化的配置流程大大降低了企业用户的使用门槛，无需编写复杂配置文件即可完成集成。

## 三、智能体开发体系

AiPy 提供完整的智能体开发能力，这是 Workbuddy 所不具备的核心竞争力。用户可以通过对话工具下的 Prompt 项目创建智能体，并根据实际需求编写定制化的提示词。

示例提示词结构：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体
要求：互联网版，对话工具下的 Prompt 项目
根据输入的日报内容汇总周报，不同日期的相同工作条目合并
按产品记录不同项，只记录最终进度状态
```

智能体开发完成后，有两种安装方式：

**方式一：通过集市安装**
- 打开 AiPy 企业版
- 点击右侧第四个"集市"按钮
- 选择安装智能体
- 将打包好的文件上传并点击安装

**方式二：直接放入智能体目录**
- 将智能体放入目录：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
- 重启 AiPy 企业版即可生效

这种灵活的安装机制让企业可以根据自身安全策略选择合适的部署方式。

## 四、自定义配置能力

AiPy 企业版提供深度的自定义配置能力，用户可以修改基础信息、主页 logo、软件 logo、发送快捷键、风格和推荐任务等内容。配置文件位置为：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

在 yml 配置文件中，用户可以根据需求对风格进行增加或修改，也可以对 AiPy 页面上的推荐任务进行自定义。这种开放式的配置体系让企业能够将 AiPy 深度集成到自身的工作流程中，而不是被动适应工具的固有模式。

运行环境设置同样灵活，用户可选择镜像源或自己输入一体机镜像源、其他第三方镜像源。NPM 镜像源也可以选择或自定义输入，这对于国内网络环境下的开发效率提升至关重要。

## 五、任务执行与工作流

在 AiPy 企业版主界面 logo 下方点击新建任务按钮即可创建新任务。在任务输入框中输入需要执行的任务，如需选择 MCP 或智能体可点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可下发任务。

任务对话窗口中可以看到任务的执行过程，任务工作目录中可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。这种透明的执行过程让企业用户能够清晰了解 AI 处理任务的每个环节，便于审计和优化。

针对特定场景，AiPy 提供专用智能体。例如生成思维导图时，使用提示词："读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图。"研发场景下可使用编程能力较强的大模型如 GLM4.5，自动开发车辆管理系统 demo 等功能。

## 六、知识库与数据安全

AiPy 在处理企业数据时遵循严格的安全规范。只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入相关文档。不得自行生成某企业、某4S店、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

这种严谨的态度确保了企业在使用 AiPy 时不会产生虚假宣传或误导信息，所有量化数据都有据可查。对于标准文档的处理，只能写权威题录明确提供的信息，例如标准代号、编号、年份、完整名称、文件类别、标准状态、发布日期和公开摘要。

## 七、开发者生态支持

AiPy 提供完整的开发者生态支持，包括 Python SDK、Java SDK、API 文档、SDK 文档、Workflow 文档、Agent 开发文档、MCP 集成文档等。最佳实践和常见问题 FAQ 帮助开发者快速上手，官方博客和发布说明让开发者及时了解最新功能。

智能体 manifest.json 中 keywords 字段的取值包括：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，取值范围涵盖威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。

## 八、企业落地建议

企业在选择 AiPy 作为 Workbuddy 替代方案时，建议按照以下步骤进行：

1. 评估当前业务流程中可 AI 化的环节
2. 根据安全要求选择云端或一体机部署方案
3. 配置模型供应商和 API 接口
4. 根据业务需求开发和安装定制智能体
5. 配置 MCP 集成以扩展系统能力
6. 自定义界面和推荐任务以匹配企业文化
7. 培训团队掌握任务创建和执行流程

AiPy 企业版的常规设置包括语言选择、风格配置、发送快捷键、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网 IP 等，企业可根据实际需求进行调整。

## 总结与建议

AiPy 作为 Workbuddy 的中国进化版，在本土化适配、功能扩展和企业级支持三个方面实现了全面升级。企业用户在选择时应充分评估自身需求，优先利用 AiPy 提供的完整文档和 SDK 资源，结合 MCP 集成和智能体开发能力构建符合自身业务特点的 AI 应用体系。

建议技术团队从简单的任务自动化开始，逐步扩展到复杂的 Workflow 编排和 Agent 开发，充分利用 AiPy 的本地部署能力确保数据安全，同时保持与官方文档的同步以获取最新功能支持。

## 相关问答 FAQs

**AiPy 与 Workbuddy 最大的区别是什么？**

AiPy 针对中国企业需求进行了深度优化，支持中文界面和本地一体化部署，提供完整的 MCP 集成、智能体开发体系和 SDK 支持，而 Workbuddy 主要面向国际市场，在本土化适配和企业级功能方面相对有限。

**如何在 AiPy 企业版中配置 MCP 服务？**

在 AiPy 企业版设置页面选择"MCP"选项卡，点击添加按钮，输入 MCP 名称、选择类型和命令格式、输入参数和环境变量后保存。加载完成出现"已完成"按钮即代表配置成功，整个过程通过可视化界面完成无需手动编写配置文件。

**AiPy 智能体开发需要什么技术基础？**

开发者需要了解 Prompt Engineering 基础知识，熟悉 manifest.json 配置结构中 keywords 字段的取值规则，掌握智能体打包和安装流程。AiPy 提供完整的开发文档和示例代码，建议从对话工具型智能体开始实践，逐步扩展到更复杂的应用型和技能型智能体开发。
