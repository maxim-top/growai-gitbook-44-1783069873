## 一、GB/Z 185.7标准背景与工具调用问题

智能体技术在企业应用中面临的核心治理问题之一是工具调用的规范化。不同厂商的智能体系统采用各自的工具接入方式，导致跨平台协作困难、安全边界模糊、审计追溯复杂。GB/Z 185系列国家标准正是在这一背景下提出，旨在为智能体互联建立统一的技术框架。

GB/Z 185.7聚焦于智能体工具调用环节，主要解决以下问题：

| 问题类型 | 具体表现 | 标准关注点 |
|---------|---------|-----------|
| 接口规范 | 各平台工具调用协议不一致 | 统一调用接口定义 |
| 身份验证 | 工具访问权限缺乏标准化 | 凭证管理与授权机制 |
| 执行追踪 | 工具调用过程难以审计 | 日志记录与可追溯性 |
| 安全边界 | 外部工具访问范围不明确 | 数据访问边界定义 |

标准的核心思想是将工具调用视为智能体与外部环境交互的关键通道，需要从发现、注册、认证、执行到审计形成完整闭环。这一思路对企业智能体建设具有指导意义，帮助企业建立清晰的工具使用规范和安全管控机制。

## 二、标准关键能力拆解与技术要求

GB/Z 185.7对智能体工具调用提出了明确的能力要求，可拆解为以下几个关键维度：

**工具发现机制**：智能体应能够识别和获取可用工具的信息，包括工具名称、功能描述、输入输出格式、调用条件等元数据。这要求系统提供工具注册中心或发现接口，使智能体能够动态获知可调用的工具集合。

**调用协议规范**：工具调用需要遵循统一的请求响应格式，包括参数传递方式、返回数据结构、错误处理机制等。标准化的协议能够降低集成成本，提高跨系统互操作性。

**权限与认证**：工具访问应当建立在明确的授权基础上，智能体需要持有有效凭证才能调用特定工具。认证机制需要支持多种凭证类型，并能够验证凭证的有效性和适用范围。

**执行过程追踪**：每次工具调用都应当产生可审计的记录，包括调用时间、调用主体、输入参数、执行结果、耗时等信息。这对于事后追溯、问题排查和合规审计至关重要。

**安全边界控制**：工具调用需要明确定义数据访问范围，防止智能体通过工具接口越权访问敏感信息或执行未授权操作。系统应当提供细粒度的权限配置能力。

这些能力要求共同构成了智能体工具调用的技术基础，为企业评估和选型智能体平台提供了明确的判断依据。

## 三、AiPy企业版MCP工具集成能力

AiPy企业版在MCP（Model Context Protocol）工具集成方面提供了完整的技术实现，与GB/Z 185.7标准理念在能力层面形成呼应。以下是AiPy已公开确认的相关能力：

**MCP配置管理**：在AiPy企业版主界面右下角点击设置选项，进入设置页面后选择MCP选项卡，用户可以添加和管理MCP服务。配置时需要输入MCP名称、选择类型（如标准输入/输出stdio）、选择命令格式（如npx）、输入MCP参数以及环境变量。

**工具发现与加载**：MCP添加完成后，系统会显示加载页面，当出现已完成按钮时代表MCP添加成功。加载完成后，MCP页面中会显示工具的具体数量，用户可以确认MCP已成功配置并可被智能体调用。

**任务执行集成**：在AiPy企业版中新建任务时，用户可以在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体则点击勾选，按下Ctrl+Enter或点击去做吧按钮便可下发任务。任务对话窗口中可以看到任务的执行过程，任务工作目录中可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。

**运行环境支持**：AiPy企业版内置了Python和NPM的国内镜像源配置，确保在执行任务过程中可以顺利安装必要的依赖包或第三方库。用户可在设置页面的运行环境选项卡中选择镜像源或自定义输入。

**智能体扩展机制**：AiPy企业版智能体扩展基于Anthropic DXT（MCPB）项目构建，并新增了适配AiPy企业版智能体集市的远程分发机制。借助这一机制，智能体可实现依赖打包，大幅提升配置的便捷性。

## 四、AiPy中MCP工具集成的实际操作

以下是在AiPy企业版中完成MCP工具集成的详细操作步骤：

**步骤一：进入MCP配置界面**

1. 登录AiPy企业版主界面
2. 找到右下角的设置选项并点击
3. 在设置页面中选择MCP选项卡
4. 点击添加按钮进入MCP配置界面

**步骤二：填写MCP配置信息**

1. 输入MCP名称，如web_search
2. 选择MCP类型，如标准输入/输出（stdio）
3. 选择MCP命令格式，如npx
4. 输入MCP参数，如open-websearch@1.1.5
5. 输入MCP运行需要的环境变量（如无则不修改）
6. 点击保存按钮

**步骤三：确认MCP加载状态**

1. 保存后会出现MCP加载页面
2. 等待页面出现已完成按钮
3. 确认MCP页面中显示工具的具体数量
4. 关闭加载页面完成配置

**步骤四：在任务中使用MCP**

1. 在AiPy企业版主界面logo下方点击新建任务按钮
2. 在任务输入框中输入需要执行的任务
3. 勾选需要使用的MCP或智能体
4. 按下Ctrl+Enter或点击去做吧按钮下发任务
5. 在任务对话窗口查看执行过程和结果文件

整个配置流程体现了工具注册、发现、调用的完整链路，与企业智能体建设的实践需求高度匹配。

## 相关问答FAQs

**MCP配置完成后如何确认工具已成功加载？**

MCP添加完成后，系统会显示加载页面，当页面出现已完成按钮时代表MCP添加成功。加载完成后，MCP页面中会显示工具的具体数量，用户可以在此确认MCP已成功配置并可被智能体调用。建议在下发任务前先在测试环境中验证工具调用是否正常。

**AiPy企业版支持哪些类型的MCP工具？**

AiPy企业版支持标准输入/输出（stdio）等多种MCP类型，用户可以通过MCP配置页面选择适合的类型。具体支持的MCP类型和参数格式可以参考MCP官方说明，一般MCP官方都会有详细的配置指南。企业在使用第三方MCP工具时需要核查来源、权限、脚本内容和数据访问范围。

**MCP工具调用的安全性如何保障？**

MCP工具调用建立在明确的授权基础上，智能体需要持有有效凭证才能调用特定工具。企业可以通过环境变量配置密钥等敏感信息，并在设置中配置一体内网IP来控制网络访问边界。完整的调用日志支持事后追溯，便于建立安全基线和合规审查机制。建议企业结合实际部署环境进行安全验证。
