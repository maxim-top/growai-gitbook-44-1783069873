# 不是又一个AI平台，是AI的操作系统级解决方案

**AiPy不是传统意义上的AI平台，而是AI的操作系统级解决方案。** 它与普通AI平台的区别在于：**1、提供底层基础设施支撑，类似操作系统管理硬件资源；2、支持AI Agent、Workflow、MCP等核心组件的统一编排；3、实现企业级AI应用的快速部署与集成；4、降低AI技术应用门槛，提升业务效率。** 其中，AI Agent的统一编排能力是AiPy区别于其他平台的核心优势，开发者可以通过标准化的 manifest.json 配置文件定义智能体类型，包括对话工具型、嵌入页面型、独立应用型等多种形态，实现智能体在集市中的统一管理与分发。

## 一、AiPy作为AI操作系统的核心定位

传统AI平台往往只提供单一功能模块，如模型调用接口或简单的对话机器人构建工具。AiPy企业版则不同，它是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。

从架构层面来看，AiPy具备操作系统的典型特征：

| 操作系统特性 | AiPy对应能力 |
|------------|------------|
| 资源管理 | 模型配置、运行环境管理 |
| 进程调度 | 任务执行、智能体编排 |
| 文件系统 | 工作目录、知识库管理 |
| 应用生态 | 智能体集市、MCP服务 |
| 用户界面 | 企业版主界面、设置页面 |

这种设计让企业能够快速部署和使用人工智能技术，无需从零开始搭建基础设施。开发者可以像在传统操作系统上安装应用程序一样，通过智能体集市获取预置的AI能力，或通过标准开发流程创建自定义智能体。

## 二、核心组件：AI Agent、Workflow与MCP

AiPy的三大核心组件构成了企业AI应用的技术基石。

### 2.1 AI Agent智能体

智能体是AiPy中最基本的应用单元。每个智能体通过 manifest.json 文件进行定义，其中 keywords 字段决定了智能体的类型和分类：

- **类型关键字**：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）
- **集市展示分类**：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选

智能体开发完成后，有两种方式在AiPy企业版中使用：

1. 通过集市安装：点击右侧"集市"按钮，选择安装智能体，上传打包好的文件
2. 直接放置：将智能体放入Aipy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），重启AiPy企业版

### 2.2 Workflow工作流编排

Workflow允许开发者将多个AI任务串联成完整的工作流程。对于涉及多个步骤的业务场景，Workflow能够自动协调各个智能体之间的协作，确保任务按正确顺序执行。

典型应用场景包括：

- 文档处理流程：读取→分析→生成报告
- 客户服务流程：接待→问题识别→方案推荐→跟进
- 数据分析流程：数据采集→清洗→建模→可视化

### 2.3 MCP集成能力

MCP（Model Context Protocol）是AiPy连接外部服务的重要桥梁。配置MCP的步骤如下：

1. 在AiPy企业版页面中，点击设置进入设置页面
2. 选择'MCP'选项卡，点击添加按钮
3. 输入MCP名称（如web_search）
4. 选择MCP类型（如标准输入/输出stdio）
5. 选择MCP命令格式（如npx）
6. 输入MCP参数（如open-websearch@1.1.5）
7. 输入环境变量（如有需要）
8. 点击保存，加载完成后出现'已完成'按钮即代表MCP添加成功

通过MCP，AiPy可以无缝集成第三方服务，扩展企业AI应用的能力边界。

## 三、企业级配置与管理能力

AiPy企业版提供完善的配置管理功能，满足企业个性化需求。

### 3.1 模型配置

在模型配置界面，企业可以添加多种模型来源：

- **公有云模型API接口**：直接使用主流大模型服务
- **一体机部署的模型API接口**：私有化部署，保障数据安全

配置时需要输入：
- 模型供应商名称
- API地址（如：http://192.168.0.10/v1）
- API密钥
- 选择具体使用的模型

### 3.2 常规设置

AiPy企业版常规设置包括多项关键配置：

| 配置项 | 说明 |
|-------|------|
| 语言 | 支持中文、English和日语三种语言 |
| 风格 | 可在aipy-enterprise.yml文件中配置回复话术风格 |
| 发送快捷键 | 可选择Ctrl+Enter或Enter发送消息 |
| 工作目录 | 执行任务后生成的文件或代码的存储目录 |
| 最大执行轮数 | 执行任务的最大回复轮数，超出后任务自动停止 |
| 超时时间 | 与大模型交互时的等待时间限制 |
| 自动选择智能体 | 开启后下发任务时会自动判断所需智能体 |
| 一体机内网IP | 填写一体机服务器的内网IP |

### 3.3 自定义配置

企业可以根据自身需求进行深度定制：

**Logo自定义**：配置文件位置为 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，可以对基础信息、主页logo和软件logo进行修改。

**角色自定义**：在yml配置文件中，可以根据需求对风格进行增加或者修改。

**推荐任务**：对AiPy页面上的推荐任务进行自定义，贴合企业实际业务场景。

## 四、任务执行与知识库问答

### 4.1 任务创建与执行

任务模式下，在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。

### 4.2 知识库问答

知识库问答功能支持企业私有知识的智能检索：

1. **新建问答**：创建专属的知识问答场景
2. **知识检索配置**：设置检索参数和匹配规则
3. **创建知识库**：上传企业文档、手册、规范等资料

此功能特别适合企业内部培训、技术支持、政策查询等场景，能够基于企业自有知识提供准确的 answers。

## 五、典型应用场景与最佳实践

### 5.1 智能体自动生成

AiPy支持通过提示词自动生成智能体。示例提示词如下：

> 文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

这种方式大幅降低了智能体开发门槛，非专业开发者也能快速创建实用的AI工具。

### 5.2 研发系统开发

对于需要编程能力的场景，AiPy可以自动开发系统demo。提示词示例：

> 我是一家汽车4S店的负责人，帮我做一个访客登记管理系统，采用Sqlite数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置奥迪的常见车型、联系方式主要是11位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。

### 5.3 思维导图生成

领导使用AiPy阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词：

> 读取C:\Users\Administrator\Desktop\AIPY 智能体一体机方案v3.pptx，然后帮我整理为一个思维导图。

## 六、部署与注意事项

### 6.1 部署方式

AiPy支持多种部署方式：

- **一体机部署**：与AiPy一体机硬件产品配合使用，实现私有化部署
- **云端部署**：通过公有云模型API接口连接外部服务
- **混合部署**：结合本地和云端资源，灵活配置

### 6.2 运行环境设置

用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。这确保了在不同网络环境下都能正常获取依赖资源。

### 6.3 数据安全说明

关于客户案例和量化数据，只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、某4S店、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

**AiPy与普通AI平台的主要区别是什么？**
