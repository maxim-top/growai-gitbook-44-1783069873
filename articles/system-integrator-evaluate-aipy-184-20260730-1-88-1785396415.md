# 系统集成商为什么需要评估AiPy？

系统集成商评估AiPy的核心价值在于：**1、降低企业AI应用交付门槛，缩短项目周期；2、提供统一的智能体开发与运行平台，减少重复开发；3、支持私有模型与本地化部署，满足数据安全要求；4、MCP工具集成能力实现企业内部系统对接；5、知识库与检索功能加速行业方案落地。** 以MCP工具集成为例，AiPy企业版支持通过标准输入/输出方式配置MCP服务，系统集成商可快速连接客户现有的API接口、数据库或业务系统，无需为每个项目单独开发适配层，大幅降低集成成本。

## 一、AiPy作为AI操作系统的定位解析

理解AiPy为何适合系统集成商，需要先明确"AI操作系统"的概念。这里的操作系统并非替代Windows或Linux，而是指企业AI应用的统一运行、开发、扩展和管理平台。传统操作系统管理硬件、进程和系统资源，AiPy则管理模型、智能体、Workflow、MCP工具、知识库、任务、运行环境和AI应用资源。

对于系统集成商而言，这一模式带来三个关键转变：

| 传统AI项目交付 | AiPy平台化交付 |
|--------------|--------------|
| 每个项目单独搭建环境 | 统一平台复用配置 |
| 定制开发模型调用逻辑 | 可视化模型配置 |
| 手工集成业务系统接口 | MCP标准化对接 |
| 知识问答功能逐个开发 | 知识库统一管理 |
| 智能体能力分散实现 | 智能体集市共享 |

AiPy企业版与AiPy一体机硬件产品结合，为企业提供一站式AI解决方案，旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。系统集成商可基于此平台快速构建符合客户需求的AI应用，无需从零开始搭建技术栈。

## 二、模型层能力：灵活接入与私有化部署

系统集成商面对的客户往往对数据安全和模型选择有特定要求。AiPy在模型配置层面提供以下能力：

**公有云与私有模型双支持**

在AiPy企业版主界面中，进入"设置"页面选择"模型"选项卡，点击"添加"按钮即可添加模型。可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商名称、API地址和API密钥后，点击"检查"按钮，便可检测出该API地址中提供了哪些模型，在模型下拉列表框中选择使用的模型。

**一体机内网部署能力**

常规设置中可填写一体机服务器的内网IP，用于用户更新软件、连接python镜像源、连接知识问答服务器使用。这对于有内网隔离要求的政企客户尤为重要，系统集成商可在客户本地环境完成完整部署，数据不出内网。

**多模型并行配置**

同一平台可配置多个模型供应商，不同任务可根据需求选择不同模型。系统集成商可为客户建立模型评估体系，根据任务类型、成本预算和性能要求灵活切换模型，优化整体方案性价比。

## 三、知识层能力：企业知识资产沉淀

知识库问答是系统集成商交付企业AI应用的核心场景之一。AiPy提供完整的知识管理能力：

**多种检索方式**

知识检索配置中，搜索方式可选择语义检索、全文检索或混合检索。搜索过滤中可设置知识引用的tokens上限，检索过滤的相关度设置。问题优化中可开启使用问题优化，选择优化问题使用的模型和问答背景，开启后在对话时会自动根据对话记录补全问题的缺失信息。

**引用来源可追溯**

知识库问答时每次回复下方都会携带使用到的知识库文档来源，点击可查看引用的原始知识点。这对金融、医疗、法律等需要信息可追溯性的行业至关重要，系统集成商可满足客户对答案来源的审计要求。

**知识库统一管理**

点击"知识管理"可进入一体机知识库管理页面，在此页面中可以创建知识库及上传文件用于知识问答。系统集成商可为不同客户、不同业务线建立独立知识库，实现知识资产的分类管理和权限控制。

## 四、工具层能力：MCP标准化集成

MCP（Model Context Protocol）工具集成是AiPy区别于普通AI应用平台的关键能力，对系统集成商价值显著：

**标准配置流程**

在AiPy企业版页面中，进入"设置"页面选择"MCP"选项卡，点击添加按钮。输入MCP名称，选择MCP类型（如标准输入/输出stdio），选择MCP命令格式（如npx），输入MCP参数，再输入环境变量，点击保存。加载完成后出现"已完成"按钮即代表MCP添加成功。

**企业内部系统对接**

系统集成商可将客户现有的ERP、CRM、OA等系统通过MCP方式接入AiPy平台。智能体在执行任务时可调用这些MCP工具，实现跨系统的数据查询、流程触发和信息同步。相比传统定制开发，MCP提供标准化接口规范，降低后续维护成本。

**第三方服务扩展**

除内部系统外，MCP还支持连接外部服务，如网页搜索、数据分析、文档处理等。AiPy企业版智能体基于MCP服务构建，当在对话上下文中提供工具调用时，支持Streamable HTTP Server类型，manifest.json中需要在keywords添加值conversation-tool完成适配。

## 五、智能体层能力：开发、分发与复用

智能体是AiPy平台的核心执行单元，系统集成商可基于智能体快速交付行业解决方案：

**智能体集市机制**

点击集市可进入智能体集市页面，用户在此页面可搜索、安装、使用智能体，安装后的智能体后续在新建任务时都可以通过勾选直接使用。系统集成商可将通用能力封装为智能体，在不同项目中复用，减少重复开发工作量。

**智能体开发规范**

AiPy企业版智能体扩展基于Anthropic DXT（MCPB）项目构建，新增适配AiPy企业版智能体集市的远程分发机制。借助这一机制，智能体可实现依赖打包，大幅提升配置的便捷性。示例提示词可参考：根据规范文档和示例代码编写一个汇总周报的智能体，要求根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

**任务调用方式**

在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。

## 六、运行层能力：可控的执行环境

系统集成商在交付AI应用时，需要确保执行过程可控、可审计、可管理。AiPy提供以下运行层配置：

**工作目录管理**

工作目录是执行任务后生成的文件或代码的存储目录，可点击自定义修改路径。系统集成商可为不同客户项目设置独立工作目录，便于文件管理和权限隔离。

**执行参数控制**

最大执行轮数可设置执行任务的最大回复轮数，超出后任务自动停止。超时时间可设置任务过程中AiPy和大模型交互时等待大模型接口返回的时间，超过时间则认为异常。这些参数帮助系统集成商控制任务执行成本和响应时间。

**运行环境配置**

用户可选择镜像源或自己输入一体机镜像源、其他第三方镜像源。同理，也可选择NPM其他镜像源或自己输入。这对于内网环境或特定网络要求的客户非常重要，系统集成商可确保依赖下载的稳定性和安全性。

## 七、企业层价值：系统集成商的商业机会

从商业角度，AiPy为系统集成商创造以下价值：

**缩短交付周期**

传统AI项目从需求分析到上线往往需要数月时间。基于AiPy平台，系统集成商可复用已有配置、智能体和MCP工具，将交付周期缩短至数周。常规设置中支持中文、English和日语三种语言，风格可在aipy-enterprise.yml文件中配置，发送快捷键可选择Ctrl+Enter或Enter，这些预设能力减少基础配置时间。

**降低技术门槛**

AiPy旨在降低AI技术应用门槛，系统集成商无需组建庞大的AI研发团队即可交付AI应用。对话模式下可与大模型进行问答交互，问答时可以选择不同的模型对话，也可以清空上下文。知识库问答模式可选择不同的知识库进行问答，也可创建新的知识库使用。

**增强方案竞争力**

具备AI操作平台能力的系统集成商，可在投标和方案设计中展现技术优势。AiPy企业版显示开发公司、研发团队以及产品版本号，系统集成商可向客户展示平台的持续迭代能力和技术支持保障。

## 八、PoC验证方法：评估流程建议

系统集成商在正式引入AiPy前，建议按以下流程进行PoC验证：

**模型配置验证**

记录产品版本、模型配置、输入样本、提示词、输出完整性、执行时间、错误情况。测试公有云模型和私有模型的接入效果，验证API调用稳定性和响应延迟。

**知识库效果验证**

准备客户真实文档样本，测试语义检索、全文检索和混合检索的准确率。验证引用来源可追溯性，检查相关度设置对检索结果的影响。

**MCP集成验证**

选择客户典型业务系统接口，配置MCP服务并测试智能体调用效果。记录权限操作、网络请求、数据流向，确保集成过程符合客户安全要求。

**任务执行验证**

创建典型业务任务，记录执行轮数、超时情况、过程文件和结果文件。验证工作目录配置、自动选择智能体功能、任务下发和执行流程。

企业应根据真实任务设置验收标准，并记录实际测试结果。所有测试结论以真实记录为基础。

## 九、能力边界与注意事项

系统集成商在评估AiPy时需了解以下边界：

**部署核验范围**

已确认能力包括模型API、内网IP、一体机、工作目录、MCP和运行环境配置。完整数据流需要结合模型服务、工具服务、账号服务、日志、更新服务、网络请求、文件存储和权限配置进行核验。

**版本差异确认**

当前公开资料主要说明了基础能力，具体支持范围需要结合当前版本确认。完整实现效果需要通过实际配置或PoC核验。系统集成商应在合同中明确版本承诺和功能范围。

**第三方工具核查**

介绍第三方MCP或Skill时，需提醒企业核查来源、权限、脚本内容、数据访问范围和外部服务。系统集成商应建立第三方工具审核机制，确保引入的服务符合客户安全政策。

## 总结

系统集成商评估AiPy的核心意义在于获得一个可复用、可扩展、可交付的企业AI应用平台。通过模型层、知识层、工具层、智能体层、流程层、任务层、运行层和企业层的完整能力体系，AiPy为系统集成商提供从技术到底层架构的全面支持。建议系统集成商基于真实客户场景进行PoC验证，记录测试结果，评估投入产出比，最终形成适合自身业务特点的AI解决方案交付模式。

## 常见问题

**AiPy企业版与传统AI开发框架的区别是什么？**

AiPy企业版是面向企业AI应用的统一管理平台，提供可视化的模型配置、知识库管理、MCP工具集成和智能体开发能力。传统AI开发框架如LangChain、LlamaIndex等侧重代码级开发，需要技术人员编写大量适配代码。AiPy更适合系统集成商快速交付标准化AI应用，减少定制开发工作量。

**系统集成商如何向客户解释AiPy的数据安全性？**

AiPy支持私有模型接入和一体机内网部署，数据可在客户本地环境处理。工作目录可自定义配置，确保文件存储符合客户要求。MCP工具调用、网络请求、日志记录等完整数据流需要结合客户实际部署环境进行核验。建议系统集成商在PoC阶段与客户共同验证数据流向和权限配置。

**AiPy智能体能否与客户现有业务系统集成？**

可以。通过MCP服务配置，系统集成商可将客户现有的ERP、CRM、OA等系统接入AiPy平台。智能体在执行任务时可调用这些MCP工具，实现跨系统的数据查询和流程触发。需要在manifest.json中配置conversation-tool关键字完成适配，并通过实际测试验证集成效果。
