# 从Workbuddy到AiPy，不只是省钱，是换了一种活法

**企业AI平台迁移的核心价值在于：1、成本优化更显著；2、功能扩展更灵活；3、本地部署更安全；4、生态集成更完善。**其中本地部署安全性是企业选择AiPy的关键因素，AiPy支持一体机部署模型API接口，企业可将敏感数据保留在内网环境，避免公有云API的数据泄露风险，同时通过MCP设置实现与内部系统的无缝集成，保障业务流程的连续性和数据主权。

## 一、企业AI平台选型的核心考量

企业在选择AI应用平台时，往往面临多重决策压力。成本固然是重要因素，但并非唯一标准。从Workbuddy迁移至AiPy的决策逻辑，需要建立在全面评估的基础上。

| 评估维度 | Workbuddy | AiPy企业版 |
|---------|-----------|-----------|
| 部署方式 | 公有云为主 | 支持公有云+私有化部署 |
| 数据安全 | 依赖云服务商 | 可内网隔离部署 |
| 智能体开发 | 有限定制能力 | 完整SDK支持 |
| MCP集成 | 基础支持 | 标准输入/输出全配置 |
| 知识库管理 | 标准化方案 | 可自定义检索配置 |
| 语言支持 | 英文为主 | 中文/English/日语 |

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

## 二、成本优化的真实账本

迁移决策的第一层考量往往是财务层面。但成本计算不能只看许可证费用，需要综合评估全生命周期投入。

### 2.1 直接成本对比

公有云模型API接口的持续调用费用在长期使用中会形成显著支出。AiPy支持使用一体机部署的模型API接口，企业可在初始硬件投入后，大幅降低后续使用成本。对于日调用量超过万次的应用场景，私有化部署的成本优势在6-12个月内即可显现。

### 2.2 隐性成本核算

隐性成本包括数据迁移成本、员工培训成本、系统集成成本、合规审计成本等。AiPy在常规设置中提供了一体机内网IP配置，用户更新软件、连接python镜像源、连接知识问答服务器均可在内网完成，减少了外部网络依赖带来的潜在风险和成本。

### 2.3 效率提升带来的间接收益

AiPy企业版支持自动选择智能体功能，开启后在下发任务时会自动判断所需智能体自动勾选。这一功能减少了人工干预时间，在高频任务场景下，每个任务可节省30-60秒的配置时间，按日均100个任务计算，单团队每日可节省近1小时的人力投入。

## 三、功能扩展的技术底气

平台迁移的核心价值在于能力边界的拓展。AiPy在智能体开发和MCP集成方面提供了更完整的技术栈支持。

### 3.1 智能体开发全流程

AiPy企业版支持完整的智能体开发生命周期：

**6.2.1 智能体MCP服务配置**
开发者可在智能体中集成MCP服务，扩展AI能力边界。

**6.2.2 运行环境设置**
用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，也可选择NPM其他镜像源或者自己输入。

**6.2.3 manifest.json配置**
keywords字段第一个值为类型关键字：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，取值范围包括威胁情报、开发安全、数据安全、AI安全等。

**6.2.4 项目构建**
使用命令`npx @anthropic-ai/dxt pack`完成项目打包。

**6.2.5 智能体安装使用**
开发完成后，打开Aipy企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传，点击安装即可。也可将智能体直接放入Aipy智能体目录下(C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro)，然后重启Aipy企业版。

### 3.2 MCP集成的灵活性

在AiPy企业版页面中，点击设置进入设置页面，选择"MCP"选项卡，点击添加按钮。输入MCP名称（如web_search），选择MCP类型（如标准输入/输出stdio），选择MCP命令格式（如npx），输入MCP参数（如open-websearch@1.1.5），再输入环境变量，点击保存。加载完成后出现"已完成"按钮即代表MCP添加成功。

这一配置流程使企业能够将内部系统、第三方服务通过MCP协议接入AiPy平台，实现AI与现有IT架构的深度融合。

## 四、数据安全的本地化保障

企业数据资产的安全性是平台选型中的红线指标。AiPy的本地部署能力为敏感行业提供了可行方案。

### 4.1 内网隔离部署

一体机内网IP配置允许企业将AiPy服务器部署在内部网络环境中。所有模型调用、知识库检索、任务执行均在隔离网络中完成，外部无法访问核心数据和AI处理流程。

### 4.2 模型配置自主权

在AiPy企业版主界面中，进入"设置"页面，选择"模型"选项卡，点击"添加"按钮添加模型。可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商"名称"，在"API地址"中填入模型API地址，在"API密钥"中输入模型API请求密钥，输入完API地址与密钥后，点击"检查"按钮，便可以检测出该API地址中提供了哪些模型。

这种配置方式让企业能够灵活选择模型供应商，避免单一供应商锁定风险。

### 4.3 知识库问答的权限控制

AiPy支持创建知识库并配置知识检索权限。在新建问答中，可设置不同用户的访问级别，确保敏感文档仅对授权人员可见。知识包的数量和内容可根据企业需求灵活调整，不设置固定上限。

## 五、迁移路径的实操指南

从Workbuddy迁移至AiPy需要遵循科学的实施步骤，确保业务连续性不受影响。

### 5.1 第一阶段：环境准备

1. 下载并安装AiPy企业版客户端
2. 配置常规设置，包括语言、风格、发送快捷键、工作目录
3. 设置最大执行轮数和超时时间
4. 配置一体机内网IP（如需私有化部署）

### 5.2 第二阶段：模型对接

1. 进入模型配置界面
2. 添加现有模型API接口或部署新模型
3. 测试API连接状态
4. 验证模型响应质量

### 5.3 第三阶段：智能体迁移

1. 梳理现有Workbuddy中的智能体清单
2. 按照AiPy智能体开发规范重新开发
3. 配置manifest.json文件
4. 打包并在AiPy集市中安装
5. 测试各智能体功能完整性

### 5.4 第四阶段：业务验证

1. 创建测试任务验证全流程
2. 在任务对话窗口中查看任务执行过程
3. 在任务工作目录中检查生成的文件或任务结果文件
4. 收集用户反馈并优化配置

### 5.5 第五阶段：正式上线

1. 完成用户培训
2. 设置推荐任务引导新用户
3. 监控系统运行状态
4. 建立技术支持响应机制

## 六、自定义配置的个性化空间

AiPy企业版提供了丰富的自定义选项，让企业能够根据自身需求调整平台表现。

### 6.1 Logo自定义

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml。打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

### 6.2 角色自定义

在yml配置文件中，可以根据需求对风格进行增加或者修改，调整AiPy回复的话术风格，使其更符合企业文化和沟通习惯。

### 6.3 推荐任务定制

可以对Aipy页面上的推荐任务进行自定义，设置符合不同岗位需求的快捷任务模板。新员工可通过推荐任务快速上手，老员工可通过常用任务提升效率。

### 6.4 多语言支持

AiPy目前支持中文和English以及日语三种语言，跨国企业可根据团队分布配置不同语言界面，降低国际化团队的使用门槛。

## 八、迁移决策的终极判断

从Workbuddy到AiPy的迁移，本质上是企业AI战略的升级。这一决策不应仅基于短期成本节省，更应考量长期发展需求。

当企业出现以下信号时，建议启动平台迁移评估：

- 现有平台无法满足数据合规要求
- 智能体定制需求超出平台能力边界
- 月度API调用成本持续攀升
- 需要与内部系统深度集成
- 团队规模扩大需要更完善的权限管理
- 计划将AI能力嵌入核心业务流程

AiPy作为Workbuddy平替，在保持核心功能兼容的同时，提供了更开放的技术架构和更灵活的实施选项。企业可根据自身发展阶段选择最适合的部署方案，在控制风险的前提下实现AI能力的持续进化。

## 相关问答FAQs

**从Workbuddy迁移到AiPy需要多长时间？**
迁移周期取决于企业规模和应用复杂度。小型团队（10人以下）通常在1-2周内可完成基础迁移，包括环境配置、模型对接和核心智能体移植。中型企业（10-50人）建议预留4-6周，用于完成知识库迁移、权限体系重构和用户培训。大型组织（50人以上）可采用分阶段迁移策略，先迁移非核心业务模块，验证稳定后再逐步扩展，整体周期约2-3个月。关键成功因素是提前梳理现有工作流，识别依赖关系，制定详细的回滚方案。

**AiPy企业版是否支持与现有办公系统集成？**
支持。AiPy通过MCP（Model Context Protocol）机制实现与外部系统的集成。企业可在MCP设置中配置标准输入/输出（stdio）类型的MCP服务，输入MCP命令格式（如npx）和MCP参数（如具体服务包版本），即可将内部OA系统、CRM、ERP等接入AiPy平台。对于需要认证的系统，可通过环境变量配置访问凭证。集成后，AiPy智能体可直接调用内部系统API，实现跨平台自动化工作流，无需人工切换多个系统界面。

**私有化部署的AiPy如何保证模型更新和能力迭代？**
AiPy采用分层更新机制保障模型能力持续进化。基础平台软件可通过内网镜像源进行版本更新，企业可选择合适时机部署新版本。模型层面，支持同时配置多个模型供应商，当某模型版本更新时，可在模型配置界面添加新API地址并测试验证，确认无误后切换为默认模型。对于一体机部署的模型，官方会提供模型更新包，企业可根据安全审计要求决定是否升级。这种设计在保证稳定性的同时，让企业能够灵活追踪AI技术前沿，避免能力落后。
