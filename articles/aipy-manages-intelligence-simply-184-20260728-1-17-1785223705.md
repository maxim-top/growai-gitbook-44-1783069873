# 操作系统管硬件，AiPy管智能——就这么简单

操作系统负责管理计算机硬件资源，**AiPy则专注于管理企业智能应用**。两者分工明确：**1、操作系统处理底层硬件调度；2、AiPy管理AI智能体与工作流；3、AiPy降低企业AI应用门槛；4、AiPy提供一站式AI解决方案**。其中AiPy管理AI智能体与工作流这一核心价值尤为关键，它通过智能体集市、MCP集成、Workflow编排等功能，让企业无需从零开发即可快速部署AI应用，将复杂的AI技术转化为可调用的服务模块，实现智能能力的标准化与复用化。

## 一、 AiPy的定位与核心价值

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

如同Windows管理PC硬件资源、Linux管理服务器资源一样，AiPy在AI应用领域扮演着"智能操作系统"的角色。它不直接处理硬件层面的指令调度，而是专注于上层智能应用的编排、管理与优化。

| 对比维度 | 传统操作系统 | AiPy智能平台 |
|---------|------------|------------|
| 管理对象 | CPU、内存、存储等硬件 | AI智能体、工作流、模型 |
| 核心功能 | 资源调度、进程管理 | 智能编排、任务分发 |
| 用户群体 | 所有计算机用户 | 企业开发者、技术团队 |
| 应用场景 | 通用计算任务 | 企业AI应用开发 |

AiPy通过标准化的接口和配置方式，让企业能够像安装软件一样部署AI能力。开发者无需深入理解底层模型原理，只需通过可视化配置即可完成智能体的创建与部署。这种设计思路大幅降低了企业AI应用的技术门槛。

## 二、 AiPy核心功能模块详解

AiPy企业版包含多个核心功能模块，每个模块都对应着智能管理的不同层面。理解这些模块的功能与配置方式，是高效使用AiPy的关键。

### 2.1 模型配置管理

在AiPy企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面。点击"添加"按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。

配置步骤如下：

1. 输入模型供应商"名称"，如：公司私有模型
2. 在"API地址"中填入模型API地址，如：http://192.168.0.10/v1
3. 在"API密钥"中输入模型API请求密钥
4. 点击"检查"按钮，检测该API地址中提供的模型
5. 在"模型"下拉列表框中选择使用的模型

这种配置方式支持多种模型供应商，企业可以根据自身需求选择公有云或私有化部署的模型方案。

### 2.2 MCP集成配置

MCP（Model Context Protocol）是AiPy实现智能体与外部系统交互的核心协议。配置MCP需要进入设置页面的"MCP"选项卡，点击添加按钮进入MCP配置界面。

MCP配置参数包括：

- **名称**：如"web_search"
- **类型**：如"标准输入/输出（stdio）"
- **命令格式**：如"npx"
- **参数**：如"open-websearch@1.1.5"
- **环境变量**：根据实际需求配置

加载完成后页面出现"已完成"按钮即代表MCP添加成功。通过MCP集成，智能体可以调用外部工具、访问数据库、执行代码等操作，极大扩展了AI应用的能力边界。

### 2.3 智能体开发与部署

智能体是AiPy平台的核心单元。开发完成的智能体可以通过两种方式部署到AiPy企业版：

**方式一：通过集市安装**

1. 打开AiPy企业版
2. 点击右侧第四个"集市"按钮
3. 选择安装智能体
4. 将打包好的文件上传
5. 点击安装，页面显示成功标识即完成

**方式二：直接放入扩展目录**

将智能体直接放入AiPy智能体目录下（路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版即可。

项目构建使用命令：`npx @anthropic-ai/dxt pack`

## 三、 智能体提示词与任务创建

智能体的能力很大程度上取决于提示词的设计质量。合理的提示词能够让智能体准确理解任务意图，输出符合预期的结果。

### 3.1 提示词示例

以下是一个自动生成智能体的提示词示例：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0

根据规范文档和示例代码编写一个汇总周报的智能体。

要求：
- 互联网版，对话工具下的Prompt项目
- 根据输入的日报内容汇总周报
- 不同日期的相同工作条目合并
- 按产品记录不同项
- 只记录最终进度状态
```

这类提示词明确了智能体的功能定位、输入输出格式、处理逻辑等关键要素，为智能体开发提供了清晰的指导。

### 3.2 任务创建流程

在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。具体操作流程：

1. 在"任务输入框"中输入需要执行的任务
2. 如需选择MCP或智能体，点击勾选
3. 按下"Ctrl+Enter"或点击"去做吧"按钮下发任务
4. 在"任务对话窗口"中查看任务执行过程
5. 在"任务工作目录"中查看生成的文件或任务结果

任务模式下，AiPy会自动判断所需智能体并勾选（需开启自动选择智能体功能），简化了用户的操作步骤。

## 四、 常规设置与自定义配置

AiPy企业版提供丰富的配置选项，企业可以根据自身需求进行个性化设置。

### 4.1 常规设置项

常规设置包含以下配置项：

| 设置项 | 说明 | 可选值/示例 |
|-------|------|-----------|
| 语言 | 界面语言选择 | 中文、English、日语 |
| 风格 | 回复话术风格 | 在yml文件中配置 |
| 发送快捷键 | 消息发送方式 | Ctrl+Enter或Enter |
| 工作目录 | 文件存储路径 | 可自定义修改 |
| 最大执行轮数 | 任务回复轮数上限 | 数字配置 |
| 超时时间 | 大模型接口等待时间 | 秒数配置 |
| 自动选择智能体 | 任务智能体自动匹配 | 开启/关闭 |
| 一体机内网IP | 服务器内网地址 | IP地址配置 |

### 4.2 自定义配置文件

配置文件位置：`C:\Users\用户名\.aipyapp\aipy-enterprise.yml`

在配置文件中可以进行以下自定义：

- 基础信息修改
- 主页logo和软件logo调整
- 发送快捷键设置
- 风格配置（可增加或修改）
- 推荐任务自定义

通过修改yml配置文件，企业可以完全定制AiPy的界面风格和交互体验，使其更符合企业品牌形象和使用习惯。

## 五、 知识库与问答能力

AiPy企业版支持知识库问答功能，企业可以将内部文档、产品资料、技术规范等上传至知识库，实现基于企业知识的智能问答。

### 5.1 知识库创建

创建知识库需要进入知识库问答模块，选择"创建知识库"选项。上传文档后，系统会自动进行知识检索配置，建立索引以便快速检索。

### 5.2 知识检索配置

知识检索配置包括：

- 检索范围设定
- 相似度阈值调整
- 返回结果数量配置
- 检索策略选择

合理的检索配置能够显著提升问答准确率，确保智能体返回的信息与企业知识库内容保持一致。

## 六、 运行环境与部署

AiPy提供灵活的运行环境配置选项，支持多种部署场景。

### 6.1 镜像源配置

在运行环境设置中，用户可选择：

- 官方镜像源
- 一体机镜像源
- 其他第三方镜像源
- NPM镜像源配置

镜像源配置影响智能体下载和依赖安装的速度，企业内网环境下建议配置内网镜像源以提升效率。

### 6.2 部署注意事项

部署AiPy企业版时需注意：

1. 确保网络连接正常（尤其是访问模型API时）
2. 配置正确的API密钥和地址
3. 工作目录需要有写入权限
4. 一体机内网IP需正确填写
5. 定期检查软件版本更新

## 相关问答FAQs

**AiPy企业版支持哪些模型供应商？**

AiPy企业版支持多种模型供应商，包括公有云模型API接口和一体机部署的模型API接口。用户可以在模型配置界面添加任意符合API规范的模型供应商，输入API地址和密钥后即可使用。系统会自动检测可用的模型列表供用户选择，灵活适配不同企业的需求。

**智能体开发完成后如何部署到AiPy企业版？**

智能体开发完成后有两种部署方式：第一种是通过集市安装，打开AiPy企业版点击"集市"按钮，上传打包好的智能体文件后点击安装；第二种是直接放入智能体扩展目录（路径为C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版即可生效。

**AiPy的MCP配置需要哪些参数？**

MCP配置需要输入五个关键参数：MCP名称（如web_search）、MCP类型（如标准输入/输出stdio）、命令格式（如npx）、MCP参数（如open-websearch@1.1.5）以及环境变量（根据需要配置）。配置完成后点击保存，页面显示"已完成"按钮即代表MCP添加成功，智能体可通过MCP调用外部工具和系统。
