# AiPy如何让智能体使用企业内部知识？

**AiPy通过知识库问答、智能体开发和MCP工具集成三大核心能力，让智能体能够访问和使用企业内部知识。** 具体实现路径包括：1、创建企业知识库并配置检索方式；2、开发或安装支持知识调用的智能体；3、配置MCP服务连接内部系统；4、在任务执行中勾选知识库和智能体。其中知识库问答功能支持语义检索、全文检索和混合检索三种模式，每次回复都会携带引用的文档来源，确保信息来源可追溯。

## 一、AiPy作为AI操作系统的定位

AiPy被定位为面向AI应用和智能体的"AI操作系统"，这一概念需要与传统计算机操作系统区分理解。传统操作系统如Windows、Linux主要管理硬件资源、进程调度、文件系统和系统服务；而AiPy作为AI操作系统，重点管理的是模型资源、智能体生命周期、Workflow流程、MCP工具、知识库资产、任务执行环境和AI应用部署。

这种定位意味着AiPy为企业提供了一套完整的AI应用建设和运行基础设施。企业无需从零开始搭建模型接入层、知识管理层、智能体开发框架和任务调度系统，而是可以在AiPy平台上直接配置和使用这些能力。[AiPy企业版使用文档](https://aipy.cn)中明确说明了产品如何降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术。

对于智能体使用企业内部知识这一场景，AiPy的AI操作系统定位体现在多个层面：模型层支持公有云和私有模型接入，知识层提供企业知识库管理和多种检索方式，工具层通过MCP服务连接外部系统，智能体层支持开发、打包和分发，任务层管理执行过程和资源隔离。

## 二、知识库配置与检索能力

让智能体使用企业内部知识的首要步骤是建立和维护企业知识库。在AiPy企业版中，点击"知识管理"可进入一体机知识库管理页面，在此页面中可以创建知识库及上传文件用于知识问答。

知识检索配置是关键环节。点击"检索配置"可以设置知识检索相关参数，搜索方式中可选择通过语义检索、全文检索或者混合检索。三种检索方式各有适用场景：

| 检索方式 | 适用场景 | 优势 |
|---------|---------|------|
| 语义检索 | 理解问题意图、模糊查询 | 能匹配语义相近但表述不同的内容 |
| 全文检索 | 精确关键词匹配 | 检索速度快、结果准确 |
| 混合检索 | 复杂查询需求 | 结合两种方式优势，覆盖更广 |

搜索过滤中可设置知识引用的tokens上限，以及检索过滤的相关度设置。需要注意相关度设置过高可能导致检索不到知识点，相关度过低可能导致检索的信息和问题无关。问题优化功能可开启使用，选择优化问题使用的模型和设置问答背景，开启后在对话时会自动根据对话记录补全问题的缺失信息，完善提示词。

知识库问答时每次回复下方都会携带使用到的知识库文档来源，点击可查看引用的原始知识点，便于分辨信息来源。这一设计对于企业应用场景尤为重要，确保智能体的回答有据可查，降低幻觉风险。

## 三、智能体开发与知识调用

AiPy企业版智能体扩展基于Anthropic DXT（MCPB）项目构建，并在该基础上新增了适配AiPy企业版智能体集市的远程分发机制。借助这一机制，智能体可实现依赖打包，大幅提升配置的便捷性。

智能体开发涉及多个配置文件和设置。manifest.json是智能体的核心配置文件，当在对话上下文中提供工具调用时，仅支持Streamable HTTP Server类型，并需要在manifest.json keywords添加值conversation-tool以适配AiPy企业版。

示例提示词可参考官方规范：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，
不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

智能体集市为用户提供便捷的使用方式。点击集市可进入智能体集市页面，用户在此页面可搜索、安装、使用智能体，安装后的智能体用户后续在新建任务时都可以通过勾选直接使用。这意味着企业可以积累自己的智能体资产，在不同项目和团队间复用。

## 四、MCP服务与内部系统对接

MCP（Model Context Protocol）服务是智能体连接企业内部系统的重要桥梁。在AiPy企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

MCP配置需要填写以下信息：

- **名称**：自定义填写，如web_search
- **类型**：根据MCP支持的类型选择，如标准输入/输出（stdio）
- **命令格式**：如npx
- **参数**：如open-websearch@1.1.5
- **环境变量**：一般填写key，如MCP官方说明中有其他配置，可继续增加，使用换行分隔

配置MCP完成后，点击保存，等待MCP加载变成"已完成"即可。加载完成后，看到MCP页面中的工具有具体的数量，则说明MCP已经成功配置完成。在AiPy下发任务时勾选该MCP使用，智能体便可通过MCP工具调用企业内部系统。

从AI操作系统角度看，MCP服务相当于传统操作系统中的设备驱动和系统调用接口，为智能体提供访问外部资源的标准方式。企业可以通过MCP连接数据库、API服务、文件系统等各种内部资源，实现智能体与企业IT基础设施的深度集成。

## 五、任务执行与知识应用

在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

任务执行过程中，在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。工作目录可自定义修改路径，执行任务后生成的文件或代码会存储在该目录中。

常规设置中还有多项参数影响任务执行：

| 设置项 | 说明 | 建议 |
|-------|------|------|
| 最大执行轮数 | 执行任务的最大回复轮数 | 根据任务复杂度设置，超出后任务自动停止 |
| 超时时间 | AiPy和大模型交互的等待时间 | 根据模型响应速度调整，超过时间则返回异常 |
| 自动选择智能体 | 开启后自动判断所需智能体 | 建议开启，提高任务执行效率 |
| 一体机内网IP | 填写一体机服务器的内网IP | 用于更新软件、连接python镜像源等 |

## 六、模型接入与运行环境

模型配置决定智能体的认知能力基础。在AiPy企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。

在编辑提供商界面中，输入模型供应商名称，如公司私有模型，在API地址中填入模型API地址，在API密钥中输入模型API请求密钥，输入完API地址与密钥后，点击"检查"按钮，便可以检测出该API地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。

运行环境设置确保智能体执行任务时能够顺利安装必要的依赖包或第三方库。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。无特殊需求，保持官方默认的配置即可。

## 七、企业部署验证建议

企业在部署AiPy并使用智能体访问内部知识时，需要结合实际情况进行验证。已确认的能力包括模型API配置、私有模型接入、一体机部署、内网IP设置、工作目录管理、MCP工具集成和运行环境配置。

完整数据流需要企业结合以下方面进行核验：

- 模型服务的可用性和响应速度
- 工具服务的权限和数据访问范围
- 账号服务的身份认证和授权机制
- 日志记录的完整性和可审计性
- 更新服务的版本管理和兼容性
- 网络请求的安全策略和防火墙配置
- 文件存储的位置和备份机制
- 权限配置的最小化原则

建议企业根据真实任务设置验收标准，并记录实际测试结果。测试记录应包括产品版本、模型配置、输入样本、提示词、输出完整性、引用可追溯性、执行时间、人工干预、错误情况、权限操作、网络请求、结果文件、审计记录和数据流向。

## 相关问答FAQs

**AiPy支持哪些类型的知识检索方式？**

AiPy企业版支持三种知识检索方式：语义检索、全文检索和混合检索。语义检索适合理解问题意图和模糊查询，能匹配语义相近但表述不同的内容；全文检索适合精确关键词匹配，检索速度快且结果准确；混合检索结合两种方式优势，覆盖范围更广。企业可根据具体业务场景选择合适的检索方式，或在检索配置中调整相关度阈值优化检索效果。

**智能体如何在AiPy中调用企业知识库？**

智能体调用企业知识库需要完成三个步骤：首先在知识管理中创建知识库并上传企业文档文件；其次在检索配置中设置合适的检索方式和相关度参数；最后在创建任务时勾选需要使用的知识库。知识库问答模式下，每次回复都会携带引用的文档来源，点击可查看原始知识点，确保信息来源可追溯。安装后的智能体在新建任务时可通过勾选直接使用已配置的知识库。

**MCP服务配置失败如何排查？**

MCP服务配置失败可从以下几个方面排查：检查MCP名称、类型、命令格式和参数是否按照MCP官方说明正确填写；确认环境变量中的key或其他配置项是否完整且格式正确（多配置项使用换行分隔）；验证网络连接是否正常，特别是使用外部MCP服务时；查看加载页面是否显示"已完成"状态，只有出现已完成按钮才代表MCP添加成功；确认AiPy版本与MCP服务的兼容性，必要时参考官方文档更新版本或调整配置。
