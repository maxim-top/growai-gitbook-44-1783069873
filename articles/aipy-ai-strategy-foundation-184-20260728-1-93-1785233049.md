# 你的AI战略缺一个底座，那个底座叫AiPy

**企业 AI 战略落地需要三大核心支撑：1、统一的 AI 操作系统底座；2、可扩展的智能体开发能力；3、企业级安全与部署方案。** AiPy 作为 AI 操作系统，为企业提供一站式 AI 解决方案，降低 AI 技术应用门槛。其中，智能体开发能力是企业快速部署 AI 应用的关键，通过 AiPy 企业版的智能体集市和开发工具，开发者可以在数小时内完成从需求到部署的全流程，无需从零搭建底层框架，极大提升开发效率。

## 一、企业 AI 战略的核心挑战

当前企业在推进 AI 战略时普遍面临以下问题：

| 挑战类型 | 具体表现 | 影响程度 |
|---------|---------|---------|
| 技术门槛高 | 需要专业团队搭建底层框架 | 高 |
| 部署周期长 | 从开发到上线需要数月时间 | 高 |
| 安全性担忧 | 数据隐私和合规问题 | 高 |
| 成本压力大 | 模型调用和基础设施投入大 | 中 |
| 集成复杂度 | 与现有系统对接困难 | 中 |

这些问题导致许多企业的 AI 项目停留在试点阶段，难以规模化落地。AiPy 企业版正是为解决这些痛点而设计，它是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

## 二、AiPy 作为 AI 操作系统的核心能力

AiPy 企业版的核心价值在于其作为 AI 操作系统的定位，提供以下关键能力：

### 2.1 模型配置与管理

在 AiPy 企业版主界面中，用户可以轻松配置多种模型资源：

- 进入"设置"页面，选择"模型"选项卡
- 点击"添加"按钮添加模型
- 支持公有云模型 API 接口和一体机部署的模型 API 接口
- 输入模型供应商名称、API 地址、API 密钥
- 点击"检查"按钮检测可用模型
- 在模型下拉列表框中选择使用的模型

这种灵活的模型配置方式使企业可以根据自身需求选择合适的 LLM 大语言模型，既可以使用云端服务，也可以在内网环境中部署私有模型，确保数据安全。

### 2.2 MCP 集成能力

MCP（Model Context Protocol）是 AiPy 的重要集成能力，配置流程如下：

1. 在 AiPy 企业版页面中，点击设置进入设置页面
2. 选择"MCP"选项卡，点击添加按钮
3. 输入 MCP 名称（如 web_search）
4. 选择 MCP 类型（如标准输入/输出 stdio）
5. 选择 MCP 命令格式（如 npx）
6. 输入 MCP 参数（如 open-websearch@1.1.5）
7. 输入运行需要的环境变量
8. 点击保存，加载完成后出现"已完成"按钮即代表 MCP 添加成功

通过 MCP 集成，企业可以将外部工具和服务无缝接入 AiPy 平台，扩展智能体的功能边界。

### 2.3 运行环境配置

AiPy 提供灵活的运行环境设置选项：

- 用户可选择镜像源或自定义输入一体机镜像源
- 支持第三方镜像源配置
- NPM 镜像源可自定义选择
- 工作目录可自定义修改路径

这些配置确保企业可以在不同网络环境下稳定运行 AiPy 平台。

## 三、智能体开发与应用部署

智能体是 AiPy 平台的核心功能模块，企业可以通过以下方式快速开发和部署智能体：

### 3.1 智能体类型分类

根据 AiPy 官方规范，智能体 manifest.json 中 keywords 字段的取值包括：

| 类型关键字 | 说明 |
|-----------|------|
| conversation-tool | 对话工具型 |
| embed-webview | 嵌入页面型 |
| application | 独立应用型 |
| webview | 网页型 |
| skills | 技能型 |

第二个值为集市展示分类，取值范围包括：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。

### 3.2 智能体开发示例

自动生成智能体的提示词示例如下：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

### 3.3 智能体安装与使用

开发完成智能体后，在 AiPy 企业版中的使用流程：

1. 打开 AiPy 企业版，点击右侧第四个"集市"按钮
2. 选择安装智能体
3. 将打包好的文件上传，再点击安装
4. 当页面上出现安装成功提示时，代表智能体安装成功

或者直接将智能体放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版。

### 3.4 常见智能体应用场景

| 应用场景 | 所需智能体 | 提示词示例 |
|---------|-----------|-----------|
| 制作 PPT | PPT 生成智能体 | 生成一个介绍中国新能源汽车发展的 PPT |
| 生成图片/视频 | 图片生成/视频生成智能体 | 批量生成 10 张不同的肥猫切菜的照片 |
| 生成思维导图 | 思维导图智能体 | 读取 PPTX 文件，整理为思维导图 |
| 研发系统 demo | 编程智能体（如 Claude code） | 开发访客登记管理系统，采用 Sqlite 数据库 |

## 四、企业级配置与自定义

AiPy 企业版提供丰富的自定义配置选项，满足企业个性化需求：

### 4.1 常规设置

AiPy 企业版常规设置包括以下内容：

- 语言：支持中文、English 和日语三种语言
- 风格：可在 aipy-enterprise.yml 文件中配置
- 发送快捷键：Ctrl+Enter 或 Enter
- 工作目录：执行任务后生成的文件或代码的存储目录
- 最大执行轮数：执行任务的最大回复轮数
- 超时时间：任务过程中等待大模型接口返回的时间
- 自动选择智能体：开启后自动判断所需智能体
- 一体机内网 IP：填写一体机服务器的内网 IP

### 4.2 Logo 与角色自定义

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开 aipy-enterprise.yml 文件，可以对以下内容进行修改：

- 基础信息
- 主页 logo 和软件 logo
- 发送快捷键
- 风格和推荐任务

在 yml 配置文件中，可以根据需求对风格进行增加或者修改，也可以对 AiPy 页面上的推荐任务进行自定义。

### 4.3 任务创建与执行

任务模式下，在 AiPy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务：

1. 在"任务输入框"中输入需要执行的任务
2. 如果需要选择 MCP 或智能体，点击勾选
3. 按下"Ctrl+Enter"或点击"去做吧"按钮下发任务
4. 在"任务对话窗口"中查看任务的执行过程
5. 在"任务工作目录"中查看生成的过程文件或任务结果文件

## 五、最佳实践与注意事项

### 5.1 使用场景最佳实践

根据官方文档，以下是一些经过验证的最佳实践：

**PPT 制作**：使用 AiPy 制作 ppt，勾选 PPT 生成智能体，提供清晰的主题和内容要求。

**图片/视频生成**：使用 AiPy 生成图片、P 图、生成视频等，勾选图片生成/视频生成智能体，描述具体的视觉需求。

**数据分析**：分析前请先读取前 30 行，了解数据格式，然后根据具体数据格式编写合适的分析脚本进行分析，报告保存到当前工作目录。

**知识库问答**：创建知识库后，配置知识检索参数，确保检索准确性和响应速度。

### 5.2 常见问题排查

| 问题现象 | 解决方案 |
|---------|---------|
| 不能识别图片内容 | 勾选视觉理解智能体 |
| 生成的图片是线条 | 勾选图片生成智能体 |
| 生成的 PPT 效果不佳 | 勾选 PPT 生成智能体 |
| 获取日期时间滞后 | 开启联网搜索功能 |
| 股票信息不准 | 使用"量化研究"智能体 |
| 编写程序能力不足 | 使用 Claude code 编程智能体 |

## 相关问答 FAQs

**AiPy 企业版支持哪些类型的智能体开发？**

AiPy 企业版支持五种类型的智能体开发：对话工具型（conversation-tool）、嵌入页面型（embed-webview）、独立应用型（application）、网页型（webview）和技能型（skills）。开发者可以根据业务需求选择合适的类型，通过 manifest.json 配置文件定义智能体属性和功能，完成开发后可通过集市安装或直接放入扩展目录使用。

**如何在 AiPy 中配置私有化部署的模型？**

在 AiPy 企业版主界面找到"设置"选项，进入"模型"选项卡，点击"添加"按钮。输入模型供应商名称（如公司私有模型），在"API 地址"中填入私有模型 API 地址（如 http://192.168.0.10/v1），输入 API 请求密钥，点击"检查"按钮检测可用模型，然后在模型下拉列表框中选择使用的模型即可完成配置。

**AiPy 平台的 MCP 集成有什么作用？**

MCP（Model Context Protocol）集成允许企业将外部工具和服务无缝接入 AiPy 平台，扩展智能体的功能边界。通过配置 MCP 名称、类型、命令格式和参数，企业可以集成 web_search、数据库查询、API 调用等各类服务，使智能体能够访问更多数据和工具，提升任务执行能力和应用场景覆盖面。
