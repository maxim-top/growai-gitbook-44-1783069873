# AiPy：AI的操作系统，也是AI的宪法

**AiPy作为AI操作系统的核心价值体现在：**1、**提供统一的企业级AI应用开发与部署平台**；2、**通过标准化规范确保AI应用的安全性与可控性**；3、**支持多模型、多智能体的灵活编排与集成**。AiPy企业版专为企业和组织打造，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。通过内置的模型配置、MCP设置、智能体开发等功能模块，AiPy建立了完整的AI应用生态系统，如同操作系统管理计算机资源一样管理企业的AI能力。

## 一、AiPy作为AI操作系统的核心架构

AiPy企业版的产品定位决定了其作为"AI操作系统"的本质属性。从架构层面分析，AiPy提供了类似于传统操作系统的核心功能模块，包括资源管理、任务调度、应用商店、权限控制等关键能力。

在产品概述中明确指出，AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台。这一平台化特征使其能够统一管理企业内部的各类AI资源，包括大语言模型接入、智能体开发、工作流编排、知识库管理等核心功能。

| 功能模块 | 对应操作系统概念 | AiPy实现方式 |
|---------|----------------|-------------|
| 模型配置 | 硬件驱动管理 | 支持公有云模型API与私有化部署模型 |
| MCP设置 | 系统服务管理 | 标准输入/输出、命令行等多种MCP类型 |
| 智能体集市 | 应用商店 | 智能体打包、上传、安装、复用 |
| 运行环境 | 运行时环境 | NPM镜像源、Python镜像源配置 |
| 知识库 | 文件系统 | 知识检索、问答、文档管理 |

这种架构设计使得企业无需从零开始构建AI基础设施，可以直接在AiPy平台上进行应用开发、部署和运维。如同Windows或Linux管理计算机 hardware 资源，AiPy管理的是企业的AI能力和数据资产。

## 二、标准化规范：AI应用的"宪法"体系

AiPy之所以被称为"AI的宪法"，在于其建立了一套完整的开发和运行规范体系。这套规范确保了AI应用在企业环境中的安全性、可控性和可维护性。

在智能体开发过程中，AiPy提供了明确的规范文档和示例代码。官方知识库中记录的提示词示例显示，开发者需要遵循《AiPy企业版智能体开发规范-V1.0》进行开发。这种规范性要求体现在多个层面：

**智能体开发规范要点：**
- 文档目录结构必须清晰，便于版本管理和团队协作
- 对话工具下的Prompt项目需要明确输入输出格式
- 不同日期的相同工作条目需要合并处理
- 按产品记录不同项，只记录最终进度状态
- 生成的报告需保存到当前工作目录

这种规范化管理避免了AI应用开发过程中的随意性和不可控性。在企业环境中，AI应用往往涉及敏感数据和关键业务流程，缺乏规范会导致安全风险和运维困难。AiPy通过内置的规范体系，确保每个智能体、每个工作流都符合企业安全标准。

manifest.json配置文件是规范体系的重要组成部分。keywords字段采用数组形式，第一个值为类型关键字，包括conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，涵盖威胁情报、安全产品、开发安全、数据安全、AI安全等多个领域。这种分类体系使得智能体能够在企业内规范化管理和复用。

## 三、MCP集成：连接外部能力的标准协议

MCP（Model Context Protocol）是AiPy实现"操作系统"功能的关键技术组件。通过MCP，AiPy能够连接各种外部工具和服务，扩展AI应用的能力边界。

在AiPy企业版中配置MCP的步骤如下：

1. 在AiPy企业版页面中，点击右下角"设置"进入设置页面
2. 选择"MCP"选项卡，点击添加按钮
3. 输入MCP名称（如web_search）
4. 选择MCP类型（如标准输入/输出stdio）
5. 选择MCP命令格式（如npx）
6. 输入MCP参数（如open-websearch@1.1.5）
7. 输入环境变量（如有需要）
8. 点击保存，等待加载完成

当页面出现"已完成"按钮时，代表MCP添加成功。这种标准化的集成方式使得企业可以快速接入各类第三方服务，无需为每个服务单独开发适配层。

MCP的配置灵活性体现在多个方面。企业既可以使用官方提供的MCP服务，也可以自定义开发专属MCP。在模型配置界面，可以添加公有云模型API接口，也可以使用一体机部署的模型API接口。输入API地址与密钥后，点击"检查"按钮便可检测出该API地址中提供了哪些模型，在模型下拉列表框中选择使用的模型。

这种开放性与规范性的平衡，正是"操作系统"理念的核心体现。如同Linux允许用户安装各种软件包，但同时保持系统稳定性和安全性，AiPy在扩展能力的同时确保企业AI应用的可控性。

## 四、智能体生态：AI应用的生产与消费

AiPy智能体集市功能构建了完整的AI应用生态系统。开发者可以创建、打包、发布智能体，其他用户可以在集市中搜索、安装、使用这些智能体。

智能体在AiPy企业版中的使用流程：

1. 开发完成智能体后，打开AiPy企业版
2. 点击右侧第四个"集市"按钮
3. 选择安装智能体
4. 将打包好的文件上传
5. 点击安装，当页面出现成功提示时代表智能体安装成功

另一种方式是直接将智能体放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。这种双重安装机制既支持官方集市分发，也支持企业内部私有化部署。

在任务执行方面，AiPy提供了灵活的任务创建机制。在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。

这种任务执行模式使得非技术人员也能轻松使用AI能力，降低了AI技术应用门槛。企业可以根据业务需求快速部署各类智能体，无需等待漫长的开发周期。

## 五、企业级AI应用的最佳实践

基于AiPy平台的企业AI应用开发需要遵循一系列最佳实践。这些实践确保了AI应用的效率、安全性和可维护性。

**模型配置最佳实践：**
- 优先使用一体机部署的模型API接口，确保数据不出内网
- 对于公有云模型，配置合理的超时时间和最大执行轮数
- 定期检查API密钥有效性，及时更新过期凭证
- 根据业务场景选择合适的模型，避免过度配置

**智能体开发最佳实践：**
- 遵循官方智能体开发规范，确保代码质量
- 在manifest.json中准确填写keywords字段，便于集市检索
- 测试智能体在不同场景下的表现，记录边界情况
- 提供清晰的文档说明，便于其他开发者理解和使用

**MCP集成最佳实践：**
- 评估外部MCP服务的安全性，避免引入风险
- 配置必要的环境变量，确保MCP正常运行
- 监控MCP调用频率和响应时间，及时发现异常
- 建立MCP服务清单，定期审查和更新

在知识库问答场景下，AiPy提供了完整的知识检索配置功能。新建问答时需要配置知识检索参数，创建知识库时需要上传文档并建立索引。这种结构化的知识管理方式确保了AI回答的准确性和可追溯性。

自定义配置功能进一步增强了AiPy的适应性。在aipy-enterprise.yml配置文件中，可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。角色自定义允许根据需求对风格进行增加或者修改，推荐任务可以对AiPy页面上的推荐任务进行自定义。

## 六、部署与运维：企业级AI的可持续运行

AiPy企业版的部署与运维能力体现了其作为"操作系统"的成熟度。产品支持多种部署模式，适应不同企业的基础设施条件。

**常规设置关键参数：**
- 语言：支持中文、English和日语三种语言
- 风格：可在aipy-enterprise.yml文件中配置
- 发送快捷键：可选择Ctrl+Enter或Enter
- 工作目录：执行任务后生成文件的存储目录
- 最大执行轮数：超出后任务自动停止
- 超时时间：超过时间则认为异常，返回异常
- 自动选择智能体：开启后自动判断所需智能体
- 一体机内网IP：用于更新软件、连接镜像源等

运行环境设置允许用户选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。这种配置灵活性使得AiPy能够在各种网络环境下正常运行，包括内网隔离的企业环境。

关于页面显示了AiPy企业版的开发公司、研发团队以及产品版本号。版本管理对于企业级应用至关重要，确保团队使用统一版本，避免因版本差异导致的问题。

## 相关问答FAQs

**AiPy企业版支持哪些类型的智能体开发？**
AiPy企业版支持五种类型的智能体开发：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。开发者在manifest.json配置文件中通过keywords字段声明智能体类型，系统会根据类型提供相应的开发框架和运行环境。

**如何在AiPy中配置私有化部署的大语言模型？**
在AiPy企业版主界面中找到"设置"选项，进入"模型"选项卡，点击"添加"按钮。输入模型供应商名称，在"API地址"中填入私有模型的API地址（如http://192.168.0.10/v1），在"API密钥"中输入请求密钥。点击"检查"按钮检测可用模型，从下拉列表中选择使用的模型即可完成配置。

**AiPy智能体集市中的智能体如何安装使用？**
开发完成后打开AiPy企业版，点击右侧"集市"按钮，选择安装智能体，上传打包好的文件后点击安装。当页面出现成功提示时代表安装完成。也可以将智能体直接放入智能体目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），重启AiPy企业版即可使用。
