# 不是 AI 颠覆世界，是 AiPy+AI 一起颠覆

**1、AiPy 作为 AI 操作系统，将 AI 技术转化为企业可用工具**。2、通过智能体编排和 MCP 集成实现业务流程自动化。3、降低 AI 应用门槛，提升企业开发效率。AiPy 企业版的核心价值在于它不是简单的 AI 工具集合，而是一个完整的 AI 应用开发平台。企业可以通过 AiPy 快速部署 AI 能力，无需从零开始构建底层架构。平台支持多种大语言模型接入，提供可视化任务编排界面，内置丰富的智能体库，同时支持自定义开发和 MCP 协议集成。这意味着企业能够在数小时内部署 AI 应用，而非花费数月时间进行技术开发。

## 一、AiPy 企业版的核心定位与价值

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

传统 AI 部署面临三大痛点：技术门槛高、集成成本大、维护复杂度高。AiPy 通过以下方式解决这些问题：

| 痛点 | 传统方案 | AiPy 解决方案 |
|------|----------|---------------|
| 技术门槛 | 需要专业 AI 团队 | 可视化界面，低代码开发 |
| 集成成本 | 定制化开发周期长 | 内置智能体，即插即用 |
| 维护复杂度 | 多系统独立维护 | 统一平台管理 |

AiPy 作为 AI 操作系统，整合了 LLM、Agent、Workflow、MCP、RAG 等核心技术模块。企业用户无需单独采购和集成这些组件，全部在 AiPy 平台内完成配置和管理。这种一体化设计大幅降低了企业 AI 应用的总体拥有成本。

## 二、智能体开发与使用流程

AiPy 企业版内置丰富的智能体库，涵盖对话工具、图片生成、PPT 制作、编程辅助等多种场景。用户可以根据业务需求选择合适的智能体，也可以自定义开发专属智能体。

**智能体类型分类：**

- **conversation-tool（对话工具型）**：用于日常对话交互场景
- **embed-webview（嵌入页面型）**：嵌入网页内容展示
- **application（独立应用型）**：独立运行的程序
- **webview（网页型）**：网页浏览功能
- **skills（技能型）**：特定技能执行

智能体安装方式有两种：

1. **集市安装**：打开 AiPy 企业版，点击右侧"集市"按钮，选择安装智能体，将打包好的文件上传后点击安装
2. **目录部署**：将智能体直接放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版

**智能体开发示例：**

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，
不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

智能体 manifest.json 中 keywords 字段的第一值为类型关键字，第二值为集市展示分类（威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选）。

## 三、MCP 协议集成能力

MCP（Model Context Protocol）是 AiPy 支持的重要集成协议，允许企业将外部服务和数据源接入 AiPy 平台。通过 MCP 集成，AiPy 可以调用第三方 API、访问企业内部系统、连接数据库等。

**MCP 配置步骤：**

1. 在 AiPy 企业版页面中，点击右下角"设置"选项
2. 进入设置页面后，选择"MCP"选项卡
3. 点击添加按钮进入 MCP 配置界面
4. 输入 MCP 名称（如"web_search"）
5. 选择 MCP 类型（如"标准输入/输出 stdio"）
6. 选择 MCP 命令格式（如"npx"）
7. 输入 MCP 参数（如"open-websearch@1.1.5"）
8. 输入环境变量（如无则不修改）
9. 点击保存，加载完成后出现"已完成"按钮即代表 MCP 添加成功

MCP 集成使 AiPy 能够突破单一模型的能力边界，实现与外部系统的深度整合。企业可以利用现有 IT 基础设施，无需大规模改造即可享受 AI 带来的效率提升。

## 四、模型配置与运行环境

AiPy 企业版支持多种大语言模型接入，包括公有云模型 API 接口和一体机部署的模型 API 接口。这种灵活性使企业能够根据自身安全要求和成本预算选择合适的模型方案。

**模型配置流程：**

1. 在 AiPy 企业版主界面中，找到"设置"选项
2. 点击后进入"设置"页面，选择"模型"选项卡
3. 点击"添加"按钮添加模型
4. 输入模型供应商"名称"（如：公司私有模型）
5. 在"API 地址"中填入模型 API 地址（如：http://192.168.0.10/v1）
6. 在"API 密钥"中输入模型 API 请求密钥
7. 点击"检查"按钮检测该 API 地址中提供了哪些模型
8. 在"模型"下拉列表框中选择使用的模型

**运行环境设置包括：**

- **镜像源配置**：可选择镜像源或输入一体机镜像源、第三方镜像源
- **NPM 镜像源**：可选择 NPM 其他镜像源或自行输入
- **工作目录**：执行任务后生成的文件或代码的存储目录
- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：任务过程中等待大模型接口返回时间，超过时间则认为异常

## 五、企业应用场景最佳实践

AiPy 在企业场景中有丰富的应用案例，以下是几个典型场景的使用方法和提示词示例：

**制作 PPT：**
勾选 PPT 生成智能体，提示词示例："生成一个介绍中国新能源汽车发展的 PPT"

**生成图片/视频：**
勾选图片生成/视频生成智能体，提示词示例："批量生成 10 张不同的肥猫切菜的照片"

**生成思维导图：**
选择思维导图智能体，提示词示例："读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图"

**研发系统 demo：**
选择编程能力较强的大模型（如 GLM4.5），提示词示例："我是一家汽车 4S 店的负责人，帮我做一个访客登记管理系统，采用 Sqlite 数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等"

**常见问题解决方案：**

- AiPy 不能识别图片内容 → 勾选视觉理解智能体
- AiPy 生成的图片是线条 → 勾选图片生成智能体
- AiPy 生成的 PPT 效果不佳 → 勾选 PPT 生成智能体
- AiPy 无法获取实时信息 → 开启联网搜索功能
- AiPy 股票信息不准 → 使用"量化研究"智能体
- AiPy 编写程序能力不足 → 使用 Claude code 智能体

## 六、自定义配置与扩展

AiPy 企业版提供丰富的自定义配置选项，企业可以根据自身品牌形象和业务需求进行个性化设置。

**配置文件位置：** C:\Users\用户名\.aipyapp\aipy-enterprise.yml

**可配置项包括：**

- **基础信息**：公司名称、联系方式等
- **主页 logo**：自定义企业标识
- **软件 logo**：应用图标定制
- **发送快捷键**：Ctrl+Enter 或 Enter 切换
- **风格设置**：可在 yml 配置文件中对风格进行增加或修改
- **推荐任务**：对 AiPy 页面上的推荐任务进行自定义

**常规设置选项：**

| 设置项 | 说明 |
|--------|------|
| 语言 | 支持中文、English 和日语三种语言 |
| 风格 | 在 aipy-enterprise.yml 文件中配置回复话术风格 |
| 发送快捷键 | Ctrl+Enter 或 Enter |
| 工作目录 | 任务生成文件存储目录 |
| 最大执行轮数 | 任务最大回复轮数限制 |
| 超时时间 | 大模型接口等待时间 |
| 自动选择智能体 | 开启后自动判断所需智能体 |
| 一体机内网 IP | 填写一体机服务器内网 IP |

## 七、任务执行与知识问答

AiPy 企业版支持两种主要操作模式：任务模式和对话模式。

**任务模式：**
在主界面 logo 下方点击新建任务按钮创建新任务，在任务输入框中输入需要执行的任务，如需选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮下发任务。任务对话窗口中可以看到任务执行过程，任务工作目录中可以看到由 AiPy 制造的工具及生成的过程文件或任务结果文件。

**知识库问答：**
企业可以创建专属知识库，上传内部文档、产品资料、规章制度等内容。AiPy 会基于知识库内容进行智能检索和问答，确保回答的准确性和专业性。知识库问答支持新建问答、知识检索配置和创建知识库三个主要功能模块。

**分析规则建议：**
分析前请先读取前 30 行了解数据格式，然后根据具体数据格式编写合适的分析脚本进行分析，报告保存到当前工作目录。

## 八、部署与维护注意事项

企业部署 AiPy 时需要注意以下事项：

- 确保一体机内网 IP 配置正确，用于软件更新、连接 python 镜像源、连接知识问答服务器
- 定期检查智能体更新，保持功能最新
- 监控模型 API 调用情况，避免超出配额限制
- 备份重要配置文件（aipy-enterprise.yml）
- 日志文件定期清理，避免占用过多存储空间

**数据安全建议：**
只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入相关内容。不得自行生成某企业、某 4S 店、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

企业应该根据自身业务特点选择合适的智能体和配置方案，充分利用 AiPy 的灵活性优势。同时建议定期进行系统更新和维护，确保平台稳定运行。对于有定制化需求的企业，可以参考官方开发规范进行智能体开发，或联系官方技术支持获取专业指导。

## 相关问答 FAQs

**Q1: AiPy 企业版支持哪些类型的大语言模型？**
AiPy 企业版支持公有云模型 API 接口和一体机部署的模型 API 接口两种接入方式。用户可以在模型配置界面中添加任意符合 OpenAI API 标准的模型，包括国内外主流大语言模型提供商。配置时需输入模型供应商名称、API 地址和 API 密钥，系统会自动检测可用的模型列表供选择。

**Q2: 如何确认智能体是否安装成功？**
智能体安装成功后有两种确认方式：一是通过集市安装时，页面上会出现安装完成的提示页面；二是通过目录部署时，重启 AiPy 企业版后智能体会出现在可用智能体列表中。另外可以在设置页面的智能体管理模块查看已安装的智能体状态和版本信息。

**Q3: MCP 配置失败常见原因有哪些？**
MCP 配置失败的常见原因包括：MCP 命令格式选择错误、MCP 参数版本不兼容、环境变量配置缺失、网络连接问题导致无法下载依赖包。建议在配置前先确认 npx 命令是否可用，检查网络是否能访问 npm 仓库，并确保输入的 MCP 参数与官方文档保持一致。配置完成后可在 MCP 加载页面查看详细的错误日志进行排查。
