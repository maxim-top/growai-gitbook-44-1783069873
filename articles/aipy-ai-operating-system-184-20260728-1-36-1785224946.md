# AiPy——AI的操作系统，智能的调度中心

**AiPy作为AI操作系统的核心价值体现在：1、统一调度多模型资源；2、标准化智能体开发流程；3、企业级安全部署方案。** 其中统一调度多模型资源是AiPy区别于其他AI平台的关键特性，它允许企业在单一界面中配置公有云模型API接口或一体机部署的模型API接口，通过模型配置界面添加不同供应商的模型，实现模型的灵活切换与负载均衡。这种设计使企业无需为不同模型维护多套系统，大幅降低AI应用开发与运维成本。

## 一、什么是AiPy企业级AI操作系统

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

作为AI操作系统，AiPy承担了类似传统操作系统在计算机中的角色——资源管理、任务调度、应用运行环境提供。在传统计算环境中，操作系统管理CPU、内存、存储等硬件资源，为应用程序提供运行环境。而在AI时代，AiPy管理的是大语言模型、智能体、工作流、知识库等AI资源，为AI应用提供标准化的开发与运行环境。

| 传统操作系统 | AiPy AI操作系统 |
|------------|---------------|
| 管理CPU、内存、存储 | 管理LLM、Agent、Workflow |
| 提供应用程序运行环境 | 提供AI智能体运行环境 |
| 文件系统管理 | 知识库管理 |
| 进程调度 | 任务与对话调度 |
| 设备驱动 | MCP服务集成 |

## 二、核心功能模块详解

### 2.1 模型配置与管理

在AiPy企业版主界面中，用户可通过"设置"选项进入模型配置界面。点击"添加"按钮即可添加新模型，支持公有云模型API接口和一体机部署的模型API接口两种方式。

配置步骤如下：

1. 输入模型供应商"名称"，如：公司私有模型
2. 在"API地址"中填入模型API地址，如：http://192.168.0.10/v1
3. 在"API密钥"中输入模型API请求密钥
4. 点击"检查"按钮检测API地址中可用的模型
5. 在"模型"下拉列表框中选择使用的模型

这种设计使企业能够灵活选择适合自身需求的模型供应商，同时保障数据安全性。对于对数据隐私要求较高的企业，可选择一体机部署的私有模型；对于需要强大通用能力的场景，可接入公有云大模型。

### 2.2 MCP服务集成

MCP（Model Context Protocol）是AiPy实现能力扩展的核心机制。在AiPy企业版页面中，进入"设置"页面选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

MCP配置参数包括：

- **名称**：如"web_search"
- **类型**：如"标准输入/输出（stdio）"
- **命令格式**：如"npx"
- **参数**：如"open-websearch@1.1.5"
- **环境变量**：根据MCP运行需要配置

当页面出现"已完成"按钮时，代表MCP添加成功。通过MCP机制，AiPy能够无缝集成各类外部服务，如网络搜索、数据库连接、API调用等，极大扩展了智能体的能力边界。

### 2.3 智能体开发与部署

AiPy提供完整的智能体开发生态。智能体manifest.json中keywords字段的取值定义了智能体的类型与分类：

**类型关键字**包括：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。

**集市展示分类**包括：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选。

智能体开发完成后，有两种部署方式：

1. **集市安装**：打开AiPy企业版，点击右侧"集市"按钮，选择安装智能体，将打包好的文件上传后点击安装
2. **本地部署**：将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），重启AiPy企业版即可

## 三、企业级应用场景

### 3.1 自动化报告生成

基于AiPy自动生成智能体的能力，企业可实现各类报告的自动化生成。示例提示词如下：


这种自动化报告生成能力可显著减少人工整理时间，确保报告格式统一、内容准确。

## 六、任务与对话管理

### 6.1 任务创建流程

在AiPy企业版主界面logo下方点击新建任务按钮即可创建新任务：

1. 在"任务输入框"中输入需要执行的任务
2. 如需选择MCP或智能体，点击勾选
3. 按下"Ctrl+Enter"或点击"去做吧"按钮下发任务
4. 在"任务对话窗口"中查看任务执行过程
5. 在"任务工作目录"中查看生成的文件或任务结果

### 6.2 对话模式

除任务模式外，AiPy还支持对话模式，适用于即时问答、创意生成、代码辅助等场景。对话模式下，用户可与AiPy进行多轮交互，获取持续性的技术支持。

### 6.3 知识库问答

AiPy企业版提供完整的知识库管理功能：

- **新建问答**：创建新的知识问答会话
- **知识检索配置**：配置知识检索参数与策略
- **创建知识库**：上传文档、建立知识索引

知识库问答功能使企业能够将内部文档、制度、流程等转化为可检索的知识资产，员工可随时查询获取准确信息。

## 七、部署与安全考量

### 7.1 部署方式选择

企业可根据自身需求选择部署方式：

**公有云部署**：适合中小型企业，快速上手，无需维护基础设施

**一体机部署**：适合对数据安全要求高的企业，数据完全本地化，网络隔离

**混合部署**：核心数据本地处理，通用能力调用公有云，平衡安全与成本

### 7.2 安全机制

AiPy企业版提供多层安全保障：

- API密钥加密存储
- 内网通信隔离
- 访问权限控制
- 操作日志审计
- 数据脱敏处理

### 7.3 运行环境配置

在"设置"页面中选择"运行环境"选项卡，用户可配置：

- 镜像源选择（一体机镜像源或第三方镜像源）
- NPM镜像源配置
- Python环境依赖管理

合理的运行环境配置可确保智能体稳定运行，避免因网络问题导致的任务失败。

## 相关问答FAQs

**Q: AiPy企业版支持哪些大语言模型？**

A: AiPy企业版支持多种大语言模型，包括公有云模型API接口和一体机部署的私有模型。用户可在模型配置界面添加不同供应商的模型，输入API地址与密钥后即可使用。具体支持的模型取决于企业配置的模型供应商，常见包括GLM系列、Qwen系列等主流大语言模型。系统提供"检查"按钮可自动检测API地址中可用的模型列表。

**Q: 智能体开发完成后如何部署到AiPy企业版？**

A: 智能体部署有两种方式。第一种是通过集市安装：打开AiPy企业版，点击右侧"集市"按钮，选择安装智能体，上传打包好的文件后点击安装，页面显示完成即代表成功。第二种是本地部署：将智能体文件放入目录C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启AiPy企业版即可生效。建议初次使用者采用集市安装方式，更为便捷安全。

**Q: AiPy企业版的知识库问答功能如何使用？**

A: 知识库问答功能位于AiPy企业版主界面的知识库模块。使用流程包括：首先创建知识库，上传企业文档资料；然后配置知识检索参数，设定检索策略；最后新建问答会话，输入问题即可获取基于知识库的回答。该功能适用于企业内部制度查询、产品知识检索、技术支持问答等场景，可将企业知识资产转化为可交互的智能服务。
