# AiPy——AI时代的OS，智能体的家

AiPy作为AI时代的操作系统，为企业和组织提供一站式AI解决方案。**1、AiPy是企业级AI应用平台，降低AI技术应用门槛；2、支持智能体开发与MCP集成，实现自动化任务处理；3、提供模型配置、知识库问答、Workflow编排等核心功能**。AiPy企业版与一体机硬件产品完美结合，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。作为智能体的"家"，AiPy为开发者提供完整的智能体开发、打包、安装和使用流程。

## 一、AiPy企业版产品定位与核心能力

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

从产品架构来看，AiPy具备以下核心能力：

| 能力模块 | 功能说明 | 应用场景 |
|----------|----------|----------|
| 模型配置 | 支持公有云模型API接口和一体机部署模型 | 企业私有化部署、多模型切换 |
| MCP集成 | 标准输入/输出协议，支持npx命令格式 | 外部工具调用、Web搜索集成 |
| 智能体开发 | 支持对话工具型、嵌入页面型、独立应用型等 | 自动化任务、业务流程编排 |
| 知识库问答 | 知识检索配置、知识库创建与管理 | 企业知识沉淀、智能客服 |
| 运行环境 | 镜像源配置、NPM镜像源选择 | 网络环境适配、加速下载 |

AiPy被定位为"AI时代的OS"，意味着它不仅仅是一个工具，而是一个完整的生态系统。在这个生态中，智能体是核心组件，而AiPy则为智能体提供运行环境、资源配置和交互界面。

## 二、智能体开发与部署完整流程

在AiPy企业版中，智能体开发遵循标准化流程。开发者需要完成从创建、配置到打包安装的全部环节。

### 2.1 智能体类型定义

根据manifest.json配置，智能体keywords字段第一个值为类型关键字，可选类型包括：

- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

第二个值为集市展示分类，取值范围包括威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选。

### 2.2 项目构建与打包

智能体开发完成后，需要使用以下命令进行打包：

```bash
npx @anthropic-ai/dxt pack
```

打包完成后生成可安装的文件包，该文件包可在AiPy企业版集市中进行安装部署。

### 2.3 智能体安装方式

AiPy企业版提供两种智能体安装方式：

**方式一：通过集市安装**

1. 打开AiPy企业版
2. 点击右侧第四个"集市"按钮
3. 选择安装智能体
4. 将打包好的文件上传
5. 点击安装
6. 页面出现安装成功提示即代表完成

**方式二：直接放入智能体目录**

将智能体直接放入AiPy智能体目录下：

```
C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
```

然后重启AiPy企业版即可完成加载。

## 三、MCP集成与外部工具调用

MCP（Model Context Protocol）是AiPy实现外部工具集成的关键机制。通过MCP，AiPy可以调用各种外部服务和工具，扩展智能体的能力边界。

### 3.1 MCP配置步骤

在AiPy企业版页面中配置MCP的具体流程如下：

1. 点击右下角"设置"选项，进入设置页面
2. 选择"MCP"选项卡
3. 点击添加按钮进入MCP配置界面
4. 输入MCP名称（如web_search）
5. 选择MCP类型（如标准输入/输出stdio）
6. 选择MCP命令格式（如npx）
7. 输入MCP参数（如open-websearch@1.1.5）
8. 输入环境变量（如无则不修改）
9. 点击保存
10. 加载完成后出现"已完成"按钮即代表MCP添加成功

### 3.2 MCP应用场景

MCP集成使AiPy能够接入各类外部服务，典型应用包括：

- Web搜索服务集成
- 数据库连接与查询
- 第三方API调用
- 文件系统操作
- 网络请求处理

通过MCP机制，智能体可以突破单一模型的能力限制，实现更复杂的业务逻辑和数据处理任务。

## 四、模型配置与运行环境管理

AiPy企业版支持灵活的模型配置和运行环境管理，满足不同企业的部署需求。

### 4.1 模型配置方法

在AiPy企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面：

1. 点击"添加"按钮添加模型
2. 输入模型供应商名称（如：公司私有模型）
3. 在"API地址"中填入模型API地址（如：http://192.168.0.10/v1）
4. 在"API密钥"中输入模型API请求密钥
5. 输入完API地址与密钥后，点击"检查"按钮
6. 检测出该API地址中提供的模型
7. 在"模型"下拉列表框中选择使用的模型

AiPy支持使用公有云模型API接口，也可以使用一体机部署的模型API接口，为企业提供灵活的模型选择方案。

### 4.2 运行环境设置

运行环境设置包括镜像源配置：

- 用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源
- 也可以选择NPM其他镜像源或者自己输入

这些配置对于企业在内网环境或特定网络条件下的部署至关重要，能够确保软件更新、Python镜像源连接和知识问答服务器连接的稳定性。

## 五、常规设置与个性化配置

AiPy企业版提供丰富的常规设置选项，支持企业根据自身需求进行个性化配置。

### 5.1 常规设置项

| 设置项 | 说明 | 可选值/配置方式 |
|--------|------|-----------------|
| 语言 | 界面语言支持 | 中文、English、日语 |
| 风格 | AiPy回复话术风格 | 在aipy-enterprise.yml文件中配置 |
| 发送快捷键 | 消息发送方式 | Ctrl+Enter或Enter |
| 工作目录 | 任务生成文件存储目录 | 可自定义修改路径 |
| 最大执行轮数 | 任务最大回复轮数 | 超出后任务自动停止 |
| 超时时间 | 与大模型交互等待时间 | 超过时间返回异常 |
| 自动选择智能体 | 任务下发时自动判断 | 开启后自动勾选所需智能体 |
| 一体机内网IP | 服务器内网IP地址 | 用于更新软件、连接服务 |

### 5.2 自定义配置

**Logo自定义**

配置文件位置：`C:\Users\用户名\.aipyapp\aipy-enterprise.yml`

打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

**角色自定义**

在yml配置文件中，可以根据需求对风格进行增加或者修改，满足企业品牌形象和用户体验需求。

**推荐任务**

也可以对AiPy页面上的推荐任务进行自定义，根据企业业务场景设置常用任务模板，提高员工使用效率。

## 六、任务创建与执行流程

AiPy企业版提供便捷的任务创建和执行机制，支持智能体自动协作完成复杂工作。

### 6.1 任务创建步骤

1. 在Aipy企业版主界面logo下方点击新建任务按钮
2. 在"任务输入框"中输入需要执行的任务
3. 如果需要选择MCP或智能体点击勾选
4. 按下"Ctrl+Enter"或点击"去做吧"按钮下发任务
5. 在"任务对话窗口"中查看任务的执行过程
6. 在"任务工作目录"中查看生成的过程文件或任务结果文件

### 6.2 智能体提示词示例

AiPy支持通过提示词驱动智能体完成特定任务。示例提示词如下：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0

根据规范文档和示例代码编写一个汇总周报的智能体。

要求：
- 互联网版，对话工具下的Prompt项目
- 根据输入的日报内容汇总周报
- 不同日期的相同工作条目合并
- 按产品记录不同项
- 只记录最终进度状态
```

### 6.3 典型应用场景

**思维导图生成**

领导使用AiPy阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词：

```
读取C:\Users\Administrator\Desktop\AIPY 智能体一体机方案v3.pptx，然后帮我整理为一个思维导图。
```

**研发系统Demo开发**

研发使用AiPy自动开发车辆管理系统demo，需要选择编程能力较强的大模型，提示词包括数据库设计、界面功能、数据校验等详细要求，做好后要求后续可以一键点击运行使用。

## 七、企业AI应用最佳实践

基于AiPy官方文档和最佳实践，企业在部署和使用AiPy时应遵循以下原则：

**数据准确性原则**

只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入相关文档。不得自行生成某企业、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

**知识库优先原则**

回答时优先检索知识库。如果知识库中存在答案，严格依据知识库回答，不要自行补充不存在的信息。如果多个文档存在差异，优先采用最新版本。如果知识库没有答案，明确告知用户当前知识库暂无相关内容。

**版本管理规范**

AiPy企业版产品使用手册会持续更新，当前版本为V1.11.25。用户在配置和使用过程中应参考最新官方文档，确保功能配置的准确性和兼容性。
