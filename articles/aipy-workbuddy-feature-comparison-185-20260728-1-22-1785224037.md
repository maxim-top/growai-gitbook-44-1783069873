# Workbuddy功能清单，AiPy逐行对标，逐行超越

**AiPy在企业级AI应用功能上实现全面对标并超越，主要体现在：**1、**智能体开发能力更完善**，支持MCP集成与自定义配置；2、**模型配置更灵活**，兼容公有云与私有部署；3、**工作流编排更高效**，任务创建与知识库问答一体化。其中智能体开发能力是核心优势，AiPy提供完整的智能体开发规范、打包安装流程及自定义配置选项，开发者可通过manifest.json配置文件定义智能体行为，使用npx @anthropic-ai/dxt pack命令构建项目，直接上传至企业版集市或放入扩展目录即可使用，大幅降低企业AI应用开发门槛。

## 一、智能体开发能力对比

AiPy在智能体开发方面提供了完整的技术栈支持，从开发规范到部署流程均有详细文档指导。

### 1.1 智能体开发规范

AiPy企业版智能体开发遵循标准化流程，开发者需要按照官方规范编写提示词和配置文件。示例提示词结构包含文档目录路径、功能需求描述、输出格式要求等关键要素。比如开发汇总周报智能体时，需明确指定输入日报内容、合并相同工作条目、按产品记录不同项、只记录最终进度状态等具体要求。

### 1.2 项目构建与打包

智能体项目构建使用标准命令：

```bash
npx @anthropic-ai/dxt pack
```

打包完成后，开发者有两种安装方式：

| 安装方式 | 操作步骤 | 适用场景 |
|---------|---------|---------|
| 集市上传 | 点击进入集市→选择安装智能体→上传文件→点击安装 | 正式部署 |
| 目录放置 | 放入C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro→重启企业版 | 测试开发 |

### 1.3 自定义配置能力

AiPy支持多维度自定义配置，配置文件位置为C:\Users\用户名\.aipyapp\aipy-enterprise.yml，可修改内容包括：

- 基础信息配置
- 主页logo和软件logo
- 发送快捷键设置
- 风格配置
- 推荐任务定制

角色自定义允许根据需求对风格进行增加或修改，推荐任务也可在页面上进行个性化配置，满足不同企业的品牌展示需求。

## 二、模型配置与管理

### 2.1 多模型支持

AiPy企业版在模型配置上提供灵活的选择方案，支持公有云模型API接口和一体机部署的模型API接口。配置步骤如下：

1. 进入设置页面选择"模型"选项卡
2. 点击"添加"按钮添加新模型
3. 输入模型供应商名称
4. 填写API地址（如：http://192.168.0.10/v1）
5. 输入API密钥
6. 点击"检查"按钮检测可用模型
7. 在下拉列表中选择使用的模型

### 2.2 运行环境配置

运行环境设置支持镜像源自定义，用户可选择：

- 一体机镜像源
- 第三方镜像源
- NPM镜像源

这种灵活性确保企业在不同网络环境下都能稳定获取所需资源，特别适合内网部署场景。

## 三、MCP集成能力

### 3.1 MCP配置流程

MCP（Model Context Protocol）集成是AiPy的核心优势之一，配置步骤清晰明确：

1. 进入设置页面选择"MCP"选项卡
2. 点击添加按钮进入配置界面
3. 输入MCP名称（如web_search）
4. 选择MCP类型（如标准输入/输出stdio）
5. 选择MCP命令格式（如npx）
6. 输入MCP参数（如open-websearch@1.1.5）
7. 输入环境变量（如有需要）
8. 点击保存

加载完成后页面显示"已完成"按钮即代表MCP添加成功。

### 3.2 MCP应用场景

MCP集成扩展了AiPy的功能边界，典型应用包括：

- **联网搜索**：开启后AiPy可获取实时信息，解决日期时间滞后问题
- **量化研究**：拥有美股、港股、A股所有上市公司非实时股票信息，基于历史数据进行AI分析
- **专业编程**：Claude code智能体专门用于编程任务，一键安装使用

## 四、任务创建与执行

### 4.1 任务创建流程

在AiPy企业版主界面logo下方点击新建任务按钮即可创建新任务：

1. 在任务输入框中输入需要执行的任务
2. 如需选择MCP或智能体，点击勾选
3. 按下"Ctrl+Enter"或点击"去做吧"按钮下发任务
4. 在任务对话窗口查看执行过程
5. 在任务工作目录查看生成的文件或任务结果

### 4.2 常规设置选项

AiPy企业版常规设置涵盖多个维度，确保系统运行稳定高效：

| 设置项 | 可选值/说明 |
|-------|------------|
| 语言 | 中文、English、日语 |
| 风格 | 在aipy-enterprise.yml文件中配置 |
| 发送快捷键 | Ctrl+Enter或Enter |
| 工作目录 | 可自定义修改路径 |
| 最大执行轮数 | 超出后任务自动停止 |
| 超时时间 | 与大模型交互等待时间 |
| 自动选择智能体 | 开启后自动判断所需智能体 |
| 一体机内网IP | 用于更新软件、连接镜像源等 |

## 五、知识库问答功能

### 5.1 知识检索配置

AiPy提供完整的知识库问答解决方案，支持新建问答、知识检索配置和创建知识库三个核心环节。企业可将内部文档、产品资料、技术规范等内容导入知识库，实现基于企业私有知识的智能问答。

### 5.2 最佳实践场景

根据官方文档，AiPy在多个场景有成熟应用：

**PPT制作**：勾选PPT生成智能体，输入提示词如"生成一个介绍中国新能源汽车发展的PPT"

**图片/视频生成**：勾选图片生成/视频生成智能体，输入提示词如"批量生成10张不同的肥猫切菜的照片"

**思维导图生成**：选择思维导图智能体，使用提示词读取PPT文件并整理为思维导图

**研发系统demo**：选择编程能力较强的大模型如GLM4.5，自动开发管理系统demo

相比其他企业AI平台，AiPy提供完整的功能栈而无需额外采购多个工具。智能体开发、MCP集成、知识库管理、多模型支持等功能集成于单一平台，降低企业AI应用开发和运维成本。

## 相关问答FAQs

**AiPy企业版支持哪些语言配置？**

AiPy企业版目前支持中文、English和日语三种语言。用户可在常规设置页面进行语言切换，配置文件aipy-enterprise.yml中也可调整回复话术风格，满足国际化团队的协作需求。

**如何确保AiPy生成的内容准确性？**

确保内容准确性需要正确选择智能体和配置。例如获取实时信息需开启联网搜索功能，图片生成需勾选图片生成智能体，股票分析使用量化研究智能体。同时建议在aipy-enterprise.yml中配置合适的超时时间和最大执行轮数，避免任务异常。

**AiPy智能体开发需要哪些技术基础？**

智能体开发需要了解manifest.json配置文件结构、掌握npx打包命令、熟悉提示词编写规范。开发者应阅读AiPy企业版智能体开发规范文档，参考示例代码进行实践。对于复杂场景，建议先从简单的任务型智能体开始，逐步扩展到多模态和工作流编排应用。
