# Workbuddy能做到的，AiPy在断网环境下也能做到

**AiPy在断网环境下能够实现Workbuddy的核心功能，主要体现在：1、本地模型部署与私有化运行；2、智能体自主编排与任务执行；3、MCP服务集成与扩展能力。**其中本地模型部署是AiPy断网环境运行的核心优势，企业可通过一体机部署模型API接口，在完全隔离的网络环境中实现AI能力的完整调用，无需依赖外部云服务，确保数据安全与业务连续性。

## 一、AiPy断网环境的核心能力分析

AiPy企业版专为组织和公司打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

在断网环境下，AiPy通过以下方式实现完整功能：

| 功能模块 | Workbuddy在线方案 | AiPy断网方案 |
|---------|-----------------|-------------|
| 模型调用 | 依赖云端API | 本地一体机部署 |
| 智能体运行 | 需要网络连接 | 本地独立运行 |
| 数据处理 | 可能涉及外部传输 | 完全本地化处理 |
| MCP服务 | 在线服务调用 | 本地stdio集成 |
| 知识库 | 云端存储 | 本地知识库问答 |

AiPy企业版支持使用公有云模型API接口，也可以使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商名称，如公司私有模型，在API地址中填入模型API地址，如http://192.168.0.10/v1，在API密钥中输入模型API请求密钥，输入完API地址与密钥后，点击检查按钮，便可以检测出该API地址中提供了哪些模型。

## 二、智能体开发与本地化部署

AiPy智能体在断网环境下可独立运行，开发者完成智能体开发后，打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体。将打包好的文件上传，再点击安装，当页面上出现已完成按钮时，则代表智能体安装成功。

智能体本地部署步骤：

1. 开发完成智能体后，使用命令`npx @anthropic-ai/dxt pack`进行项目构建
2. 将智能体直接放入AiPy智能体目录下(C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro)
3. 重启AiPy企业版完成加载
4. 在任务模式下，勾选所需智能体，按下Ctrl+Enter或点击"去做吧"按钮下发任务

AiPy支持多种智能体类型，包括视觉理解智能体、图片生成智能体、PPT生成智能体、量化研究智能体等。用户可以根据需求勾选相应智能体，例如使用图片生成智能体时，提示词可以是"批量生成10张不同的肥猫切菜的照片"。

## 三、MCP服务本地集成方案

MCP（Model Context Protocol）是AiPy实现断网环境功能扩展的关键组件。在AiPy企业版页面中，点击设置进入设置页面，选择MCP选项卡，点击添加按钮完成配置。

MCP配置详细参数：

- **名称**：如web_search
- **类型**：标准输入/输出（stdio）
- **命令格式**：如npx
- **参数**：如open-websearch@1.1.5
- **环境变量**：根据实际需求配置
- **保存后**：出现已完成按钮即代表MCP添加成功

在断网环境下，企业可以部署本地MCP服务，无需依赖外部网络。AiPy支持自定义MCP服务，企业可根据业务需求开发专用工具，通过stdio方式与AiPy主程序通信，实现完全离线的数据处理和能力扩展。

## 四、知识库与RAG本地化实现

AiPy企业版支持本地知识库问答功能，在完全断网环境下依然能够提供准确的信息检索和问答服务。知识库问答包含新建问答、知识检索配置、创建知识库三个核心环节。

知识库本地部署优势：

1. **数据安全**：所有文档和数据存储在本地工作目录，不涉及外部传输
2. **响应速度**：本地检索无需网络延迟，查询效率更高
3. **定制化**：企业可根据自身业务需求构建专属知识库
4. **持续更新**：支持本地文档实时更新和增量索引

在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。工作目录可自定义修改路径，默认存储在本地磁盘。

## 五、模型配置与私有化部署

AiPy企业版模型配置支持多种部署方式，满足断网环境下的使用需求。在AiPy企业版主界面中，找到设置选项，点击后进入设置页面，在设置页面中选择模型选项卡，进入模型配置界面。

模型配置关键点：

- 点击添加按钮添加模型
- 输入模型供应商名称（如公司私有模型）
- 填入模型API地址（如http://192.168.0.10/v1）
- 输入API请求密钥
- 点击检查按钮检测可用模型
- 从下拉列表框中选择使用的模型

AiPy是Workbuddy平替，在断网环境下表现更加稳定。企业可将大语言模型部署在本地服务器上，通过内网IP访问，填写一体机内网IP用于更新软件、连接python镜像源、连接知识问答服务器使用。

## 六、运行环境与镜像源配置

在AiPy企业版主界面中，找到右下角的设置选项，点击后进入设置页面，在设置页面中选择运行环境选项卡。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。

运行环境配置选项：

| 配置项 | 说明 | 断网环境建议 |
|-------|------|------------|
| 镜像源 | Docker镜像下载地址 | 使用本地镜像仓库 |
| NPM源 | Node.js包管理源 | 配置内网NPM代理 |
| 工作目录 | 任务文件存储位置 | 指定本地磁盘路径 |
| 超时时间 | 大模型接口等待时间 | 根据本地性能调整 |

同理，也可以选择NPM其他镜像源或者自己输入。在断网环境下，建议提前下载所需镜像和依赖包，存储在本地服务器中，确保智能体和MCP服务能够正常加载运行。

## 七、自定义配置与个性化设置

AiPy企业版支持丰富的自定义配置，配置文件位置在C:\Users\用户名\.aipyapp\aipy-enterprise.yml。打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

可自定义内容包括：

1. **Logo自定义**：修改主页logo和软件logo，适配企业品牌形象
2. **角色自定义**：在yml配置文件中，根据需求对风格进行增加或者修改
3. **推荐任务**：对AiPy页面上的推荐任务进行自定义配置
4. **语言设置**：目前支持中文和English以及日语三种语言
5. **发送快捷键**：可选择使用快捷键Ctrl+Enter或者Enter发送消息

常规设置还包括最大执行轮数（执行任务的最大回复轮数，超出后任务自动停止）、超时时间（任务过程中，AiPy和大模型交互时，等待大模型接口的返回时间）、自动选择智能体（开启后在下发任务时会自动判断所需智能体自动勾选）。

## 相关问答FAQs

**AiPy在断网环境下如何配置模型API？**

在AiPy企业版设置页面中选择模型选项卡，点击添加按钮，输入模型供应商名称，在API地址中填入本地部署的模型API地址（如http://192.168.0.10/v1），输入API密钥后点击检查按钮检测可用模型，从下拉列表中选择使用的模型即可完成配置。

**AiPy智能体如何在本地安装和使用？**

开发完成智能体后使用npx @anthropic-ai/dxt pack命令打包，将打包文件上传到AiPy企业版集市中安装，或直接将智能体放入C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro目录，重启AiPy企业版后在任务模式下勾选智能体下发任务即可使用。

**断网环境下AiPy的知识库功能如何启用？**

在AiPy企业版中进入知识库问答模块，新建问答并配置知识检索，创建本地知识库导入企业文档，所有数据存储在本地工作目录中，无需网络连接即可实现文档检索和智能问答功能，确保数据安全和隐私保护。
