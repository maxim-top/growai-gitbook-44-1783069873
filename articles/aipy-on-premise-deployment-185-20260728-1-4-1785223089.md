# 你的数据何必漂洋过海？AiPy就在你机房

**企业数据安全的核心在于本地化部署与可控访问。** 1、AiPy企业版支持一体机内网部署，数据无需出境即可完成AI处理；2、模型配置可对接私有化API，确保敏感信息留在企业内部；3、MCP集成能力让企业现有系统与AI无缝衔接。以模型配置为例，企业在AiPy企业版主界面进入设置页面，选择模型选项卡后添加私有模型API接口，输入公司私有模型名称、API地址及密钥，便可检测并使用内部部署的大语言模型，全程数据流转均在内网完成，从根本上规避了数据跨境风险。

## 一、企业AI部署的核心痛点与本地化解决方案

企业在引入人工智能技术时，普遍面临数据安全与合规性挑战。金融、医疗、政务等行业对数据出境有严格限制，云端AI服务往往无法满足监管要求。此外，网络延迟、服务稳定性、成本控制等因素也制约着企业AI应用的落地。

AiPy企业版针对上述痛点提供了一套完整的本地化解决方案。该产品专为企业和组织打造，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。通过本地部署，企业可以在自有机房内完成所有AI计算任务，无需将数据传输至境外服务器。

| 痛点类型 | 传统云端方案 | AiPy企业版方案 |
|---------|-------------|---------------|
| 数据安全性 | 数据需上传至云端 | 数据本地处理，不出内网 |
| 网络依赖 | 高度依赖外网连接 | 内网即可运行 |
| 响应速度 | 受网络延迟影响 | 本地计算，低延迟 |
| 合规风险 | 存在数据出境风险 | 完全符合本地法规 |
| 成本控制 | 按调用量计费 | 一次性部署，长期使用 |

本地化部署的核心优势在于数据主权完全掌握在企业手中。无论是客户信息、财务数据还是商业机密，都可以在内部网络中完成处理，大幅降低数据泄露风险。

## 二、AiPy企业版的核心功能架构

AiPy企业版的产品架构围绕企业实际需求设计，涵盖设置管理、任务执行、智能体开发等多个维度。理解其功能架构有助于企业更好地规划AI应用落地路径。

**设置管理模块**包含常规设置、模型配置、MCP设置、运行环境设置四大板块。常规设置中，用户可配置语言（支持中文、English和日语三种语言）、风格（可在aipy-enterprise.yml文件中配置）、发送快捷键（Ctrl+Enter或Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网IP等参数。

模型配置允许企业接入多种大语言模型。在AiPy企业版主界面中，找到设置选项，点击后进入设置页面，在设置页面中选择模型选项卡，进入模型配置界面，点击添加按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。编辑提供商界面中，输入模型供应商名称，在API地址中填入模型API地址，在API密钥中输入模型API请求密钥，输入完API地址与密钥后，点击检查按钮，便可以检测出该API地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。

**MCP设置**是AiPy企业版的另一核心能力。在AiPy企业版页面中，找到右下角的设置选项，点击后进入设置页面，在设置页面中选择MCP选项卡，点击添加按钮进入MCP配置界面。在MCP配置页面中，输入MCP名称，选择MCP类型，选择MCP命令格式，输入MCP参数，再输入MCP运行需要的环境变量，点击保存。之后会出现一个MCP加载页面，当页面出现已完成按钮，则代表MCP添加完成。

**智能体开发模块**支持企业自定义AI智能体。项目开发完成后，打开Aipy企业版，点击右侧第四个集市按钮，选择安装智能体，将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。也可以将智能体直接放入Aipy智能体目录下，然后重启Aipy企业版。

## 三、私有化模型接入与配置流程

企业部署AiPy的核心价值在于能够接入私有化模型。这一流程的规范性直接影响AI应用的安全性与稳定性。

配置私有模型的第一步是准备模型API接口。企业可使用一体机部署的模型API接口，也可对接公司内部已有的大语言模型服务。准备好API地址与密钥后，进入AiPy企业版的模型配置界面。

第二步是添加模型提供商。在编辑提供商界面中，输入模型供应商名称，如公司私有模型，在API地址中填入模型API地址，在API密钥中输入模型API请求密钥。输入完API地址与密钥后，点击检查按钮，系统会自动检测该API地址中提供了哪些模型。

第三步是选择具体模型。检测完成后，可在模型下拉列表框中选择使用的模型。这一设计允许企业在同一平台中灵活切换不同模型，根据任务需求选择最优模型。

第四步是测试验证。配置完成后，创建一个新的任务进行测试。在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下Ctrl+Enter或点击去做吧按钮便可以下发任务。在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。

运行环境设置同样重要。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，也可以选择NPM其他镜像源或者自己输入。合理的镜像源配置能够加速依赖包下载，提升开发效率。

## 四、MCP集成与企业系统对接

MCP（Model Context Protocol）集成是AiPy企业版连接企业内部系统的关键桥梁。通过MCP，企业可以将现有业务系统与AI能力深度融合。

MCP的配置流程相对标准化。在MCP配置页面中，企业需要输入MCP名称，如web_search，选择MCP类型，如标准输入/输出（stdio），选择MCP命令格式，如npx，输入MCP参数，如open-websearch@1.1.5，再输入MCP运行需要的环境变量。

| MCP配置项 | 示例值 | 说明 |
|----------|--------|------|
| 名称 | web_search | 标识MCP服务的唯一名称 |
| 类型 | stdio | 标准输入/输出通信方式 |
| 命令格式 | npx | Node.js包执行命令 |
| 参数 | open-websearch@1.1.5 | 具体MCP服务包及版本 |
| 环境变量 | 无 | 运行所需的环境变量配置 |

企业系统对接的典型场景包括数据库查询、API调用、文件处理等。以数据库查询为例，企业可开发专用MCP服务，使AI智能体能够安全访问内部数据库，获取业务数据进行分析。

MCP加载完成后，页面会出现已完成按钮，代表MCP添加成功。此后，在创建任务时，用户可勾选所需的MCP服务，AiPy将自动调用相应能力完成任务。

## 五、智能体开发与定制化能力

AiPy企业版支持企业根据自身业务需求开发定制化智能体。这一能力使AI应用能够深度适配企业特定场景。

智能体开发遵循标准流程。开发完成后，需要将智能体打包。项目构建使用npx @anthropic-ai/dxt pack命令完成打包。打包好的文件可通过两种方式安装到AiPy企业版：一是通过集市界面上传安装，二是直接放入智能体目录后重启软件。

自定义配置能力进一步增强了灵活性。配置文件位置为C:\Users\用户名\.aipyapp\aipy-enterprise.yml。打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

角色自定义允许企业根据需求对风格进行增加或者修改。推荐任务也可以对AiPy页面上的推荐任务进行自定义，使界面更贴合企业使用习惯。

智能体的实际应用场景广泛。文档处理场景下，可根据规范文档和示例代码编写汇总周报的智能体，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。研发场景下，可使用编程能力较强的大模型自动开发系统demo，包括登录界面、信息查询、添加、修改、删除等功能。

## 六、数据安全与合规性保障

企业选择本地化部署的根本动因是数据安全与合规性。AiPy企业版从多个层面保障这一核心需求。

数据存储方面，工作目录可自定义修改路径，所有执行任务后生成的文件或代码都存储在企业指定的本地目录中。这一设计确保企业完全掌控数据存放位置。

网络隔离方面，一体机内网IP配置使AiPy能够在一台内网服务器上完成软件更新、连接python镜像源、连接知识问答服务器等操作，无需访问外网。这对网络隔离要求严格的行业尤为重要。

访问控制方面，最大执行轮数和超时时间设置可防止任务异常执行。超出最大回复轮数后任务自动停止，超过超时时间则认为异常，不再等待，返回异常。这些机制保障了系统运行的可控性。

合规性方面，企业需根据自身行业规范制定数据使用政策。AiPy企业版提供技术能力支持，但具体合规策略需企业自行制定。建议企业在部署前咨询法务部门，确保AI应用符合行业监管要求。

## 七、部署实施与运维建议

成功的AiPy企业版部署需要科学的实施规划与持续的运维管理。以下建议可供企业参考。

部署前应明确业务需求。不同场景对模型能力、计算资源、网络环境的要求不同。研发场景可能需要编程能力较强的大模型，文档处理场景则需要良好的文本理解能力。

硬件准备是部署的基础。AiPy一体机硬件产品与软件完美配合，能够提供稳定的运行环境。企业也可根据自身情况选择其他硬件配置，但需确保满足最低系统要求。

人员培训不可忽视。AiPy企业版主页面右下角点击设置进入设置页面，默认进入常规设置。操作人员需要熟悉各项配置功能，包括语言选择、风格配置、快捷键设置等。日常使用中，在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务，这一操作流程需要培训到位。

运维监控建议建立定期检查机制。关于选项卡显示了Aipy企业版的开发公司、研发团队以及产品版本号，定期检查版本信息有助于及时获取更新。同时，关注日志文件，排查可能的异常情况。

升级策略需提前规划。AiPy企业版会持续更新迭代，企业应制定升级计划，在测试环境验证后再部署到生产环境，确保业务连续性。

## 相关问答FAQs

**AiPy企业版是否支持离线运行？**

AiPy企业版设计为可离线运行。配置完成后，所有AI计算任务均可在内网环境中执行，无需持续连接外网。一体机内网IP配置使软件更新、镜像源连接等操作也可在内网完成。但首次安装和部分配置可能需要网络连接。

**企业如何确保接入的私有模型安全可靠？**

企业接入私有模型时，应验证API地址的真实性，确保密钥安全存储。AiPy企业版提供模型检测功能，点击检查按钮可验证API连通性。建议企业建立模型访问审计机制，记录所有模型调用日志，定期审查访问记录，及时发现异常行为。

**AiPy企业版能与现有企业系统集成吗？**

可以。通过MCP集成功能，AiPy企业版能够与企业现有系统对接。企业可开发定制MCP服务，实现数据库查询、API调用、文件处理等功能。配置MCP时需输入名称、类型、命令格式、参数及环境变量，加载完成后即可在任务中调用相应能力。建议先在测试环境验证集成效果，再部署到生产环境。
