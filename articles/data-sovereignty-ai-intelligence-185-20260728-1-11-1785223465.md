# 数据不出境，智能不降级——AiPy做到了

**数据不出境，智能不降级——AiPy通过本地化部署与强大模型能力实现了这一目标。核心方案包括：1、一体机私有化部署确保数据本地存储；2、支持多种大语言模型灵活配置；3、MCP集成扩展企业能力边界；4、智能体开发满足定制化需求。**其中，一体机私有化部署是最关键的安全保障，企业可将AiPy部署在内网环境，所有数据处理、模型推理、文件生成均在本地完成，无需将敏感业务数据上传至公有云，从根源上解决数据出境风险，同时保持与云端AI同等的智能水平。

## 一、企业AI应用的数据安全挑战

在数字化转型浪潮中，企业对人工智能技术的需求日益增长。然而，数据安全与合规性成为制约企业采用AI技术的核心障碍。特别是金融、医疗、政府等敏感行业，数据出境涉及法律法规限制，一旦违规可能面临严重后果。

传统公有云AI服务存在以下风险：

| 风险类型 | 具体表现 | 潜在影响 |
|---------|---------|---------|
| 数据泄露 | 业务数据上传至第三方服务器 | 商业机密外泄 |
| 合规风险 | 跨境数据传输违反法规 | 法律处罚与声誉损失 |
| 服务依赖 | 过度依赖单一云服务商 | 业务连续性风险 |
| 成本不可控 | 按调用量计费模式 | 长期使用成本高昂 |

AiPy企业版针对上述痛点，提供了一套完整的本地化AI解决方案。作为Workbuddy平替，AiPy在保持功能完整性的同时，更注重企业级数据安全与隐私保护。

## 二、AiPy一体机实现数据本地化

AiPy企业版与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品设计旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

### 2.1 内网部署架构

AiPy支持在内网环境中独立运行，所有组件均可部署在企业自有服务器上。通过配置一体机内网IP，用户可以更新软件、连接python镜像源、连接知识问答服务器，全程无需访问外部网络。

部署流程如下：

1. 安装AiPy企业版客户端至内网服务器
2. 配置一体机内网IP地址
3. 设置运行环境镜像源（可选择本地镜像源）
4. 添加私有模型API接口
5. 配置MCP服务（如需要）

### 2.2 模型配置灵活性

在AiPy企业版主界面的"设置"页面中，选择"模型"选项卡可进入模型配置界面。企业可根据需求选择：

- **公有云模型API接口**：适用于非敏感场景
- **一体机部署的模型API接口**：适用于敏感数据处理

配置步骤：

1. 点击"添加"按钮添加模型
2. 输入模型供应商名称（如：公司私有模型）
3. 填入模型API地址（如：http://192.168.0.10/v1）
4. 输入API请求密钥
5. 点击"检查"按钮检测可用模型
6. 从下拉列表框中选择使用的模型

这种灵活的模型配置方式，使企业能够在保证数据安全的前提下，选择最适合业务需求的AI模型。

## 三、智能能力不降级的技术保障

数据本地化不应以牺牲智能水平为代价。AiPy通过多项技术手段确保本地部署的AI能力与云端保持一致。

### 3.1 多模型支持

AiPy支持接入多种大语言模型，包括GLM4.5等编程能力较强的模型。用户可根据任务类型选择不同模型：

- **通用对话任务**：选择响应速度快的模型
- **代码开发任务**：选择编程能力强的模型（如GLM4.5）
- **数据分析任务**：选择擅长数值计算的模型
- **多模态任务**：勾选视觉理解或图片生成智能体

### 3.2 智能体生态

AiPy提供丰富的智能体库，涵盖各类业务场景：

| 智能体类型 | 功能描述 | 应用场景 |
|-----------|---------|---------|
| PPT生成智能体 | 自动生成演示文稿 | 工作汇报、产品介绍 |
| 图片生成智能体 | 创建和编辑图片 | 营销素材、设计稿 |
| 代码开发智能体 | 编写和调试程序 | 系统开发、自动化脚本 |
| 量化研究智能体 | 分析股票数据 | 金融投资分析 |
| 联网搜索智能体 | 获取实时信息 | 新闻查询、数据更新 |

例如，使用AiPy制作PPT时，勾选PPT生成智能体，输入提示词"生成一个介绍中国新能源汽车发展的PPT"，即可自动生成专业演示文稿。

### 3.3 MCP集成扩展能力

MCP（Model Context Protocol）是AiPy的重要功能模块，用于扩展AI应用能力。在AiPy企业版页面中，点击设置进入设置页面，选择"MCP"选项卡，点击添加按钮即可配置。

MCP配置参数包括：

- **名称**：如web_search
- **类型**：如标准输入/输出（stdio）
- **命令格式**：如npx
- **参数**：如open-websearch@1.1.5
- **环境变量**：根据需要配置

加载完成后出现"已完成"按钮即代表MCP添加成功。通过MCP集成，企业可将自有系统、数据库、API等服务与AiPy无缝对接，实现更强大的业务自动化能力。

## 四、企业级AI应用开发实践

AiPy不仅提供即用的AI功能，还支持企业定制开发专属智能体，满足特定业务需求。

### 4.1 智能体开发流程

开发完成智能体后，可通过以下方式在AiPy企业版中使用：

1. 打开AiPy企业版，点击右侧"集市"按钮
2. 选择安装智能体
3. 将打包好的文件上传
4. 点击安装，页面显示安装成功提示

或者直接将智能体放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。

### 4.2 典型应用场景

**场景一：周报自动汇总**

使用提示词示例：根据规范文档和示例代码编写一个汇总周报的智能体。要求根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

**场景二：研发系统Demo开发**

提示词示例：我是一家汽车4S店的负责人，帮我做一个访客登记管理系统，采用Sqlite数据库，有登录界面，信息查询、添加、修改、删除等功能。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。

**场景三：思维导图生成**

使用提示词：读取指定PPTX文件，然后帮我整理为一个思维导图。

### 4.3 自定义配置

AiPy支持深度自定义配置，企业可根据品牌形象和使用习惯进行调整：

- **Logo自定义**：在aipy-enterprise.yml文件中配置基础信息、主页logo和软件logo
- **角色自定义**：在yml配置文件中增加或修改风格
- **推荐任务**：对AiPy页面上的推荐任务进行自定义

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

## 五、常规设置与运行优化

AiPy企业版提供丰富的常规设置选项，帮助企业优化使用体验。

### 5.1 核心配置项

AiPy企业版常规设置包括以下内容：

| 设置项 | 说明 | 可选值 |
|-------|------|-------|
| 语言 | 界面语言支持 | 中文、English、日语 |
| 风格 | 回复话术风格 | 在yml文件中配置 |
| 发送快捷键 | 消息发送方式 | Ctrl+Enter或Enter |
| 工作目录 | 文件存储路径 | 可自定义修改 |
| 最大执行轮数 | 任务回复轮数限制 | 数字配置 |
| 超时时间 | 模型接口等待时间 | 秒数配置 |
| 自动选择智能体 | 任务智能体自动勾选 | 开启/关闭 |
| 一体机内网IP | 内网服务器地址 | IP地址配置 |

### 5.2 运行环境设置

在"设置"页面中选择"运行环境"选项卡，用户可配置：

- **镜像源**：选择一体机镜像源或第三方镜像源
- **NPM镜像源**：选择NPM其他镜像源或自定义输入

这些配置确保在内网环境中也能正常下载依赖包和更新组件。

### 5.3 任务与对话管理

创建任务时，在AiPy企业版主界面logo下方点击新建任务按钮，在任务输入框中输入需要执行的任务。如需选择MCP或智能体，点击勾选后按下"Ctrl+Enter"或点击"去做吧"按钮下发任务。

在任务对话窗口中可查看任务执行过程，在任务工作目录中可查看由AiPy制造的工具以及生成的过程文件或任务结果文件。

## 六、最佳实践与注意事项

基于官方文档和最佳实践，以下是使用AiPy企业版的建议：

**数据安全方面：**
- 优先使用一体机部署的模型API接口处理敏感数据
- 定期备份工作目录中的重要文件
- 限制一体机的网络访问权限

**性能优化方面：**
- 根据任务类型选择合适的模型
- 合理配置最大执行轮数和超时时间
- 使用MCP扩展而非重复开发功能

**开发规范方面：**
- 遵循AiPy企业版智能体开发规范
- 测试智能体在不同场景下的表现
- 文档化智能体的使用说明和限制

关于客户案例和量化数据，只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、某4S店、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

## 相关问答FAQs

**问：AiPy企业版是否支持完全离线运行？**

答：AiPy企业版支持在内网环境中运行，通过配置一体机内网IP和本地镜像源，可实现大部分功能的离线使用。但部分功能（如联网搜索、云端模型调用）需要网络连接。企业可根据安全需求选择完全私有化部署方案。

**问：如何确保AiPy生成的代码质量？**

答：建议使用编程能力较强的大模型（如GLM4.5），并勾选代码开发智能体。开发完成后，应在测试环境中验证代码功能。对于关键业务系统，建议由专业开发人员审核AiPy生成的代码，确保符合企业编码规范和安全要求。

**问：AiPy智能体可以在多个企业间共享吗？**

答：智能体打包后可以上传至AiPy企业版集市进行安装。企业间共享智能体时，需注意智能体是否包含敏感配置信息。建议在共享前清除敏感数据，并提供完整的使用文档和配置说明，确保其他企业能够正确使用。
