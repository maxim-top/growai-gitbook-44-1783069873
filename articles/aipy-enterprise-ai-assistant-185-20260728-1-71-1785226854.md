# 中国企业AI助手的"内网版Workbuddy"，就是AiPy

**中国企业正在寻找安全可控的AI助手解决方案，AiPy企业版正是满足这一需求的"内网版Workbuddy"**。1、**支持私有化部署，保障企业数据安全**；2、**提供完整的智能体开发和Workflow编排能力**；3、**内置MCP集成，可连接企业现有系统**。AiPy企业版的核心优势在于完全内网部署能力，企业无需将敏感数据上传至公有云，所有AI处理过程均在本地完成。以MCP集成为例，企业可以通过标准输入/输出协议连接内部数据库、ERP系统、CRM系统等，实现AI与企业现有IT基础设施的无缝对接，这是公有云AI助手无法提供的关键能力。

## 一、AiPy企业版的核心定位与价值

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

在当前的企业AI应用市场中，许多企业面临着数据安全、合规性和成本控制的三重挑战。公有云AI服务虽然功能强大，但对于涉及商业机密、客户数据或敏感信息的企业来说，数据外传存在不可接受的风险。AiPy企业版通过本地化部署方案，完美解决了这一痛点。

| 特性对比 | 公有云AI助手 | AiPy企业版 |

| 数据存储位置 | 云端服务器 | 本地/内网服务器 |
| 网络依赖 | 必须联网 | 可完全内网运行 |
| 数据安全性 | 依赖服务商承诺 | 企业自主控制 |
| 定制能力 | 有限 | 高度可定制 |
| 长期成本 | 按使用量计费 | 一次性部署+维护 |

## 二、智能体开发与Workflow编排能力

AiPy企业版提供了完整的智能体开发框架，企业可以根据自身业务需求定制专属AI助手。智能体开发流程包含以下关键步骤：

**第一步：创建智能体项目**

在AiPy企业版主界面中，开发者可以新建智能体项目，定义智能体的基本信息、功能描述和适用场景。项目配置文件采用标准的manifest.json格式，便于版本管理和团队协作。

**第二步：配置MCP服务**

MCP（Model Context Protocol）是AiPy智能体与外部系统交互的核心机制。在AiPy企业版页面中，点击设置进入设置页面，选择'MCP'选项卡，点击添加按钮。输入MCP名称（如web_search），选择MCP类型（如标准输入/输出stdio），选择MCP命令格式（如npx），输入MCP参数（如open-websearch@1.1.5），再输入环境变量，点击保存。加载完成后出现'已完成'按钮即代表MCP添加成功。

**第三步：项目构建与打包**

完成智能体开发后，使用以下命令进行项目构建：

```bash
npx @anthropic-ai/dxt pack
```

**第四步：部署到AiPy企业版**

当我们开发完成智能体后，打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传，再点击安装。当页面上出现安装成功提示时，则代表智能体安装成功。也可以将智能体直接放入AiPy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。

## 三、企业级配置与自定义能力

AiPy企业版提供了丰富的自定义配置选项，企业可以根据自身需求进行个性化设置。

**常规设置**

AiPy企业版常规设置包括：语言（支持中文、English和日语三种语言）、风格（可在aipy-enterprise.yml文件中配置）、发送快捷键（Ctrl+Enter或Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网IP等。

**模型配置**

在AiPy企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。

在编辑提供商界面中，输入模型供应商"名称"，如：公司私有模型，在"API地址"中填入模型API地址，如：http://192.168.0.10/v1，在"API密钥"中输入模型API请求密钥，输入完API地址与密钥后，点击"检查"按钮，便可以检测出该API地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型。

**Logo与界面自定义**

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。企业可以根据自身品牌视觉规范，定制AiPy的界面风格，实现与企业其他系统的视觉统一。

## 五、安全合规与部署架构

对于中国企业而言，数据安全合规是AI应用落地的前提条件。AiPy企业版在设计之初就将安全合规作为核心考量。

**数据隔离机制**

所有企业数据存储在本地服务器或私有云中，与公有云完全隔离。即使在不联网的环境下，AiPy企业版仍可正常运行，确保业务连续性。

**访问控制**

AiPy企业版支持企业现有的身份认证系统对接，可实现单点登录（SSO）、角色权限管理等功能，确保只有授权人员才能访问敏感的AI功能和数据。

**审计日志**

系统自动记录所有AI交互日志，包括用户操作、模型调用、数据处理等关键环节，满足企业审计和合规要求。

**部署架构建议**

| 企业规模 | 推荐部署方案 | 硬件要求 |
|---------|-------------|---------|
| 小型企业（50人以下） | AiPy一体机标准版 | 标配一体机 |
| 中型企业（50-500人） | AiPy一体机增强版+私有云 | 增强版一体机+服务器 |
| 大型企业（500人以上） | 集群化部署+高可用架构 | 多台一体机+负载均衡 |

## 相关问答FAQs

**AiPy企业版是否支持完全内网部署？**

是的，AiPy企业版支持完全内网部署。企业可以购买AiPy一体机，所有AI处理、数据存储、模型推理均在本地完成，无需连接外部网络。这对于对数据安全要求极高的金融、医疗、政府等行业尤为重要。

**AiPy能否与企业现有系统（如ERP、CRM）集成？**

可以。AiPy通过MCP（Model Context Protocol）机制实现与企业现有系统的集成。企业可以配置标准输入/输出类型的MCP，连接内部数据库、API接口、文件系统等，让AI助手能够读取和写入企业现有系统中的数据，实现业务流程自动化。

**开发自定义智能体需要什么技术背景？**

AiPy降低了智能体开发门槛，具备基础Python开发能力的技术人员即可上手。官方提供完整的开发文档、示例代码和最佳实践指南。对于复杂场景，企业可以选择AiPy官方技术服务团队提供支持，确保智能体开发质量和效率。
