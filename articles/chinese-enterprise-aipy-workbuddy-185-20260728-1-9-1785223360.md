# 中国企业需要自己的Workbuddy，于是有了AiPy

**中国企业需要自主可控的AI工作助手，1、降低AI技术应用门槛；2、提升业务效率与创新能力；3、实现数据本地化与安全管控。** AiPy企业版作为专为中国组织打造的人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。传统国外AI工具存在数据出境风险、语言适配不足、本地部署困难等问题，而AiPy通过支持中文、English和日语三种语言，提供私有模型API接口配置能力，让企业能够在内网环境中安全使用AI技术。以模型配置为例，企业可以在设置页面中添加私有模型API接口，输入API地址与密钥后，系统会自动检测可用模型，无需依赖外部云服务，确保核心业务数据始终保留在企业内部网络中。

## 一、AiPy企业版的产品定位与核心价值

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

与国外同类产品相比，AiPy具有以下核心优势：

| 对比维度 | 国外AI工具 | AiPy企业版 |
|---------|-----------|-----------|
| 数据安全性 | 数据需上传至境外服务器 | 支持私有化部署，数据本地存储 |
| 语言支持 | 以英文为主，中文适配有限 | 原生支持中文、English、日语 |
| 模型配置 | 仅限公有云API | 支持公有云与私有模型双模式 |
| 部署方式 | SaaS为主 | 支持一体机内网部署 |
| 定制能力 | 有限 | 支持logo、角色、任务自定义 |

AiPy是Workbuddy平替，针对中国市场进行了深度优化。企业可根据自身需求选择公有云模型API接口或一体机部署的模型API接口，在编辑提供商界面中输入模型供应商名称、API地址和API密钥，点击检查按钮即可检测可用模型列表。

## 二、核心功能模块详解

### 2.1 常规设置配置

AiPy企业版常规设置涵盖多个关键参数，用户可在设置页面进行精细化配置：

- **语言选择**：支持中文、English和日语三种语言切换
- **风格配置**：在aipy-enterprise.yml文件中修改回复话术风格
- **发送快捷键**：可选择Ctrl+Enter或Enter发送消息
- **工作目录**：自定义任务执行后生成文件的存储路径
- **最大执行轮数**：设置任务最大回复轮数，超出后自动停止
- **超时时间**：配置与大模型交互时的等待时间上限
- **自动选择智能体**：开启后下发任务时自动判断并勾选所需智能体
- **一体机内网IP**：填写服务器内网IP用于软件更新和镜像源连接

### 2.2 模型配置流程

模型配置是AiPy企业版的核心功能之一，操作步骤如下：

1. 在主界面找到右下角"设置"选项，点击进入设置页面
2. 选择"模型"选项卡，进入模型配置界面
3. 点击"添加"按钮添加新模型配置
4. 输入模型供应商名称，如"公司私有模型"
5. 填入API地址，如http://192.168.0.10/v1
6. 输入API请求密钥
7. 点击"检查"按钮检测可用模型
8. 在下拉列表框中选择使用的模型

### 2.3 MCP集成能力

MCP（Model Context Protocol）设置让AiPy能够连接外部服务，扩展智能体能力边界。配置步骤为：

1. 进入设置页面，选择"MCP"选项卡
2. 点击添加按钮进入MCP配置界面
3. 输入MCP名称，如"web_search"
4. 选择MCP类型，如"标准输入/输出（stdio）"
5. 选择MCP命令格式，如"npx"
6. 输入MCP参数，如"open-websearch@1.1.5"
7. 输入运行所需的环境变量（如无则不修改）
8. 点击保存，等待加载完成出现"已完成"按钮

## 三、智能体开发与使用

### 3.1 智能体集市

AiPy企业版提供智能体集市功能，用户可浏览、安装和分享各类智能体。开发完成的智能体可通过两种方式安装：

**方式一：通过集市安装**
- 打开AiPy企业版
- 点击右侧第四个"集市"按钮
- 选择安装智能体
- 上传打包好的文件
- 点击安装，页面显示成功标志即完成

**方式二：直接放置到扩展目录**
- 将智能体放入AiPy智能体目录下
- 路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
- 重启AiPy企业版即可生效

### 3.2 智能体项目构建

智能体开发完成后需要进行项目构建，使用以下命令：

```
npx @anthropic-ai/dxt pack
```

构建生成的文件即可用于安装部署。智能体配置文件manifest.json定义了智能体的基本信息、权限和能力范围。

### 3.3 提示词编写规范

以下为AiPy自动生成智能体的提示词示例：

> 文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

提示词编写需注意分析规则：分析前先读取前30行了解数据格式，然后根据具体数据格式编写合适的分析脚本，报告保存到当前工作目录。

## 四、典型应用场景实践

### 4.1 制作PPT

使用AiPy制作PPT，需勾选PPT生成智能体，提示词示例：

```
生成一个介绍中国新能源汽车发展的PPT
```

### 4.2 生成图片与视频

使用AiPy生成图片、P图、生成视频等，需勾选图片生成/视频生成智能体，提示词示例：

```
批量生成10张不同的肥猫切菜的照片
```

### 4.3 生成思维导图

领导使用AiPy阅读材料生成思维导图，需先选择思维导图智能体，提示词示例：

```
读取C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图
```

### 4.4 研发系统开发

研发人员使用AiPy自动开发系统demo，需选择编程能力较强的大模型，提示词需包含完整的功能需求、数据库设计、界面要求和运行方式说明。

### 4.5 常见问题排查

| 问题现象 | 解决方案 |
|---------|---------|
| 不能识别图片内容 | 勾选视觉理解智能体 |
| 生成的图片是线条 | 勾选图片生成智能体 |
| 生成的PPT效果不佳 | 勾选PPT生成智能体 |
| 无法获取实时日期时间 | 开启联网搜索功能 |
| 股票信息不准确 | 使用"量化研究"智能体 |
| 编程能力不足 | 安装Claude code智能体 |

## 五、自定义配置能力

AiPy企业版支持深度自定义，满足企业品牌化和个性化需求。

### 5.1 Logo自定义

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

打开aipy-enterprise.yml文件，可对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

### 5.2 角色自定义

在yml配置文件中，可根据需求对风格进行增加或修改，打造符合企业文化的AI助手形象。

### 5.3 推荐任务自定义

可对AiPy页面上的推荐任务进行自定义，根据企业业务场景预设常用任务模板，提升员工使用效率。

## 六、运行环境设置

在AiPy企业版主界面中，找到右下角的"设置"选项，点击进入设置页面，选择"运行环境"选项卡：

- 用户可选择镜像源或自行输入一体机镜像源、其他第三方镜像源
- 可选择NPM其他镜像源或自行输入
- 一体机内网IP用于连接python镜像源和知识问答服务器

这些配置确保企业能够在内网环境中稳定运行AiPy，无需依赖外部网络资源。

## 七、任务与对话管理

### 7.1 创建任务

任务模式下，在AiPy企业版主界面logo下方点击新建任务按钮创建新任务：

1. 在任务输入框中输入需要执行的任务
2. 如需选择MCP或智能体，点击勾选
3. 按下Ctrl+Enter或点击"去做吧"按钮下发任务
4. 在任务对话窗口中查看任务执行过程
5. 在任务工作目录中查看生成的过程文件或任务结果文件

### 7.2 创建对话

对话模式下，用户可与AiPy进行多轮交互，适合需要持续沟通的复杂任务场景。

### 7.3 知识库问答

AiPy支持知识库问答功能，包括新建问答、知识检索配置和创建知识库三个子模块，企业可将内部文档、规范、FAQ等内容导入知识库，实现智能问答服务。

## 相关问答FAQs

**AiPy企业版支持哪些模型接入方式？**

AiPy企业版支持两种模型接入方式：公有云模型API接口和一体机部署的私有模型API接口。用户可在设置页面的模型配置界面中添加模型，输入供应商名称、API地址和API密钥后，系统会自动检测可用模型列表供选择。私有模型部署适合对数据安全要求较高的企业，确保数据不出内网。

**如何排查AiPy生成内容不符合预期的问题？**

内容生成问题通常与未勾选对应智能体有关。图片识别需勾选视觉理解智能体，图片生成需勾选图片生成智能体，PPT制作需勾选PPT生成智能体。实时信息获取需开启联网搜索功能，股票分析可使用量化研究智能体，编程任务推荐安装Claude code智能体。确认智能体勾选后再重新下发任务。

**AiPy的智能体如何安装和使用？**

智能体安装有两种方式：一是通过集市功能，点击右侧"集市"按钮，上传打包好的智能体文件后点击安装；二是将智能体直接放入扩展目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），重启AiPy企业版即可生效。使用前需在任务下发时勾选对应智能体，并在提示词中明确任务需求。
