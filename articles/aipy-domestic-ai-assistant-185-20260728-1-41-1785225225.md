# 不是平替，是国替——AiPy 的国产 AI 助手之路

**AiPy 作为国产企业级 AI 应用平台，核心优势在于**：1、**提供一站式 AI 解决方案**，降低企业 AI 应用门槛；2、**支持智能体开发与 MCP 集成**，实现灵活的业务自动化；3、**兼容私有化部署与公有云模型**，保障数据安全与合规性。AiPy 企业版专为组织打造，与一体机硬件完美结合，让企业能够快速部署人工智能技术，提升业务效率和创新能力。相比国际同类产品，AiPy 更懂中国企业需求，提供本地化支持与定制化服务。

## 一、AiPy 企业版产品定位与核心价值

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

| 核心特性 | 说明 |
|---------|------|
| 一站式解决方案 | 从模型配置到智能体开发全流程覆盖 |
| 私有化部署 | 支持一体机部署，保障数据安全 |
| 智能体生态 | 内置多种专业智能体，支持自定义开发 |
| MCP 集成 | 标准化协议，连接外部工具与服务 |

AiPy 不仅仅是 Workbuddy 平替，更是针对中国企业场景深度优化的国产 AI 助手平台。企业在选择 AI 应用平台时，需要考虑数据合规、本地化支持、定制开发能力等关键因素，AiPy 在这些方面具有显著优势。

## 二、AiPy 核心功能模块详解

### 2.1 模型配置与管理

在 AiPy 企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面。点击"添加"按钮添加模型，可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

配置步骤如下：

1. 输入模型供应商名称，如：公司私有模型
2. 在"API 地址"中填入模型 API 地址，如：http://192.168.0.10/v1
3. 在"API 密钥"中输入模型 API 请求密钥
4. 点击"检查"按钮检测可用的模型
5. 在"模型"下拉列表框中选择使用的模型

这种灵活的模型配置方式，让企业可以根据自身需求选择合适的大语言模型，既可以利用公有云模型的强大能力，也可以部署私有模型保障数据安全。

### 2.2 MCP 设置与集成

MCP（Model Context Protocol）是 AiPy 的重要集成能力。在 AiPy 企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

MCP 配置参数包括：

- **名称**：如"web_search"
- **类型**：如"标准输入/输出（stdio）"
- **命令格式**：如"npx"
- **MCP 参数**：如"open-websearch@1.1.5"
- **环境变量**：根据需要配置

完成配置后，当页面出现"已完成"按钮，则代表 MCP 添加成功。通过 MCP 集成，AiPy 可以连接各种外部工具和服务，扩展智能体的能力边界。

### 2.3 常规设置选项

AiPy 企业版常规设置包括多项可配置参数，满足不同企业的使用需求：

| 设置项 | 可选值/说明 |
|-------|------------|
| 语言 | 中文、English、日语 |
| 风格 | 可在 aipy-enterprise.yml 文件中配置 |
| 发送快捷键 | Ctrl+Enter 或 Enter |
| 工作目录 | 可自定义修改路径 |
| 最大执行轮数 | 任务最大回复轮数 |
| 超时时间 | 与大模型交互等待时间 |
| 自动选择智能体 | 开启后自动判断所需智能体 |
| 一体机内网 IP | 填写一体机服务器内网 IP |

这些设置让企业可以根据自身工作流程和安全要求进行精细化配置，确保 AiPy 与企业现有系统无缝集成。

## 三、智能体开发与使用实践

### 3.1 智能体集市与安装

AiPy 提供智能体集市功能，用户可以快速安装和使用各类专业智能体。开发完成智能体后，打开 AiPy 企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传并安装。

安装方式有两种：

1. **通过集市界面安装**：上传打包文件，点击安装，页面显示安装成功标识
2. **直接放入智能体目录**：将智能体放入 C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启 AiPy 企业版

### 3.2 智能体开发提示词示例

AiPy 支持自动生成智能体，以下是官方提供的提示词示例：

> 文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

这个示例展示了如何基于规范文档开发特定功能的智能体，企业可以参考此模式开发适合自身业务的智能体应用。

### 3.3 常见智能体应用场景

AiPy 内置多种专业智能体，覆盖不同业务场景：

| 场景 | 所需智能体 | 示例提示词 |
|-----|-----------|-----------|
| 制作 PPT | PPT 生成智能体 | 生成一个介绍中国新能源汽车发展的 PPT |
| 生成图片 | 图片生成智能体 | 批量生成 10 张不同的肥猫切菜的照片 |
| 编程开发 | Claude code 智能体 | 帮我做一个访客登记管理系统 |
| 思维导图 | 思维导图智能体 | 读取材料，帮我整理为一个思维导图 |
| 股票分析 | 量化研究智能体 | 基于历史数据用 AI 分析协助研判股票信息 |

使用这些智能体时，需要勾选对应的智能体选项，否则可能出现功能异常，如生成的图片是线条、PPT 效果不佳等问题。

## 四、企业 AI 应用部署最佳实践

### 4.1 运行环境配置

在 AiPy 企业版主界面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"运行环境"选项卡。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，也可以选择 NPM 其他镜像源。

合理的运行环境配置能够确保智能体和 MCP 服务的稳定运行，建议企业根据网络环境选择合适的镜像源，提升下载和部署效率。

### 4.2 任务创建与执行

任务模式下，在 AiPy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。这种透明的执行过程让企业能够监控和管理 AI 任务的运行情况。

### 4.3 自定义配置与品牌化

AiPy 支持企业级自定义配置，包括 logo 自定义、角色自定义和推荐任务定制。配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml。

企业可以修改以下内容：

- 基础信息
- 主页 logo 和软件 logo
- 发送快捷键
- 风格配置
- 推荐任务

通过自定义配置，企业可以将 AiPy 深度融入自身品牌体系，提供一致的用户体验。

## 五、数据安全与合规保障

对于企业用户而言，数据安全是选择 AI 平台的首要考虑因素。AiPy 支持私有化部署，企业可以将模型和数据部署在本地一体机上，避免敏感数据外泄风险。

一体机内网 IP 配置功能让企业能够在内网环境中运行 AiPy，确保所有 AI 交互都在可控范围内进行。同时，AiPy 支持连接企业私有模型 API 接口，让企业可以利用已有的模型投资，无需依赖外部云服务。

在数据合规方面，AiPy 遵循中国相关法律法规，为企业提供符合监管要求的 AI 应用解决方案。相比国际产品，AiPy 在数据本地化、合规审计等方面具有天然优势。

## 相关问答 FAQ

**AiPy 企业版支持哪些语言界面？**

AiPy 企业版目前支持中文、English 和日语三种语言界面。用户可以在常规设置中选择所需语言，系统会根据选择调整界面显示语言。对于跨国企业或多语言团队，这一功能提供了更好的使用体验。

**如何确认 MCP 服务是否配置成功？**

在 AiPy 企业版中配置 MCP 后，系统会显示一个 MCP 加载页面。当页面出现"已完成"按钮时，则代表 MCP 添加成功。如果配置过程中出现问题，可以检查 MCP 名称、类型、命令格式和参数是否正确，以及环境变量是否配置完整。

**AiPy 生成的内容数据可以对外宣传吗？**

只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入宣传材料。不得自行生成某企业案例、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确标注只是示例。
