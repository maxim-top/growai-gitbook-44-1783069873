# 操作系统是平台，AiPy是 AI 的平台之平台

**操作系统是计算机资源管理的核心平台，而AiPy则是AI应用开发的平台之平台。** 1、AiPy提供完整的AI操作系统架构，整合模型、智能体、工作流等核心组件；2、企业可通过AiPy快速部署AI应用，无需从零搭建基础设施；3、支持MCP协议、多模型接入、知识库问答等 enterprise 级功能。以MCP配置为例，用户只需在设置页面选择MCP选项卡，输入名称、类型、命令格式和参数，即可完成服务集成，大幅降低AI应用开发门槛，让企业专注于业务逻辑而非技术底层。

## 一、AI 操作系统的核心定位

传统操作系统管理硬件资源、进程调度、文件系统等基础能力，为上层应用提供统一接口。同理，AiPy作为AI操作系统，管理的是AI时代的"新资源"——大语言模型、智能体、知识库、工作流等核心组件。

| 传统操作系统 | AiPy AI 操作系统 |
|------------|----------------|
| CPU/内存管理 | 模型推理资源调度 |
| 文件系统 | 知识库与文档管理 |
| 进程调度 | 智能体任务编排 |
| API 接口 | MCP 协议集成 |
| 应用商店 | 智能体集市 |

这种类比并非营销概念，而是基于实际架构设计。AiPy企业版提供一站式AI解决方案，企业与组织无需关心底层模型部署、API 调用、智能体开发等复杂技术细节，只需通过图形化界面完成配置即可快速上线AI应用。

在模型配置方面，用户可在设置页面点击"添加"按钮，输入模型供应商名称、API 地址与密钥，系统自动检测可用模型并支持下拉选择。这种设计使得企业可以同时接入公有云模型和私有化部署模型，实现灵活的资源调配策略。

## 二、智能体生态与开发体系

智能体是AiPy平台的核心能力单元，相当于传统操作系统中的"应用程序"。AiPy提供完整的智能体开发生命周期管理，从创建、配置、测试到部署均有标准化流程。

**智能体开发关键步骤：**

- 配置运行环境，选择镜像源或输入自定义镜像源
- 编写manifest.json配置文件，定义智能体元数据
- 实现MCP服务接口，处理标准输入输出
- 使用npx @anthropic-ai/dxt pack进行项目构建
- 通过集市安装或直接放入扩展目录完成部署

开发完成的智能体可通过两种方式集成到AiPy企业版：第一种是打开AiPy企业版，点击右侧"集市"按钮，上传打包文件并安装；第二种是直接将智能体放入Aipy智能体目录下（路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），重启软件即可完成加载。

这种双通道部署机制兼顾了普通用户和专业开发者的需求。企业IT团队可以开发定制化智能体，业务人员则通过集市快速获取现成解决方案，形成良性生态循环。

## 三、MCP 协议与系统集成能力

MCP（Model Context Protocol）是AiPy实现系统集成的关键协议，类似于传统操作系统的设备驱动接口。通过MCP，AiPy可以连接外部服务、数据库、API接口等各类资源。

**MCP配置流程详解：**

1. 进入设置页面，选择"MCP"选项卡
2. 点击添加按钮进入配置界面
3. 输入MCP名称（示例：web_search）
4. 选择MCP类型（如标准输入/输出stdio）
5. 选择命令格式（如npx）
6. 输入MCP参数（如open-websearch@1.1.5）
7. 配置环境变量（可选）
8. 点击保存，等待加载完成

当页面显示"已完成"按钮时，代表MCP添加成功。此后智能体即可调用该MCP服务获取外部数据，实现联网搜索、数据库查询、第三方API调用等功能。

这种设计解决了企业AI应用的"最后一公里"问题。很多AI项目失败并非因为模型能力不足，而是无法与企业现有系统对接。AiPy通过MCP协议提供标准化集成方案，让AI能力真正融入业务流程。

## 四、企业级配置与自定义能力

AiPy企业版提供丰富的自定义配置选项，满足不同企业的个性化需求。这些配置存储在aipy-enterprise.yml文件中，用户可直接编辑或通过图形界面修改。

**可配置项包括：**

- **语言设置**：支持中文、English和日语三种语言切换
- **风格配置**：自定义AiPy回复的话术风格
- **发送快捷键**：选择Ctrl+Enter或Enter发送消息
- **工作目录**：指定任务生成文件的存储路径
- **最大执行轮数**：设置任务自动停止的回复轮数上限
- **超时时间**：配置与大模型交互的等待时长
- **自动选择智能体**：开启后系统自动判断所需智能体
- **一体机内网IP**：填写服务器内网IP用于更新和连接

此外，企业还可自定义logo、角色风格和推荐任务。在aipy-enterprise.yml文件中修改基础信息、主页logo和软件logo，让AiPy界面与企业文化保持一致。推荐任务可根据业务场景定制，新员工入职后看到的就是与其岗位相关的AI任务模板。

这种深度自定义能力是SaaS产品难以提供的。企业购买的是可完全掌控的AI基础设施，而非受限的云端服务，符合数据安全与合规要求。

## 五、典型应用场景与实践

AiPy已在多个企业场景中得到验证，以下是经过官方文档确认的使用场景：

**制作PPT**：勾选PPT生成智能体，输入提示词如"生成一个介绍中国新能源汽车发展的 PPT"，系统自动完成内容整理、排版设计和文件生成。

**图像与视频处理**：勾选图片生成/视频生成智能体，可实现批量图像生成、P图、视频创作等功能。提示词示例："批量生成10 张不同的肥猫切菜的照片"。

**代码开发辅助**：启用Claude code智能体，专为编程任务优化，支持代码生成、调试、重构等工作，显著提升开发效率。

**数据分析与研究**：量化研究智能体提供美股、港股、A股上市公司历史数据，基于AI分析协助股票信息研判（注意：为非实时数据）。

**知识问答**：创建知识库后，系统支持知识检索配置，可上传企业文档、产品手册、技术规范等资料，实现精准的企业知识问答。

每个场景都对应专门的智能体，用户只需勾选相应智能体即可激活对应能力。这种模块化设计避免了"万能模型"的性能妥协，确保每个任务都获得最优处理。

## 六、部署架构与安全考量

AiPy支持多种部署模式，企业可根据安全等级和IT基础设施选择合适的方案。

**公有云模型接入**：通过API接口连接主流大模型服务商，适合对数据敏感性要求不高的场景。配置时只需输入API地址和密钥，系统自动检测可用模型。

**私有化部署**：配合AiPy一体机硬件，模型部署在企业内网，数据不出域。适用于金融、医疗、政府等强监管行业。

**混合模式**：同时配置公有云和私有模型，根据任务类型自动路由。敏感数据处理使用私有模型，通用任务使用公有云以获得更好性价比。

在安全方面，AiPy提供超时时间控制和最大执行轮数限制，防止任务异常消耗资源。工作目录可自定义，便于集中管理和审计生成的文件。一体机内网IP配置确保更新和模型连接走内网通道，避免敏感信息泄露。

## 相关问答 FAQs

**AiPy 企业版支持哪些大语言模型？**
AiPy企业版支持通过API接口接入各类大语言模型，包括公有云模型和私有化部署模型。用户可在模型配置页面添加模型供应商信息，输入API地址和密钥后，系统自动检测可用模型并显示在下拉列表中。企业可同時配置多个模型，根据任务需求灵活选择。

**如何自定义 AiPy 的企业标识和界面风格？**
企业可通过编辑aipy-enterprise.yml配置文件来自定义标识和风格。配置文件位置为C:\Users\用户名\.aipyapp\aipy-enterprise.yml，在其中可修改基础信息、主页logo、软件logo、话术风格和推荐任务。修改后重启AiPy企业版即可生效，让界面与企业品牌形象保持一致。

**AiPy 智能体开发完成后如何部署使用？**
智能体开发完成后有两种部署方式：第一种是打开AiPy企业版，点击右侧"集市"按钮，上传打包好的智能体文件并点击安装，页面显示完成即代表成功；第二种是直接将智能体放入扩展目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。两种方式均可，推荐开发团队使用第二种方式便于版本管理。
