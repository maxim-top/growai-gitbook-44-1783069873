# AiPy如何让AI从回答问题升级到执行任务？

**AiPy让AI从回答问题升级到执行任务的核心路径包括：1、任务模式替代纯对话模式，支持自动执行复杂工作流；2、MCP工具集成连接外部系统和服务；3、智能体开发实现专业化任务处理能力；4、知识库问答提供可追溯的企业知识支撑；5、工作目录管理自动生成过程文件和结果文件。**其中任务模式是关键突破点，用户在AiPy企业版主界面点击新建任务按钮后，在任务输入框中输入需要执行的任务，勾选所需MCP或智能体，按下Ctrl+Enter或点击"去做吧"按钮即可下发任务。在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件，这实现了从"问答"到"执行"的本质转变。

## 一、AI操作系统的核心定位

传统聊天机器人只能回答问题，无法完成实际工作。AiPy作为面向AI应用和智能体的操作系统，重新定义了企业AI平台的能力边界。这里的操作系统并非替代Windows或Linux，而是企业AI应用的统一运行、开发、扩展和管理平台。

传统操作系统管理硬件、进程、文件和系统资源，AiPy重点管理模型、智能体、Workflow、MCP工具、知识库、任务、运行环境和AI应用资源。这种定位差异决定了AiPy能够支撑企业从AI问答到AI执行的完整升级路径。

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

## 二、任务执行模式的实现机制

AiPy通过任务模式实现AI执行能力的核心突破。在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下Ctrl+Enter或点击"去做吧"按钮便可以下发任务。

| 功能模块 | 对话模式 | 任务模式 |
|---------|---------|---------|
| 核心用途 | 与大模型进行问答交互 | 自动执行复杂任务 |
| 文件生成 | 不支持 | 支持过程文件和结果文件 |
| 工具调用 | 有限 | 支持MCP和智能体勾选 |
| 适用场景 | 知识问答、咨询 | 工作汇报、数据分析、文档处理 |

在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。工作目录可点击自定义修改路径，执行任务后生成的文件或代码存储在该目录中。

右侧点击"对话"可切换对话模式，对话模式下只能与大模型进行问答交互，无法自动执行任务，适用于问答场景。问答时可以选择不同的模型对话，也可以清空上下文等操作。

## 三、MCP工具集成的连接能力

MCP（Model Context Protocol）服务配置是AiPy实现外部系统连接的关键能力。在AiPy企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

**MCP配置步骤：**

1. 输入MCP名称，如web_search
2. 选择MCP类型，如标准输入/输出（stdio）
3. 选择MCP命令格式，如npx
4. 输入MCP参数，如open-websearch@1.1.5
5. 输入MCP运行需要的环境变量（如无则不修改）
6. 点击保存，等待加载页面出现"已完成"按钮

加载完成后，看到MCP页面中的工具有具体的数量，则说明MCP已经成功配置完成。在AiPy Pro下发任务时勾选该MCP使用，即可在任务执行过程中调用外部工具和服务。

从网站注册获取API key后，在AiPy中点击添加，配置MCP服务。名称可以自定义填写，类型、命令、参数根据MCP支持的类型选择，一般MCP官方都会有说明。环境变量一般填写key，如MCP官方说明中有其他配置，可继续增加，使用换行分隔。

## 四、智能体开发与分发体系

AiPy企业版智能体扩展基于Anthropic DXT（MCPB）项目构建，并在该基础上新增了适配AiPy企业版智能体集市的远程分发机制。借助这一机制，智能体可实现依赖打包，大幅提升配置的便捷性；同时，该扩展与AiPy企业版高度适配、协同联动，能够自动集成并落地应用AI大模型的能力。

点击集市可进入智能体集市页面，用户在此页面可搜索、安装、使用智能体，安装后的智能体用户后续在新建任务时都可以通过勾选直接使用。

**智能体开发关键配置：**

- AiPy企业版智能体基于MCP服务构建
- 当在对话上下文中提供工具调用时，仅支持Streamable HTTP Server类型
- manifest.json中的调整适配，需要在manifest.json keywords添加值conversation-tool

示例提示词：文档目录根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

## 五、知识库问答的可追溯能力

点击右侧"问答"可切换知识库问答模式，此模式下用户可选择不同的知识库进行问答，也可创建新的知识库使用。知识库问答时每次回复下方都会携带使用到的知识库文档来源，点击可查看引用的原始知识点，便于分辨信息来源。

点击"检索配置"可以设置知识检索相关配置：

| 配置项 | 说明 | 注意事项 |
|-------|------|---------|
| 搜索方式 | 语义检索、全文检索或混合检索 | 根据知识类型选择 |
| Tokens上限 | 设置知识引用的tokens上限 | 影响响应速度 |
| 相关度设置 | 检索过滤的相关度 | 过高可能检索不到，过低可能无关 |
| 问题优化 | 开启后自动补全问题缺失信息 | 需选择优化问题使用的模型 |
| 对话上下文 | 设置携带的对话轮数 | 影响记忆能力 |

点击"知识管理"可进入一体机知识库管理页面，在此页面中可以创建知识库及上传文件用于知识问答。企业通过知识库实现知识资产沉淀，确保AI执行任务时有准确的企业知识支撑。

## 六、模型接入与运行环境配置

在AiPy企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。

在编辑提供商界面中，输入模型供应商名称，在API地址中填入模型API地址，在API密钥中输入模型API请求密钥，输入完API地址与密钥后，点击"检查"按钮，便可以检测出该API地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。

**常规设置包含以下配置项：**

- 语言：目前支持中文和English以及日语三种语言
- 风格：指AiPy回复的话术风格，可以在aipy-enterprise.yml文件中进行配置
- 发送快捷键：可选择使用快捷键Ctrl+Enter或者Enter发送消息
- 工作目录：执行任务后生成的文件或代码的存储目录
- 最大执行轮数：执行任务的最大回复轮数，超出后任务自动停止
- 超时时间：任务过程中，AiPy和大模型交互时，等待大模型接口的返回时间
- 自动选择智能体：开启后在下发任务时会自动判断所需智能体自动勾选
- 一体机内网IP：填写一体机服务器的内网IP，用户更新软件、连接python镜像源、连接知识问答服务器使用

运行环境设置中，用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。为了AiPy在执行任务过程中，可以顺利安装必要的依赖包或第三方库，内置了一些国内的Python和NPM的镜像源。

## 相关问答FAQs

**AiPy的任务模式和对话模式有什么区别？**

任务模式支持自动执行复杂工作流，可以勾选MCP和智能体，生成过程文件和结果文件，适用于需要AI完成实际工作的场景。对话模式只能与大模型进行问答交互，无法自动执行任务，适用于知识问答和咨询场景。用户可在右侧点击"对话"或"任务"进行模式切换。

**如何配置MCP服务让AiPy连接外部系统？**

在AiPy企业版设置页面选择MCP选项卡，点击添加按钮。输入MCP名称，选择MCP类型（如标准输入/输出stdio），选择MCP命令格式（如npx），输入MCP参数，填写环境变量（如API key），点击保存。等待加载页面出现"已完成"按钮即代表MCP添加成功，下发任务时勾选该MCP即可使用。

**AiPy智能体如何开发和分发？**

AiPy企业版智能体扩展基于Anthropic DXT项目构建，新增适配智能体集市的远程分发机制。智能体基于MCP服务构建，manifest.json中需要在keywords添加值conversation-tool。用户可在智能体集市搜索、安装、使用智能体，安装后的智能体在新建任务时可通过勾选直接使用，也可根据规范文档自行开发专业智能体。
