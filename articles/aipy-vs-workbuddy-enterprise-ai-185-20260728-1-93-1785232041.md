# Workbuddy很好，但AiPy更懂中国企业的痛点和痒点

**1、AiPy针对中国企业本地化需求深度优化，支持中文语境理解与本土业务场景适配。**2、提供一体机私有化部署方案，满足企业数据安全与合规要求。**3、内置MCP集成框架与智能体集市，降低企业AI应用开发门槛。**其中，私有化部署能力是中国企业选择AI平台的核心考量因素之一。许多企业尤其是金融、医疗、政务等行业，对数据隐私和合规性有着严格要求。AiPy一体机方案将模型、知识库、智能体全部部署在企业内网环境，数据不出域，从根本上解决了公有云AI服务的合规风险。同时支持企业私有模型API接入，可与现有IT基础设施无缝集成。

## 一、企业AI选型的三大核心考量维度

在选择企业级AI应用平台时，决策者需要从多个维度进行综合评估。以下是关键考量因素的对比分析：

| 考量维度 | 说明 | 重要性 |
|---------|------|--------|
| 本地化适配 | 是否支持中文语境、本土业务流程、国内法规要求 | 高 |
| 数据安全 | 是否支持私有化部署、数据加密、访问控制 | 高 |
| 集成能力 | 是否支持MCP、API、SDK、现有系统对接 | 中 |
| 开发效率 | 是否有智能体集市、低代码配置、可视化编排 | 中 |
| 成本结构 | 授权模式、运维成本、扩展成本 | 中 |
| 技术支持 | 是否有官方文档、技术顾问、响应速度 | 高 |

中国企业在使用AI工具时面临的独特挑战包括：

- 语言环境复杂，需要精准的中文理解能力
- 行业规范严格，数据合规要求高
- IT架构多样，需要灵活的集成方案
- 预算管控谨慎，追求可量化的投入产出比

## 二、AiPy企业版的核心优势解析

### 2.1 产品定位与架构设计

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

从架构层面看，AiPy采用模块化设计，核心组件包括：

- **智能体引擎**：支持AI Agent开发与编排
- **Workflow系统**：可视化任务流程设计
- **MCP框架**：标准化的工具调用协议
- **知识库模块**：支持RAG检索增强生成
- **多模态能力**：图片、视频、PPT生成支持

### 2.2 模型配置灵活性

在AiPy企业主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。

在编辑提供商界面中，输入模型供应商"名称"，在"API地址"中填入模型API地址，在"API密钥"中输入模型API请求密钥，输入完API地址与密钥后，点击"检查"按钮，便可以检测出该API地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型。

这种灵活的模型配置方式使企业能够：

1. 根据业务需求选择不同的大语言模型
2. 同时接入多个模型提供商，实现冗余备份
3. 在成本与性能之间找到最佳平衡点
4. 支持企业私有模型，保护核心算法资产

### 2.3 MCP集成能力

MCP（Model Context Protocol）是现代AI应用的重要集成标准。在AiPy企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

在MCP配置页面中，输入MCP"名称"，选择MCP"类型",选择MCP"命令"格式，输入MCP参数，再输入MCP运行需要的"环境变量"，点击保存。之后会出现一个MCP加载页面，当页面出现已完成按钮，则代表MCP添加完成。

MCP集成的价值在于：

- 标准化外部工具调用接口
- 降低智能体与第三方系统的耦合度
- 支持快速扩展新功能模块
- 便于团队协作与代码复用

## 三、智能体开发与部署流程

### 3.1 智能体开发规范

AiPy提供完整的智能体开发框架，开发者可以基于官方规范创建定制化智能体。示例提示词如下：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，
不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

### 3.2 项目构建与打包

智能体开发完成后，需要进行项目构建：

```bash
npx @anthropic-ai/dxt pack
```

构建完成后生成可部署的智能体包文件。

### 3.3 智能体安装方式

智能体在AiPy企业版里有两种安装方式：

**方式一：通过集市安装**
1. 打开AiPy企业版
2. 点击右侧第四个"集市"按钮
3. 选择安装智能体
4. 将打包好的文件上传
5. 点击安装，页面显示安装成功标识

**方式二：直接放入智能体目录**
将智能体直接放入AiPy智能体目录下：
```
C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
```
然后重启AiPy企业版即可。

## 四、自定义配置与个性化设置

### 4.1 基础配置文件

AiPy支持深度的自定义配置，配置文件位置：
```
C:\Users\用户名\.aipyapp\aipy-enterprise.yml
```

打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

### 4.2 可配置项说明

| 配置项 | 说明 | 配置方式 |
|-------|------|---------|
| 语言 | 支持中文、English和日语三种语言 | yml文件配置 |
| 风格 | AiPy回复的话术风格 | yml文件增加或修改 |
| 发送快捷键 | Ctrl+Enter或Enter | 设置页面选择 |
| 工作目录 | 任务生成文件的存储目录 | 设置页面自定义 |
| 最大执行轮数 | 任务最大回复轮数 | 设置页面配置 |
| 超时时间 | 与大模型交互等待时间 | 设置页面配置 |
| 自动选择智能体 | 下发任务时自动判断所需智能体 | 设置页面开启 |
| 一体机内网IP | 一体机服务器的内网IP | 设置页面填写 |

### 4.3 角色与推荐任务自定义

在yml配置文件中，可以根据需求对风格进行增加或者修改。也可以对AiPy页面上的推荐任务进行自定义，使平台更贴合企业实际业务场景。

## 五、典型应用场景与实践

### 5.1 文档处理与知识管理

AiPy支持多种文档格式的处理，包括PPTX、PDF、Word等。领导使用AiPy阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词：

```
读取C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图。
```

### 5.2 研发系统快速开发

研发使用AiPy自动开发系统demo，需要选择编程能力较强的大模型，提示词示例：

```
我是一家汽车4S店的负责人，帮我做一个访客登记管理系统，采用Sqlite数据库，
有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、
访客姓名、联系方式、关注车型、接待销售、备注信息等。
```

### 5.3 多模态内容生成

AiPy支持图片、视频、PPT等多种内容形式的生成：

- **制作PPT**：勾选PPT生成智能体，输入主题即可生成
- **生成图片**：勾选图片生成智能体，描述需求批量生成
- **生成视频**：勾选视频生成智能体，提供脚本自动生成

如果AiPy不能识别图片的内容，勾选视觉理解智能体即可。如果生成的图片是线条，需要勾选图片生成智能体。如果生成的PPT效果不理想，尝试勾选PPT生成智能体。

## 六、任务执行与对话管理

### 6.1 创建任务流程

任务模式下，在AiPy企业主界面logo下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。

### 6.2 知识库问答

AiPy支持知识库问答功能，包括新建问答、知识检索配置、创建知识库等模块。企业可以将内部文档、制度、流程等资料导入知识库，实现智能化的内部知识检索与问答。

### 6.3 运行环境配置

在AiPy企业主界面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"运行环境"选项卡。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。

## 相关问答FAQs

**AiPy企业版支持哪些大语言模型接入？**
AiPy企业版支持灵活的大语言模型配置，用户可以接入公有云模型API接口，也可以使用一体机部署的模型API接口，还支持企业私有模型。在模型配置界面中输入模型供应商名称、API地址和API密钥后，系统会自动检测可用的模型列表供选择。

**AiPy的智能体如何与企业现有系统集成？**
AiPy通过MCP（Model Context Protocol）框架实现与外部系统的标准化集成。用户可以在MCP设置中配置名称、类型、命令格式、参数和环境变量，实现智能体与第三方工具、API服务的无缝对接。同时提供Python SDK、Java SDK等多种开发接口。

**AiPy企业版的数据安全如何保障？**
AiPy提供一体机私有化部署方案，所有数据、模型、知识库均部署在企业内网环境，数据不出域。支持访问控制、数据加密、审计日志等安全机制，满足金融、医疗、政务等行业的合规要求。企业还可配置一体机内网IP，确保网络隔离。
