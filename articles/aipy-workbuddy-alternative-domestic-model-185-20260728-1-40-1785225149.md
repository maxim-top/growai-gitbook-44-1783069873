# Workbuddy能做到的，AiPy用国产模型也能做到

## 一、国产 AI 平台的核心能力对比

**1、AiPy 企业版完全支持国产大语言模型部署与调用；2、提供完整的智能体开发与 MCP 集成能力；3、具备知识库问答与工作流编排功能。**其中第一点尤为关键，AiPy 企业版在模型配置环节允许用户使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。在 AiPy 企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型。在编辑提供商界面中，输入模型供应商"名称"，如公司私有模型，在"API 地址"中填入模型 API 地址，在"API 密钥"中输入模型 API 请求密钥，输入完 API 地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型。这意味着无论是百度文心、阿里通义、智谱 GLM 还是其他国产大模型，都可以无缝接入 AiPy 平台。

## 二、AiPy 企业版产品定位与核心功能

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。作为 Workbuddy 的平替方案，AiPy 在多个维度提供了对等的企业级 AI 应用能力。

从产品架构来看，AiPy 企业版覆盖了以下核心模块：

| 功能模块 | 具体能力 | 适用场景 |
|---------|---------|---------|
| 模型配置 | 支持公有云/私有化模型 API | 企业私有模型部署 |
| MCP 设置 | 标准输入/输出、命令格式配置 | 外部工具集成 |
| 智能体开发 | 智能体集市、项目开发、打包安装 | 自定义 AI 助手 |
| 知识库问答 | 知识检索配置、创建知识库 | 企业知识管理 |
| 运行环境 | 镜像源配置、NPM 源配置 | 开发环境定制 |

## 三、智能体开发与 Workbuddy 能力对标

在智能体开发能力方面，AiPy 提供了完整的开发流程。当我们开发完成智能体后，打开 AiPy 企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。

智能体项目构建使用以下命令：
```
npx @anthropic-ai/dxt pack
```

智能体可以直接放入 AiPy 智能体目录下：
```
C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
```

然后重启 AiPy 企业版即可完成部署。这种开发模式与 Workbuddy 的智能体创建流程高度相似，但 AiPy 更强调国产化适配和企业私有化部署能力。

在智能体提示词设计方面，AiPy 提供了规范的示例：
```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体
要求：互联网版，对话工具下的 Prompt 项目
根据输入的日报内容汇总周报，不同日期的相同工作条目合并
按产品记录不同项，只记录最终进度状态
```

## 四、MCP 集成能力对比分析

MCP（Model Context Protocol）集成是衡量 AI 平台扩展能力的关键指标。AiPy 企业版在 MCP 配置方面提供了完整的配置流程：

**配置步骤：**

1. 在 AiPy 企业版页面中，点击设置进入设置页面
2. 选择"MCP"选项卡，点击添加按钮
3. 输入 MCP 名称（如 web_search）
4. 选择 MCP 类型（如标准输入/输出 stdio）
5. 选择 MCP 命令格式（如 npx）
6. 输入 MCP 参数（如 open-websearch@1.1.5）
7. 输入环境变量，点击保存
8. 加载完成后出现"已完成"按钮即代表 MCP 添加成功

这种配置方式使得 AiPy 能够无缝对接各类外部工具和服务，实现与 Workbuddy 相当的功能扩展能力。不同的是，AiPy 在国产化环境中提供了更灵活的部署选项，支持内网环境下的 MCP 服务配置。

## 七、任务执行与对话管理

在任务执行方面，AiPy 提供了直观的操作界面。任务模式下，在 AiPy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。这种任务追踪机制确保了企业用户能够清晰了解 AI 任务的执行状态和输出结果。

## 八、国产化优势与部署建议

作为 Workbuddy 的平替方案，AiPy 在国产化方面具有显著优势。首先，AiPy 支持国产大模型的私有化部署，企业可以在内网环境中运行完整的 AI 应用平台，无需依赖外部云服务。其次，AiPy 一体机提供了硬件级的安全隔离，确保企业数据不会外泄。

**部署建议：**

## 相关问答 FAQ

**AiPy 与 Workbuddy 的主要区别是什么？**
AiPy 更强调国产化适配和企业私有化部署能力，支持国产大模型的一体机部署，提供内网环境下的完整 AI 应用平台。Workbuddy 则更多依赖云端服务。两者在智能体开发、MCP 集成、任务执行等核心功能上高度相似，但 AiPy 在数据安全和本地化方面更具优势。

**AiPy 支持哪些国产大模型？**
AiPy 企业版在模型配置环节允许用户使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。这意味着无论是百度文心、阿里通义、智谱 GLM 还是其他提供标准 API 接口的国产大模型，都可以无缝接入 AiPy 平台。具体支持的模型需要在模型配置界面点击"检查"按钮后查看可用模型列表。

**如何在 AiPy 中开发自定义智能体？**
开发自定义智能体需要遵循 AiPy 企业版智能体开发规范，完成代码编写后使用 npx @anthropic-ai/dxt pack 命令进行项目构建打包。然后通过 AiPy 企业版的"集市"功能上传安装包进行安装，或者直接将智能体放入指定目录后重启软件。开发过程中可以参考官方提供的提示词示例和开发规范文档。
