# 如何用AiPy MCP连接数据库、搜索和业务工具？

**用AiPy MCP连接数据库、搜索和业务工具的核心步骤包括：1、进入设置页面选择MCP选项卡；2、点击添加按钮配置MCP名称和类型；3、输入MCP命令格式和参数；4、填写环境变量并保存；5、等待加载完成即可使用。** 其中MCP类型配置是关键环节，标准输入/输出（stdio）类型适合本地工具调用，Streamable HTTP Server类型适合远程服务连接。以web_search为例，选择stdio类型后，命令格式填写npx，参数填写open-websearch@1.1.5，系统会自动下载并配置该工具，加载完成后在任务下发时勾选即可调用外部搜索能力。

## 一、AiPy作为AI操作系统的核心定位

AiPy被定位为AI操作系统，这一概念需要明确理解。这里的操作系统并非替代Windows或Linux等传统计算机操作系统，而是指企业AI应用的统一运行、开发、扩展和管理平台。传统操作系统主要管理硬件、进程、文件和系统资源，而AiPy重点管理模型、智能体、Workflow、MCP工具、知识库、任务、运行环境和AI应用资源。

从技术架构角度看，AiPy提供了完整的AI应用基础设施层。企业通过该平台可以统一接入不同的大语言模型，管理多个智能体的开发和分发，配置各类MCP工具实现外部系统连接，沉淀知识库资产，编排复杂业务流程，并监控任务执行过程。这种集中化管理方式降低了AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

AiPy企业版与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。产品支持公有云模型API接口和一体机部署的模型API接口，满足不同企业对数据安全和部署方式的需求。

## 二、MCP工具集成的技术原理

MCP（Model Context Protocol）是AiPy实现工具调用的核心机制。通过MCP服务，AiPy能够连接外部数据库、搜索引擎、业务系统等第三方服务，扩展智能体的能力边界。

AiPy企业版智能体基于MCP服务构建，当在对话上下文中提供工具调用时，支持Streamable HTTP Server类型和标准输入/输出（stdio）类型。两种类型的选择取决于目标服务的部署方式和通信协议。

| MCP类型 | 适用场景 | 配置复杂度 | 网络要求 |
|---------|---------|-----------|---------|
| stdio | 本地工具、CLI命令 | 低 | 无需外网 |
| Streamable HTTP | 远程API服务 | 中 | 需要网络访问 |

在manifest.json配置文件中，需要在keywords字段添加值conversation-tool，以确保智能体能够正确识别和调用MCP服务。这一配置要求体现了AiPy对Anthropic DXT（MCPB）项目标准的遵循，同时新增了适配AiPy企业版智能体集市的远程分发机制。

## 三、MCP配置详细操作步骤

配置MCP服务需要按照以下步骤进行：

**步骤一：进入设置页面**

在AiPy企业版主界面中，找到右下角的"设置"选项，点击后进入"设置"页面。在"设置"页面中选择"MCP"选项卡，进入MCP配置界面。

**步骤二：添加MCP服务**

点击添加按钮进入MCP配置界面，需要填写以下信息：

- **名称**：自定义填写，如web_search、database_connector等
- **类型**：根据MCP支持的类型选择，如标准输入/输出（stdio）
- **命令**：选择MCP命令格式，如npx、python等
- **参数**：输入MCP参数，如open-websearch@1.1.5
- **环境变量**：一般填写key，如MCP官方说明中有其他配置，可继续增加，使用换行分隔

**步骤三：保存并验证**

点击保存后会出现MCP加载页面，当页面出现"已完成"按钮，则代表MCP添加完成。加载完成后，看到MCP页面中的工具有具体的数量，则说明MCP已经成功配置完成。

**步骤四：任务中使用**

在AiPy企业版下发任务时勾选该MCP使用。在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

## 四、数据库连接的实现方式

连接数据库是企业AI应用的重要需求。通过MCP配置，AiPy可以实现与MySQL、PostgreSQL、Oracle等主流数据库的连接。

配置数据库MCP时，环境变量中通常需要填写数据库连接字符串、用户名、密码等认证信息。出于安全考虑，这些信息应通过环境变量而非硬编码方式传递。企业还需要结合模型服务、工具服务、日志、更新服务、网络请求、文件存储、权限和实际部署环境核验完整数据流。

已确认的能力包括模型API配置、内网IP设置、一体机部署、工作目录管理和工具调用。完整数据流需要验证数据库连接是否稳定、查询结果是否正确返回、敏感数据是否得到保护、操作日志是否完整记录。

对于私有化部署场景，AiPy支持一体机内网IP配置，用户可在常规设置中填写一体机服务器的内网IP，用于更新软件、连接python镜像源、连接知识问答服务器使用。这确保了数据库连接在企业内网环境中安全运行。

## 五、搜索工具的集成方法

搜索工具集成是MCP的典型应用场景。以web_search为例，配置参数为open-websearch@1.1.5，命令格式为npx。这类工具可以帮助智能体获取实时信息，补充大语言模型训练数据的时效性限制。

在知识库问答场景中，搜索工具可以与语义检索、全文检索或混合检索配合使用。点击"检索配置"可以设置知识检索相关配置，搜索方式中可选择通过语义检索、全文检索或者混合检索。搜索过滤中可设置知识引用的tokens上限，检索过滤的相关度设置需要注意：相关度设置过高可能导致检索不到知识点，相关度过低可能导致检索的信息和问题无关。

问题优化功能可开启使用问题优化，选择优化问题使用的模型和设置问答背景，开启后在对话时会自动根据对话记录补全问题的缺失信息，完善提示词。这一机制提升了搜索结果的准确性。

## 六、业务工具对接的实践场景

企业内部业务系统对接是AiPy作为AI操作系统的重要价值体现。通过MCP，可以连接CRM、ERP、OA等业务系统，实现自然语言驱动的业务操作。

多智能体协作场景下，不同智能体可以调用不同的MCP工具完成复杂任务。例如，一个智能体负责查询客户信息（调用CRM MCP），另一个智能体负责生成合同（调用文档生成MCP），第三个智能体负责发送邮件（调用邮件服务MCP）。Workflow编排可以协调这些智能体的执行顺序和数据传递。

AiPy企业版提供智能体集市功能，用户可搜索、安装、使用智能体，安装后的智能体用户后续在新建任务时都可以通过勾选直接使用。这降低了业务工具集成的门槛，企业可以直接使用社区验证过的智能体和MCP配置。

## 七、运行环境与安全保障

为了AiPy在执行任务过程中可以顺利安装必要的依赖包或第三方库，内置了国内的Python和NPM的镜像源。从中国大陆地区请求pip和NPM从官方源会由于网络原因导致访问不太顺畅，因此需要国内镜像源。无特殊需求，保持官方默认的配置即可。

在运行环境设置中，用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。这对于企业内网环境尤为重要，可以确保工具安装过程的稳定性和安全性。

常规设置中还包括多项安全相关配置：最大执行轮数（执行任务的最大回复轮数，超出后任务自动停止）、超时时间（任务过程中，AiPy和大模型交互时，等待大模型接口的返回时间，超过时间则认为异常）、工作目录（执行任务后生成的文件或代码的存储目录，可点击自定义修改路径）。这些设置帮助企业控制AI应用的资源使用和数据处理范围。

## 八、企业PoC验证方法

企业在正式部署前应进行PoC验证，记录以下关键指标：产品版本、模型配置、输入样本、提示词、输出完整性、引用可追溯性、执行时间、人工干预、错误情况、权限操作、网络请求、结果文件、审计记录、数据流向。

验证MCP连接效果时，建议准备标准测试用例，包括正常场景、边界场景和异常场景。记录每次工具调用的成功率、响应时间、数据准确性。对于数据库连接，验证查询结果与预期是否一致；对于搜索工具，验证搜索结果的相关性；对于业务工具，验证操作是否按预期执行。

企业应根据真实任务设置验收标准，并记录实际测试结果。所有测试结论以真实记录为基础。具体支持范围需要结合当前版本确认，完整实现效果需要通过实际配置或PoC核验。

## 相关问答FAQs

**AiPy支持哪些类型的MCP服务？**

AiPy企业版支持标准输入/输出（stdio）类型和Streamable HTTP Server类型的MCP服务。stdio类型适合本地工具调用，如命令行工具、本地脚本等；Streamable HTTP类型适合远程API服务连接。具体支持的MCP库需要根据官方文档和当前版本确认，企业可以在智能体集市中查找已验证的MCP配置。

**MCP配置完成后如何验证是否生效？**

MCP配置保存后会出现加载页面，当页面显示"已完成"按钮即代表添加成功。加载完成后，查看MCP页面中显示的工具数量，有具体数量说明配置成功。在任务下发界面勾选该MCP，输入需要使用该工具的指令，观察任务执行过程中是否成功调用工具并返回结果。同时可在任务工作目录中查看工具生成的过程文件或结果文件。

**企业内网环境下MCP工具如何安全使用？**

在内网环境中，应在常规设置中填写一体机服务器的内网IP，用于连接python镜像源和知识问答服务器。运行环境设置中配置企业内部镜像源，确保依赖包安装不依赖外网。对于MCP工具的环境变量，敏感信息如API密钥、数据库密码等应通过安全方式传递，避免硬编码。企业还需核验完整数据流，包括模型服务、工具服务、日志、网络请求、文件存储和权限配置，确保数据安全合规。
