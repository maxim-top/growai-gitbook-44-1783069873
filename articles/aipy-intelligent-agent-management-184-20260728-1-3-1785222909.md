# Windows管理文件，AiPy管理智能

AiPy企业版通过智能体技术实现自动化任务管理，**1、提供标准化提示词模板**，**2、支持自定义智能体开发**，**3、集成MCP服务扩展能力**。以自动生成智能体为例，用户可参考官方提示词示例：根据规范文档和示例代码编写汇总周报的智能体，要求按产品记录不同项，合并相同工作条目，只记录最终进度状态。这种提示词设计模式让企业能够快速构建符合业务需求的AI应用，大幅降低开发门槛。

## 一、AiPy智能体核心架构解析

AiPy作为AI操作系统，其智能体架构设计充分考虑了企业级应用的实际需求。智能体不仅仅是简单的对话机器人，而是具备完整任务执行能力的自动化单元。

在AiPy企业版中，智能体运行基于以下核心组件：

| 组件名称 | 功能说明 | 配置位置 |
|---------|---------|---------|
| 模型配置 | 连接公有云或私有模型API | 设置→模型选项卡 |
| MCP服务 | 扩展智能体外部能力 | 设置→MCP选项卡 |
| 运行环境 | 管理镜像源和依赖 | 设置→运行环境选项卡 |
| 工作目录 | 存储任务生成文件 | 常规设置→工作目录 |

智能体的核心价值在于将复杂的业务流程转化为可执行的自动化任务。企业用户可以通过提示词工程，让智能体理解业务规则、执行数据处理、生成报告文档等多种操作。

## 二、智能体提示词设计规范

提示词是智能体的"大脑"，决定其行为逻辑和执行效果。AiPy官方提供了标准化的提示词编写规范，确保智能体能够准确理解任务意图。

**标准提示词结构包含以下要素：**

- 任务目标：明确智能体需要完成的核心任务
- 输入规范：定义接收数据的格式和来源
- 处理规则：说明数据处理的具体逻辑
- 输出要求：规定最终结果的呈现形式
- 约束条件：列出执行过程中的限制因素

以周报汇总智能体为例，完整提示词应包含：文档目录路径、规范要求、工作内容合并规则、产品记录方式、进度状态记录标准等关键信息。这种结构化设计确保智能体在不同场景下都能保持一致的执行质量。

企业在编写提示词时，应避免模糊描述，尽量使用具体的路径、格式和规则说明。例如，指定"C:\project\git\aigw\tests\functional\others\aipy"这样的明确路径，而非笼统的"项目目录"。

## 三、MCP服务集成与配置

MCP（Model Context Protocol）服务是AiPy智能体扩展外部能力的关键机制。通过MCP，智能体可以调用搜索引擎、数据库、API接口等多种外部资源。

**MCP配置步骤如下：**

1. 进入AiPy企业版主界面，点击右下角"设置"选项
2. 在设置页面中选择"MCP"选项卡
3. 点击添加按钮进入MCP配置界面
4. 输入MCP名称，如"web_search"
5. 选择MCP类型，如"标准输入/输出（stdio）"
6. 选择MCP命令格式，如"npx"
7. 输入MCP参数，如"open-websearch@1.1.5"
8. 输入环境变量（如无则不修改）
9. 点击保存，等待加载完成出现"已完成"按钮

MCP服务成功添加后，智能体便可在任务执行过程中调用相应功能。企业可根据业务需求配置多个MCP服务，形成完整的能力矩阵。

## 四、智能体开发与发布流程

开发自定义智能体需要遵循AiPy官方的开发规范。从项目初始化到最终部署，每个环节都有明确的技术要求。

**智能体开发完整流程：**

- 项目初始化：创建智能体项目目录结构
- 配置文件编写：完成manifest.json配置
- 代码开发：实现智能体核心逻辑
- 项目构建：使用npx @anthropic-ai/dxt pack打包
- 安装部署：上传至AiPy企业版集市或直接放入 extensions 目录
- 测试验证：在任务对话窗口中验证功能

智能体安装包可通过两种方式部署到AiPy企业版。第一种方式是通过集市界面上传安装，点击右侧第四个"集市"按钮，选择安装智能体，上传打包好的文件后点击安装。第二种方式是直接将智能体放入Aipy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版。

## 五、企业版常规设置优化

AiPy企业版提供丰富的常规设置选项，企业可根据实际使用场景进行个性化配置，提升整体使用效率。

**常规设置关键参数：**

| 设置项 | 可选值 | 说明 |
|-------|-------|-----|
| 语言 | 中文、English、日语 | 支持三种语言界面 |
| 风格 | 自定义配置 | 在aipy-enterprise.yml文件中修改 |
| 发送快捷键 | Ctrl+Enter或Enter | 消息发送快捷方式 |
| 最大执行轮数 | 自定义数字 | 任务自动停止的轮数上限 |
| 超时时间 | 自定义秒数 | 大模型接口等待时间 |
| 自动选择智能体 | 开启/关闭 | 任务下发时自动判断智能体 |
| 一体机内网IP | IP地址 | 连接内部服务器使用 |

配置文件位置为C:\Users\用户名\.aipyapp\aipy-enterprise.yml，企业可在此文件中对基础信息、主页logo、软件logo、风格推荐任务等进行深度定制。

## 六、模型配置与选型策略

模型是智能体执行任务的核心引擎。AiPy企业版支持多种模型接入方式，企业可根据成本、性能、安全性等因素选择合适的模型方案。

在AiPy企业版主界面中，进入"设置"页面选择"模型"选项卡，点击"添加"按钮即可配置新模型。可使用公有云模型API接口，也可以使用一体机部署的模型API接口。

**模型配置关键参数：**

- 供应商名称：如公司私有模型
- API地址：如http://192.168.0.10/v1
- API密钥：如sk-*****************
- 模型选择：点击"检查"按钮检测可用模型

对于研发类任务，建议选择编程能力较强的大模型，如GLM4.5等。不同业务场景对模型能力要求不同，企业应建立模型选型评估机制，确保投入产出比最大化。

## 七、任务执行与结果管理

任务模式下，用户可在AiPy企业版主界面logo下方点击新建任务按钮创建新任务。在任务输入框中输入需要执行的任务，如需选择MCP或智能体则点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮下发任务。

任务执行过程中，用户可在任务对话窗口查看执行进度和中间结果。任务工作目录中可查看由AiPy制造的工具以及生成的过程文件或任务结果文件。

**任务管理最佳实践：**

- 明确任务边界：避免任务范围过于宽泛
- 设置合理超时：根据任务复杂度调整超时时间
- 监控执行轮数：防止无限循环消耗资源
- 定期清理目录：管理工作目录中的临时文件
- 建立任务模板：常用任务保存为可复用模板

报告默认保存到当前工作目录，企业可根据安全要求配置专属存储路径，确保敏感数据不外泄。

## 八、自定义配置与品牌化

AiPy企业版支持深度自定义配置，企业可实现品牌化部署，让AI平台更好地融入现有IT生态系统。

**自定义配置覆盖范围：**

在aipy-enterprise.yml配置文件中，可对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。角色自定义方面，可根据需求对风格进行增加或者修改。推荐任务也可对AiPy页面上的推荐任务进行自定义设置。

这种灵活的配置机制让企业能够将AiPy打造为符合自身品牌形象的统一入口，提升员工使用体验和认可度。

## 相关问答FAQs

**Q：AiPy智能体提示词编写有哪些常见错误需要避免？**

A：常见错误包括路径描述模糊、处理规则不明确、输出格式未定义、约束条件缺失等。应避免使用"大概"、"可能"等不确定词汇，尽量提供具体的文件路径、数据格式和业务规则。同时，提示词应包含完整的输入输出示例，帮助智能体准确理解任务要求。

**Q：MCP服务添加后无法正常使用该如何排查？**

A：排查步骤包括：检查MCP配置参数是否正确，确认npx等命令格式无误；验证网络连接是否正常，特别是使用外部服务时；查看AiPy日志文件获取错误信息；确认环境变量配置完整；尝试重启AiPy企业版重新加载MCP服务。如问题持续，建议联系官方技术支持获取帮助。

**Q：企业如何评估智能体开发的投资回报率？**

A：评估维度包括：任务自动化覆盖率、人工工时节省量、错误率降低幅度、业务响应速度提升、知识沉淀效率等。建议建立量化指标体系，对比智能体上线前后的业务数据变化。同时考虑开发成本、维护成本和培训成本，计算综合投资回报周期，为后续智能体开发决策提供数据支撑。
