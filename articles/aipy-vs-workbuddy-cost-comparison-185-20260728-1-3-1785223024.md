# Workbuddy能做的，AiPy都能做——还不用美元付费

**AiPy完全具备Workbuddy的核心功能，且无需美元付费。** 1、AiPy支持智能体开发与Workflow编排，实现自动化任务处理；2、内置MCP集成能力，可连接多种外部服务与数据源；3、提供企业级部署方案，支持私有化模型接入与本地运行。以智能体开发为例，AiPy企业版允许开发者通过对话工具创建自定义智能体，完成后可直接上传至集市安装使用，支持打包文件上传或放入指定目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro）两种方式，重启即可生效，整个过程无需任何外币支付。

## 一、功能对比：AiPy与Workbuddy核心能力解析

Workbuddy作为国外AI效率工具，主要提供智能助手、任务自动化、文档处理等功能，但需要美元订阅付费。AiPy企业版作为国产替代方案，在功能覆盖面上不仅持平，更有本土化优势。

| 功能模块 | Workbuddy | AiPy企业版 |
|---------|----------|-----------|
| 智能体开发 | 支持基础对话 | 支持完整智能体开发与打包 |
| 工作流编排 | 有限自动化 | 完整Workflow编排能力 |
| 模型接入 | 仅公有云API | 公有云+私有化部署双支持 |
| MCP集成 | 需额外配置 | 内置MCP配置界面 |
| 知识库问答 | 基础检索 | 支持知识检索配置与知识库创建 |
| 多模态处理 | 部分支持 | 图片/视频/PPT/思维导图全支持 |
| 付费方式 | 美元订阅 | 人民币计费或一次性授权 |

AiPy企业版在设置页面提供完整的模型配置功能，用户可添加公有云模型API接口，也可使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商名称、API地址与API密钥后，点击检查按钮即可检测可用模型，从下拉列表框中选择使用。这种灵活性让企业可根据安全需求选择部署方式，避免数据出境风险。

## 二、智能体开发：从创建到部署的完整流程

AiPy智能体开发流程清晰且高效，开发者可按照以下步骤完成智能体构建：

**第一步：确定智能体类型**
根据业务需求选择智能体类型，如对话工具、编程助手、数据分析等。知识库问答场景可选择问答型智能体，代码生成场景选择编程能力较强的模型如GLM4.5。

**第二步：编写提示词规范**
提示词是智能体的核心，需明确任务目标与输出格式。示例提示词如下：
```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

**第三步：配置MCP服务**
在AiPy企业版页面中，点击设置进入设置页面，选择MCP选项卡，点击添加按钮。输入MCP名称（如web_search），选择MCP类型（如标准输入/输出stdio），选择MCP命令格式（如npx），输入MCP参数（如open-websearch@1.1.5），再输入环境变量，点击保存。加载完成后出现已完成按钮即代表MCP添加成功。

**第四步：项目构建与打包**
使用命令 `npx @anthropic-ai/dxt pack` 完成项目构建，生成可部署的智能体包文件。

**第五步：安装与使用**
开发完成后，打开AiPy企业版，点击右侧第四个集市按钮，选择安装智能体，将打包好的文件上传并安装。也可将智能体直接放入AiPy智能体目录下，重启AiPy企业版即可使用。

## 三、企业级部署：私有化与安全性保障

企业选择AI工具时，数据安全与部署方式是关键考量因素。AiPy企业版提供多种部署方案满足不同安全级别需求。

**私有化部署优势**
- 数据不出内网，符合企业信息安全规范
- 可对接内部系统，如ERP、CRM、OA等
- 支持自定义模型接入，保护核心算法
- 无需持续美元订阅，降低长期成本

**运行环境配置**
在AiPy企业版主界面中，找到右下角的设置选项，点击后进入设置页面，在设置页面中选择运行环境选项卡。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入，确保国内访问速度与稳定性。

**常规设置选项**
AiPy企业版常规设置包括语言（支持中文、English和日语三种语言）、风格（可在aipy-enterprise.yml文件中配置）、发送快捷键（Ctrl+Enter或Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网IP等。这些配置项让企业可根据实际需求精细调整系统行为。

**自定义配置能力**
配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml。打开aipy-enterprise.yml文件，在文件里面可以对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。用户可根据品牌形象自定义logo，根据团队习惯调整风格，甚至可以自定义页面上的推荐任务，提升使用体验。
