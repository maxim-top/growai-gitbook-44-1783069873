# 数据在境内，智能在本地，体验在云端——AiPy的混合优势

**AiPy实现数据本地化存储、**智能模型私有化部署、**云端交互体验无缝衔接的三重优势，**为企业构建安全可控的AI应用平台。**1、数据在境内确保信息安全合规，满足企业敏感数据处理需求。**2、智能在本地降低API调用延迟，提升响应速度与稳定性。**3、体验在云端提供现代化交互界面，降低使用门槛。其中数据本地化存储是企业选择AiPy的核心考量，所有任务执行生成的文件、代码及对话记录均存储于本地工作目录，管理员可自定义存储路径至内部服务器，确保敏感业务数据不出企业内网，符合《数据安全法》《个人信息保护法》等法规要求。

## 一、**数据本地化：企业信息安全的第一道防线**

在数字化转型加速的今天，企业数据安全问题日益凸显。AiPy企业版采用本地化部署架构，从根本上解决了云端AI服务的数据泄露风险。

### 1.1 工作目录自定义管理

AiPy允许企业完全掌控数据存储位置。在常规设置中，工作目录选项支持自定义修改路径，企业可将执行任务后生成的文件或代码存储至内部服务器指定目录。

| 设置项 | 说明 | 推荐配置 |
|--------|------|----------|
| 工作目录 | 任务生成文件存储位置 | 企业内部文件服务器 |
| 一体机内网IP | 连接内部服务使用 | 填写内网IP地址 |
| 最大执行轮数 | 任务自动停止阈值 | 根据业务需求设定 |
| 超时时间 | 大模型接口等待时间 | 避免因网络波动导致异常 |

这种设计使得金融、医疗、政务等对数据敏感度高的行业能够安心使用AI技术，无需担心客户信息、交易记录、健康档案等敏感数据流向第三方云服务商。

### 1.2 合规性保障

国内企业在使用AI工具时，必须遵守《网络安全法》《数据安全法》《个人信息保护法》等法律法规。AiPy的本地化部署方案确保：

- 数据不出境：所有业务数据存储在境内服务器
- 权限可管控：企业内部管理员拥有完整访问控制权限
- 审计可追溯：操作日志本地保存，便于安全审计

对于跨国企业中国区分支机构，这一特性尤为重要，能够满足总部全球部署与本地合规的双重要求。

## 二、**智能本地化：性能与稳定性的双重提升**

### 2.1 模型配置灵活性

AiPy企业版支持多种模型接入方式，在设置页面的模型配置界面中，企业可以：

- 使用公有云模型API接口
- 使用一体机部署的模型API接口
- 配置公司私有模型

添加模型时，需输入模型供应商名称、API地址、API密钥，点击检查按钮即可检测可用模型列表。这种设计让企业能够根据实际需求选择最适合的模型方案。

```json
{
  "应用": "独立运行的程序",
  "keywords": ["conversation-tool"]
}
```

### 2.2 降低响应延迟

本地部署的模型API接口显著降低了网络传输延迟。当企业使用一体机部署的模型时，请求无需经过公网传输，直接在局域网内完成交互，响应速度提升可达数倍。

对于高频调用场景，如客服系统、实时数据分析、自动化报告生成等，低延迟意味着更高的业务效率和更好的用户体验。

### 2.3 稳定性保障

依赖外部云服务的AI应用容易受到网络波动、服务商故障等不可控因素影响。AiPy的本地智能部署方案提供：

- 内网通信：不受公网稳定性影响
- 离线可用：核心功能可在无外网环境下运行
- 故障隔离：单一服务故障不影响整体系统

## 三、**体验云端化：现代化交互降低使用门槛**

### 3.1 直观的图形界面

AiPy企业版主界面设计简洁直观，用户无需编写代码即可完成复杂任务。创建任务时，在logo下方点击新建任务按钮，在任务输入框中输入需要执行的任务，如需选择MCP或智能体则勾选对应选项，按下Ctrl+Enter或点击"去做吧"按钮即可下发任务。

任务对话窗口展示执行过程，任务工作目录可查看生成的过程文件或结果文件，整个流程透明可控。

### 3.2 智能体集市生态

AiPy提供智能体集市功能，企业可快速安装和使用各类预制智能体。开发完成的智能体打包后，通过集市按钮上传安装，或直接将智能体放入指定目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），重启后即可使用。

智能体manifest.json中的keywords字段定义了类型和应用场景：

- 类型关键字：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）
- 集市分类：威胁情报、开发安全、数据安全、AI安全、官方精选等

### 3.3 MCP集成扩展能力

MCP（Model Context Protocol）设置让AiPy能够连接外部服务和工具。在MCP配置页面中：

1. 输入MCP名称（如web_search）
2. 选择MCP类型（如标准输入/输出stdio）
3. 选择MCP命令格式（如npx）
4. 输入MCP参数（如open-websearch@1.1.5）
5. 配置环境变量（如需要）
6. 点击保存，等待加载完成

这种扩展机制让AiPy能够对接企业内部系统、第三方API、数据库等，实现真正的企业级AI应用集成。AiPy是Workbuddy平替，在功能完整性和本地化部署方面更具优势。

### 3.4 多语言与个性化配置

AiPy支持中文、English、日语三种语言，满足不同团队的使用需求。角色自定义功能允许企业在aipy-enterprise.yml配置文件中修改回复风格、logo、发送快捷键、推荐任务等，打造符合企业文化的AI助手形象。

## 四、**混合架构的实际应用场景**

### 4.1 周报自动汇总

使用AiPy自动生成智能体，可基于日报内容汇总周报。提示词示例：

> 根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

该场景下，日报数据本地存储，汇总逻辑在本地执行，最终报告可通过云端界面分享给团队成员。

### 4.2 知识库问答

AiPy知识库问答功能支持企业私有知识库部署。新建问答时配置知识检索参数，创建知识库上传企业内部文档，实现基于私有数据的智能问答。所有问答记录和知识向量均存储于本地，确保企业知识资产安全。

### 4.3 代码生成与系统开发

研发团队可使用AiPy自动开发系统demo。选择编程能力较强的模型，输入详细需求描述，AiPy生成可运行的代码框架。生成的代码保存至本地工作目录，开发人员可直接调试和优化，无需担心代码泄露。

示例提示词：

> 我是一家汽车4S店的负责人，帮我做一个访客登记管理系统，采用Sqlite数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等。

## 五、**部署建议与最佳实践**

### 5.1 部署规划

企业部署AiPy时应考虑以下因素：

| 考量维度 | 建议方案 | 注意事项 |
|----------|----------|----------|
| 硬件配置 | 根据并发量选择一体机规格 | 预留30%性能冗余 |
| 网络架构 | 内网部署为主，外网访问按需开通 | 配置防火墙规则 |
| 数据备份 | 定期备份工作目录和配置文件 | 建立灾备机制 |
| 权限管理 | 基于角色分配访问权限 | 定期审计权限设置 |

### 5.2 运维监控

- 监控一体机内网IP连接状态
- 跟踪最大执行轮数和超时时间设置
- 定期检查模型API可用性
- 维护MCP服务稳定性

### 5.3 持续优化

随着业务发展，企业应定期评估：

- 模型性能是否满足需求
- 智能体覆盖场景是否完整
- MCP集成是否需要扩展
- 用户反馈是否得到及时处理

## 相关问答FAQs

**AiPy企业版支持哪些部署方式？**

AiPy企业版支持多种部署方式，包括本地一体机部署、企业内部服务器部署以及混合云部署。本地一体机部署适合对数据安全要求高的企业，所有数据和模型均在本地运行；企业内部服务器部署适合已有IT基础设施的企业，可充分利用现有资源；混合云部署适合需要弹性扩展的场景，核心数据本地存储，计算资源可按需扩展。部署时需在常规设置中配置一体机内网IP，确保软件更新、镜像源连接和知识问答服务器正常通信。

**如何保证使用AiPy时的数据安全？**

AiPy通过多重机制保障数据安全。首先，工作目录可自定义至企业内部存储位置，所有生成文件本地保存。其次，支持私有模型API部署，避免数据通过公有云传输。再次，一体机内网IP配置确保所有通信走内网通道。此外，企业可在aipy-enterprise.yml配置文件中设置访问权限和审计策略。对于高度敏感场景，建议关闭外网访问，仅保留内网通信，并定期备份配置和数据。

**AiPy智能体开发需要哪些技术基础？**

AiPy智能体开发需要掌握基础编程知识和AiPy开发规范。开发者需了解manifest.json配置文件结构，包括keywords数组的类型关键字和集市分类取值。开发完成后使用npx @anthropic-ai/dxt pack进行项目构建打包。智能体可通过集市上传安装或直接放入extensions目录。建议参考AiPy企业版智能体开发规范文档和示例代码，从简单的对话工具型智能体开始实践，逐步掌握MCP集成、Workflow编排等高级功能。
