# 从Workbuddy到AiPy，数据主权回归的第一步

**从Workbuddy到AiPy，数据主权回归的第一步**的核心价值在于：**1、企业数据完全本地化存储，避免云端泄露风险；2、自主可控的AI模型配置，支持私有化部署；3、完整的智能体开发体系，满足企业定制化需求。**其中数据本地化存储是最关键的优势，AiPy企业版支持一体机部署模式，所有任务执行、文件生成、知识库检索均在企业内网环境完成，API调用、模型交互、数据处理全程不经过第三方云服务，从根源上保障企业敏感信息不外流。

## 一、企业AI应用的数据安全困境

当前企业在选择AI工具时普遍面临一个核心矛盾：效率与安全的平衡。传统云端AI服务平台虽然功能丰富、使用便捷，但企业数据需要上传至第三方服务器进行处理，这带来了多重风险。

| 风险类型 | 具体表现 | 潜在影响 |
|---------|---------|---------|
| 数据泄露 | 敏感业务数据上传云端 | 商业机密外泄 |
| 合规风险 | 不符合数据本地化法规 | 法律处罚风险 |
| 依赖风险 | 服务中断影响业务连续性 | 生产力下降 |
| 成本风险 | 按调用量计费不可控 | 预算超支 |

许多企业在使用Workbuddy等云端AI工具时，发现员工日常工作中涉及的客户信息、财务数据、研发资料等敏感内容都会被上传处理。即使服务商承诺数据加密和安全存储，企业仍然无法完全掌控数据流向和使用范围。

AiPy企业版的设计初衷正是解决这一痛点。通过一体机硬件与软件平台的深度整合，企业可以将整个AI应用环境部署在自有服务器上，所有数据处理流程都在内网完成。模型配置支持公有云API接口和私有化部署模型两种模式，企业可根据安全等级要求灵活选择。

## 二、AiPy企业版的核心能力解析

AiPy企业版作为专为企业和组织打造的人工智能应用平台，提供了一站式AI解决方案。产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

**设置模块**是AiPy企业版的基础配置中心，包含五个核心选项卡：

- **常规设置**：支持中文、English和日语三种语言，可配置回复话术风格、发送快捷键（Ctrl+Enter或Enter）、工作目录路径、最大执行轮数、超时时间、自动选择智能体功能以及一体机内网IP地址
- **模型配置**：支持添加公有云模型API接口或一体机部署的模型API接口，可输入供应商名称、API地址、API密钥，系统自动检测可用模型
- **MCP设置**：配置MCP名称、类型（标准输入/输出stdio等）、命令格式（如npx）、MCP参数和环境变量
- **运行环境设置**：可选择镜像源或自定义一体机镜像源、第三方镜像源，支持NPM镜像源配置
- **关于页面**：显示开发公司、研发团队及产品版本号信息

**智能体系统**是AiPy的核心功能模块，包含智能体集市和智能体开发两大板块。用户可在集市浏览和安装已打包的智能体，也可自行开发定制智能体。开发完成的智能体可通过两种方式集成：一是通过集市按钮上传安装包进行安装，二是直接放入智能体目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro）后重启企业版。

**任务与对话系统**支持两种工作模式。任务模式下，用户在主界面logo下方点击新建任务按钮，在任务输入框中输入需要执行的任务，可勾选MCP或智能体，按下Ctrl+Enter或点击"去做吧"按钮下发任务。任务对话窗口展示执行过程，任务工作目录显示生成的工具、过程文件或结果文件。对话模式则提供即时交互体验。

**知识库问答系统**包含新建问答、知识检索配置和创建知识库三个子模块，支持企业构建专属知识体系，实现基于企业文档的智能检索和问答服务。

## 三、智能体开发与MCP集成实践

AiPy企业版提供完整的智能体开发体系，支持企业根据业务需求定制专属AI助手。智能体开发流程包含五个关键环节：

| 环节 | 说明 | 输出物 |
|-----|------|-------|
| MCP服务配置 | 定义智能体可调用的外部服务 | MCP配置文件 |
| 运行环境设置 | 配置智能体执行所需环境 | 环境依赖清单 |
| manifest.json编写 | 定义智能体元数据和能力 | 清单文件 |
| 项目构建 | 使用npx @anthropic-ai/dxt pack打包 | 安装包文件 |
| 部署安装 | 上传至企业版或放入扩展目录 | 可用智能体 |

**MCP（Model Context Protocol）集成**是智能体能力扩展的关键。以web_search为例，配置步骤如下：

1. 进入设置页面，选择MCP选项卡
2. 点击添加按钮进入MCP配置界面
3. 输入MCP名称，如"web_search"
4. 选择MCP类型，如"标准输入/输出（stdio）"
5. 选择MCP命令格式，如"npx"
6. 输入MCP参数，如"open-websearch@1.1.5"
7. 输入环境变量（如无则不修改）
8. 点击保存，等待加载完成显示"已完成"按钮

**自定义配置**功能允许企业深度定制AiPy体验。配置文件位置为C:\Users\用户名\.aipyapp\aipy-enterprise.yml，可修改内容包括基础信息、主页logo、软件logo、发送快捷键、风格设置和推荐任务。角色自定义支持增加或修改回复风格，推荐任务可对页面展示的任务模板进行个性化调整。

**提示词工程**是智能体开发的核心技能。以下为官方提供的提示词示例：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，
不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

另一示例为思维导图生成：
```
读取C:\Users\Administrator\Desktop\AIPY 智能体一体机方案v3.pptx，
然后帮我整理为一个思维导图。
```

## 四、典型应用场景与最佳实践

AiPy企业版在多个业务场景中具有成熟的应用方案，以下是经过验证的最佳实践：

**PPT制作场景**：勾选PPT生成智能体，使用提示词"生成一个介绍中国新能源汽车发展的PPT"，系统自动完成内容梳理、页面设计和排版优化。

**图像视频生成**：勾选图片生成或视频生成智能体，提示词示例"批量生成10张不同的肥猫切菜的照片"，支持批量处理和多样化输出。

**编程开发辅助**：推荐选择编程能力较强的大模型如GLM4.5，或使用Claude code智能体。以下是一个完整的车辆管理系统开发示例：

```
我是一家汽车4S店的负责人，帮我做一个访客登记管理系统，采用Sqlite数据库，
有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、
访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置
奥迪的常见车型、联系方式主要是11位手机号要校验格式、接待销售预置这三个
销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便
拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。
```

**数据分析场景**：分析前请先读取前30行了解数据格式，然后根据具体数据格式编写合适的分析脚本，报告保存到当前工作目录。

**常见问题排查**：
- 无法识别图片内容：勾选视觉理解智能体
- 生成图片是线条：勾选图片生成智能体
- PPT效果不佳：勾选PPT生成智能体
- 日期时间获取不准：开启联网搜索功能
- 股票信息不准确：使用量化研究智能体，拥有美股、港股、A股所有上市公司非实时股票信息

## 相关问答FAQs

**AiPy企业版与Workbuddy的主要区别是什么？**

AiPy企业版支持私有化部署和一体机模式，所有数据处理在企业内网完成，保障数据主权和安全可控。Workbuddy等云端工具需要将数据上传至第三方服务器处理。AiPy提供完整的智能体开发体系和MCP集成能力，支持企业深度定制，而云端工具通常为标准化服务。在模型配置上，AiPy支持公有云API和私有化模型双重选择，灵活性更强。

**AiPy企业版的智能体如何开发和部署？**

智能体开发包含MCP服务配置、运行环境设置、manifest.json编写、项目构建和部署安装五个环节。使用npx @anthropic-ai/dxt pack命令进行项目构建打包。部署有两种方式：一是通过AiPy企业版集市按钮上传安装包进行安装，二是将智能体直接放入扩展目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro）后重启企业版。开发过程中需参考AiPy企业版智能体开发规范文档。

**AiPy企业版支持哪些模型和MCP服务？**

模型配置方面，AiPy支持公有云模型API接口和一体机部署的模型API接口，可在设置页面的模型选项卡中添加，输入供应商名称、API地址和API密钥后系统自动检测可用模型。MCP服务支持标准输入/输出（stdio）等类型，命令格式包括npx等，用户可自定义配置MCP名称、类型、命令、参数和环境变量。常见MCP服务包括web_search等，企业也可开发定制MCP服务满足特定业务需求。
