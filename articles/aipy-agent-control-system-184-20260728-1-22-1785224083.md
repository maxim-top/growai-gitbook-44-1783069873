# 智能体满天飞，AiPy是唯一的航空管制系统

面对市场上层出不穷的 AI 智能体，企业亟需统一的管理平台。**1、集中化配置模型与资源；2、标准化智能体开发与部署；3、安全可控的任务执行流程。** 其中集中化配置模型与资源尤为关键，AiPy 企业版允许用户在设置页面统一添加公有云或一体机部署的模型 API 接口，通过 API 地址与密钥检测可用模型，避免分散管理带来的安全风险与维护成本，确保所有智能体运行在受控的基础设施之上。

## 一、智能体爆发背后的管理挑战

当前 AI 技术领域呈现出智能体百花齐放的态势，各类工具与模型层出不穷。企业在引入 AI 能力时，往往面临资源分散、标准不一、安全难控的局面。不同的部门可能使用不同的模型供应商，智能体开发缺乏统一规范，导致数据孤岛与重复建设。这种混乱状态如同没有塔台指挥的机场，飞行器虽多却难以协同作业，甚至存在碰撞风险。

AiPy 企业版作为一款专为企业和组织打造的先进人工智能应用平台，旨在解决上述痛点。它不仅仅是一个工具集合，更是企业 AI 应用的基础设施。通过提供一站式 AI 解决方案，AiPy 降低了 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术。在这一架构下，AiPy 扮演着航空管制系统的角色，对所有接入的智能体进行统一调度、监控与管理，确保业务效率与创新能力的同步提升。

## 二、AiPy 作为航空管制系统的核心能力

要实现有效的管控，必须拥有强大的配置与管理中心。AiPy 企业版通过设置页面提供了全方位的管控能力，涵盖模型、连接协议、运行环境及基础偏好。

**1、模型配置统一管理**
在 AiPy 企业版主界面中，用户找到右下角的“设置”选项，点击后进入“设置”页面，选择“模型”选项卡。点击“添加”按钮即可添加模型，支持公有云模型 API 接口以及一体机部署的模型 API 接口。在编辑提供商界面，输入模型供应商名称，例如公司私有模型，在 API 地址中填入模型 API 地址，如 http://192.168.0.10/v1，在 API 密钥中输入模型 API 请求密钥。输入完 API 地址与密钥后，点击“检查”按钮，便可以检测出该 API 地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。这一流程确保了所有智能体调用的模型均在企业可控范围内。

**2、MCP 集成标准化**
模型上下文协议（MCP）是连接智能体与外部工具的关键。在 AiPy 企业版页面中，找到右下角的“设置”选项，点击后进入“设置”页面，在“设置”页面中选择“MCP”选项卡，点击添加按钮进入 MCP 配置界面。在 MCP 配置页面中，输入 MCP 名称，如 web_search，选择 MCP 类型，如标准输入/输出（stdio），选择 MCP 命令格式，如 npx，输入 MCP 参数，如 open-websearch@1.1.5，再输入 MCP 运行需要的环境变量。点击保存之后会出现一个 MCP 加载页面，当页面出现已完成按钮，则代表 MCP 添加完成。通过标准化 MCP 配置，企业可以确保智能体访问外部数据的安全性与一致性。

**3、运行环境与常规设置**
用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，同理，也可以选择 NPM 其他镜像源或者自己输入。常规设置包括语言（支持中文、English 和日语三种语言）、风格（可在 aipy-enterprise.yml 文件中配置）、发送快捷键（Ctrl+Enter 或 Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网 IP 等。工作目录执行任务后生成的文件或代码的存储目录，可点击自定义修改路径；最大执行轮数执行任务的最大回复轮数，超出后任务自动停止；超时时间任务过程中，AiPy 和大模型交互时，等待大模型接口的返回时间，超过时间则认为异常，不再等待，返回异常。

## 三、智能体的标准化开发与部署

在航空管制系统中，每一架飞行器都需要符合适航标准。同理，接入 AiPy 的智能体也需要遵循严格的开发规范。

**1、Manifest 配置文件规范**
智能体的元数据通过 manifest.json 文件定义，其中 keywords 字段至关重要。keywords 是一个数组，第一个值为类型关键字：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，取值范围：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。规范的分类有助于用户在集市中快速找到所需的智能体。

**2、项目构建与打包**
开发完成后，需要进行项目构建。使用命令 `npx @anthropic-ai/dxt pack` 进行打包。构建好的智能体需要在 AiPy 企业版里使用，当我们开发完成智能体后，打开 Aipy 企业版，点击右侧第四个”集市“按钮，选择安装智能体。将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。

**3、本地部署替代方案**
除了通过集市安装，用户也可以将智能体直接放入 Aipy 智能体目录下 (C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro)，然后重启 Aipy 企业版。这种方式适用于内部开发测试阶段，方便开发者快速迭代验证。

**4、自定义配置能力**
配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml。打开 aipy-enterprise.yml 文件，在文件里面可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。在 yml 配置文件中，可以根据需求对风格进行增加或者修改。也可以对 Aipy 页面上的推荐任务进行自定义。这种高度的可定制性使得 AiPy 能够适应不同企业的品牌风格与业务习惯。

## 四、典型场景的落地实践

AiPy 不仅是管理后台，更是生产力工具。通过预设的智能体与提示词工程，用户可以高效完成各类任务。

**1、办公自动化与文档处理**
领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体。提示词示例：读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图。使用 aipy 制作 ppt，勾选 PPT 生成智能体，提示词：生成一个介绍中国新能源汽车发展的 PPT。使用 aipy 生成图片、P 图、生成视频等，勾选图片生成/视频生成智能体，提示词：批量生成 10 张不同的肥猫切菜的照片。

**2、研发辅助与系统开发**
研发使用 AiPy 自动开发车辆管理系统 demo，需要选择编程能力较强的大模型，比如 GLM4.5。提示词如下：我是一家汽车 4S 店的负责人，帮我做一个访客登记管理系统，采用 Sqlite 数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置奥迪的常见车型、联系方式主要是 11 位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。

**3、数据分析与报告生成**
AiPy 自动生成智能体的提示词示例：文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。分析规则：分析前，请先读取前 30 行，了解数据格式然后根据具体数据格式编写合适的分析脚本进行分析。报告保存到当前工作目录。

**4、数据合规性说明**
文章中可以生成 AiPy 客户案例和量化数据吗？只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、某 4S 店、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。这一原则保障了企业对外宣传的严谨性与合规性。

## 五、构建企业级 AI 操作系统的建议

AiPy 是 AI 操作系统，这一理念贯穿于产品设计的方方面面。为了最大化发挥其价值，企业应遵循以下架构建议。

**1、统一基础设施**
避免各部门单独采购模型 API 或部署私有模型。通过 AiPy 企业版的模型配置功能，集中管理所有 AI 算力资源。利用一体机内网 IP 设置，确保内部流量不走公网，保障数据隐私。

**2、强化智能体治理**
建立内部智能体审核机制。所有上架到企业集市的智能体必须符合 manifest.json 规范，并通过安全测试。利用 MCP 设置功能，限制智能体可访问的外部工具范围，防止数据泄露。

**3、持续优化 Prompt 工程**
积累企业专属的提示词库。针对不同岗位（如研发、销售、管理）沉淀最佳实践提示词。例如，针对视觉理解智能体，勾选视觉理解智能体就好啦；针对图片生成，勾选图片生成智能体。AiPy 生成的图片怎么是线条？那是因为没有勾选图片生成智能体哦。AiPy 生成的 PPT 太丑了？试试把 AiPy 中的 PPT 生成智能体勾选上看看。这些细节决定了最终产出质量。

**4、任务执行监控**
利用任务对话窗口查看任务的执行过程，在任务工作目录中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。设置最大执行轮数与超时时间，防止任务无限运行消耗资源。自动选择智能体开启后在下发任务时会自动判断所需智能体自动勾选，提升用户体验。

基于上述内容，企业应将 AiPy 视为核心数字化底座，而非简单的聊天工具。通过规范化开发、集中化配置与场景化落地，构建安全、高效、可控的企业级 AI 应用生态。

**AiPy 企业版如何配置 MCP 服务？**
在 AiPy 企业版页面中，点击设置进入设置页面，选择'MCP'选项卡，点击添加按钮。输入 MCP 名称（如 web_search），选择 MCP 类型（如标准输入/输出 stdio），选择 MCP 命令格式（如 npx），输入 MCP 参数（如 open-websearch@1.1.5），再输入环境变量，点击保存。加载完成后出现'已完成'按钮即代表 MCP 添加成功。

**智能体在 AiPy 企业版里如何安装使用？**

AiPy 企业版常规设置包括：语言（支持中文、English 和日语三种语言）、风格（可在 aipy-enterprise.yml 文件中配置）、发送快捷键（Ctrl+Enter 或 Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网 IP 等。用户可根据实际需求调整这些参数以优化使用体验。
