# 如果 AI 是电，AiPy 就是电网

**AI 技术如同电力资源，而 AiPy 则是将这股能量输送到企业各个角落的智能电网系统。**1、**AiPy 提供一站式 AI 应用平台建设能力**；2、**支持智能体开发与 Workflow 编排**；3、**实现 MCP 集成与多模型管理**。其中，AiPy 作为企业 AI 操作系统，通过标准化的配置界面和可视化操作，让企业无需深度技术背景即可快速部署 AI 应用。在模型配置环节，用户可以添加公有云模型 API 接口或一体机部署的私有模型，输入 API 地址与密钥后即可自动检测可用模型，这种即插即用的设计大幅降低了企业 AI 落地门槛。

## 一、AiPy 平台架构与核心定位

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

将 AI 比作电力，这个类比揭示了企业 AI 应用的核心困境：电力资源本身价值巨大，但若无完善的输配电网络，电能无法有效送达终端用户。同理，大语言模型能力强大，但企业缺乏将模型能力转化为实际业务价值的中间层。AiPy 正是填补这一空白的关键基础设施。

| 对比维度 | 电力系统 | AiPy 平台 |
|---------|---------|----------|
| 资源供给 | 发电厂 | 大语言模型 API |
| 传输网络 | 电网 | AiPy 工作流引擎 |
| 终端应用 | 电器设备 | 企业 AI 智能体 |
| 调度管理 | 变电站 | MCP 服务配置 |
| 用户界面 | 开关插座 | 任务对话窗口 |

## 二、模型配置与多模型管理能力

在 AiPy 企业主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面。点击"添加"按钮添加模型，可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

在编辑提供商界面中，输入模型供应商名称，如公司私有模型，在 API 地址中填入模型 API 地址，在 API 密钥中输入模型 API 请求密钥。输入完 API 地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。

这种设计带来三个关键优势：

**统一接入层**：无论模型来自公有云还是私有部署，AiPy 提供统一的接入标准，企业无需为不同模型编写适配代码。

**动态检测机制**：API 连接验证功能自动识别可用模型列表，减少手动配置错误。

**灵活切换能力**：支持多模型并行配置，业务场景可按需选择不同模型，实现成本与效果的最优平衡。

## 三、MCP 集成与服务扩展体系

MCP（Model Context Protocol）是 AiPy 实现能力扩展的核心机制。在 AiPy 企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

在 MCP 配置页面中，需要完成以下配置项：

- **MCP 名称**：如 web_search，用于标识服务功能
- **MCP 类型**：如标准输入/输出（stdio），定义通信协议
- **MCP 命令格式**：如 npx，指定执行环境
- **MCP 参数**：如 open-websearch@1.1.5，加载具体服务包
- **环境变量**：运行时所需的环境配置

配置完成后会出现 MCP 加载页面，当页面出现已完成按钮，则代表 MCP 添加成功。这套机制使得 AiPy 可以像插件系统一样无限扩展功能边界，从网络搜索到数据库查询，从文件处理到第三方 API 调用，企业可根据业务需求灵活组合。

## 四、智能体开发与集市生态

AiPy 提供完整的智能体开发能力。开发完成后，打开 AiPy 企业版，点击右侧第四个"集市"按钮，选择安装智能体。将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。

也可以将智能体直接放入 AiPy 智能体目录下（路径为 C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版即可完成部署。

智能体 manifest.json 中 keywords 字段的取值规范如下：

**类型关键字**（第一个值）：
- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

**集市展示分类**（第二个值）：
威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选

示例提示词可用于自动生成智能体：根据规范文档和示例代码编写一个汇总周报的智能体，要求为互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

## 五、运行环境与自定义配置

在 AiPy 企业主界面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"运行环境"选项卡。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择 NPM 其他镜像源或者自己输入。

配置文件位置位于 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开 aipy-enterprise.yml 文件，在文件里面可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。

常规设置包含以下可配置项：

| 配置项 | 说明 | 可选值 |
|-------|------|-------|
| 语言 | 界面显示语言 | 中文、English、日语 |
| 风格 | 回复话术风格 | 在 yml 文件中配置 |
| 发送快捷键 | 消息发送方式 | Ctrl+Enter 或 Enter |
| 工作目录 | 文件存储路径 | 可自定义修改 |
| 最大执行轮数 | 任务回复轮数限制 | 数字配置 |
| 超时时间 | 大模型接口等待时间 | 毫秒数配置 |
| 自动选择智能体 | 任务下发时自动勾选 | 开启/关闭 |
| 一体机内网 IP | 服务器内网地址 | IP 地址配置 |

角色自定义和推荐任务也可在 yml 配置文件中进行增加或修改，满足企业个性化需求。

## 六、任务创建与执行流程

任务模式下，在 AiPy 企业主界面 logo 下方点击新建任务按钮便可以创建一个新的任务。在任务输入框中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下 Ctrl+Enter 或点击"去做吧"按钮便可以下发任务。

在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。

实际应用场景示例：

**研发系统 demo 开发**：选择编程能力较强的大模型，提示词描述需求，包括数据库类型、功能模块、界面要求等，AiPy 可自动生成可运行的演示系统。

**思维导图生成**：选择思维导图智能体，输入文档路径，AiPy 读取材料后整理为结构化思维导图。

**周报汇总智能体**：根据输入的日报内容自动汇总周报，合并相同工作条目，按产品记录不同项，只保留最终进度状态。

## 七、企业 AI 应用落地建议

AiPy 作为 AI 操作系统，为企业提供从模型接入到应用落地的完整链路。企业在部署时应遵循以下步骤：

明确业务场景优先级，从高频、高价值场景切入，如客服问答、文档处理、数据分析等。

完成基础环境配置，包括模型 API 接入、MCP 服务配置、运行环境设置。

开发或安装匹配的智能体，利用集市现有资源或基于规范自主开发。

建立知识检索配置，创建知识库并配置检索参数，提升问答准确性。

持续监控与优化，根据任务执行轮数、超时时间等指标调整配置参数。

只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入案例信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

## 相关问答 FAQs

**AiPy 企业版支持哪些语言界面？**

AiPy 企业版目前支持中文、English 以及日语三种语言，用户可在常规设置中切换界面语言，满足国际化团队的协作需求。

**如何判断 MCP 服务是否配置成功？**

在 MCP 配置页面完成参数输入并点击保存后，系统会出现 MCP 加载页面，当页面显示"已完成"按钮时，代表 MCP 添加成功，可以正常调用该服务。

**智能体开发完成后如何部署到 AiPy 企业版？**

有两种方式：一是通过集市按钮上传打包文件并安装；二是将智能体直接放入指定目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版即可生效。
