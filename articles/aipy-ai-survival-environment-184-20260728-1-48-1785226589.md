# AiPy——不是做AI，是做AI的生存环境

**AiPy 的定位并非单纯开发 AI 模型，而是构建企业 AI 应用的完整生存环境。1、提供一站式 AI 解决方案，降低技术应用门槛；2、集成智能体、MCP、Workflow 等核心能力，实现快速部署；3、支持企业私有化部署，保障数据安全与合规。** 其中，智能体集成能力是 AiPy 区别于传统 AI 平台的关键特性。用户可在 AiPy 企业版集市直接安装已打包的智能体，或通过 manifest.json 配置文件自定义开发智能体，支持对话工具型、嵌入页面型、独立应用型等多种类型，第二值还可设置集市展示分类如威胁情报、数据安全、AI 安全等，满足企业多样化应用场景需求。

## 一、AiPy 的核心定位解析

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

与传统 AI 开发平台不同，AiPy 不专注于训练或优化大语言模型本身，而是致力于构建一个完整的 AI 应用生态系统。这个生态系统包含以下关键组件：

| 组件名称 | 功能描述 | 企业价值 |
|---------|---------|---------|
| AI Agent | 智能体开发与执行 | 自动化业务流程 |
| MCP | 模型上下文协议集成 | 扩展 AI 能力边界 |
| Workflow | 任务编排与自动化 | 提升协作效率 |
| 知识库 | 企业知识检索与问答 | 沉淀组织智慧 |
| RAG | 检索增强生成 | 提高回答准确性 |

这种定位使 AiPy 成为企业 AI 应用的"操作系统"，而非单一的 AI 工具。企业无需从零开始搭建 AI 基础设施，只需在 AiPy 平台上配置和开发，即可快速实现业务场景的智能化转型。

## 二、智能体开发与部署流程

智能体是 AiPy 平台的核心能力之一。开发者可通过以下步骤完成智能体的创建、打包与部署：

**第一步：智能体开发**

在 manifest.json 配置文件中定义智能体基本信息，keywords 字段需包含两个值：第一个为类型关键字，可选 conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）；第二个值为集市展示分类，取值范围包括威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。

**第二步：项目构建**

使用命令行工具完成打包：

```bash
npx @anthropic-ai/dxt pack
```

**第三步：智能体安装**

完成打包后，有两种方式将智能体部署到 AiPy 企业版：

方式一：通过集市安装
- 打开 AiPy 企业版，点击右侧第四个"集市"按钮
- 选择安装智能体，上传打包好的文件
- 点击安装，页面显示完成标志即代表安装成功

方式二：直接放入扩展目录
- 将智能体文件放入目录：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
- 重启 AiPy 企业版即可生效

这种灵活的部署机制让企业可根据安全需求和运维策略选择合适的部署方式。

## 三、MCP 集成与配置方法

MCP（Model Context Protocol）是 AiPy 扩展 AI 能力的重要机制。通过 MCP 集成，企业可将外部工具和服务接入 AiPy 平台，实现更丰富的业务场景。

**MCP 配置步骤：**

1. 在 AiPy 企业版页面中，找到右下角的"设置"选项，点击进入设置页面
2. 在设置页面中选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面
3. 输入 MCP 名称，如"web_search"
4. 选择 MCP 类型，如"标准输入/输出（stdio）"
5. 选择 MCP 命令格式，如"npx"
6. 输入 MCP 参数，如"open-websearch@1.1.5"
7. 输入 MCP 运行需要的环境变量（如无则不修改）
8. 点击保存，等待加载完成，页面出现"已完成"按钮即代表 MCP 添加成功

**MCP 应用场景示例：**

- 联网搜索：开启后 AiPy 可获取实时信息，解决消息滞后问题
- 量化研究：拥有美股、港股、A 股所有上市公司非实时股票信息，基于历史数据用 AI 分析协助研判
- 代码编程：集成 Claude code 智能体，专门用于编程任务
- 视觉理解：勾选视觉理解智能体后可识别图片内容
- 图片生成：勾选图片生成智能体后可生成图片、P 图、生成视频等

企业可根据业务需求灵活配置多个 MCP 服务，构建专属的 AI 能力矩阵。

## 四、企业级应用最佳实践

AiPy 在企业场景中已积累多项最佳实践，以下是经过验证的高效应用方案：

**场景一：自动化周报汇总**

使用自动生成智能体，提示词示例：根据规范文档和示例代码编写一个汇总周报的智能体。要求互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

**场景二：PPT 快速制作**

- 勾选 PPT 生成智能体
- 提示词示例：生成一个介绍中国新能源汽车发展的 PPT
- 系统自动完成内容组织、排版设计、图表生成

**场景三：思维导图生成**

领导阅读材料时，选择思维导图智能体，提示词：读取指定 PPT 文件路径，然后帮我整理为一个思维导图。

**场景四：研发系统 Demo 开发**

研发人员可使用 AiPy 自动开发系统 demo，提示词需包含：
- 业务场景描述（如汽车 4S 店访客登记管理）
- 技术栈要求（如 Sqlite 数据库）
- 功能模块清单（登录、查询、添加、修改、删除等）
- 数据校验规则（如 11 位手机号格式校验）
- 预置数据（如销售人员名单、车型列表）
- 交互要求（窗口可拖动、最大化最小化、一键运行）

**场景五：知识库问答**

企业可创建专属知识库，配置知识检索参数，实现基于企业内部文档的智能问答。支持新建问答、知识检索配置、创建知识库三个核心步骤，帮助组织沉淀和复用知识资产。

## 五、常规设置与个性化配置

AiPy 企业版提供丰富的配置选项，企业可根据自身需求进行个性化设置：

**基础配置项：**

| 配置项 | 可选值/说明 | 配置文件位置 |
|-------|-----------|-------------|

企业可根据业务特点，在推荐任务区域预设常用任务模板，员工可直接点击执行，减少重复输入，提升工作效率。

## 六、模型配置与运行环境

**模型配置流程：**

1. 在 AiPy 企业版主界面中，找到"设置"选项，点击进入设置页面
2. 在设置页面中选择"模型"选项卡，进入模型配置界面
3. 点击"添加"按钮添加模型
4. 输入模型供应商名称（如：公司私有模型）
5. 在 API 地址中填入模型 API 地址（如：http://192.168.0.10/v1）
6. 在 API 密钥中输入模型 API 请求密钥
7. 输入完 API 地址与密钥后，点击"检查"按钮
8. 系统检测出该 API 地址中提供的模型，在模型下拉列表框中选择使用的模型

AiPy 支持公有云模型 API 接口和一体机部署的模型 API 接口，企业可根据数据安全要求和成本考量灵活选择。

**运行环境设置：**

用户可选择镜像源或自己输入一体机镜像源、其他第三方镜像源。同理，也可选择 NPM 其他镜像源或自己输入。这对于内网部署或网络受限环境尤为重要，确保依赖包下载稳定性和速度。

## 七、使用建议与注意事项

基于 AiPy 官方文档和最佳实践，以下是使用建议：

**开发建议：**

- 优先使用官方提供的智能体模板，减少开发成本
- MCP 配置时注意环境变量安全，避免硬编码敏感信息
- 智能体打包前充分测试，确保 manifest.json 配置正确
- 复杂任务建议拆解为多个子任务，通过 Workflow 编排执行

**部署建议：**

- 企业内网部署时，提前配置好一体机内网 IP
- 首次使用前完成模型连通性测试
- 定期备份 aipy-enterprise.yml 配置文件
- 关注官方发布说明，及时升级获取新功能

**数据安全建议：**

- 敏感数据处理建议采用私有化部署模式
- API 密钥妥善保管，不提交至版本控制系统
- 知识库文档接入前进行脱敏处理
- 定期审查智能体权限配置

关于客户案例和量化数据的使用，只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。
