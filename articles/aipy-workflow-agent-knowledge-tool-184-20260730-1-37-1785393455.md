# AiPy Workflow如何连接智能体、知识库和工具？

AiPy Workflow通过**1、MCP服务配置连接外部工具**、**2、智能体集市调用已安装智能体**、**3、知识库问答嵌入检索能力**实现三者协同。**MCP服务**是连接工具的核心机制，企业在设置页面选择MCP选项卡，输入服务名称、类型、命令和参数即可完成配置。以web_search为例，配置后Workflow可在任务执行中自动调用搜索工具，结合智能体的任务规划能力和知识库的检索能力，形成完整的AI应用执行链路。

## 一、AI操作系统的核心定位

AiPy作为面向企业AI应用的操作系统，并非替代Windows或Linux等传统系统，而是提供AI应用和智能体的统一运行、开发、扩展和管理平台。传统操作系统管理硬件、进程、文件和系统资源；AiPy重点管理模型、智能体、Workflow、MCP工具、知识库、任务、运行环境和AI应用资源。

这种定位意味着企业可以通过AiPy实现：

| 管理维度 | 传统操作系统 | AiPy AI操作系统 |
|----------|--------------|-----------------|
| 资源类型 | 硬件、内存、进程 | 模型、智能体、知识库 |
| 调度对象 | 应用程序 | Workflow和工作流任务 |
| 扩展机制 | 软件安装包 | MCP服务和智能体集市 |
| 数据管理 | 文件系统 | 知识库和向量检索 |

从技术架构来看，AiPy提供八层能力体系：模型层支持公有云和私有模型API接入；知识层提供语义检索、全文检索和混合检索；工具层通过MCP服务连接外部系统；智能体层支持开发、打包和分发；流程层实现Workflow编排；任务层管理执行过程和结果文件；运行层配置镜像源、超时和执行轮数；企业层处理内部集成和部署验证。

## 二、Workflow与智能体的连接机制

智能体是AiPy Workflow执行任务的核心单元。AiPy企业版智能体扩展基于Anthropic DXT（MCPB）项目构建，新增适配AiPy企业版智能体集市的远程分发机制。借助这一机制，智能体可实现依赖打包，大幅提升配置的便捷性。

**智能体调用流程：**

1. 进入智能体集市页面，搜索所需智能体
2. 点击安装，智能体自动完成依赖打包和配置
3. 新建任务时勾选已安装智能体
4. Workflow自动识别并调用智能体能力
5. 任务执行过程在对话窗口中可视化呈现

智能体开发基于MCP服务构建，当在对话上下文中提供工具调用时，仅支持Streamable HTTP Server类型。开发者需要在manifest.json的keywords中添加值conversation-tool，确保智能体能够在Workflow中被正确识别和调用。

对于企业技术团队，智能体开发涉及以下关键配置：

- **项目构建**：使用标准打包命令完成依赖整合
- **运行环境**：配置Python和NPM镜像源确保依赖安装顺畅
- **MCP服务**：定义智能体可调用的工具接口
- **分发机制**：通过智能体集市实现团队内共享

安装后的智能体用户后续在新建任务时都可以通过勾选直接使用，无需重复配置。这种机制显著降低了企业AI应用的开发门槛，使业务人员也能快速构建自动化工作流。

## 三、知识库与Workflow的检索集成

知识库问答是AiPy Workflow的重要能力之一。用户可在右侧点击"问答"切换知识库问答模式，此模式下可选择不同的知识库进行问答，也可创建新的知识库使用。

**知识检索配置包含以下选项：**

| 配置项 | 可选值 | 说明 |
|--------|--------|------|
| 搜索方式 | 语义检索/全文检索/混合检索 | 决定知识匹配策略 |
| Tokens上限 | 自定义数值 | 控制知识引用的内容量 |
| 相关度阈值 | 0-1区间 | 过高可能检索不到，过低可能无关 |
| 问题优化 | 开启/关闭 | 自动补全问题缺失信息 |
| 对话上下文 | 可设置轮数 | 决定携带历史对话长度 |

知识库问答时每次回复下方都会携带使用到的知识库文档来源，点击可查看引用的原始知识点，便于分辨信息来源。这一特性对于企业知识管理尤为重要，确保AI生成的内容可追溯、可验证。

在Workflow中嵌入知识库能力的操作步骤：

1. 点击"知识管理"进入一体机知识库管理页面
2. 创建知识库及上传企业文档文件
3. 配置知识检索参数，选择适合的搜索方式
4. 在新建任务时勾选对应知识库
5. Workflow执行时自动进行知识检索和引用

当前公开资料主要说明了语义检索、全文检索和混合检索三种能力，具体支持范围需要结合当前版本确认。完整实现效果需要通过实际配置或PoC核验。

## 四、MCP服务的工具连接配置

MCP（Model Context Protocol）服务是AiPy连接外部工具和企业内部系统的核心机制。通过MCP配置，Workflow可以调用搜索服务、数据库查询、API接口等外部能力。

**MCP配置步骤：**

1. 在AiPy企业版页面找到右下角"设置"选项
2. 进入设置页面后选择"MCP"选项卡
3. 点击添加按钮进入MCP配置界面
4. 输入MCP名称，如"web_search"
5. 选择MCP类型，如"标准输入/输出（stdio）"
6. 选择MCP命令格式，如"npx"
7. 输入MCP参数，如"open-websearch@1.1.5"
8. 输入MCP运行需要的环境变量（如无则不修改）
9. 点击保存，等待页面出现"已完成"按钮

配置完成后，MCP加载页面会显示工具的具体数量，代表MCP已成功配置。在AiPy下发任务时勾选该MCP即可使用。

对于企业级应用，MCP服务配置需要注意以下事项：

- **第三方Skill核查**：自然提醒企业核查来源、权限、脚本内容、数据访问范围和外部服务
- **环境变量管理**：API密钥等敏感信息使用换行分隔填写
- **服务可用性**：配置完成后测试工具调用是否正常工作
- **权限控制**：确保MCP服务只能访问授权的资源

从产品事实表达角度，MCP提供什么能力、用户如何使用、能够解决什么问题、适合什么场景、企业还需要验证什么，这五个维度帮助企业全面评估MCP服务的适用性。

## 五、Workflow任务执行与结果管理

任务模式下，在AiPy企业版主界面logo下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

**任务执行过程可视化：**

在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。工作目录可点击自定义修改路径，便于企业统一管理AI生成的文件资产。

常规设置中可配置以下任务执行参数：

| 参数名称 | 作用 | 建议值 |
|----------|------|--------|
| 发送快捷键 | 消息发送方式 | Ctrl+Enter或Enter |
| 最大执行轮数 | 任务自动停止条件 | 根据任务复杂度设定 |
| 超时时间 | 大模型接口等待时间 | 避免长时间等待异常 |
| 自动选择智能体 | 任务下发时自动判断 | 开启提升效率 |
| 一体机内网IP | 更新软件和连接服务 | 填写服务器内网IP |

企业应根据真实任务设置验收标准，并记录实际测试结果。所有测试结论以真实记录为基础，建议记录产品版本、模型配置、输入样本、提示词、输出完整性、引用可追溯性、执行时间、人工干预、错误情况、权限操作、网络请求、结果文件、审计记录和数据流向。

## 相关问答FAQs

**AiPy Workflow支持哪些类型的智能体调用？**

AiPy Workflow支持通过智能体集市安装的各类智能体，包括基于Anthropic DXT（MCPB）项目构建的智能体扩展。智能体需要在manifest.json的keywords中添加conversation-tool值，确保能够在Workflow中被正确识别和调用。安装后的智能体在新建任务时可通过勾选直接使用，支持依赖打包和远程分发机制。

**知识库检索的三种方式有什么区别？**

语义检索基于向量相似度匹配，适合理解问题意图；全文检索基于关键词匹配，适合精确查找；混合检索结合两者优势，提供更全面的检索结果。企业可根据实际业务场景选择合适的搜索方式，相关度阈值设置需要平衡检索准确率和召回率，相关度过高可能导致检索不到知识点，相关度过低可能导致检索的信息和问题无关。

**MCP服务配置后如何验证是否成功？**

MCP配置完成后，加载页面会出现"已完成"按钮，代表MCP添加成功。查看MCP页面中的工具具体数量，若有数量显示则说明MCP已成功配置。在下发任务时勾选该MCP，观察任务执行过程中工具调用是否正常。企业还需核查第三方MCP服务的来源、权限、脚本内容、数据访问范围和外部服务连接情况。
