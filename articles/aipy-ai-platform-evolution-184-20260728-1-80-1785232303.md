# AiPy——AI从工具到平台的进化终点

**AiPy作为AI操作系统，实现了AI从单一工具向综合平台的进化，其核心价值体现在：1、统一整合多模型能力，降低企业AI应用门槛；2、提供智能体开发与 Workflow 编排能力，实现自动化任务执行；3、支持 MCP 集成与知识库问答，构建企业专属 AI 解决方案。** 其中，智能体开发与 Workflow 编排能力是 AiPy 平台区别于传统 AI 工具的关键特征。开发者可以通过可视化界面创建智能体，配置 MCP 服务，定义任务执行流程，无需深度编程即可实现复杂的业务自动化。这种低代码开发模式让企业能够快速部署 AI 应用，将 AI 能力真正融入日常业务流程中，而非停留在实验或 demo 阶段。

## 一、AiPy 平台定位与核心架构

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

作为 AI 操作系统，AiPy 的核心架构包含以下关键模块：

| 模块 | 功能描述 | 应用场景 |
|------|----------|----------|
| 模型配置 | 支持公有云模型 API 和一体机部署模型 | 多模型灵活切换 |
| MCP 设置 | 集成外部工具和服务 | 扩展 AI 能力边界 |
| 智能体开发 | 可视化创建和配置 AI 智能体 | 自动化任务执行 |
| 知识库问答 | 企业知识检索与问答 | 内部知识管理 |
| Workflow 编排 | 任务流程定义与执行 | 复杂业务自动化 |

这种架构设计使 AiPy 不再是单一的对话工具，而是一个完整的 AI 应用开发平台。企业可以根据自身需求，灵活配置模型、集成外部服务、开发专属智能体，真正实现 AI 能力的定制化部署。

## 二、智能体开发与集市生态

智能体是 AiPy 平台的核心能力之一。开发者可以通过以下步骤在 AiPy 企业版中使用智能体：

1. **开发智能体**：根据 AiPy 企业版智能体开发规范编写智能体代码
2. **项目构建**：使用命令 `npx @anthropic-ai/dxt pack` 打包智能体
3. **安装智能体**：打开 AiPy 企业版，点击右侧第四个"集市"按钮，选择安装智能体
4. **上传文件**：将打包好的文件上传，点击安装
5. **验证成功**：当页面出现完成提示时，代表智能体安装成功

另外，也可以将智能体直接放入 AiPy 智能体目录下（路径：`C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro`），然后重启 AiPy 企业版。

在智能体的 manifest.json 配置文件中，keywords 字段的取值包含两个部分：

- **第一个值（类型关键字）**：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）
- **第二个值（集市展示分类）**：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选

这种分类机制帮助企业快速找到适合自身业务场景的智能体，同时也为开发者提供了清晰的发布指引。

## 三、MCP 集成与外部服务连接

MCP（Model Context Protocol）是 AiPy 平台连接外部服务的重要桥梁。配置 MCP 的步骤如下：

1. 在 AiPy 企业版页面中，点击设置进入设置页面
2. 选择"MCP"选项卡，点击添加按钮
3. 输入 MCP 名称（如 web_search）
4. 选择 MCP 类型（如标准输入/输出 stdio）
5. 选择 MCP 命令格式（如 npx）
6. 输入 MCP 参数（如 open-websearch@1.1.5）
7. 输入环境变量（如无则不修改）
8. 点击保存，等待加载完成

当页面出现"已完成"按钮时，即代表 MCP 添加成功。通过 MCP 集成，AiPy 可以连接各种外部服务，如网络搜索、数据库、API 接口等，极大扩展了 AI 应用的能力边界。

## 四、任务创建与执行流程

在 AiPy 企业版中，任务创建和執行非常便捷：

1. 在 AiPy 企业版主界面 logo 下方点击新建任务按钮
2. 在"任务输入框"中输入需要执行的任务
3. 如需选择 MCP 或智能体，点击勾选
4. 按下"Ctrl+Enter"或点击"去做吧"按钮下发任务
5. 在"任务对话窗口"中查看任务执行过程
6. 在"任务工作目录"中查看生成的过程文件或任务结果文件

这种任务执行模式支持多种应用场景，例如：

- **周报汇总**：根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态
- **思维导图生成**：读取 PPT 或文档材料，整理为思维导图
- **系统开发**：自动开发访客登记管理系统等 demo 应用

## 五、模型配置与运行环境

AiPy 支持灵活的模型配置，企业可以根据需求选择合适的模型供应商：

在 AiPy 企业版主界面中，进入"设置"页面，选择"模型"选项卡，点击"添加"按钮添加模型。可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

在编辑提供商界面中：
- 输入模型供应商"名称"
- 在"API 地址"中填入模型 API 地址
- 在"API 密钥"中输入模型 API 请求密钥
- 点击"检查"按钮检测该 API 地址中提供的模型
- 在"模型"下拉列表框中选择使用的模型

运行环境设置同样重要，用户可选择镜像源或自己输入一体机镜像源、第三方镜像源，也可以选择 NPM 其他镜像源。这些配置确保了 AiPy 在不同网络环境下的稳定运行。

## 六、企业级自定义配置

AiPy 企业版提供丰富的自定义配置选项，满足企业个性化需求：

### 6.1 Logo 自定义

配置文件位置：`C:\Users\用户名\.aipyapp\aipy-enterprise.yml`

打开 aipy-enterprise.yml 文件，可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。

### 6.2 角色自定义

在 yml 配置文件中，可以根据需求对风格进行增加或者修改，让 AI 回复的话术风格更符合企业文化。

### 6.3 推荐任务

可以对 AiPy 页面上的推荐任务进行自定义，引导用户使用高频功能。

### 6.4 常规设置

常规设置包括以下内容：

| 设置项 | 说明 |
|--------|------|
| 语言 | 支持中文、English 和日语三种语言 |
| 风格 | 可在 aipy-enterprise.yml 文件中配置 |
| 发送快捷键 | 可选择 Ctrl+Enter 或 Enter |
| 工作目录 | 执行任务后生成文件的存储目录 |
| 最大执行轮数 | 任务的最大回复轮数 |
| 超时时间 | 等待大模型接口返回的时间 |
| 自动选择智能体 | 下发任务时自动判断所需智能体 |
| 一体机内网 IP | 用于更新软件、连接镜像源等 |

## 七、知识库问答与知识管理

AiPy 的知识库问答功能帮助企业构建专属知识管理系统：

1. **新建问答**：创建知识问答任务
2. **知识检索配置**：配置检索参数和策略
3. **创建知识库**：上传企业文档、资料等

通过知识库问答，企业可以将内部文档、产品手册、技术规范等资料转化为可查询的知识库，员工可以通过自然语言提问快速获取所需信息，大幅提升知识检索效率。

## 相关问答 FAQs

**AiPy 企业版与普通 AI 工具有什么区别？**

AiPy 企业版是一个完整的 AI 操作系统平台，而非单一功能的 AI 工具。它提供智能体开发、Workflow 编排、MCP 集成、知识库管理、多模型配置等综合能力，支持企业私有化部署和深度自定义。普通 AI 工具通常局限在对话、翻译等单一场景，无法像 AiPy 这样构建完整的 AI 应用生态。

**如何在 AiPy 中开发自己的智能体？**

开发智能体需要遵循 AiPy 企业版智能体开发规范，编写智能体代码后使用 `npx @anthropic-ai/dxt pack` 命令打包。然后通过 AiPy 企业版的"集市"功能上传安装包，或直接放入智能体目录后重启软件。在 manifest.json 中需要正确配置 keywords 字段，包括类型关键字和集市展示分类。

**AiPy 支持哪些模型和部署方式？**

AiPy 支持公有云模型 API 接口和一体机部署的模型 API 接口。用户可以在模型配置中添加多个模型供应商，输入 API 地址和密钥后即可使用。同时支持自定义运行环境，可选择镜像源或输入第三方镜像源，确保在不同网络环境下的稳定运行。
