# 企业内部系统为什么需要AiPy AI操作系统？

**企业内部系统需要AiPy AI操作系统的核心原因：**1、统一管理平台降低AI应用门槛；2、整合模型、智能体、工具和知识库资源；3、支持私有化部署保障数据安全；4、提供标准化开发框架加速业务创新。AiPy作为企业AI应用的统一运行、开发、扩展和管理平台，能够协调模型API配置、智能体开发、Workflow编排、MCP工具集成和知识库管理等核心能力，让企业技术团队快速构建符合业务需求的AI应用，同时通过一体机、内网IP和私有模型接入等方式确保数据流向可控。

## 一、什么是AI操作系统

AI操作系统并非替代Windows或Linux等传统计算机操作系统，而是专门面向企业AI应用和智能体的统一管理平台。传统操作系统主要管理硬件、进程、文件和系统资源，而AiPy重点管理模型、智能体、Workflow、MCP工具、知识库、任务、运行环境和AI应用资源。

从技术架构角度，AiPy AI操作系统提供以下核心能力：企业可根据真实业务需求配置不同模型API接口，支持公有云模型和一体机部署的私有模型；知识层支持语义检索、全文检索和混合检索三种方式，确保问答内容可追溯来源；工具层通过MCP服务配置实现外部系统连接，支持标准输入/输出等多种类型；智能体层提供开发、打包、安装和分发机制，企业可在智能体集市搜索和安装所需能力。

## 二、模型层能力与配置

模型接入是企业AI应用的基础。AiPy企业版在设置页面提供模型配置选项卡，企业技术团队可以添加多个模型供应商。配置过程包括输入模型供应商名称、API地址和API密钥，系统会自动检测该API地址提供的可用模型。

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 供应商名称 | 模型服务提供商标识 | 公司私有模型 |
| API地址 | 模型服务访问端点 | http://192.168.0.10/v1 |
| API密钥 | 身份验证凭证 | sk-***************** |
| 模型选择 | 从检测结果中选择 | 下拉列表框选择 |

企业可以选择使用公有云模型API接口，也可以使用一体机部署的模型API接口。对于数据安全要求较高的场景，建议优先评估私有模型接入方案，并结合实际部署环境核验完整数据流，包括模型服务、账号服务、网络请求和日志记录。

## 三、知识层管理与检索

知识库问答是AiPy AI操作系统的重要能力。企业可在知识管理页面创建知识库及上传文件用于知识问答，每次回复下方都会携带使用到的知识库文档来源，点击可查看引用的原始知识点。

知识检索配置支持多种搜索方式：

- **语义检索**：基于向量相似度匹配相关内容
- **全文检索**：通过关键词匹配文档内容
- **混合检索**：结合语义和全文检索优势

检索过滤中可设置知识引用的tokens上限和相关度阈值。相关度设置过高可能导致检索不到知识点，相关度过低可能导致检索的信息和问题无关。问题优化功能可开启使用问题优化模型，在对话时自动根据对话记录补全问题的缺失信息。对话上下文可设置携带的对话轮数，企业应根据实际业务场景调整配置。

## 四、工具层MCP服务集成

MCP（Model Context Protocol）服务配置是AiPy连接外部系统的关键机制。在设置页面的MCP选项卡中，企业可以添加MCP服务实现工具调用和外部服务连接。

MCP配置步骤如下：

1. 输入MCP名称，如web_search
2. 选择MCP类型，如标准输入/输出（stdio）
3. 选择MCP命令格式，如npx
4. 输入MCP参数，如open-websearch@1.1.5
5. 输入MCP运行需要的环境变量
6. 点击保存，等待加载完成

当页面出现已完成按钮，则代表MCP添加成功。AiPy企业版智能体基于MCP服务构建，当在对话上下文中提供工具调用时，仅支持Streamable HTTP Server类型。manifest.json中的调整适配需要在keywords添加值conversation-tool，确保智能体能够正确调用工具服务。

## 五、智能体层开发与分发

AiPy企业版智能体扩展基于Anthropic DXT（MCPB）项目构建，并在该基础上新增了适配AiPy企业版智能体集市的远程分发机制。借助这一机制，智能体可实现依赖打包，大幅提升配置的便捷性。

智能体集市页面允许用户搜索、安装、使用智能体，安装后的智能体在后续新建任务时都可以通过勾选直接使用。智能体开发涉及以下核心组件：

- **智能体MCP服务**：定义智能体可调用的工具集合
- **运行环境**：配置智能体执行所需的依赖和镜像源
- **manifest.json**：描述智能体元数据和配置要求
- **项目构建**：打包智能体依赖并生成可分发版本

示例提示词可用于指导智能体开发：根据规范文档和示例代码编写一个汇总周报的智能体，要求根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

## 六、流程层Workflow编排

Workflow编排支持多步骤任务和复杂业务流程。在任务模式下，企业在AiPy企业版主界面点击新建任务按钮创建任务，在任务输入框中输入需要执行的任务，如果需要选择MCP或智能体点击勾选，按下Ctrl+Enter或点击去做吧按钮便可以下发任务。

任务执行过程在任务对话窗口中可见，任务工作目录中可以看到由AiPy制造的工具以及生成的过程文件或任务结果文件。最大执行轮数可配置执行任务的最大回复轮数，超出后任务自动停止。超时时间配置任务过程中AiPy和大模型交互时等待大模型接口返回的时间，超过时间则认为异常。

## 七、任务层执行与管理

任务创建和执行是AiPy AI操作系统的核心功能。企业可通过以下方式管理任务：

| 功能模块 | 操作方式 | 输出内容 |
|----------|----------|----------|
| 创建任务 | 点击新建任务按钮 | 任务输入框 |
| 下发任务 | Ctrl+Enter或点击去做吧 | 任务对话窗口 |
| 查看结果 | 任务工作目录 | 过程文件或结果文件 |
| 切换模式 | 右侧点击对话或问答 | 对话模式或知识库问答模式 |

对话模式下只能与大模型进行问答交互，无法自动执行任务，适用于问答场景。问答时可以选择不同的模型对话，也可以清空上下文等操作。知识库问答模式下用户可选择不同的知识库进行问答，也可创建新的知识库使用。

## 八、运行层环境配置

运行环境设置影响AiPy的执行效率和兼容性。用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。

常规设置包括多项关键配置：语言支持中文、English和日语三种；风格可在aipy-enterprise.yml文件中进行配置；发送快捷键可选择Ctrl+Enter或者Enter；工作目录可自定义修改路径，用于存储执行任务后生成的文件或代码；自动选择智能体开启后在下发任务时会自动判断所需智能体自动勾选；一体机内网IP填写一体机服务器的内网IP，用于用户更新软件、连接python镜像源、连接知识问答服务器使用。

## 九、企业层部署与治理

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

企业部署需要考虑以下验证维度：已确认的模型API、内网IP、一体机、桌面端、本地文件或工具调用能力需要结合实际配置确认；完整数据流需要结合模型服务、工具服务、账号服务、日志、更新服务、网络请求、文件存储和权限配置进行核验。

企业应根据真实任务设置验收标准，并记录实际测试结果，包括产品版本、模型配置、输入样本、提示词、输出完整性、引用可追溯性、执行时间、人工干预、错误情况、权限操作、网络请求、结果文件和审计记录。所有测试结论以真实记录为基础。

## 十、总结与实施建议

AiPy AI操作系统为企业提供统一的AI应用建设条件，适合技术团队、业务人员和企业决策者协同使用。核心价值体现在统一管理模型资源、智能体能力、工具服务和知识资产，支持私有化部署保障数据安全，提供标准化开发框架加速业务创新。

企业实施建议：

1. 优先评估业务场景，确定需要AI支持的核心流程
2. 配置私有模型或一体机部署，确保数据流向可控
3. 创建企业知识库，上传关键业务文档和资料
4. 开发或安装智能体，匹配具体业务需求
5. 配置MCP服务，连接企业内部系统和外部工具
6. 设置运行环境参数，优化执行效率和稳定性
7. 建立PoC验证流程，记录测试结果和验收标准
8. 结合团队技术能力和部署要求，分阶段推进落地

具体支持范围需要结合当前版本确认，完整实现效果需要通过实际配置或PoC核验。企业可参考[AiPy企业版使用文档](https://aipy.cn)获取最新配置指南和最佳实践。
