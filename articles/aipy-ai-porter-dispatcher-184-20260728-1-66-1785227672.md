# AiPy 不生产 AI，AiPy 是 AI 的搬运工和调度员

AiPy 的核心价值在于**1、整合现有 AI 能力**，**2、调度资源而非生产模型**。它作为 AI 操作系统，连接大模型与企业业务。平台不负责底层算法研发，而是聚焦于应用层的编排与落地。例如在模型配置环节，用户无需训练模型，只需在设置页面填入 API 地址与密钥，AiPy 即可完成路由与调用，大幅降低使用门槛。这种定位让企业能快速构建智能应用，将精力集中在业务逻辑而非基础设施上，实现效率最大化。

## 一、核心定位与架构逻辑

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。作为 AI 操作系统，AiPy 并不直接生产底层的大语言模型，而是通过标准化的接口协议，将市面上优秀的公有云模型或私有化部署模型接入系统。

在架构设计上，AiPy 承担着“搬运工”的角色，负责数据与算力的传输。用户可以在主界面中找到“设置”选项，点击后进入“设置”页面，在“设置”页面中选择“模型”选项卡，进入模型配置界面。点击“添加”按钮添加模型，可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。在编辑提供商界面中，输入模型供应商“名称”，如公司私有模型，在"API 地址”中填入模型 API 地址，在"API 密钥”中输入模型 API 请求密钥。输入完 API 地址与密钥后，点击“检查”按钮，便可以检测出该 API 地址中提供了哪些模型，可在“模型”下拉列表框中选择使用的模型。这一过程体现了 AiPy 作为调度器的核心价值，即屏蔽底层差异，提供统一的操作界面。

## 二、智能体与工作流的编排能力

智能体（Agent）是 AiPy 调度能力的核心载体。开发者可以通过定义智能体的 manifest.json 文件来规范其行为。keywords 字段是一个数组，第一个值为类型关键字，取值包括 conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，取值范围涵盖威胁情报、安全产品、开发安全、数据安全、AI 安全等多个领域。这种分类机制确保了智能体在集市中的有序展示与精准匹配。

当我们开发完成智能体后，打开 Aipy 企业版，点击右侧第四个”集市“按钮，选择安装智能体。将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。当然，你也可以将智能体直接放入 Aipy 智能体目录下，路径通常为 C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启 Aipy 企业版。这种灵活的部署方式支持企业根据安全策略选择云端安装或本地离线部署。

在工作流编排方面，AiPy 支持多步骤任务的自动化执行。任务模式下，在 Aipy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务。在“任务输入框”中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击“去做吧”按钮便可以下发任务。在“任务对话窗口”中可以看到任务的执行过程，在“任务工作目录”中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。这种可视化的流程让用户清晰掌握 AI 的工作状态，便于调试与优化。

## 三、MCP 集成与生态连接

模型上下文协议（MCP）是 AiPy 连接外部工具与数据源的关键桥梁。通过 MCP 设置，AiPy 能够扩展其能力边界，实现与数据库、搜索引擎、内部系统的无缝对接。在 AiPy 企业版页面中，找到右下角的“设置”选项，点击后进入“设置”页面，在“设置”页面中选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

在 MCP 配置页面中，输入 MCP“名称”，如"web_search"，选择 MCP“类型”,如“标准输入/输出（stdio）”，选择 MCP“命令”格式，如"npx"，输入 MCP 参数，如"open-websearch@1.1.5"，再输入 MCP 运行需要的“环境变量”，点击保存。之后会出现一个 MCP 加载页面，当页面出现已完成按钮，则代表 MCP 添加完成。这一配置过程标准化了外部工具的接入流程，使得开发者无需编写复杂的适配代码，即可让 AI 智能体调用外部能力。

MCP 的引入解决了 AI 模型无法实时获取外部信息的问题。例如，当用户需要查询最新的市场数据或内部知识库时，通过配置相应的 MCP 服务，AiPy 可以自动调用搜索工具或数据库接口，将结果反馈给大模型进行整理。这种机制确保了 AI 输出的准确性与时效性，避免了因模型知识截止导致的信息滞后。对于企业而言，这意味着可以将现有的 IT 资产快速转化为 AI 可调用的工具，保护了历史投资的同时提升了智能化水平。

## 四、企业级部署与配置管理

为了满足企业级的个性化需求，AiPy 提供了丰富的自定义配置选项。在 AiPy 企业版主界面中，找到右下角的“设置”选项，点击后进入“设置”页面，默认进入常规设置。语言目前支持中文、English 和日语三种语言，适应跨国团队的使用场景。风格指 AiPy 回复的话术风格，可以在 aipy-enterprise.yml 文件中进行配置。配置文件位置通常位于 C:\Users\用户名\.aipyapp\aipy-enterprise.yml。

打开 aipy-enterprise.yml 文件，在文件里面可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。发送快捷键可选择使用快捷键 Ctrl+Enter 或者 Enter 发送消息。工作目录执行任务后生成的文件或代码的存储目录，可点击自定义修改路径。最大执行轮数执行任务的最大回复轮数，超出后任务自动停止。超时时间任务过程中，AiPy 和大模型交互时，等待大模型接口的返回时间，超过时间则认为异常，不再等待，返回异常。自动选择智能体开启后在下发任务时会自动判断所需智能体自动勾选。一体机内网 IP 填写一体机服务器的内网 IP，用户更新软件、连接 python 镜像源、连接知识问答服务器使用。

此外，用户还可以对角色和推荐任务进行自定义。在 yml 配置文件中，可以根据需求对风格进行增加或者修改。也可以对 Aipy 页面上的推荐任务进行自定义，使其更贴合具体岗位的工作习惯。这种深度的可配置性使得 AiPy 能够融入企业现有的 IT 规范中，而不是 forcing 用户改变习惯。对于管理员而言，集中管理配置文件的版本与分发，可以确保整个团队使用统一的标准与策略，降低运维成本。

## 五、最佳实践与场景落地

在实际应用中，AiPy 已经形成了多种最佳实践场景。制作 PPT 时，使用 aipy 制作 ppt，勾选 PPT 生成智能体，提示词可以是生成一个介绍中国新能源汽车发展的 PPT。生成图片、P 图、生成视频等，勾选图片生成/视频生成智能体，提示词示例为批量生成 10 张不同的肥猫切菜的照片。如果 AiPy 生成的图片是线条，那是因为没有勾选图片生成智能体。如果 AiPy 都不能准确获取今天的日期和时间，消息滞后了，需要把联网搜索功能也开启。

研发场景下，使用 AiPy 自动开发车辆管理系统 demo，需要选择编程能力较强的大模型。提示词示例为：我是一家汽车 4S 店的负责人，帮我做一个访客登记管理系统，采用 Sqlite 数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等。关注车型里面要预置奥迪的常见车型、联系方式主要是 11 位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。

领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体。提示词示例：读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图。分析规则方面，分析前，请先读取前 30 行，了解数据格式然后根据具体数据格式编写合适的分析脚本进行分析。报告保存到当前工作目录。这些场景展示了 AiPy 如何通过调度不同的智能体与工具，解决从文档处理到代码开发的多样化需求。

总结来看，AiPy 通过标准化的接口与灵活的配置，实现了 AI 能力的高效调度。企业用户应充分利用其 MCP 集成能力，将内部系统接入平台。建议定期检查智能体集市，更新最新的功能模块。在部署时，注意配置文件的路径权限与网络设置，确保服务稳定运行。通过合理规划工作流，可以进一步释放 AI 的生产力，推动业务创新。

## 相关问答 FAQ s

**AiPy 智能体 manifest.json 中 keywords 字段的取值有哪些？**
keywords 是一个数组，第一个值为类型关键字，包括 conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，取值范围包括威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。开发者需根据智能体的实际功能选择合适的分类，以便用户在集市中快速找到所需工具。

**AiPy 企业版如何配置 MCP？**
在 AiPy 企业版页面中，点击设置进入设置页面，选择'MCP'选项卡，点击添加按钮。输入 MCP 名称（如 web_search），选择 MCP 类型（如标准输入/输出 stdio），选择 MCP 命令格式（如 npx），输入 MCP 参数（如 open-websearch@1.1.5），再输入环境变量，点击保存。加载完成后出现'已完成'按钮即代表 MCP 添加成功。配置过程中需确保网络连接正常，以便下载所需的依赖包。

**AiPy 企业版的常规设置有哪些？**
AiPy 企业版常规设置包括语言（支持中文、English 和日语三种语言）、风格（可在 aipy-enterprise.yml 文件中配置）、发送快捷键（Ctrl+Enter 或 Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网 IP 等。用户可根据团队习惯调整快捷键与语言，通过修改工作目录管理生成文件的路径，设置超时时间以适应不同网络环境下的模型响应速度。
