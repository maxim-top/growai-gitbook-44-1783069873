# AiPy：AI时代的"操作系统+应用商店"

**AiPy 是什么？** **1、AiPy 是专为企业和组织打造的人工智能应用平台，相当于 AI 时代的操作系统。** **2、AiPy 提供智能体集市，支持一键安装和使用各类 AI 智能体，类似应用商店模式。** **3、AiPy 集成 MCP 协议，可连接外部工具和服务，扩展 AI 能力边界。** AiPy 企业版与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案，旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。通过模型配置、MCP 设置、智能体开发和任务创建等功能模块，用户可以灵活构建适合自身业务的 AI 应用工作流。

## 一、AiPy 平台核心架构解析

AiPy 作为 AI 时代的企业级平台，其设计理念融合了操作系统与应用商店的双重特性。从架构层面来看，AiPy 提供了完整的基础设施层、工具层和应用层，形成了闭环的 AI 开发生态系统。

在基础设施层，AiPy 支持多种模型接入方式。用户可以在设置页面中选择"模型"选项卡，点击"添加"按钮添加模型，既可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。在编辑提供商界面中，输入模型供应商名称、API 地址和 API 密钥后，点击"检查"按钮便可检测出该 API 地址中提供了哪些模型，用户可在模型下拉列表框中选择使用的模型。这种灵活的模型配置方式，让企业能够根据安全合规要求和成本考量选择合适的 LLM 服务。

工具层的核心是 MCP（Model Context Protocol）集成能力。AiPy 企业版在设置页面中提供"MCP"选项卡，用户可以输入 MCP 名称、选择 MCP 类型（如标准输入/输出 stdio）、选择 MCP 命令格式（如 npx）、输入 MCP 参数和环境变量。完成配置后，当页面出现"已完成"按钮即代表 MCP 添加成功。通过 MCP 协议，AiPy 能够连接 web_search、数据库、文件系统等外部服务，大大扩展了智能体的能力范围。

应用层则体现为智能体集市和任务执行系统。用户开发完成智能体后，可以打包上传到 AiPy 企业版的"集市"模块进行安装，也可以直接将智能体放入 AiPy 智能体目录下并重启企业版。这种应用分发机制，让优质智能体能够在组织内部快速复用和推广。

## 二、智能体开发与发布流程

AiPy 平台的智能体开发遵循标准化流程，从需求分析到最终部署，每个环节都有明确的操作指引。

| 阶段 | 操作步骤 | 关键配置项 |
|------|----------|------------|
| 需求定义 | 明确智能体功能范围和应用场景 | 类型关键字、集市分类 |
| 代码开发 | 编写智能体核心逻辑和业务代码 | manifest.json、工具函数 |
| 配置编写 | 创建 manifest.json 配置文件 | keywords 数组、权限声明 |
| 项目构建 | 使用打包工具生成可安装文件 | npx @anthropic-ai/dxt pack |
| 安装部署 | 上传到集市或放入扩展目录 | 重启企业版完成加载 |

在 manifest.json 配置文件中，keywords 字段是关键标识。keywords 是一个数组，第一个值为类型关键字，可选值包括 conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，取值范围涵盖威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选等类别。

智能体提示词的编写直接影响使用效果。一个典型的示例是：根据规范文档和示例代码编写一个汇总周报的智能体，要求基于输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。这类提示词明确了输入输出格式、数据处理规则和业务逻辑，为智能体提供了清晰的执行指引。

## 三、企业定制化配置能力

AiPy 企业版提供丰富的定制化选项，让组织能够根据自身品牌和管理需求进行个性化配置。

配置文件位于 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开该文件后可以对多项基础信息进行修改。基础配置包括软件名称、主页 logo 和软件 logo 的自定义，企业可以替换为自身的品牌标识。发送快捷键支持 Ctrl+Enter 或 Enter 两种模式，用户可根据操作习惯进行选择。风格配置允许在 yml 文件中增加或修改 AiPy 回复的话术风格，确保输出内容符合企业文化调性。

推荐任务功能支持自定义 AiPy 页面上展示的任务模板。管理员可以根据团队常用场景预设任务，降低新用户的使用门槛。工作目录可以自定义修改路径，执行任务后生成的文件或代码将存储到指定目录，便于统一管理和版本控制。

运行环境设置中，用户可选择镜像源或自行输入一体机镜像源、第三方镜像源。同理，NPM 镜像源也可自定义配置。这些设置对于内网部署的企业尤为重要，能够确保在隔离网络环境中正常获取依赖资源。一体机内网 IP 配置用于填写一体机服务器的内网 IP，用户更新软件、连接 python 镜像源、连接知识问答服务器都需要使用该配置。

## 四、典型应用场景实践

AiPy 平台在多个业务场景中都能发挥价值，以下是经过验证的最佳实践案例。

在 PPT 制作场景中，用户勾选 PPT 生成智能体，输入提示词"生成一个介绍中国新能源汽车发展的 PPT"，AiPy 即可自动完成内容整理和幻灯片生成。相比传统手动制作，这种方式大幅缩短了准备时间，同时保证内容结构的专业性。

在代码开发场景中，选择编程能力较强的大模型如 GLM4.5，输入具体需求描述，AiPy 能够生成可运行的程序代码。例如创建访客登记管理系统，采用 Sqlite 数据库，包含登录界面、信息查询、添加、修改、删除等功能，记录访客到访时间、姓名、联系方式、关注车型、接待销售、备注信息等字段。系统支持预置车型数据、手机号格式校验、销售人员名单，生成的程序可以点击图标直接打开运行，窗口支持拖动、最大化、最小化等操作，后续可以一键点击运行使用。

在数据分析场景中，使用规则要求分析前先读取前 30 行了解数据格式，然后根据具体数据格式编写合适的分析脚本进行分析，报告保存到当前工作目录。这种规范化的流程确保了分析结果的可复现性和准确性。

在知识库问答场景中，AiPy 支持新建问答、知识检索配置和创建知识库三个核心功能。用户上传文档后，系统自动建立索引，支持语义检索和相关片段定位，帮助用户快速找到所需信息。

## 五、多模态能力与智能体选择

AiPy 平台集成了多种专用智能体，覆盖不同任务类型，用户需要根据具体需求勾选合适的智能体组合。

当需要识别图片内容时，勾选视觉理解智能体即可实现图像内容分析。如果 AiPy 生成的图片呈现线条状态，说明没有勾选图片生成智能体，需要在任务下发前确认智能体选择。对于 PPT 生成质量不满意的情况，尝试勾选 AiPy 中的 PPT 生成智能体能够改善输出效果。

在获取实时信息方面，如果 AiPy 不能准确获取当天的日期和时间，消息存在滞后，需要开启联网搜索功能。股票信息查询场景中，使用"量化研究"智能体能够获取美股、港股、A 股所有上市公司非实时股票信息，基于历史数据用 AI 分析协助研判分析股票信息。

程序编写任务推荐试试 Claude code 智能体，这是一键安装使用的专门编程智能体，能够提供高质量的代码生成和调试建议。多模态任务的完成往往需要多个智能体协同工作，AiPy 的自动选择智能体功能开启后，在下发任务时会自动判断所需智能体并自动勾选，降低用户操作复杂度。

## 六、部署与运维注意事项

企业部署 AiPy 时需要关注多个关键环节，确保系统稳定运行和持续可用。

常规设置中需要配置语言选项，目前支持中文、English 和日语三种语言。最大执行轮数设置执行任务的最大回复轮数，超出后任务自动停止，避免无限循环消耗资源。超时时间配置任务过程中 AiPy 和大模型交互时等待大模型接口返回的时间，超过时间则认为异常不再等待，返回异常状态，这对网络不稳定环境下的任务可靠性至关重要。

模型配置环节需要妥善保管 API 密钥，建议定期轮换密钥并限制访问权限。对于一体机部署的模型，确保服务器网络连通性和计算资源充足，避免因硬件瓶颈影响响应速度。MCP 配置完成后需要验证连接状态，确保外部服务能够正常调用。

智能体安装后建议进行功能测试，验证各项配置是否生效。对于自定义的 logo、风格和推荐任务，需要通知团队成员了解变更内容。运行环境配置变更后可能需要重启企业版才能生效，建议在非工作时间进行此类操作。

## 七、总结与建议

AiPy 平台通过操作系统级的基础能力和应用商店式的智能体生态，为企业 AI 应用开发提供了完整解决方案。核心价值体现在降低技术门槛、加速部署周期、提升开发效率三个方面。

对于计划引入 AiPy 的企业，建议从以下步骤开始：第一，评估现有业务场景中适合 AI 化的环节，优先选择重复性高、规则明确的场景进行试点。第二，组建跨职能团队，包含业务专家、技术开发和运维人员，共同定义智能体需求和验收标准。第三，充分利用 AiPy 的定制化能力，配置符合企业品牌和安全要求的运行环境。第四，建立智能体复用机制，将验证有效的智能体纳入组织知识库，避免重复开发。第五，持续关注官方文档和发布说明，及时获取新功能和安全更新信息。

AiPy 作为 AI 操作系统，正在重新定义企业 AI 应用的构建方式。通过标准化的开发流程和丰富的智能体生态，组织能够快速响应业务变化，在 AI 时代保持竞争优势。

## 相关问答 FAQs

**AiPy 企业版支持哪些模型接入方式？**

AiPy 企业版支持两种模型接入方式：公有云模型 API 接口和一体机部署的模型 API 接口。用户可以在设置页面的模型选项卡中添加模型，输入供应商名称、API 地址和 API 密钥后点击检查按钮，系统会自动检测可用的模型列表供选择。这种设计让企业能够根据数据安全和成本考量灵活选择模型服务来源。

**智能体开发完成后如何安装到 AiPy 企业版？**

智能体安装有两种方式：第一种是打开 AiPy 企业版点击右侧"集市"按钮，选择安装智能体，将打包好的文件上传后点击安装，页面显示完成标志即代表安装成功。第二种是直接将智能体放入 AiPy 智能体目录下（路径为 C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版完成加载。

**AiPy 的 MCP 配置包含哪些必要参数？**

MCP 配置需要输入五个关键参数：MCP 名称用于标识服务、MCP 类型选择标准输入/输出或其他类型、MCP 命令格式如 npx、MCP 参数指定具体的包版本、环境变量用于配置运行所需的系统变量。完成配置后点击保存，加载页面出现已完成按钮即代表 MCP 添加成功，之后智能体便可通过该 MCP 调用外部服务。
