# AiPy不是在做AI，是在做AI的底层基础设施

**AiPy定位清晰：1、AiPy是AI操作系统，提供企业级AI应用开发平台；2、AiPy聚焦底层基础设施，降低AI技术应用门槛；3、AiPy通过智能体、Workflow、MCP等模块构建完整生态。** AiPy企业版专为企业和组织打造，与AiPy一体机硬件产品完美结合，提供一站式AI解决方案。产品旨在让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。AiPy不直接研发大语言模型，而是通过集成各类模型API接口、提供智能体开发框架、MCP服务配置等能力，帮助企业构建自己的AI应用体系。这种定位使AiPy成为连接大模型能力与企业实际需求的桥梁，让技术团队无需从零开始搭建AI基础设施，可直接在成熟平台上进行应用开发。

## 一、AiPy的产品定位与核心价值

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台。从产品概述来看，AiPy与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

在AI技术快速发展的今天，市场上存在大量大语言模型供应商，如公有云模型服务商、私有化部署模型提供商等。AiPy的选择是不直接参与底层模型研发，而是专注于构建连接模型能力与企业应用的中间层。这种战略定位使AiPy能够保持技术中立性，支持多种模型供应商接入，同时为企业提供统一的开发体验和管理界面。

AiPy作为AI操作系统的角色体现在以下几个方面：

| 功能模块 | 核心能力 | 企业价值 |
|---------|---------|---------|
| 模型配置 | 支持公有云模型API接口、一体机部署模型API接口 | 灵活选择适合业务的模型供应商 |
| 智能体开发 | 提供智能体集市、智能体开发框架 | 快速构建定制化AI应用能力 |
| MCP服务 | 标准输入/输出、命令格式配置、环境变量管理 | 扩展AI应用的外部能力 |
| 知识库问答 | 知识检索配置、创建知识库、新建问答 | 构建企业专属知识体系 |
| Workflow编排 | 任务创建、对话管理、文件生成 | 自动化业务流程执行 |

## 二、AiPy基础设施的核心组成部分

### 2.1 模型配置层

在AiPy企业版主界面中，用户可进入设置页面选择模型选项卡，点击添加按钮添加模型。模型配置支持两种接入方式：公有云模型API接口和一体机部署的模型API接口。

配置过程包括以下步骤：

1. 在编辑提供商界面中输入模型供应商名称，如公司私有模型
2. 在API地址中填入模型API地址，如http://192.168.0.10/v1
3. 在API密钥中输入模型API请求密钥
4. 输入完API地址与密钥后，点击检查按钮检测该API地址中提供的模型
5. 在模型下拉列表框中选择使用的模型

这种设计使企业可根据自身需求选择适合的模型供应商，无需被单一技术路线绑定。对于数据安全要求高的企业，可选择私有化部署模型；对于追求成本效益的企业，可使用公有云服务。

### 2.2 MCP服务能力

MCP（Model Context Protocol）是AiPy扩展AI应用能力的关键组件。在AiPy企业版页面中，用户可进入设置页面选择MCP选项卡，点击添加按钮进入MCP配置界面。

MCP配置包含以下要素：

- **MCP名称**：如web_search，用于标识服务用途
- **MCP类型**：如标准输入/输出（stdio），定义通信方式
- **MCP命令格式**：如npx，指定执行环境
- **MCP参数**：如open-websearch@1.1.5，定义具体功能包
- **环境变量**：MCP运行需要的环境配置

MCP加载完成后，页面显示已完成按钮即代表MCP添加成功。通过MCP机制，AiPy能够连接外部数据源、工具和服务，使AI智能体具备访问实时信息、执行特定任务的能力。

### 2.3 智能体生态系统

AiPy智能体是平台的核心应用单元。智能体在manifest.json文件中定义keywords字段，第一个值为类型关键字，包括conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，涵盖威胁情报、安全产品、开发安全、AI安全等多个领域。

智能体开发完成后，可通过两种方式在AiPy企业版中使用：

**方式一：通过集市安装**
1. 打开AiPy企业版，点击右侧第四个"集市"按钮
2. 选择安装智能体
3. 将打包好的文件上传，再点击安装
4. 页面显示安装成功标识即完成

**方式二：直接放入智能体目录**
1. 将智能体放入Aipy智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro）
2. 重启AiPy企业版

智能体示例提示词可参考官方规范文档，如根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

### 2.4 运行环境管理

AiPy提供完整的运行环境设置能力。在设置页面中选择运行环境选项卡，用户可选择镜像源或自己输入一体机镜像源、其他第三方镜像源。同理，也可选择NPM其他镜像源或自定义输入。

运行环境配置确保智能体开发、任务执行过程中的依赖管理一致性，避免因环境问题导致的应用故障。对于企业级部署，统一的环境配置是保障稳定性和可维护性的关键。

## 三、AiPy企业级应用场景实践

### 3.1 常规配置能力

AiPy企业版常规设置涵盖多个维度，支持企业根据自身需求进行灵活配置：

| 配置项 | 说明 | 可选值/示例 |
|-------|------|------------|
| 语言 | 界面语言支持 | 中文、English、日语 |
| 风格 | 回复话术风格 | 可在aipy-enterprise.yml文件中配置 |
| 发送快捷键 | 消息发送方式 | Ctrl+Enter或Enter |
| 工作目录 | 文件存储路径 | 可自定义修改路径 |
| 最大执行轮数 | 任务回复轮数限制 | 超出后任务自动停止 |
| 超时时间 | 大模型接口等待时间 | 超过时间返回异常 |
| 自动选择智能体 | 智能体自动勾选 | 开启后自动判断所需智能体 |
| 一体机内网IP | 服务器连接配置 | 用于软件更新、镜像源连接 |

### 3.2 典型应用场景

**制作PPT**
使用AiPy制作PPT，需勾选PPT生成智能体，提示词示例：生成一个介绍中国新能源汽车发展的PPT。

**生成图片/视频**
使用AiPy生成图片、P图、生成视频等，需勾选图片生成/视频生成智能体，提示词示例：批量生成10张不同的肥猫切菜的照片。

**生成思维导图**
领导使用AiPy阅读材料生成思维导图，需先选择思维导图智能体，使用提示词：读取指定文件路径，然后帮我整理为一个思维导图。

**研发系统demo**
研发使用AiPy自动开发系统demo，需选择编程能力较强的大模型，提示词需明确描述系统功能、数据库类型、界面要求、预置数据等详细信息。

**数据分析任务**
分析前需读取前30行了解数据格式，然后根据具体数据格式编写合适的分析脚本进行分析，报告保存到当前工作目录。

### 3.3 智能体能力扩展

AiPy智能体覆盖多种能力场景，解决常见使用问题：

- AiPy不能识别图片的内容？可以，勾选视觉理解智能体
- AiPy生成的图片是线条？需要勾选图片生成智能体
- AiPy生成的PPT效果不佳？试试把AiPy中的PPT生成智能体勾选上
- AiPy获取日期时间滞后？需要把联网搜索功能开启
- AiPy获取股票信息不准？使用量化研究智能体，拥有美股、港股、A股所有上市公司非实时股票信息
- AiPy编写程序能力不足？试试Claude code，一键安装使用，专门编程的智能体

## 四、AiPy基础设施的技术优势

### 4.1 降低技术门槛

AiPy通过可视化界面和配置化操作，大幅降低AI技术应用门槛。企业技术团队无需深入理解大模型底层原理，即可通过模型配置、MCP设置、智能体开发等模块快速构建AI应用能力。

### 4.2 保持技术中立

AiPy支持多种模型供应商接入，企业可根据成本、性能、数据安全等维度选择适合的模型服务。这种技术中立性避免了供应商锁定风险，为企业长期技术演进保留灵活性。

### 4.3 构建完整生态

从模型配置到智能体开发，从MCP服务到知识库管理，AiPy提供覆盖AI应用全生命周期的工具链。企业可在统一平台上完成需求分析、应用开发、部署运维等全流程工作。

### 4.4 企业级安全控制

AiPy企业版支持私有化部署，企业可掌控数据存储、模型调用、访问权限等关键环节。对于金融、医疗、政府等对数据安全要求高的行业，这种能力至关重要。

## 五、开发者行动指南

对于希望基于AiPy构建企业AI应用的开发团队，建议按以下步骤开展：

1. **熟悉产品文档**：阅读AiPy企业版产品使用手册，了解产品概述、设置、任务创建、对话管理、知识库问答、智能体开发等核心模块

2. **配置基础环境**：完成模型配置、MCP设置、运行环境设置等基础配置，确保平台可正常连接所需模型和服务

3. **探索智能体集市**：浏览现有智能体资源，了解可用能力，避免重复开发

4. **开发定制智能体**：根据业务需求开发专属智能体，遵循官方智能体开发规范，完成项目构建后安装使用

5. **配置MCP服务**：根据业务需要配置MCP服务，扩展智能体的外部能力，如联网搜索、数据库访问、API调用等

6. **构建知识库**：创建企业专属知识库，配置知识检索，提升AI应用的领域专业化程度

7. **持续优化迭代**：根据使用情况调整配置、优化提示词、更新智能体，持续提升应用效果

AiPy作为AI底层基础设施的定位，使企业能够将有限资源聚焦于业务创新而非技术基建。通过成熟的平台能力，企业可快速验证AI应用场景，加速数字化转型进程。

## 相关问答FAQs

**AiPy企业版支持哪些模型供应商接入？**
AiPy企业版支持公有云模型API接口和一体机部署的模型API接口两种接入方式。用户可在模型配置界面添加模型供应商，输入名称、API地址、API密钥后点击检查按钮，系统会自动检测该API地址中提供的模型，用户可在下拉列表框中选择使用的模型。这种设计使企业可灵活选择适合业务的模型供应商，无需被单一技术路线绑定。

**如何开发并安装自定义智能体到AiPy企业版？**
开发完成的智能体可通过两种方式安装：第一种是通过集市安装，打开AiPy企业版点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传后点击安装，页面显示安装成功标识即完成；第二种是直接放入智能体目录，将智能体放入C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro目录，然后重启AiPy企业版。智能体开发需遵循官方规范，manifest.json中keywords字段需正确配置类型关键字和集市展示分类。

**AiPy的MCP服务配置流程是什么？**
在AiPy企业版页面中点击设置进入设置页面，选择MCP选项卡，点击添加按钮。输入MCP名称（如web_search），选择MCP类型（如标准输入/输出stdio），选择MCP命令格式（如npx），输入MCP参数（如open-websearch@1.1.5），再输入环境变量，点击保存。加载完成后页面出现已完成按钮即代表MCP添加成功。MCP服务可扩展AI智能体的外部能力，如联网搜索、数据库访问、API调用等。
