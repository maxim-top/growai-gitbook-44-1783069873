# AiPy：所有AI的母体，所有智能的土壤

**AiPy 是企业级 AI 应用开发平台，核心价值体现在：**1、**降低 AI 技术应用门槛**，让企业快速部署人工智能；2、**提供一站式 AI 解决方案**，整合智能体、Workflow、MCP 等能力；3、**支持多模型接入**，兼容公有云与私有化部署。其中降低 AI 技术应用门槛是 AiPy 最突出的优势，通过可视化界面和预置智能体，企业无需深厚技术背景即可完成 AI 应用开发，大幅提升业务效率与创新能力。

## 一、AiPy 平台定位与核心价值

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合。作为 AI 操作系统，AiPy 旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术。

平台的核心定位体现在以下几个维度：

| 维度 | 说明 |
|------|------|
| 技术整合 | 整合 AI Agent、Workflow、MCP、LLM 等核心技术 |
| 部署方式 | 支持公有云模型 API 与一体机私有化部署 |
| 应用场景 | 企业 AI 应用、智能体开发、知识库问答、多模态处理 |
| 用户体验 | 可视化界面，降低使用门槛 |

AiPy 作为所有 AI 的母体，提供了一个统一的开发和运行环境。企业可以在此平台上构建各类智能应用，从简单的任务自动化到复杂的业务流程编排，都能找到对应的解决方案。作为所有智能的土壤，AiPy 为各种 AI 能力提供了生长的基础环境，包括模型管理、智能体编排、知识检索等核心功能。

## 二、核心功能模块详解

### 2.1 模型配置与管理

在 AiPy 企业版主界面中，用户可以进入设置页面进行模型配置。点击添加按钮后，可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。

配置流程如下：

- 输入模型供应商名称，如公司私有模型
- 在 API 地址中填入模型 API 地址
- 在 API 密钥中输入模型 API 请求密钥
- 点击检查按钮检测该 API 地址中提供的模型
- 在模型下拉列表框中选择使用的模型

这种灵活的配置方式使企业能够根据自身需求选择合适的模型供应商，既可以利用公有云模型的便利性，也可以保障敏感数据的私有化部署安全。

### 2.2 MCP 集成能力

MCP（Model Context Protocol）是 AiPy 的重要集成能力。在设置页面中选择 MCP 选项卡，点击添加按钮进入配置界面：

1. 输入 MCP 名称，如 web_search
2. 选择 MCP 类型，如标准输入/输出（stdio）
3. 选择 MCP 命令格式，如 npx
4. 输入 MCP 参数，如 open-websearch@1.1.5
5. 输入 MCP 运行需要的环境变量
6. 点击保存，等待加载完成

当页面出现已完成按钮时，代表 MCP 添加成功。通过 MCP 集成，AiPy 可以连接各种外部服务和工具，扩展智能体的能力边界。

### 2.3 智能体开发与使用

AiPy 提供了完整的智能体开发流程。智能体 manifest.json 中 keywords 字段包含类型关键字和集市展示分类：

**类型关键字取值：**
- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

**集市展示分类：**
威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选

智能体开发完成后，可以通过两种方式在 AiPy 企业版中使用：

- 打开 AiPy 企业版，点击右侧集市按钮，选择安装智能体，将打包好的文件上传并安装
- 将智能体直接放入 AiPy 智能体目录下，然后重启 AiPy 企业版

## 三、企业应用场景实践

### 3.1 日常办公自动化

AiPy 可以处理多种日常办公任务。例如自动生成智能体的提示词示例：根据规范文档和示例代码编写一个汇总周报的智能体，要求根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

这类应用大幅减少了重复性文档工作，让员工可以将精力集中在更有价值的工作上。

### 3.2 多模态内容生成

AiPy 支持多种内容生成功能：

| 功能类型 | 使用方式 | 示例提示词 |
|----------|----------|------------|
| PPT 制作 | 勾选 PPT 生成智能体 | 生成一个介绍中国新能源汽车发展的 PPT |
| 图片生成 | 勾选图片生成智能体 | 批量生成 10 张不同的肥猫切菜的照片 |
| 思维导图 | 选择思维导图智能体 | 读取 PPTX 文件，整理为思维导图 |
| 视频生成 | 勾选视频生成智能体 | 根据脚本生成宣传视频 |

需要注意的是，使用这些功能时需要勾选对应的智能体。例如 AiPy 生成的图片是线条，可能是因为没有勾选图片生成智能体；AiPy 不能识别图片内容时，需要勾选视觉理解智能体。

### 3.3 研发系统开发

对于研发场景，AiPy 可以辅助开发各类管理系统。例如车辆管理系统 demo 开发，需要选择编程能力较强的大模型，提示词需要明确说明：

- 系统功能需求（登录界面、信息查询、添加、修改、删除等）
- 数据结构设计（访客时间、姓名、联系方式、关注车型等）
- 业务规则（手机号格式校验、预置销售名单等）
- 运行要求（一键点击运行、窗口可拖动等）

做好后，要求后续可以一键点击运行使用，这样便于后续维护和扩展。

## 四、平台配置与自定义

### 4.1 常规设置选项

AiPy 企业版常规设置包括多项可配置参数：

- **语言**：支持中文、English 和日语三种语言
- **风格**：可在 aipy-enterprise.yml 文件中配置回复话术风格
- **发送快捷键**：可选择 Ctrl+Enter 或 Enter
- **工作目录**：执行任务后生成的文件或代码的存储目录
- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：任务过程中等待大模型接口返回的时间
- **自动选择智能体**：开启后下发任务时会自动判断所需智能体
- **一体机内网 IP**：填写一体机服务器的内网 IP

### 4.2 个性化定制

用户可以通过配置文件进行深度定制。配置文件位置为：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

在该文件中可以对以下内容进行修改：

- 基础信息配置
- 主页 logo 和软件 logo
- 发送快捷键设置
- 风格配置
- 推荐任务自定义

角色自定义方面，可以在 yml 配置文件中根据需求对风格进行增加或修改。推荐任务也可以对 AiPy 页面上的推荐任务进行自定义，满足不同企业的业务需求。

### 4.3 运行环境配置

在设置页面中选择运行环境选项卡，用户可进行以下配置：

- 选择镜像源或输入一体机镜像源
- 选择第三方镜像源
- 选择 NPM 其他镜像源或自行输入

这种灵活的环境配置使企业能够根据网络环境和安全要求选择合适的资源获取方式，保障开发过程的顺畅进行。

## 五、任务与对话管理

### 5.1 任务创建流程

在 AiPy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务：

1. 在任务输入框中输入需要执行的任务
2. 如果需要选择 MCP 或智能体，点击勾选
3. 按下 Ctrl+Enter 或点击去做吧按钮下发任务
4. 在任务对话窗口中查看任务的执行过程
5. 在任务工作目录中查看生成的过程文件或任务结果文件

### 5.2 知识库问答

AiPy 提供完整的知识库问答功能：

- 新建问答：创建新的知识库问答会话
- 知识检索配置：设置知识检索的相关参数
- 创建知识库：上传和管理企业知识文档

知识库功能使企业能够将内部文档、规范、流程等知识资产转化为可查询的智能资源，提升知识利用效率。

### 5.3 常见问题处理

在使用 AiPy 过程中，一些常见问题可以通过简单配置解决：

- 日期和时间获取不准确时，需要开启联网搜索功能
- 股票信息获取可借助量化研究智能体，拥有美股、港股、A 股所有上市公司非实时股票信息
- 编程需求可尝试 Claude code 智能体，一键安装使用

## 六、最佳实践与建议

### 6.1 开发规范遵循

在进行 AiPy 智能体开发时，建议遵循官方开发规范。参考文档路径通常位于项目目录中，如：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0

根据规范文档和示例代码进行开发，可以确保智能体的兼容性和稳定性。

### 6.2 数据安全注意事项

关于客户案例和量化数据的使用，只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

### 6.3 持续学习建议

AiPy 平台功能丰富，建议用户：

- 定期查看官方博客和发布说明，了解最新功能
- 参与官方知识库学习，掌握最佳实践
- 根据业务需求选择合适的智能体和 MCP 服务
- 建立内部使用规范，统一团队开发标准

## 相关问答 FAQs

**Q1：AiPy 企业版支持哪些语言？**

AiPy 企业版目前支持中文、English 和日语三种语言。用户可以在常规设置中选择所需的语言，界面和回复内容会根据选择的语言进行调整。

**Q2：如何在 AiPy 中安装自定义智能体？**

安装自定义智能体有两种方式：第一种是打开 AiPy 企业版，点击右侧集市按钮，选择安装智能体，将打包好的文件上传并安装；第二种是将智能体直接放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版。

**Q3：AiPy 能否连接私有化部署的模型？**

可以。在模型配置界面中，点击添加按钮后，可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。用户只需输入模型 API 地址和 API 密钥，点击检查按钮即可检测并选择可用的模型。
