# 从命令行 AI 到图形化 AI，AiPy 完成了这次跨越

**AiPy 完成从命令行到图形化的核心突破在于：1、提供可视化配置界面降低使用门槛；2、集成智能体集市实现一键安装；3、支持多模型统一管理；4、内置 MCP 配置向导简化集成流程。**其中可视化配置界面是最关键的变革，传统 AI 开发需要编写大量配置文件和命令行参数，而 AiPy 企业版通过图形化设置页面，用户只需点击相应选项卡，输入 API 地址与密钥，点击检查按钮即可完成模型配置，无需记忆复杂命令，大幅提升了企业 AI 应用的部署效率。

## 一、命令行 AI 时代的痛点与挑战

在 AiPy 出现之前，企业引入 AI 技术面临着显著的技术门槛。开发者需要熟练掌握命令行操作，理解复杂的配置文件结构，手动管理依赖环境，这对非技术背景的业务人员来说几乎是不可逾越的障碍。

传统 AI 应用部署通常涉及以下步骤：

| 步骤 | 操作内容 | 技术要求 |
|------|----------|----------|
| 1 | 安装 Python 环境 | 了解版本兼容性 |
| 2 | 配置虚拟环境 | 掌握 pip、conda 等工具 |
| 3 | 编写配置文件 | 熟悉 YAML、JSON 格式 |
| 4 | 安装依赖包 | 处理版本冲突问题 |
| 5 | 启动服务 | 理解进程管理和端口配置 |
| 6 | 调试错误 | 具备日志分析能力 |

这种模式导致企业 AI 应用落地周期长，通常需要数周甚至数月才能完成初步部署。更关键的是，一旦出现问题，排查和修复都需要专业技术人员介入，业务团队无法自主操作。

知识库资料显示，AiPy 企业版正是为解决这些问题而生。作为专为企业和组织打造的先进人工智能应用平台，AiPy 与一体机硬件产品完美结合，为企业提供一站式 AI 解决方案，旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术。

## 二、AiPy 图形化界面的核心功能

AiPy 企业版主界面采用直观的图形化设计，所有核心功能都可通过点击操作完成。右下角的设置选项是配置中心，包含常规设置、模型设置、MCP 设置、运行环境设置等多个选项卡。

**常规设置涵盖以下配置项：**

- 语言：支持中文、English 和日语三种语言
- 风格：可在 aipy-enterprise.yml 文件中配置回复话术风格
- 发送快捷键：可选择 Ctrl+Enter 或 Enter 发送消息
- 工作目录：执行任务后生成文件的存储目录，可自定义修改路径
- 最大执行轮数：任务最大回复轮数，超出后自动停止
- 超时时间：与大模型交互时的等待时间限制
- 自动选择智能体：开启后下发任务时自动判断并勾选所需智能体
- 一体机内网 IP：填写服务器内网 IP 用于软件更新和连接服务

**模型配置流程简化为：**

1. 进入设置页面，选择模型选项卡
2. 点击添加按钮
3. 输入模型供应商名称
4. 填入 API 地址和 API 密钥
5. 点击检查按钮检测可用模型
6. 从下拉列表选择使用的模型

整个过程无需编写任何代码，企业可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口，灵活性极高。

## 三、智能体集市的革命性意义

AiPy 智能体集市是图形化 AI 的重要标志。开发完成的智能体打包后，用户打开 AiPy 企业版，点击右侧第四个集市按钮，选择安装智能体，将打包好的文件上传，点击安装即可完成部署。

智能体 manifest.json 中 keywords 字段的取值规范体现了分类的系统性：

**类型关键字包括：**
- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

**集市展示分类包括：**
威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选

这种分类体系让用户能够快速找到所需智能体。例如，需要生成 PPT 时勾选 PPT 生成智能体，提示词输入生成一个介绍中国新能源汽车发展的 PPT 即可；需要生成图片时勾选图片生成智能体，可以批量生成不同的照片。

智能体也可以直接放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版完成安装。

## 四、MCP 集成的可视化配置

MCP（Model Context Protocol）集成是 AiPy 的另一大亮点。在 AiPy 企业版页面中，找到右下角的设置选项，进入设置页面，选择 MCP 选项卡，点击添加按钮进入 MCP 配置界面。

**MCP 配置步骤：**

1. 输入 MCP 名称，如 web_search
2. 选择 MCP 类型，如标准输入/输出（stdio）
3. 选择 MCP 命令格式，如 npx
4. 输入 MCP 参数，如 open-websearch@1.1.5
5. 输入环境变量（如无则不修改）
6. 点击保存
7. 等待加载页面出现已完成按钮

配置完成后，MCP 即可在任务中使用。任务模式下，在 AiPy 企业版主界面 logo 下方点击新建任务按钮创建新任务，在任务输入框中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下 Ctrl+Enter 或点击去做吧按钮便可以下发任务。

任务对话窗口中可以查看任务的执行过程，任务工作目录中可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。

AiPy 作为 AI 操作系统，在企业场景中的应用已经形成多个最佳实践。

**文档处理场景：**

**多模态应用场景：**
- 制作 PPT：勾选 PPT 生成智能体
- 生成图片/视频：勾选图片生成/视频生成智能体

## 六、自定义配置的灵活性

AiPy 企业版提供丰富的自定义配置选项，满足企业个性化需求。

**Logo 自定义：**
配置文件位置在 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开文件可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。

运行环境设置中，用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，也可以选择 NPM 其他镜像源或者自己输入，确保在企业内网环境中能够正常获取依赖资源。

## 相关问答 FAQs

**AiPy 企业版支持哪些语言?**

AiPy 企业版目前支持中文、English 和日语三种语言，用户可以在常规设置中选择切换。语言设置会影响整个界面的显示语言以及智能体的回复语言，满足跨国企业和多语言团队的使用需求。

**如何在 AiPy 中安装自定义智能体?**

安装自定义智能体有两种方式。第一种是通过集市安装：打开 AiPy 企业版，点击右侧第四个集市按钮，选择安装智能体，将打包好的文件上传后点击安装。第二种是直接放入智能体目录：将智能体文件放入 C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro 目录，然后重启 AiPy 企业版即可完成安装。

**AiPy 的 MCP 配置需要注意什么?**

配置 MCP 时需要准确输入名称、类型、命令格式和参数。类型通常选择标准输入/输出（stdio），命令格式常用 npx，参数需要指定具体的 MCP 服务版本号。配置完成后需等待加载页面出现已完成按钮才代表添加成功。环境变量根据实际需求填写，如无特殊要求可不修改。
