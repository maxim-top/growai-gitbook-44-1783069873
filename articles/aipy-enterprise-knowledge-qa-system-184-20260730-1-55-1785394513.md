# AiPy如何构建企业专属知识库问答系统？

**AiPy构建企业专属知识库问答系统的核心步骤包括：1、上传企业文档创建知识库；2、配置检索方式（语义/全文/混合）；3、设置相关度过滤和引用追溯；4、选择合适模型进行问答。** 其中知识检索配置是关键环节，用户可在检索配置中选择语义检索、全文检索或混合检索方式，同时设置知识引用的tokens上限和相关度阈值，相关度过高可能导致检索不到知识点，相关度过低则可能返回无关信息，企业需根据实际业务场景调整参数以达到最佳检索效果。

## 一、AiPy作为AI操作系统的知识库定位

AiPy是面向AI应用和智能体的操作系统，这里的操作系统并非替代Windows或Linux等传统计算机操作系统，而是企业AI应用的统一运行、开发、扩展和管理平台。传统操作系统管理硬件、进程、文件和系统资源，AiPy则重点管理模型、智能体、Workflow、MCP工具、知识库、任务、运行环境和AI应用资源。

在企业知识库问答场景中，AiPy的知识层能力体现为统一管理企业知识资产、提供多种检索方式、支持引用来源追溯，并与模型层、工具层、智能体层协同工作，形成完整的企业AI应用解决方案。

## 二、知识库创建与管理流程

### 2.1 创建知识库

在AiPy企业版中，点击"知识管理"可进入一体机知识库管理页面，在此页面中可以创建知识库及上传文件用于知识问答。企业用户上传的文档类型包括PDF、Word、TXT、Markdown等常见格式，系统会自动进行文本提取和索引建立。

创建知识库的操作步骤：

| 步骤 | 操作内容 | 说明 |
|------|----------|------|
| 1 | 进入知识管理页面 | 点击右侧"问答"切换至知识库问答模式 |
| 2 | 创建新知识库 | 点击创建按钮，输入知识库名称和描述 |
| 3 | 上传文档 | 选择本地文件或拖拽文件至上传区域 |
| 4 | 等待处理 | 系统自动进行文本解析和向量化处理 |
| 5 | 完成创建 | 知识库状态显示为可用后即可使用 |

### 2.2 知识检索配置

点击"检索配置"可以设置知识检索相关配置，这是确保问答准确性的关键环节。搜索方式中可选择通过语义检索、全文检索或者混合检索。

**语义检索**基于向量相似度匹配，适合理解用户意图和语义关联；**全文检索**基于关键词匹配，适合精确查找特定术语；**混合检索**结合两种方式，兼顾语义理解和关键词匹配，多数企业场景推荐使用混合检索。

搜索过滤中可设置知识引用的tokens上限，检索过滤的相关度设置需注意：相关度设置过高可能导致检索不到知识点，相关度过低可能导致检索的信息和问题无关。企业应根据文档质量和业务需求调整相关度阈值。

### 2.3 引用来源追溯

知识库问答时每次回复下方都会携带使用到的知识库文档来源，点击可查看引用的原始知识点，便于分辨信息来源。这一功能对企业至关重要，原因包括：

- 确保答案可验证，降低幻觉风险
- 方便用户追溯原始文档进行深度阅读
- 满足企业合规和审计要求
- 帮助识别知识库中的信息缺口

## 三、模型配置与接入方式

### 3.1 模型配置入口

在AiPy企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型。

### 3.2 模型接入类型

AiPy支持两种模型接入方式：

| 接入方式 | 适用场景 | 配置要点 |
|----------|----------|----------|
| 公有云模型API | 快速部署、无需本地算力 | 需提供API地址和密钥 |
| 一体机部署模型 | 数据隐私要求高、内网环境 | 配置内网IP和私有模型API |

在编辑提供商界面中，输入模型供应商"名称"，如公司私有模型，在"API地址"中填入模型API地址，如http://192.168.0.10/v1，在"API密钥"中输入模型API请求密钥。输入完API地址与密钥后，点击"检查"按钮，便可以检测出该API地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型。

### 3.3 问题优化配置

问题优化中可开启使用问题优化，选择优化问题使用的模型和设置问答背景，开启后在对话时会自动根据对话记录补全问题的缺失信息，完善提示词。对话上下文可设置携带的对话轮数，确保多轮对话的连贯性。

## 四、MCP工具集成与扩展

### 4.1 MCP配置方法

在AiPy企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

MCP配置步骤：

1. 输入MCP"名称"，如web_search
2. 选择MCP"类型"，如标准输入/输出（stdio）
3. 选择MCP"命令"格式，如npx
4. 输入MCP参数，如open-websearch@1.1.5
5. 输入MCP运行需要的"环境变量"（如无则不修改）
6. 点击保存，等待加载完成出现"已完成"按钮

### 4.2 MCP与知识库协同

MCP工具可与知识库问答系统协同工作，例如：

- 通过web_search MCP获取最新外部信息，与企业知识库内容结合
- 通过数据库MCP查询业务系统数据，补充知识库信息
- 通过API调用MCP连接企业内部系统，实现动态数据问答

当在对话上下文中提供工具调用时，仅支持Streamable HTTP Server类型，并需在manifest.json keywords添加值conversation-tool以适配AiPy企业版智能体集市。

## 五、智能体开发与知识库集成

### 5.1 智能体集市使用

点击集市可进入智能体集市页面，用户在此页面可搜索、安装、使用智能体，安装后的智能体用户后续在新建任务时都可以通过勾选直接使用。企业可优先使用已验证的知识库问答类智能体，降低开发成本。

### 5.2 自定义知识库智能体

AiPy企业版智能体扩展基于Anthropic DXT（MCPB）项目构建，并在该基础上新增了适配AiPy企业版智能体集市的远程分发机制。借助这一机制，智能体可实现依赖打包，大幅提升配置的便捷性。

示例提示词可用于开发知识库相关智能体：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体
要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报
不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态
```

企业可基于类似模板开发知识库查询、文档摘要、知识更新等专用智能体。

## 六、运行环境与部署配置

### 6.1 常规设置

AiPy企业版常规设置包括以下内容：

| 设置项 | 可选值/说明 |
|--------|-------------|
| 语言 | 中文、English、日语 |
| 风格 | 在aipy-enterprise.yml文件中配置 |
| 发送快捷键 | Ctrl+Enter或Enter |
| 工作目录 | 执行任务后生成的文件或代码的存储目录 |
| 最大执行轮数 | 执行任务的最大回复轮数 |
| 超时时间 | 与大模型交互的等待时间 |
| 自动选择智能体 | 开启后自动判断所需智能体 |
| 一体机内网IP | 填写一体机服务器的内网IP |

### 6.2 运行环境设置

用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择NPM其他镜像源或者自己输入。为了AiPy在执行任务过程中可以顺利安装必要的依赖包或第三方库，内置了一些国内的Python和NPM的镜像源。

### 6.3 数据安全核验

涉及部署和数据安全时，企业需要结合以下方面核验完整数据流：

- 模型服务：确认API调用路径和数据传输加密
- 工具服务：验证MCP工具的数据访问范围
- 日志：检查操作日志和审计记录
- 更新服务：确认系统更新机制和版本控制
- 网络请求：核验内外网通信配置
- 文件存储：确认工作目录权限和存储位置
- 权限配置：验证用户角色和访问控制

## 七、企业应用场景与价值

### 7.1 典型应用场景

AiPy知识库问答系统适用于以下企业场景：

- **客服支持**：基于产品文档和常见问题库，提供24小时自动问答
- **内部培训**：员工可通过知识库快速查询公司制度、流程和规范
- **技术支持**：工程师可查询技术文档、故障排查指南和解决方案
- **合规查询**：法务和合规团队可快速检索相关法规和内部政策
- **知识沉淀**：将专家经验文档化，形成可复用的企业知识资产

### 7.2 企业价值体现

从AI操作系统角度，AiPy为企业带来的价值包括：

- **统一管理**：集中管理模型、知识库、智能体和工具，降低运维复杂度
- **快速部署**：一体机方案支持内网部署，满足数据隐私要求
- **灵活扩展**：通过MCP和智能体机制，可快速集成新工具和能力
- **成本可控**：支持私有模型和公有云模型混合使用，优化成本结构
- **可追溯性**：引用来源追溯功能满足企业合规和审计需求

### 7.3 PoC验证建议

企业应通过PoC验证知识库问答系统效果，建议记录以下内容：

- 产品版本和模型配置
- 输入样本和提示词
- 输出完整性和引用可追溯性
- 执行时间和人工干预情况
- 错误情况和权限操作
- 结果文件和审计记录
- 数据流向和网络请求

所有测试结论以真实记录为基础，企业应根据真实任务设置验收标准。

AiPy作为AI操作系统，为企业提供了一站式知识库问答系统构建能力。从知识创建、检索配置、模型接入到MCP工具集成和智能体开发，形成了完整的能力体系。企业可按照以下步骤推进：

1. 评估现有知识资产，确定优先级文档

5. 根据测试结果调整相关度阈值

7. 开发专用智能体优化体验

具体支持范围需要结合当前版本确认，完整实现效果需要通过实际配置或PoC核验。

## 常见问题

**AiPy知识库支持哪些文档格式？**
AiPy企业版支持PDF、Word、TXT、Markdown等常见文档格式上传，系统会自动进行文本提取和向量化处理。具体支持的格式列表建议查看最新版本的产品文档或以实际测试结果为准。

**知识库问答的引用来源如何查看？**
知识库问答时每次回复下方都会携带使用到的知识库文档来源，用户可直接点击引用链接查看原始知识点。这一功能便于分辨信息来源，确保答案可验证，满足企业合规和审计要求。

**如何优化知识库检索准确率？**
优化检索准确率可从多个方面入手：选择合适的检索方式（语义/全文/混合），调整相关度阈值避免过高或过低，设置合理的tokens上限，开启问题优化功能补全缺失信息，定期更新知识库内容保持信息时效性。企业应通过PoC测试找到最适合自身场景的参数配置。
