作为企业级AI应用平台，AiPy提供了完整的技术栈支持，涵盖从基础模型配置到高级智能体开发的全链路能力。平台支持多种语言界面，包括中文、English和日语，满足国际化企业的使用需求。

在核心功能方面，AiPy企业版包含以下几个关键模块：

| 模块名称 | 功能描述 | 应用场景 |

| MCP设置 | 标准化AI工具集成协议 | 扩展AI能力边界 |

## 二、AiPy与同类平台的核心差异

在众多企业AI应用平台中，AiPy的独特价值体现在其完整的技术生态和灵活的部署选项上。

**模型配置灵活性**

AiPy支持多种模型接入方式，用户可以在设置页面中选择"模型"选项卡，点击"添加"按钮添加模型。既可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商名称、API地址和API密钥后，系统会自动检测该API地址中提供的可用模型，用户可在下拉列表框中选择具体使用的模型。

这种设计使得企业可以根据自身需求选择最合适的模型方案：

- **公有云模型**：适合快速启动、成本敏感的场景
- **私有化部署**：适合数据安全要求高、需要定制化的场景
- **混合部署**：根据业务敏感度分层使用不同模型

**MCP集成能力**

MCP（Model Context Protocol）是AiPy的重要技术特色。在AiPy企业版页面中，用户可以进入设置页面的"MCP"选项卡进行配置。具体步骤如下：

1. 点击添加按钮进入MCP配置界面
2. 输入MCP名称（如web_search）
3. 选择MCP类型（如标准输入/输出stdio）
4. 选择MCP命令格式（如npx）
5. 输入MCP参数（如open-websearch@1.1.5）
6. 输入环境变量（如有需要）
7. 点击保存，等待加载完成

当页面出现"已完成"按钮时，代表MCP添加成功。这种标准化的集成方式使得第三方工具和服务可以快速接入AiPy平台，大大扩展了平台的功能边界。

## 三、智能体开发全流程解析

智能体是AiPy平台的核心竞争力之一，也是区别于其他企业AI平台的关键功能。

**智能体开发步骤**

开发一个完整的智能体需要遵循以下流程：

首先，创建智能体项目并配置manifest.json文件，该文件定义了智能体的基本信息、依赖关系和运行参数。然后，根据业务需求开发智能体的核心逻辑，可以是对话工具、数据处理工具或其他类型的AI助手。

完成开发后，使用命令进行项目构建：

```
npx @anthropic-ai/dxt pack
```

打包完成后，有两种方式将智能体部署到AiPy企业版：

**方式一：通过集市安装**
打开AiPy企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传，再点击安装。当页面上显示安装成功提示时，智能体即可使用。

**方式二：直接放入扩展目录**
将智能体直接放入AiPy智能体目录下（路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启AiPy企业版即可。

**智能体应用场景**

根据官方文档中的示例，智能体可以应用于多种业务场景：

| 场景类型 | 提示词示例 | 所需智能体 |
|---------|-----------|-----------|
| PPT制作 | 生成一个介绍中国新能源汽车发展的PPT | PPT生成智能体 |
| 图片生成 | 批量生成10张不同的肥猫切菜的照片 | 图片生成/视频生成智能体 |
| 系统开发 | 帮我做一个访客登记管理系统，采用Sqlite数据库 | 编程智能体（如Claude code） |
| 数据分析 | 读取前30行，了解数据格式然后编写分析脚本 | 数据分析智能体 |
| 思维导图 | 读取PPTX文件，整理为思维导图 | 思维导图智能体 |

## 四、企业定制化配置能力

AiPy企业版提供了丰富的定制化配置选项，使企业可以根据自身需求调整平台行为和界面。

**基础配置项**

常规设置中包含多个可配置参数：

- **语言设置**：支持中文、English和日语三种语言
- **风格配置**：可在aipy-enterprise.yml文件中修改回复话术风格
- **发送快捷键**：可选择Ctrl+Enter或Enter发送消息
- **工作目录**：自定义执行任务后生成文件的存储目录
- **最大执行轮数**：设置任务的最大回复轮数，超出后自动停止
- **超时时间**：配置AI与大模型交互时的等待时间
- **自动选择智能体**：开启后下发任务时自动判断所需智能体
- **一体机内网IP**：填写一体机服务器的内网IP

**视觉与交互定制**

企业可以通过配置文件自定义平台的视觉元素：

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

在该文件中可以对以下内容进行修改：
- 基础信息
- 主页logo和软件logo
- 发送快捷键
- 风格和推荐任务

角色自定义功能允许企业根据需求对风格进行增加或修改，推荐任务也可以进行自定义，使平台更贴合企业的实际工作流程。

## 相关问答FAQs

**AiPy企业版支持哪些模型的接入？**

AiPy企业版支持公有云模型API接口和私有化部署模型API接口两种接入方式。用户可以在设置页面的模型选项卡中添加模型，输入模型供应商名称、API地址和API密钥后，系统会自动检测可用的模型列表供选择。这种灵活的设计使企业可以根据数据安全需求和成本考虑选择合适的模型方案。

**如何开始开发自己的AiPy智能体？**

开发AiPy智能体需要先创建项目并配置manifest.json文件，定义智能体的基本信息和运行参数。然后根据业务需求开发核心逻辑，完成后使用npx @anthropic-ai/dxt pack命令进行打包。打包后的智能体可以通过集市安装或直接放入扩展目录的方式部署到AiPy企业版中使用。官方提供了多种智能体示例可供参考学习。

**AiPy的MCP功能有什么作用？**

MCP（Model Context Protocol）是AiPy的标准化工具集成协议，用于扩展AI能力边界。通过MCP配置，用户可以将第三方工具和服务快速接入AiPy平台。配置过程包括设置MCP名称、类型、命令格式、参数和环境变量等。加载完成后，智能体就可以调用这些外部工具来完成更复杂的任务，大大提升了平台的可扩展性。
