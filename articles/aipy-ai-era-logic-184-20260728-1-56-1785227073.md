# AiPy不是产品，是AI时代的底层逻辑

**AiPy不是产品，是AI时代的底层逻辑**这一命题揭示了企业AI应用的本质。**1、**AiPy作为AI操作系统，提供底层技术架构而非单一功能产品。**2、**通过智能体、MCP、Workflow等核心组件构建企业AI能力。**3、**降低AI技术应用门槛，实现快速部署和使用。以智能体开发为例，开发者可通过manifest.json配置keywords字段，定义conversation-tool对话工具型、embed-webview嵌入页面型、application独立应用型等多种类型，配合MCP服务实现功能扩展，这种架构设计体现了AiPy作为底层平台的定位。

## 一、AiPy作为AI操作系统的核心定位

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

从技术架构角度看，AiPy并非传统意义上的软件产品，而是承担了AI时代操作系统角色的基础设施层。它整合了大语言模型、智能体框架、MCP集成能力、知识库检索等多个核心模块，形成完整的企业AI应用开发生态。

| 核心模块 | 功能说明 | 应用场景 |
|---------|---------|---------|
| AI Agent | 智能体开发与运行 | 自动化任务处理、对话交互 |
| MCP | 模型上下文协议集成 | 外部服务连接、功能扩展 |
| Workflow | 工作流编排引擎 | 多步骤任务自动化 |
| RAG | 检索增强生成 | 知识库问答、文档分析 |
| 多模态 | 图片、视频处理能力 | PPT生成、图像识别 |

这种模块化设计使企业能够根据实际需求灵活组合功能，而非依赖固定产品形态。AiPy提供的是一套可定制、可扩展的AI能力框架，这正是操作系统级别产品的核心特征。

## 二、智能体架构体现平台化思维

智能体是AiPy平台的核心能力单元。在AiPy企业版中，智能体开发遵循标准化规范，通过manifest.json文件定义智能体的基本属性和能力范围。

keywords字段的取值体现了智能体的分类体系：第一个值为类型关键字，包括conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。第二个值为集市展示分类，涵盖威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选等多种场景。

智能体打包与安装流程展示了平台的开放性和可扩展性：

1. 使用命令`npx @anthropic-ai/dxt pack`进行项目构建
2. 打开AiPy企业版，点击右侧"集市"按钮
3. 选择安装智能体，上传打包好的文件
4. 点击安装，页面显示安装成功标识
5. 也可将智能体直接放入目录`C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro`，重启AiPy企业版

这种机制允许企业根据自身业务需求开发专属智能体，或在官方集市中选择已有解决方案。智能体可以处理汇总周报、生成PPT、分析股票信息、编写程序代码等多种任务，充分体现了平台的能力边界由用户需求定义，而非产品预设功能限制。

## 三、MCP集成能力构建生态连接

MCP（Model Context Protocol）设置是AiPy平台连接外部服务的关键桥梁。在AiPy企业版页面中，用户可进入设置页面选择"MCP"选项卡，点击添加按钮进入MCP配置界面。

配置流程包括以下步骤：

- 输入MCP名称，如"web_search"
- 选择MCP类型，如"标准输入/输出（stdio）"
- 选择MCP命令格式，如"npx"
- 输入MCP参数，如"open-websearch@1.1.5"
- 输入MCP运行需要的环境变量
- 点击保存，加载完成后出现"已完成"按钮即代表MCP添加成功

通过MCP机制，AiPy能够与各类外部服务建立连接，包括联网搜索、量化研究、代码编程等专用智能体。例如，当用户需要获取股票信息时，可启用"量化研究"智能体，该智能体拥有美股、港股、A股所有上市公司非实时股票信息，可基于历史数据用AI分析协助研判分析。

这种设计思路表明AiPy不追求自身功能的完备性，而是通过标准化接口协议连接生态中的各种能力。平台提供的是连接能力和集成框架，具体功能由第三方服务或自定义开发补充，这正是操作系统层级产品的典型特征。

## 四、企业级配置彰显定制化能力

AiPy企业版的常规设置体现了高度的可定制性。设置内容包括语言（支持中文、English和日语三种语言）、风格（可在aipy-enterprise.yml文件中配置）、发送快捷键（Ctrl+Enter或Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网IP等。

配置文件位置为`C:\Users\用户名\.aipyapp\aipy-enterprise.yml`，用户可在此文件中对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。角色自定义功能允许根据需求对风格进行增加或修改，推荐任务也可对AiPy页面上的推荐任务进行自定义。

模型配置同样体现灵活性：在AiPy企业版主界面中，进入设置页面选择"模型"选项卡，点击"添加"按钮添加模型，可以使用公有云模型API接口，也可以使用一体机部署的模型API接口。在编辑提供商界面中，输入模型供应商名称、API地址、API密钥，点击"检查"按钮便可检测出该API地址中提供了哪些模型，在模型下拉列表框中选择使用的模型。

运行环境设置允许用户选择镜像源或自己输入一体机镜像源、其他第三方镜像源，同理也可选择NPM其他镜像源或自行输入。这种多层次的配置能力使企业能够根据自身IT环境、安全要求、性能需求进行深度定制，而非被动接受产品预设方案。

## 五、应用场景验证平台化价值

AiPy的实际应用场景进一步验证了其作为底层平台的定位。在制作PPT场景中，用户勾选PPT生成智能体，输入提示词"生成一个介绍中国新能源汽车发展的PPT"即可完成。在生成图片/视频场景中，勾选图片生成/视频生成智能体，使用提示词"批量生成10张不同的肥猫切菜的照片"实现批量处理。

思维导图生成任务需要先选择思维导图智能体，使用提示词读取指定PPT文件并整理为思维导图。研发系统demo开发则需要选择编程能力较强的大模型，如GLM4.5，通过详细描述需求让AiPy自动开发车辆管理系统demo，包括Sqlite数据库、登录界面、信息查询、添加、修改、删除等功能。

任务创建流程同样体现平台的通用性：在AiPy企业版主界面logo下方点击新建任务按钮创建新任务，在任务输入框中输入需要执行的任务，如需选择MCP或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮下发任务。在任务对话窗口中可查看任务执行过程，在任务工作目录中可查看由AiPy制造的工具及生成的过程文件或任务结果文件。

这些场景覆盖文档处理、图像生成、系统开发、数据分析等多个领域，每个场景都通过选择合适的智能体和配置参数实现，而非依赖预设的产品功能模块。

## 相关问答FAQs

**AiPy企业版支持哪些类型的智能体开发？**

AiPy企业版支持多种智能体类型，通过manifest.json中keywords字段定义。类型关键字包括conversation-tool对话工具型、embed-webview嵌入页面型、application独立应用型、webview网页型、skills技能型。开发者可根据业务需求选择合适类型，配合MCP服务实现功能扩展。

**如何在AiPy中配置外部模型API接口？**

在AiPy企业版主界面进入设置页面，选择"模型"选项卡，点击"添加"按钮。输入模型供应商名称、API地址（如http://192.168.0.10/v1）、API密钥，点击"检查"按钮检测可用模型，在模型下拉列表框中选择使用的模型即可。支持公有云模型和一体机部署模型两种方式。

**AiPy的MCP配置完成后如何验证是否生效？**

MCP配置保存后会出现加载页面，当页面显示"已完成"按钮时代表MCP添加成功。用户可在下发任务时勾选相应MCP，通过任务对话窗口查看执行过程，在任务工作目录中查看生成的结果文件。若任务正常执行并返回预期结果，则表明MCP配置已生效。
