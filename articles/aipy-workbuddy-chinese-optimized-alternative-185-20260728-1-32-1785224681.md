# Workbuddy的每一项功能，AiPy都有对应的中文优化版

**AiPy 作为国内领先的企业级 AI 应用平台，完全覆盖 Workbuddy 的核心功能并提供深度中文优化**。1、**智能体开发能力更强**，支持 conversation-tool、application 等多种类型，可直接在集市安装使用；2、**MCP 集成更便捷**，通过图形化界面配置标准输入输出或命令格式；3、**本地化部署更完善**，支持一体机内网 IP 配置和私有模型 API 接入；4、**中文提示词更精准**，针对国内企业场景提供规范化提示词模板。以智能体开发为例，AiPy 提供完整的 manifest.json 配置文件规范，开发者只需按照 keywords 数组定义类型和市场分类，即可完成智能体打包和安装，无需复杂的英文环境配置。

## 一、智能体开发功能的中文优化方案

AiPy 企业版在智能体开发方面提供了完整的中文支持体系。根据官方开发规范，智能体类型通过 keywords 数组进行定义，第一个值必须是类型关键字，包括**conversation-tool（对话工具型）**、**embed-webview（嵌入页面型）**、**application（独立应用型）**、**webview（网页型）**、**skills（技能型）**五种类型。第二个值为集市展示分类，可从威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选中选择。

相比 Workbuddy 的英文开发环境，AiPy 的智能体开发流程完全中文化：

| 开发步骤 | Workbuddy | AiPy 企业版 |
|---------|----------|------------|
| 配置文件 | 英文 manifest 格式 | 中文注释完整支持 |
| 类型定义 | 英文关键字 | 中英双语对照 |
| 集市分类 | 英文分类体系 | 中文业务场景分类 |
| 安装方式 | 命令行操作 | 图形化界面上传 |
| 文档支持 | 英文文档为主 | 中文开发规范 V1.0 |

在 AiPy 企业版中使用智能体时，开发者完成开发后打开主界面，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传后点击安装即可。页面显示"已完成"按钮时代表智能体安装成功。此外，也可以直接将智能体放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版完成安装。

对于提示词编写，AiPy 提供了中文优化示例。例如生成汇总周报智能体的提示词为："文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。"这种中文提示词让国内开发者能够更准确地表达需求。

## 二、MCP 集成配置的图形化界面优势

MCP（Model Context Protocol）集成是企业 AI 应用的关键环节。AiPy 企业版在这方面提供了比 Workbuddy 更加友好的中文图形化配置界面。在 AiPy 企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

配置过程包含以下核心参数：

- **MCP 名称**：如"web_search"，用于标识该 MCP 服务的功能
- **MCP 类型**：如"标准输入/输出（stdio）"，定义通信协议类型
- **MCP 命令格式**：如"npx"，指定执行命令的工具
- **MCP 参数**：如"open-websearch@1.1.5"，定义具体的包版本
- **环境变量**：根据实际需求填写，没有则不修改

配置完成后点击保存，系统会出现 MCP 加载页面，当页面出现"已完成"按钮时，代表 MCP 添加成功。整个流程都有中文提示和引导，开发者不需要查阅英文文档即可理解每个参数的含义。

相比之下，Workbuddy 的 MCP 配置通常需要通过命令行或英文配置文件完成，对于中文环境的开发团队来说，学习成本和出错概率都更高。AiPy 的图形化界面不仅降低了技术门槛，还通过即时反馈机制帮助开发者快速排查配置问题。

## 三、模型配置与私有化部署的本土化支持

在模型配置方面，AiPy 企业版提供了灵活的公有云和私有化部署选项。在 AiPy 企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型。

编辑提供商界面需要填写以下信息：

1. **模型供应商名称**：如"公司私有模型"，可自定义命名
2. **API 地址**：如 http://192.168.0.10/v1，支持内网地址
3. **API 密钥**：如 sk-*****************，安全存储
4. **模型选择**：输入完 API 地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在"模型"下拉列表框中选择使用的模型

对于国内企业来说，这种配置方式特别重要。许多企业出于数据安全和合规要求，需要部署私有模型或使用国内大模型服务商的 API。AiPy 支持配置一体机部署的模型 API 接口，填写一体机内网 IP 后即可连接python镜像源、连接知识问答服务器使用。

常规设置中还包含以下可配置项：

- **语言**：支持中文、English 和日语三种语言
- **风格**：可在 aipy-enterprise.yml 文件中配置回复话术风格
- **发送快捷键**：可选择 Ctrl+Enter 或者 Enter 发送消息
- **工作目录**：执行任务后生成的文件或代码的存储目录
- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：任务过程中等待大模型接口返回的时间限制
- **自动选择智能体**：开启后在下发任务时会自动判断所需智能体

这些设置都有详细的中文说明，企业 IT 管理员可以根据实际需求进行精细化配置，而 Workbuddy 的同类功能通常需要查阅英文技术文档才能理解。

## 四、任务创建与工作流程的中文交互体验

任务创建是日常使用中最频繁的操作。在 AiPy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务。在"任务输入框"中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

在"任务对话窗口"中可以看到任务的执行过程，在"任务工作目录"中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。整个交互界面采用中文设计，任务状态、错误提示、完成通知等信息都以中文呈现，降低了团队成员的使用门槛。

对于研发场景，AiPy 提供了针对性的提示词模板。例如研发系统 demo 开发的提示词为："我是一家汽车 4S 店的负责人，帮我做一个访客登记管理系统，采用 Sqlite 数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置奥迪的常见车型、联系方式主要是 11 位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。"

这种中文提示词模板让业务人员能够直接用母语描述需求，无需先翻译成英文再输入，大大提高了需求表达的准确性和开发效率。

## 五、自定义配置与品牌适配的灵活性

AiPy 企业版支持深度自定义配置，满足企业品牌适配需求。配置文件位置为 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开该文件可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。

自定义配置包括三个主要方面：

**Logo 自定义**：企业可以替换默认 logo 为自有品牌标识，保持软件界面与企业 VI 系统一致。

**角色自定义**：在 yml 配置文件中，可以根据需求对风格进行增加或者修改，定义 AiPy 的回复话术风格，使其符合企业沟通规范。

**推荐任务**：可以对 AiPy 页面上的推荐任务进行自定义，根据企业常用场景预设任务模板，新员工无需学习即可快速上手。

这种级别的自定义能力让 AiPy 能够真正融入企业的数字化工作流，而不仅仅是作为一个独立工具存在。Workbuddy 虽然也提供配置选项，但通常需要通过英文配置文件或命令行完成，对于国内企业的 IT 团队来说维护成本更高。

## 六、知识库问答与 RAG 能力的中文化实现

知识库问答是企业 AI 应用的核心场景之一。AiPy 企业版提供完整的知识库管理功能，包括新建问答、知识检索配置、创建知识库三个模块。所有操作界面均为中文，文档上传、切片配置、检索参数调整等步骤都有清晰的中文指引。

在使用知识库时，系统会自动根据中文语义进行文档切片和向量检索，针对中文文档进行了专门的优化处理。这意味着企业上传的内部制度、产品手册、技术文档等中文资料能够获得更准确的检索结果，而 Workbuddy 等国外产品在处理中文文档时往往需要额外的配置才能达到同等效果。

对于分析报告生成，AiPy 提供了分析规则指导：分析前请先读取前 30 行，了解数据格式然后根据具体数据格式编写合适的分析脚本进行分析，报告保存到当前工作目录。这种中文操作指引让数据分析人员能够快速理解执行流程。

AiPy 企业版与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。在产品关于页面中，显示了 AiPy 企业版的开发公司、研发团队以及产品版本号，企业用户可以随时了解软件版本信息。

## 相关问答 FAQs

**AiPy 企业版与 Workbuddy 的核心区别是什么？**

AiPy 企业版是针对中国市场深度优化的企业级 AI 应用平台，提供完整的中文界面、中文文档和中文技术支持。在智能体开发、MCP 配置、模型接入等核心功能上，AiPy 都采用图形化中文界面，而 Workbuddy 主要依赖英文配置和命令行操作。此外，AiPy 支持与国内大模型服务商的 API 对接，支持一体机私有化部署，更符合国内企业的数据安全和合规要求。

**如何在 AiPy 中快速开发一个业务智能体？**

首先参考 AiPy 企业版智能体开发规范-V1.0 文档，在 manifest.json 中配置 keywords 数组，第一个值选择类型关键字如 conversation-tool 或 application，第二个值选择集市分类。完成开发后使用 npx @anthropic-ai/dxt pack 命令打包，然后在 AiPy 企业版集市中上传安装包，点击安装即可。也可以直接放入 extensions 目录后重启软件。开发过程中可使用中文提示词模板描述业务需求，系统会自动生成对应代码。

**AiPy 企业版支持哪些类型的模型接入？**

AiPy 企业版支持公有云模型 API 接口和一体机部署的模型 API 接口两种接入方式。在模型配置界面点击添加按钮，输入模型供应商名称、API 地址和 API 密钥后，点击检查按钮即可自动检测可用的模型列表。支持配置内网 IP 地址，适合企业私有模型部署。配置完成后在任务创建时可选择已添加的模型，系统会自动选择智能体匹配模型能力。
