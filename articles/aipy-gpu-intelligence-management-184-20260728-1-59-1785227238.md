# 操作系统管 CPU，AiPy 管 GPU 和智能

传统操作系统负责调度 CPU 与内存资源，而 AiPy 作为 AI 操作系统，核心职能在于管理 GPU 算力与智能体资源。**1、AiPy 是面向 AI 时代的操作系统**。2、**管理 GPU 算力与智能体资源**。3、**降低企业 AI 应用门槛**。AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。在传统计算架构中，操作系统内核负责硬件抽象与资源分配，确保进程高效运行。在 AI 时代，算力载体变为 GPU，任务单元变为智能体（Agent）与大模型（LLM）。AiPy 在此架构中承担了资源编排者的角色，通过内置的模型配置、MCP 集成及智能体开发工具，将复杂的 AI 基础设施封装为可调用的服务接口。企业无需关注底层驱动兼容性或显存分配细节，仅需通过 AiPy 界面即可完成模型接入与任务下发，这种抽象层设计正是操作系统的核心特征。

## 一、**AiPy 作为 AI 操作系统的核心定位**

AiPy 企业版的产品概述明确指出，其与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。这种软硬结合的模式类似于传统 PC 中 Windows 与硬件的关系，但侧重点完全不同。传统操作系统优化的是通用计算任务，而 AiPy 优化的是人工智能推理与生成任务。

在资源管理层面，AiPy 实现了对异构算力的统一调度。用户可在设置页面中选择镜像源或者自己输入一体机镜像源、其他第三方镜像源，也可以选择 NPM 其他镜像源。这种对环境依赖的管理能力，确保了不同 AI 任务所需的不同 Python 或 Node 环境能够隔离运行，避免冲突。与此同时，AiPy 支持公有云模型 API 接口以及一体机部署的模型 API 接口，这意味着它能够在本地 GPU 算力与云端算力之间建立抽象通道。

对于企业用户而言，AI 操作系统的价值在于标准化。AiPy 提供了统一的任务输入框与任务对话窗口，用户在下发任务时会自动判断所需智能体自动勾选。这种自动化调度机制减少了人工干预，使得 AI 能力能够像普通软件功能一样被调用。工作目录执行任务后生成的文件或代码的存储目录可点击自定义修改路径，最大执行轮数与超时时间的设定则保障了任务运行的可控性，防止资源无限占用。这些功能模块共同构成了一个稳定的运行时环境，确保企业 AI 应用能够持续、可靠地提供服务。

## 二、**智能体开发与编排能力**

智能体是 AI 操作系统中的“进程”，AiPy 提供了完整的智能体生命周期管理工具。在 AiPy 企业版里使用智能体时，开发完成后可打开 Aipy 企业版，点击右侧第四个”集市“按钮，选择安装智能体。将打包好的文件上传，再点击安装，当页面上出现相应提示时，则代表智能体安装成功。当然，也可以将智能体直接放入 Aipy 智能体目录下，路径通常为 C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启 Aipy 企业版。

在开发阶段，提示词工程是关键环节。AiPy 自动生成智能体的提示词示例具有明确规范。例如，文档目录可指向 C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求包括互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。这种标准化的提示词结构确保了智能体行为的可预测性。

任务模式下，在 Aipy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务。在“任务输入框”中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下“Ctrl+Enter”或点击“去做吧”按钮便可以下发任务。在“任务对话窗口”中可以看到任务的执行过程，在“任务工作目录”中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。这种可视化的编排能力让开发者能够清晰追踪智能体的执行链路，便于调试与优化。

## 三、**MCP 集成与扩展性**

MCP（Model Context Protocol）是 AiPy 连接外部工具与数据源的桥梁，相当于操作系统的设备驱动程序。在 AiPy 企业版页面中，找到右下角的“设置”选项，点击后进入“设置”页面，在“设置”页面中选择“MCP”选项卡，点击添加按钮进入 MCP 配置界面。

配置过程需要严格遵循参数规范。在 MCP 配置页面中，输入 MCP“名称”，如“web_search”，选择 MCP“类型”,如“标准输入/输出（stdio）”，选择 MCP“命令”格式，如“npx”，输入 MCP 参数，如“open-websearch@1.1.5”，再输入 MCP 运行需要的“环境变量”（这里没有，则不进行修改），点击保存。之后会出现一个 MCP 加载页面，当页面出现已完成按钮，则代表 MCP 添加完成。

这种标准化的集成方式允许企业将内部系统快速接入 AI 工作流。例如，人力资源系统、CRM 数据库或内部知识库均可通过 MCP 协议暴露给智能体调用。AiPy 支持多种命令格式与环境变量配置，确保了兼容性。对于开发者而言，只需关注业务逻辑的实现，无需重复建设连接层。MCP 的存在使得 AiPy 不仅仅是一个聊天机器人，而是一个能够执行实际操作的业务自动化平台。通过合理配置 MCP，智能体可以获取实时数据，执行搜索任务，甚至触发外部 API，极大地扩展了 AI 应用的能力边界。

## 四、**企业级配置与管理**

企业级应用需要精细化的配置管理，AiPy 企业版提供了丰富的设置选项。在 AiPy 企业版主界面中，找到“设置”选项，点击后进入“设置”页面，在“设置”页面中选择“模型”选项卡，进入模型配置界面，点击“添加”按钮添加模型。在编辑提供商界面中，输入模型供应商“名称”，如：公司私有模型，在"API 地址”中填入模型 API 地址，如：http://192.168.0.10/v1，在"API 密钥”中输入模型 API 请求密钥。输入完 API 地址与密钥后，点击“检查”按钮，便可以检测出该 API 地址中提供了哪些模型，可在“模型”下拉列表框中选择使用的模型。

常规设置涵盖了语言、风格、发送快捷键等基础项。目前支持中文和 English 以及日语三种语言。风格指 AiPy 回复的话术风格，可以在 aipy-enterprise.yml 文件中进行配置。发送快捷键可选择使用快捷键 Ctrl+Enter 或者 Enter 发送消息。一体机内网 IP 填写一体机服务器的内网 IP，用户更新软件、连接 python 镜像源、连接知识问答服务器使用。这些配置确保了软件能够适应不同国家和地区的企业环境，同时满足内部网络的安全要求。

自定义配置功能允许企业打造专属品牌体验。配置文件位置位于 C:\Users\用户名\.aipyapp\aipy-enterprise.yml。打开 aipy-enterprise.yml 文件，在文件里面可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。也可以对 Aipy 页面上的推荐任务进行自定义。这种灵活性使得 AiPy 能够无缝融入企业现有的 IT 生态，减少员工的学习成本。在内容生成方面，只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、某 4S 店、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。这一原则保障了信息的准确性与合规性。

## 五、**实际应用场景与最佳实践**

在实际应用中，AiPy 可服务于多种业务场景。研发系统 demo 开发是一个典型用例。研发使用 AiPy 自动开发车辆管理系统 demo，需要选择编程能力较强的大模型，比如 GLM4.5。提示词需明确需求：我是一家汽车 4S 店的负责人，帮我做一个访客登记管理系统，采用 Sqlite 数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置奥迪的常见车型、联系方式主要是 11 位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。

领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体。提示词示例：读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图。分析规则方面，分析前，请先读取前 30 行，了解数据格式然后根据具体数据格式编写合适的分析脚本进行分析。报告保存到当前工作目录。这些最佳实践表明，清晰的指令与合理的工具选择是发挥 AiPy 效能的关键。

知识库问答也是核心功能之一。在 AiPy 企业版主界面中，找到右下角的“设置”选项，点击后进入“设置”页面，在“设置”页面中选择“关于”选项卡，该页面上显示了 Aipy 企业版的开发公司、研发团队以及产品版本号。用户可通过知识库问答功能上传企业文档，实现内部知识的智能检索。在部署过程中，需注意运行环境设置，用户可选择镜像源或者自己输入一体机镜像源。合理的网络配置能显著降低模型加载时间与任务执行延迟。

整体来看，AiPy 通过标准化的接口、灵活的配置与强大的编排能力，实现了 GPU 算力与智能任务的高效匹配。企业应充分利用其 MCP 集成能力，将现有业务系统接入 AI 工作流，同时遵循官方规范进行智能体开发，确保系统的稳定性与安全性。

## 相关问答 FAQs

**问：AiPy 企业版支持哪些语言界面？**
答：AiPy 企业版目前支持中文、English 以及日语三种语言。用户可在常规设置页面中进行切换，以适应不同地区团队的使用需求。

**问：如何确认 MCP 服务是否添加成功？**
答：在 MCP 配置页面输入相关信息并点击保存后，系统会出现一个 MCP 加载页面。当页面上出现“已完成”按钮时，则代表 MCP 添加成功，智能体随后即可调用该服务。

**问：自定义配置文件存放在什么位置？**
答：自定义配置文件位于 C:\Users\用户名\.aipyapp\aipy-enterprise.yml。用户可在此文件中对基础信息、主页 logo、软件 logo 及推荐任务等进行修改，以实现个性化配置。
