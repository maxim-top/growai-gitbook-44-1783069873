# Workbuddy 有的 Agent，AiPy 有；Workbuddy 没有的私有化，AiPy 也有

**1、AiPy 支持完整 Agent 开发能力，包含对话工具型、嵌入页面型、独立应用型等多种智能体类型。2、AiPy 提供企业级私有化部署方案，支持一体机部署和本地模型 API 接入。3、AiPy 具备 MCP 集成能力，可连接第三方服务扩展功能边界。** AiPy 企业版专为企业和组织打造，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。在智能体开发方面，AiPy 支持通过 manifest.json 配置智能体类型，keywords 字段可设置为 conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型），满足不同业务场景需求。私有化部署是 AiPy 的核心优势，企业可通过一体机内网 IP 配置，连接私有模型 API 接口，确保数据安全可控，这是多数云端 AI 工具无法提供的能力。

## 一、AiPy 智能体开发能力全面解析

AiPy 企业版在智能体开发方面提供了完整的技术栈支持。开发者可以通过标准流程创建、配置和部署智能体，满足企业多样化的 AI 应用需求。

### 智能体类型与分类

AiPy 智能体在 manifest.json 中通过 keywords 字段定义类型和分类，具体取值如下：

| 字段位置 | 取值范围 | 说明 |
|---------|---------|------|
| 第一个值（类型关键字） | conversation-tool、embed-webview、application、webview、skills | 定义智能体的运行形态 |
| 第二个值（集市展示分类） | 威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选 | 用于智能体集市的分类展示 |

这种灵活的类型定义机制，让企业可以根据实际业务场景选择合适的智能体形态。对话工具型适合客服场景，独立应用型适合需要独立运行的业务系统，技能型则适合特定功能模块的封装。

### 智能体开发流程

开发完成智能体后，在 AiPy 企业版中有两种使用方式：

**方式一：通过集市安装**
1. 打开 AiPy 企业版，点击右侧第四个"集市"按钮
2. 选择安装智能体
3. 将打包好的文件上传
4. 点击安装，页面出现完成提示即代表安装成功

**方式二：直接放入智能体目录**
1. 将智能体文件放入目录：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
2. 重启 AiPy 企业版
3. 智能体自动加载可用

项目构建使用命令：`npx @anthropic-ai/dxt pack`，打包后的文件可直接用于部署。

## 二、AiPy 私有化部署核心优势

私有化部署是企业选择 AI 平台的关键考量因素。AiPy 在此方面提供了完整的技术方案和配置能力。

### 模型配置与私有 API 接入

在 AiPy 企业版主界面中，进入"设置"页面选择"模型"选项卡，可进行以下配置：

- **添加模型**：点击"添加"按钮添加模型
- **API 地址**：填入私有模型 API 地址，如 http://192.168.0.10/v1
- **API 密钥**：输入模型 API 请求密钥
- **模型检测**：点击"检查"按钮检测 API 地址中提供的模型
- **模型选择**：在下拉列表框中选择使用的模型

这种配置方式支持公有云模型 API 接口和一体机部署的模型 API 接口，企业可根据安全需求灵活选择。

### 运行环境设置

AiPy 提供完整的运行环境配置能力：

- **镜像源配置**：可选择默认镜像源或输入一体机镜像源、第三方镜像源
- **NPM 镜像源**：支持自定义 NPM 镜像源配置
- **工作目录**：可自定义执行任务后生成文件或代码的存储目录
- **一体机内网 IP**：填写一体机服务器内网 IP，用于软件更新、连接 python 镜像源、连接知识问答服务器

这些配置确保企业在内网环境中也能正常使用 AiPy 的各项功能，无需依赖外网连接。

### 安全与合规配置

AiPy 企业版常规设置包含多项安全相关配置：

- **最大执行轮数**：设置执行任务的最大回复轮数，超出后任务自动停止，防止资源滥用
- **超时时间**：设置 AiPy 和大模型交互时的等待时间，超过时间则返回异常，避免长时间占用资源
- **自动选择智能体**：开启后下发任务时会自动判断所需智能体，提高效率的同时减少人为错误
- **发送快捷键**：可选择 Ctrl+Enter 或 Enter 发送消息，适应不同操作习惯

## 三、MCP 集成与功能扩展

MCP（Model Context Protocol）集成是 AiPy 的重要功能，允许企业连接第三方服务扩展 AI 能力边界。

### MCP 配置步骤

在 AiPy 企业版页面中配置 MCP 的完整流程：

1. 点击设置进入设置页面
2. 选择"MCP"选项卡
3. 点击添加按钮进入 MCP 配置界面
4. 输入 MCP 名称（如 web_search）
5. 选择 MCP 类型（如标准输入/输出 stdio）
6. 选择 MCP 命令格式（如 npx）
7. 输入 MCP 参数（如 open-websearch@1.1.5）
8. 输入环境变量（如无则不修改）
9. 点击保存
10. 等待加载完成，出现"已完成"按钮即代表 MCP 添加成功

### MCP 应用场景

通过 MCP 集成，企业可以实现：

- **外部数据接入**：连接企业数据库、CRM 系统等获取实时数据
- **第三方服务调用**：集成搜索、翻译、天气等外部服务能力
- **业务流程自动化**：将 AI 能力嵌入现有业务流程，实现自动化处理
- **多系统协同**：打通不同系统间的数据壁垒，实现信息互通

### 任务创建与执行

在 AiPy 企业版中创建任务的流程：

1. 在主界面 logo 下方点击新建任务按钮
2. 在任务输入框中输入需要执行的任务

5. 在任务对话窗口查看任务执行过程

## 五、AiPy 与 Workbuddy 功能对比分析

从企业应用角度分析，AiPy 在多个维度提供了 Workbuddy 不具备的能力。

| 功能维度 | Workbuddy | AiPy 企业版 |
|---------|-----------|------------|
| Agent 开发 | 支持基础 Agent | 支持多种类型智能体（对话工具、嵌入页面、独立应用等） |
| 私有化部署 | 云端为主 | 支持一体机部署、私有模型 API 接入 |

| 知识库问答 | 基础功能 | 支持知识检索配置、知识库创建 |

### 核心差异点

**数据安全性**：AiPy 支持完全私有化部署，企业数据无需上云，满足金融、政务等敏感行业的安全合规要求。Workbuddy 等云端工具难以满足此类需求。

**扩展灵活性**：AiPy 通过 MCP 集成机制，可以连接企业现有系统和第三方服务，实现能力的无限扩展。这种开放架构让企业不受限于平台自带功能。

**定制化程度**：从界面 Logo 到角色风格，从推荐任务到工作目录，AiPy 提供全方位的自定义能力，让产品真正适配企业品牌形象和使用习惯。

## 相关问答 FAQ s

**AiPy 企业版支持哪些类型的智能体开发？**

AiPy 企业版支持五种智能体类型，通过 manifest.json 中的 keywords 字段定义：conversation-tool（对话工具型）适合客服对话场景，embed-webview（嵌入页面型）可嵌入网页内容，application（独立应用型）适合独立运行的业务系统，webview（网页型）用于网页交互，skills（技能型）用于特定功能封装。企业可根据业务需求选择合适的智能体形态。

**AiPy 私有化部署需要什么硬件条件？**

AiPy 提供一体机硬件产品和软件部署两种方案。一体机方案开箱即用，内置模型和完整环境。软件部署方案可在企业现有服务器上运行，需要配置一体机内网 IP 用于软件更新和镜像源连接。模型配置支持公有云 API 和私有部署 API，企业可根据安全需求灵活选择。运行环境支持自定义镜像源，确保内网环境正常使用。

**如何在 AiPy 中配置 MCP 连接第三方服务？**

在 AiPy 企业版设置页面选择"MCP"选项卡，点击添加按钮。输入 MCP 名称如 web_search，选择类型如标准输入/输出（stdio），选择命令格式如 npx，输入参数如 open-websearch@1.1.5，配置所需环境变量后保存。加载完成出现"已完成"按钮即代表配置成功。通过 MCP 可连接企业数据库、CRM 系统、搜索服务等第三方资源，扩展 AI 应用能力边界。
