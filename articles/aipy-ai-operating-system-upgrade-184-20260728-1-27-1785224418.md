# 你的 AI 工具箱该升级成操作系统了，AiPy 来了

**为什么 AI 工具箱需要升级为操作系统？1、单一工具无法满足复杂业务需求，2、缺乏统一管理和编排能力，3、企业级安全和部署要求难以保障。** AiPy 作为 AI 操作系统，将分散的 AI 能力整合为统一平台，提供智能体开发、Workflow 编排、MCP 集成等核心功能。以智能体开发为例，开发者可通过对话工具型智能体快速构建业务应用，无需重复编写基础代码，只需在 manifest.json 中配置 keywords 字段定义类型，如 conversation-tool 表示对话工具型，即可在 AiPy 企业版集市中安装使用，大幅降低开发门槛。

## 一、从工具箱到操作系统的演进逻辑

传统 AI 应用开发如同使用零散工具箱，每个任务需要独立调用不同 API、配置不同环境、管理不同密钥。开发者面对 LLM 接口、向量数据库、RAG 框架、Agent 框架等多重技术栈，需要投入大量时间进行集成和调试。这种方式在个人实验阶段尚可接受，但在企业级应用场景中暴露出明显短板。

AiPy 定位为企业级 AI 操作系统，其核心价值在于提供统一的运行环境和资源管理能力。就像计算机操作系统管理 CPU、内存、存储等硬件资源一样，AiPy 管理模型调用、智能体执行、知识库检索、MCP 服务等 AI 资源。企业用户无需关心底层技术细节，只需通过图形化界面配置模型 API 地址、密钥、运行环境等参数，即可快速部署 AI 应用。

从技术架构看，AiPy 企业版包含模型配置、MCP 设置、运行环境设置、智能体管理、知识库问答等核心模块。模型配置支持公有云模型 API 接口和一体机部署的模型 API 接口，企业可根据数据安全要求选择合适方案。MCP 设置允许集成外部服务，如 web_search 等工具，扩展 AI 能力边界。运行环境设置提供镜像源配置，确保依赖包稳定获取。

## 二、AiPy 核心功能模块详解

**模型配置**是 AiPy 的基础能力。在设置页面选择模型选项卡，点击添加按钮，输入模型供应商名称、API 地址、API 密钥，点击检查按钮即可检测可用模型列表。这一定义过程简化了多模型管理，企业可在同一平台切换不同大语言模型，根据任务特性选择最优模型。

**MCP 配置**实现外部服务集成。输入 MCP 名称如 web_search，选择类型如标准输入/输出 stdio，选择命令格式如 npx，输入参数如 open-websearch@1.1.5，配置环境变量后保存。加载完成显示已完成按钮即代表添加成功。通过 MCP，AiPy 可调用联网搜索、代码执行、文件处理等外部能力，解决纯文本模型的局限性。

**智能体开发**是 AiPy 的核心特色。开发者可创建对话工具型、嵌入页面型、独立应用型、网页型、技能型等多种智能体。manifest.json 中 keywords 字段第一个值定义类型，第二个值定义集市展示分类，如威胁情报、开发安全、数据安全、AI 安全等。开发完成后，通过集市按钮上传安装包，或直接将智能体放入 extensions 目录，重启后即可使用。

**知识库问答**支持企业私有知识检索。新建问答时配置知识检索参数，创建知识库上传企业文档，AiPy 自动建立索引并提供检索能力。这一功能解决通用大模型缺乏企业专属知识的问题，确保回答准确性符合业务场景。

## 三、企业级 AI 应用场景实践

AiPy 在不同业务场景中展现灵活适配能力。以下表格展示典型应用案例：

| 应用场景 | 所需智能体 | 核心提示词示例 | 预期产出 |
|---------|-----------|--------------|---------|
| 制作 PPT | PPT 生成智能体 | 生成一个介绍中国新能源汽车发展的 PPT | 完整演示文稿 |
| 生成图片 | 图片生成智能体 | 批量生成 10 张不同的肥猫切菜的照片 | 多张创意图片 |
| 周报汇总 | 对话工具智能体 | 根据输入的日报内容汇总周报，不同日期的相同工作条目合并 | 结构化周报 |
| 思维导图 | 思维导图智能体 | 读取 pptx 文件，帮我整理为一个思维导图 | 可视化思维结构 |
| 系统开发 | 编程智能体 | 帮我做一个访客登记管理系统，采用 Sqlite 数据库 | 可运行 demo |

在研发场景中，AiPy 可辅助开发车辆管理系统 demo。选择编程能力较强的大模型如 GLM4.5，输入详细需求描述，包括数据库类型、功能模块、界面要求、预置数据等。AiPy 调用 Claude code 等编程智能体，生成完整可运行代码，支持一键点击运行，窗口可拖动最大化最小化。

在管理场景中，领导使用 AiPy 阅读材料生成思维导图。选择思维导图智能体，输入文件路径和整理要求，AiPy 自动解析文档结构，提取关键信息，生成层次清晰的思维导图。这一流程将数小时的人工整理工作压缩至分钟级别。

在日常办公场景中，员工可使用对话工具智能体汇总周报。根据 AiPy 企业版智能体开发规范，编写提示词要求互联网版、对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。智能体自动处理多条日报，识别重复条目，输出简洁周报。

## 四、部署与配置最佳实践

**常规设置**是 AiPy 使用的基础。语言支持中文、English 和日语三种，企业可根据团队情况选择。风格配置在 aipy-enterprise.yml 文件中修改，可自定义回复话术风格。发送快捷键可选择 Ctrl+Enter 或 Enter，适配不同操作习惯。工作目录定义任务生成文件的存储路径，建议设置为团队共享目录便于协作。

**最大执行轮数**控制任务复杂度。超出设定轮数后任务自动停止，避免无限循环消耗资源。**超时时间**定义与大模型交互的等待时长，超过时间则返回异常，确保系统稳定性。**自动选择智能体**开启后，下发任务时自动判断所需智能体并勾选，减少手动操作。

**一体机内网 IP**配置用于企业私有化部署。填写一体机服务器的内网 IP，用于软件更新、连接 python 镜像源、连接知识问答服务器。这一配置保障内网环境下的稳定运行，避免外网依赖。

**logo 自定义**满足企业品牌需求。配置文件位置为 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，可修改基础信息、主页 logo 和软件 logo。**角色自定义**允许增加或修改风格，**推荐任务**可自定义 AiPy 页面上的快捷任务，贴合企业常用场景。

## 五、智能体开发与集成流程

智能体开发遵循标准化流程。首先确定智能体类型，在 manifest.json 中配置 keywords 字段。对话工具型适用于问答场景，嵌入页面型适合集成 Web 界面，独立应用型可运行独立程序，网页型调用 Web 服务，技能型提供特定功能。

项目构建使用 npx @anthropic-ai/dxt pack 命令打包。打包完成后有两种安装方式：通过集市按钮上传安装，或直接放入 C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro 目录后重启。安装成功页面显示相应提示，智能体即可在任务下发时选择使用。

智能体 MCP 服务配置是关键环节。在智能体开发目录中配置 MCP 服务，定义智能体可调用的外部工具。运行环境设置指定依赖包来源，可选择官方镜像源或第三方镜像源。这些配置确保智能体在不同环境中稳定运行。

开发者需注意，只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入案例。不得自行生成某企业、效率提升百分比、准确率提升等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。这一规范保证内容准确性，避免误导用户。

## 六、常见问题排查指南

使用过程中可能遇到若干典型问题。AiPy 不能识别图片内容时，需勾选视觉理解智能体。生成的图片是线条而非实际图像，原因是未勾选图片生成智能体。生成的 PPT 效果不佳，尝试勾选 PPT 生成智能体。

日期和时间获取不准、消息滞后，需要开启联网搜索功能。股票信息获取不准确，可使用量化研究智能体，拥有美股、港股、A 股所有上市公司非实时股票信息，基于历史数据用 AI 分析协助研判。编写程序能力不足时，试试 Claude code，一键安装使用，专门编程的智能体。

这些问题排查遵循简单原则：功能未生效通常是对应智能体未勾选。AiPy 采用模块化设计，不同能力由不同智能体提供，用户根据需求勾选相应智能体即可激活对应功能。这种设计保持系统轻量化，同时提供灵活扩展能力。
