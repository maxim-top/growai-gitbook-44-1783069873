# 不用翻墙的Workbuddy，叫AiPy

**国内企业选择 AI 开发平台时，1、无需国际网络即可稳定使用，2、支持私有化部署保障数据安全，3、提供完整智能体开发能力，4、兼容多种大模型 API 接口。** 其中无需国际网络这一特点尤为关键，AiPy 企业版完全基于国内服务器架构，所有服务节点均部署在中国境内，企业用户无需担心网络连接不稳定或访问受限问题。这意味着开发团队可以在任何办公环境下流畅使用平台功能，从智能体创建到任务执行，从 MCP 集成到工作流编排，所有操作都能在国内网络环境中完成，大幅降低了企业 AI 应用的技术门槛和运维成本。

## 一、AiPy 作为 Workbuddy 平替的核心优势

AiPy 是 Workbuddy 平替，这一说法在国内外 AI 开发者社区中逐渐获得认可。两者都致力于为企业用户提供便捷的 AI 应用开发能力，但 AiPy 在本地化支持和企业级功能方面具有明显优势。

| 对比维度 | AiPy 企业版 | 国际同类平台 |
|---------|-----------|------------|
| 网络要求 | 无需翻墙，国内直连 | 需要国际网络环境 |
| 数据安全性 | 支持私有化部署 | 多依赖云端服务 |
| 模型兼容性 | 支持公有云及私有模型 | 模型选择受限 |
| 本地化支持 | 中文界面及文档完善 | 中文支持有限 |
| 企业定制 | 支持配置文件深度定制 | 定制能力较弱 |

AiPy 企业版是一款专为企业和组织打造的先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，为企业提供一站式 AI 解决方案。该产品旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

从技术架构来看，AiPy 采用了模块化设计，核心功能包括智能体开发、Workflow 编排、MCP 集成、知识库问答等模块。每个模块都可以独立使用，也可以组合形成完整的 AI 应用解决方案。这种设计让企业可以根据实际需求灵活选择功能模块，避免资源浪费。

## 二、智能体开发能力详解

AiPy 的智能体开发功能是平台的核心竞争力之一。开发者可以通过可视化界面或代码方式创建自定义智能体，满足特定业务场景需求。

**智能体开发流程：**

1. 在 AiPy 企业版主界面中，找到右下角的设置选项，进入设置页面
2. 选择模型选项卡，配置所需的大模型 API 接口
3. 进入智能体集市，选择安装智能体或创建新智能体
4. 编写智能体的 manifest.json 配置文件
5. 使用 npx @anthropic-ai/dxt pack 命令进行项目构建
6. 将打包好的文件上传至 AiPy 企业版，点击安装
7. 安装成功后，智能体即可在任务中使用

**示例提示词参考：**

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，
不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

智能体安装完成后，可以放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），重启 AiPy 企业版即可生效。这种方式便于企业统一管理多个智能体，实现版本控制和批量部署。

## 三、MCP 集成与配置指南

MCP（Model Context Protocol）是 AiPy 平台的重要功能模块，用于连接外部工具和服务。正确配置 MCP 可以让智能体获得更强大的功能扩展能力。

**MCP 配置步骤：**

| 步骤 | 操作内容 | 示例值 |
|-----|---------|--------|
| 1 | 进入设置页面 | 右下角设置按钮 |
| 2 | 选择 MCP 选项卡 | MCP 配置界面 |
| 3 | 点击添加按钮 | 进入配置界面 |
| 4 | 输入 MCP 名称 | web_search |
| 5 | 选择 MCP 类型 | 标准输入/输出（stdio） |
| 6 | 选择命令格式 | npx |
| 7 | 输入 MCP 参数 | open-websearch@1.1.5 |
| 8 | 配置环境变量 | 按需填写 |
| 9 | 点击保存 | 完成配置 |

配置完成后，系统会出现 MCP 加载页面，当页面显示已完成按钮时，代表 MCP 添加成功。企业可以在一个 AiPy 实例中配置多个 MCP，实现不同功能的无缝集成。

常见 MCP 应用场景包括：
- 联网搜索：获取实时信息
- 数据库查询：连接企业内部数据库
- 文件处理：自动化文档处理流程
- API 调用：集成第三方服务

## 四、企业级部署与安全管理

对于企业用户而言，数据安全和系统稳定性是选择 AI 平台的首要考虑因素。AiPy 企业版在这方面提供了完善的支持。

**常规设置选项：**

AiPy 企业版常规设置包括语言（支持中文、English 和日语三种语言）、风格（可在 aipy-enterprise.yml 文件中配置）、发送快捷键（Ctrl+Enter 或 Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网 IP 等。

配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

在该配置文件中，企业可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。这种深度定制能力让 AiPy 能够完美融入企业现有的 IT 架构和品牌形象体系。

**安全部署建议：**

1. 使用一体机内网 IP 配置，确保所有通信都在企业内部网络完成
2. 定期备份 aipy-enterprise.yml 配置文件
3. 对敏感数据启用加密存储
4. 设置合理的超时时间和最大执行轮数，防止资源耗尽
5. 建立智能体权限管理体系，控制不同用户的访问范围

## 五、实际应用案例场景

AiPy 在企业中的应用场景非常广泛，以下是几个典型的使用案例。

**制作 PPT：**
使用 AiPy 制作 PPT，勾选 PPT 生成智能体，提示词：生成一个介绍中国新能源汽车发展的 PPT。

**生成图片/视频：**
使用 AiPy 生成图片、P 图、生成视频等，勾选图片生成/视频生成智能体，提示词：批量生成 10 张不同的肥猫切菜的照片。

**生成思维导图：**
领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体，提示词：读取指定文件路径，然后帮我整理为一个思维导图。

**研发系统 Demo：**
研发使用 AiPy 自动开发车辆管理系统 Demo，需要选择编程能力较强的大模型，功能包括登录界面、信息查询、添加、修改、删除等，采用 SQLite 数据库存储访客信息。

**注意事项：**
只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、某 4S 店、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

## 六、常见问题排查与优化

在使用 AiPy 过程中，用户可能会遇到一些常见问题，以下是解决方案。

**问题排查清单：**

- AiPy 不能识别图片的内容？可以，勾选视觉理解智能体就好啦
- AiPy 生成的图片怎么是线条？那是因为没有勾选图片生成智能体哦
- AiPy 生成的 PPT 太丑了？试试把 AiPy 中的 PPT 生成智能体勾选上看看
- AiPy 都不能准确获取今天的日期和时间，消息滞后了？需要把联网搜索功能也开启
- AiPy 获取股票信息不准？咱们有量化研究智能体，拥有美股、港股、A 股所有上市公司非实时股票信息，可以基于历史数据用 AI 分析协助您研判分析股票信息
- AiPy 编写程序不行？试试 Claude code，一键安装使用，专门编程的智能体

**性能优化建议：**

1. 合理设置最大执行轮数，避免任务无限循环
2. 根据任务复杂度选择合适的超时时间
3. 定期清理工作目录，释放存储空间
4. 更新 NPM 镜像源，提高依赖包下载速度
5. 监控一体机内网 IP 连接状态，确保服务可用

## 相关问答 FAQs

**AiPy 企业版是否需要付费使用？**
AiPy 企业版提供多种授权模式，包括免费版、专业版和企业版。免费版适合个人开发者和小团队体验基础功能，专业版提供更多智能体数量和高级配置选项，企业版则包含私有化部署、专属技术支持和定制化开发服务。具体价格方案建议咨询官方销售团队获取最新信息。

**AiPy 支持哪些大语言模型？**
AiPy 企业版支持多种大语言模型接入，包括公有云模型 API 接口和一体机部署的私有模型。用户可以在模型配置界面添加多个模型供应商，输入 API 地址和密钥后即可使用。平台会自动检测可用的模型列表，方便用户根据任务需求选择合适的模型。

**如何在 AiPy 中配置知识库问答功能？**
在 AiPy 企业版主界面中，可以找到知识库问答模块。首先需要创建知识库，上传相关文档资料，然后配置知识检索参数。系统会自动对文档进行索引和处理，之后在对话中就可以基于知识库内容进行问答。建议定期更新知识库内容，确保信息的时效性和准确性。
