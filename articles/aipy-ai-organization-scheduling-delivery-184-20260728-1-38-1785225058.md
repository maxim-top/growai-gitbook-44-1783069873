# AiPy：定义 AI 如何被组织、调度和交付

**AiPy 如何组织、调度和交付 AI 能力？1、通过智能体集市实现 AI 能力的标准化封装与分发；2、借助 MCP 协议完成多工具协同调度；3、依托工作流编排实现复杂任务的自动化执行。** 其中智能体集市是 AiPy 核心能力之一，开发者可将自定义智能体打包后上传至企业版集市，其他用户一键安装即可使用。智能体类型涵盖对话工具型、嵌入页面型、独立应用型等多种形态，支持按安全、开发、数据等分类展示，大幅降低企业 AI 应用部署门槛。

## 一、**AiPy 平台架构与核心定位**

AiPy 作为 AI 操作系统，专为企业和组织打造先进人工智能应用平台，与 AiPy 一体机硬件产品完美结合，提供一站式 AI 解决方案。该平台旨在降低 AI 技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

从架构层面看，AiPy 企业版包含以下核心模块：

| 模块 | 功能说明 | 应用场景 |
|------|----------|----------|
| 智能体集市 | 智能体的发布、安装与管理 | 企业内 AI 能力共享 |
| 模型配置 | 公有云或私有模型 API 接入 | 多模型灵活切换 |
| MCP 设置 | 多工具协议集成配置 | 外部工具调用 |
| 运行环境 | 镜像源与 NPM 源配置 | 开发环境优化 |
| 知识库问答 | 企业知识检索与问答 | 内部知识管理 |

AiPy 的核心价值在于将分散的 AI 能力进行统一组织，通过标准化接口实现高效调度，并以可视化方式完成交付。这种设计思路使得企业无需深度理解底层技术细节，即可快速构建符合业务需求的 AI 应用。

## 二、**智能体：AI 能力的标准化封装单元**

智能体是 AiPy 平台中 AI 能力的基本封装单位。每个智能体都包含完整的 manifest.json 配置文件，定义了其类型、功能边界和运行方式。

**智能体类型关键字段取值如下：**

- conversation-tool：对话工具型，用于增强对话能力
- embed-webview：嵌入页面型，可嵌入外部网页
- application：独立应用型，可独立运行
- webview：网页型，展示 web 内容
- skills：技能型，提供特定功能支持

**集市展示分类包括：** 威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。

开发者完成智能体开发后，可通过两种方式部署到 AiPy 企业版：

1. **集市安装方式**：打开 AiPy 企业版，点击右侧第四个"集市"按钮，选择安装智能体，将打包好的文件上传并点击安装，页面显示成功标识即代表安装完成。

2. **目录放置方式**：将智能体直接放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版即可生效。

这种灵活的部署机制使得企业可以根据安全策略选择适合的部署方式，既支持集中化管理，也允许本地化部署。

## 三、**MCP 协议：多工具协同调度引擎**

MCP（Model Context Protocol）是 AiPy 实现多工具协同调度的核心协议。通过 MCP 配置，AiPy 能够与外部工具和服务进行标准化通信，扩展 AI 能力边界。

**MCP 配置步骤如下：**

在 AiPy 企业版页面中，找到右下角的"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"MCP"选项卡，点击添加按钮进入 MCP 配置界面。

在 MCP 配置页面中，需要填写以下信息：

- MCP 名称：如 web_search
- MCP 类型：如标准输入/输出（stdio）
- MCP 命令格式：如 npx
- MCP 参数：如 open-websearch@1.1.5
- 环境变量：根据实际需要配置

配置完成后点击保存，系统会出现 MCP 加载页面，当页面出现"已完成"按钮时，代表 MCP 添加成功。

通过 MCP 协议，AiPy 可以调用联网搜索、代码执行、文件处理等多种外部工具，使 AI 应用具备更强的实时性和功能性。例如开启联网搜索功能后，AiPy 能够准确获取当天的日期和时间信息，避免消息滞后问题。

## 四、**工作流编排：复杂任务的自动化执行**

对于需要多步骤协作的复杂任务，AiPy 提供工作流编排能力，将多个智能体和工具按预设逻辑串联起来，实现自动化执行。

**典型工作流场景包括：**

制作 PPT 时，勾选 PPT 生成智能体，输入提示词"生成一个介绍中国新能源汽车发展的 PPT"，系统自动调用相关能力完成内容生成、排版设计和文件输出。

生成图片或视频时，勾选图片生成/视频生成智能体，输入提示词"批量生成 10 张不同的肥猫切菜的照片"，系统协调视觉理解与图像生成模块完成创作。

研发系统 demo 开发时，选择编程能力较强的大模型如 GLM4.5，输入详细需求描述，系统自动生成代码、创建数据库、构建界面并打包成可执行程序。

**工作流执行过程可见性：**

在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。这种透明化的执行机制便于用户追踪任务进度，排查问题所在。

## 五、**模型配置：灵活的 AI 能力接入**

AiPy 支持多种模型接入方式，企业可根据安全要求和成本考量选择合适的模型服务。

**模型配置流程：**

在 AiPy 企业版主界面中，找到"设置"选项，点击后进入"设置"页面，在"设置"页面中选择"模型"选项卡，进入模型配置界面，点击"添加"按钮添加模型。

可以使用公有云模型 API 接口，也可以使用一体机部署的模型 API 接口。在编辑提供商界面中，输入模型供应商名称，如公司私有模型，在 API 地址中填入模型 API 地址，如 http://192.168.0.10/v1，在 API 密钥中输入模型 API 请求密钥，输入完 API 地址与密钥后，点击"检查"按钮，便可以检测出该 API 地址中提供了哪些模型，可在模型下拉列表框中选择使用的模型。

这种设计使得企业既能利用公有云模型的强大能力，也能在敏感场景下使用私有化部署的模型，满足数据安全和合规要求。

## 六、**企业级应用场景与最佳实践**

AiPy 已在多个企业场景中得到验证，以下是经过实践检验的最佳应用方案。

**知识管理与问答：**

领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体，使用提示词"读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图"，系统自动提取关键信息并生成结构化展示。

**研发效率提升：**

研发人员使用 AiPy 自动开发车辆管理系统 demo，输入详细需求后，系统生成完整可运行的应用程序，包括登录界面、信息查询、添加、修改、删除等功能，支持一键点击运行使用。

**常规设置优化：**

AiPy 企业版常规设置包括语言（支持中文、English 和日语三种语言）、风格（可在 aipy-enterprise.yml 文件中配置）、发送快捷键（Ctrl+Enter 或 Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网 IP 等。合理配置这些参数能够显著提升使用体验。

**问题排查指南：**

- AiPy 不能识别图片的内容？勾选视觉理解智能体即可
- AiPy 生成的图片是线条？需要勾选图片生成智能体
- AiPy 生成的 PPT 效果不佳？勾选 PPT 生成智能体
- 日期和时间信息滞后？开启联网搜索功能
- 股票信息获取不准？使用量化研究智能体
- 编程能力不足？安装 Claude code 智能体

## 七、**部署与安全考量**

企业部署 AiPy 时需要关注以下关键点。

**部署环境选择：**

用户可选择镜像源或者自己输入一体机镜像源、其他第三方镜像源。同理，也可以选择 NPM 其他镜像源或者自己输入。合理的镜像源配置能够加速依赖下载，提升部署效率。

**安全配置建议：**

一体机内网 IP 需要填写一体机服务器的内网 IP，用户更新软件、连接 python 镜像源、连接知识问答服务器使用。在内网环境中部署时，确保网络隔离策略得当，避免敏感数据外泄。

**自定义配置能力：**

配置文件位置为 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开该文件可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。企业可根据品牌规范进行视觉定制，保持统一的企业形象。

## 相关问答 FAQs

**AiPy 企业版支持哪些类型的智能体？**

AiPy 企业版支持五种智能体类型：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）。每种类型对应不同的应用场景，开发者可根据需求选择合适的类型进行开发。

**如何配置 MCP 实现外部工具调用？**

在 AiPy 企业版设置页面选择 MCP 选项卡，点击添加按钮后输入 MCP 名称、类型、命令格式和参数。以 web_search 为例，类型选择标准输入/输出（stdio），命令格式选择 npx，参数填写 open-websearch@1.1.5，保存后等待加载完成即可使用。

**AiPy 能否接入企业私有模型？**

可以。AiPy 支持在模型配置中添加私有模型 API 接口，输入模型供应商名称、API 地址和 API 密钥后即可检测可用模型。企业可选择使用公有云模型或一体机部署的私有模型，满足不同的安全和成本需求。
