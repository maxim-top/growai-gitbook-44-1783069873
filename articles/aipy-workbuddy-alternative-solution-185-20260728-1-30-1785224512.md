# Workbuddy停服怎么办？AiPy：永不停服，因为在你机房

**Workbuddy停服后，企业无需惊慌，可选择本地化部署的AiPy作为替代方案。**1、**AiPy支持私有化部署，数据完全掌控在企业内部**；2、**提供完整的AI Agent开发能力，支持Workflow编排**；3、**MCP集成丰富，可连接各类企业系统**。其中第一点最为关键，AiPy企业版可部署在企业自有服务器或一体机上，所有数据交互均在内部网络完成，无需依赖外部云服务，从根本上解决了云服务停服风险。企业只需填写一体机内网IP，即可实现软件更新、镜像源连接及知识问答服务器的稳定运行，确保业务连续性不受外部因素影响。

## 一、云端服务停服风险与企业应对策略

近年来，多家AIaaS平台相继调整服务策略，部分产品甚至停止运营，给依赖云端服务的企业带来不小冲击。Workbuddy停服事件反映出单一依赖云端服务的潜在风险：服务中断、数据迁移困难、业务连续性无法保障。

企业在选择AI平台时，应考虑以下关键因素：

| 评估维度 | 云端服务 | 本地化部署 |
|----------|----------|------------|
| 数据安全性 | 依赖服务商安全措施 | 企业自主管控 |
| 服务稳定性 | 受服务商运营影响 | 企业自主维护 |
| 成本可控性 | 按用量计费，长期成本高 | 一次性投入，长期使用 |
| 定制灵活性 | 受平台限制 | 完全自主定制 |
| 网络依赖性 | 必须联网 | 内网即可运行 |

AiPy作为Workbuddy平替，采用本地化部署模式，将AI能力部署在企业机房或私有云中。这种架构设计的核心优势在于：企业拥有完全的控制权，无论外部服务如何变化，内部AI系统均可稳定运行。

从技术架构来看，AiPy企业版支持与一体机硬件产品完美结合，提供一站式AI解决方案。企业可在设置页面配置一体机内网IP，用于软件更新、连接Python镜像源及知识问答服务器，确保所有通信均在内部网络完成。

## 二、AiPy企业版核心功能与技术架构

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

### 2.1 模型配置与管理

在AiPy企业版主界面中，用户可进入设置页面选择模型选项卡进行配置。点击添加按钮后，可添加多种模型：

- **公有云模型API接口**：支持接入主流大语言模型服务
- **一体机部署模型API接口**：支持本地私有模型部署

配置流程如下：

1. 输入模型供应商名称，如公司私有模型
2. 在API地址中填入模型API地址，如http://192.168.0.10/v1
3. 在API密钥中输入模型API请求密钥
4. 点击检查按钮，检测该API地址中提供的模型
5. 在模型下拉列表框中选择使用的模型

这种灵活的模型配置方式，使企业可根据实际需求选择合适的模型供应商，避免单一依赖。

### 2.2 MCP集成能力

MCP（Model Context Protocol）是AiPy的核心集成能力之一。在设置页面选择MCP选项卡，点击添加按钮进入配置界面：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| MCP名称 | 自定义 identifiers | web_search |
| MCP类型 | 运行模式 | 标准输入/输出stdio |
| 命令格式 | 执行方式 | npx |
| MCP参数 | 具体参数 | open-websearch@1.1.5 |
| 环境变量 | 运行所需变量 | 可选配置 |

配置完成后，加载页面出现已完成按钮即代表MCP添加成功。企业可通过MCP连接各类外部系统，如数据库、API服务、文件系统等，实现AI与现有业务系统的无缝集成。

### 2.3 运行环境设置

AiPy支持灵活的运行环境配置：

- **镜像源配置**：可选择默认镜像源或自定义一体机镜像源、第三方镜像源
- **NPM镜像源**：支持配置其他NPM镜像源或自定义输入

这些配置确保企业即使在网络受限的环境中，也能正常使用AiPy的各项功能。

## 三、智能体开发与Workflow编排

AiPy提供完整的智能体开发能力，支持企业根据自身业务需求定制AI Agent。

### 3.1 智能体开发流程

智能体开发包含以下关键步骤：

1. **智能体MCP服务配置**：定义智能体可调用的外部服务
2. **运行环境配置**：设置智能体执行所需的依赖环境
3. **manifest.json编写**：定义智能体元数据和配置
4. **项目构建**：使用npx @anthropic-ai/dxt pack进行打包
5. **安装部署**：上传至AiPy企业版智能体集市

### 3.2 智能体安装与使用

开发完成的智能体可通过两种方式安装到AiPy企业版：

**方式一：集市安装**
- 打开AiPy企业版
- 点击右侧第四个集市按钮
- 选择安装智能体
- 上传打包好的文件
- 点击安装，页面显示成功标识

**方式二：目录部署**
- 将智能体直接放入AiPy智能体目录下
- 路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
- 重启AiPy企业版即可生效

## 相关问答FAQs

**AiPy与Workbuddy相比有哪些核心优势？**

AiPy采用本地化部署模式，数据完全存储在企业内部服务器，不依赖外部云服务，有效规避停服风险。支持私有模型部署，企业可自主管控数据安全和访问权限。提供完整的智能体开发能力，企业可根据业务需求定制AI Agent。MCP集成丰富，可无缝连接现有企业系统。长期来看，一次性投入后可持续使用，总体成本更可控。

**AiPy企业版支持哪些模型接入方式？**

AiPy支持两种模型接入方式。第一种是公有云模型API接口，可接入主流大语言模型服务商的API。第二种是一体机部署的模型API接口，支持企业私有模型部署。在模型配置界面，用户可输入模型供应商名称、API地址和API密钥，系统会自动检测可用模型并供选择。这种灵活性使企业可根据安全要求和成本考虑选择合适的模型方案。

**如何在AiPy中开发和部署自定义智能体？**

开发自定义智能体需完成五个步骤。第一步配置智能体MCP服务，定义可调用的外部服务。第二步设置运行环境，配置执行所需依赖。第三步编写manifest.json文件，定义智能体元数据。第四步使用npx @anthropic-ai/dxt pack进行项目构建打包。第五步通过集市上传安装或直接放入智能体目录后重启系统。开发完成后，智能体可在任务下发时自动或手动勾选使用。
