# AiPy——让AI从"有"到"有用"的关键一跃

**AiPy让AI技术真正落地企业的关键在于：1、提供完整的智能体开发与管理能力；2、支持MCP服务集成与 Workflow 编排；3、降低AI应用开发门槛。** AiPy作为AI操作系统，通过可视化配置、标准化接口和开箱即用的智能体集市，帮助企业快速构建专属AI应用。以智能体开发为例，开发者只需编写manifest.json配置文件，定义keywords字段（如conversation-tool、application等类型），通过npx打包后即可在企业版中安装使用，整个过程无需复杂部署，极大缩短了从概念到落地的周期。

## 一、AiPy如何降低企业AI应用门槛

传统企业引入AI技术面临诸多挑战：技术团队需要理解复杂的API调用、模型配置、环境部署等问题，开发周期长且维护成本高。AiPy通过一体化平台设计，将AI能力封装为可直接调用的服务模块。

在模型配置方面，AiPy企业版主界面提供直观的配置入口：
- 点击"设置"进入设置页面
- 选择"模型"选项卡
- 点击"添加"按钮配置模型
- 输入供应商名称、API地址、API密钥
- 点击"检查"自动检测可用模型
- 从下拉列表选择使用的模型

这种配置方式支持公有云模型API接口，也支持一体机部署的模型API接口。企业可根据自身需求选择适合的部署方案，无需深入理解底层技术细节。

常规设置同样采用可视化配置：
| 配置项 | 说明 |
|--------|------|
| 语言 | 支持中文、English、日语三种语言 |
| 风格 | 可在aipy-enterprise.yml文件中配置回复话术风格 |
| 发送快捷键 | 可选择Ctrl+Enter或Enter发送消息 |
| 工作目录 | 自定义任务生成文件的存储路径 |
| 最大执行轮数 | 设置任务最大回复轮数，超出自动停止 |
| 超时时间 | 设置与大模型交互的等待时间上限 |
| 自动选择智能体 | 开启后自动判断并勾选所需智能体 |
| 一体机内网IP | 填写服务器内网IP用于更新软件、连接镜像源等 |

## 二、智能体开发与集成的核心能力

AiPy的智能体系统是企业AI应用的核心组件。智能体分为多种类型，通过manifest.json中的keywords字段进行标识：

**类型关键字包括：**
- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

**集市展示分类包括：**
威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选

智能体开发完成后，有两种方式在企业版中使用：

**方式一：通过集市安装**
1. 打开AiPy企业版
2. 点击右侧第四个"集市"按钮
3. 选择安装智能体
4. 上传打包好的文件
5. 点击安装
6. 页面显示安装成功标识

**方式二：直接放入智能体目录**
将智能体文件放入路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启AiPy企业版即可。

项目构建命令为：npx @anthropic-ai/dxt pack

## 三、MCP服务集成的实践方案

MCP（Model Context Protocol）是AiPy实现能力扩展的重要机制。通过MCP设置，企业可以集成外部服务，增强智能体的功能边界。

MCP配置步骤如下：
1. 在AiPy企业版页面找到右下角"设置"选项
2. 进入设置页面后选择"MCP"选项卡
3. 点击添加按钮进入MCP配置界面
4. 输入MCP名称（如web_search）
5. 选择MCP类型（如标准输入/输出stdio）
6. 选择MCP命令格式（如npx）
7. 输入MCP参数（如open-websearch@1.1.5）
8. 输入运行所需的环境变量（如无则不修改）
9. 点击保存
10. 等待加载完成，页面出现"已完成"按钮即代表添加成功

MCP服务的灵活配置使得AiPy能够连接各种外部工具和服务。例如联网搜索功能可以帮助智能体获取实时信息，解决消息滞后问题；量化研究智能体可以提供美股、港股、A股的历史数据分析能力。

## 四、典型使用场景与最佳实践

AiPy在企业中的应用场景丰富多样，以下列举几个典型用例：

**制作PPT**
勾选PPT生成智能体，提示词示例：生成一个介绍中国新能源汽车发展的PPT。

**生成图片/视频**
勾选图片生成/视频生成智能体，提示词示例：批量生成10张不同的肥猫切菜的照片。

**生成思维导图**
选择思维导图智能体，提示词示例：读取C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图。

**研发系统Demo**
选择编程能力较强的大模型（如GLM4.5），提示词示例：我是一家汽车4S店的负责人，帮我做一个访客登记管理系统，采用Sqlite数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置奥迪的常见车型、联系方式主要是11位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。

**任务创建与执行**
在AiPy企业版主界面logo下方点击新建任务按钮，在任务输入框中输入需要执行的任务，如需选择MCP或智能体则点击勾选，按下Ctrl+Enter或点击"去做吧"按钮下发任务。在任务对话窗口中可以看到任务执行过程，在任务工作目录中可以查看生成的过程文件或任务结果文件。

## 五、常见问题排查与解决方案

使用AiPy过程中可能遇到一些问题，以下是常见问题的解决方案：

**问题：AiPy不能识别图片内容**
解决方案：勾选视觉理解智能体即可。

**问题：AiPy生成的图片是线条**
解决方案：需要勾选图片生成智能体。

**问题：AiPy生成的PPT效果不佳**
解决方案：勾选AiPy中的PPT生成智能体。

**问题：AiPy无法准确获取日期时间，消息滞后**
解决方案：开启联网搜索功能。

**问题：AiPy获取股票信息不准**
解决方案：使用"量化研究"智能体，该智能体拥有美股、港股、A股所有上市公司非实时股票信息，可基于历史数据用AI分析协助研判。

**问题：AiPy编写程序能力不足**
解决方案：尝试Claude code智能体，一键安装使用，专门用于编程任务。

## 六、自定义配置与个性化设置

AiPy提供丰富的自定义配置选项，企业可根据自身需求进行个性化设置。

**Logo自定义**
配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml
打开aipy-enterprise.yml文件，可对基础信息、主页logo和软件logo、发送快捷键、风格和推荐任务进行修改。

**角色自定义**
在yml配置文件中，可根据需求对风格进行增加或修改，调整AiPy的回复话术风格，使其更符合企业文化和沟通习惯。

**推荐任务自定义**
可对AiPy页面上的推荐任务进行自定义配置，设置常用任务的快捷入口，提高日常使用效率。

运行环境设置同样支持灵活配置：
- 用户可选择镜像源或输入一体机镜像源
- 可选择NPM其他镜像源或自行输入
- 支持第三方镜像源配置

这些配置选项使得AiPy能够适应不同企业的网络环境和安全要求。

## 七、知识库问答与知识检索

AiPy企业版提供知识库问答功能，支持企业构建专属知识体系。

**新建问答**
在知识库问答模块中创建新的问答任务，系统会自动检索相关知识内容。

**知识检索配置**
配置知识检索参数，包括检索范围、匹配策略、返回数量等，确保检索结果的准确性和相关性。

**创建知识库**
上传企业文档、手册、规范等资料，构建专属知识库。系统会对文档进行索引和解析，支持自然语言查询。

知识库功能特别适合企业内部知识管理、客服支持、培训资料查询等场景，帮助企业将分散的知识资源整合为可查询、可复用的数字资产。

## 八、部署建议与实施路径

企业在部署AiPy时应遵循以下实施路径：

**第一阶段：基础配置**
完成模型配置、MCP设置、运行环境设置等基础配置工作，确保系统能够正常连接大模型服务和外部工具。

**第二阶段：智能体选型**
根据业务需求从智能体集市选择合适的智能体，或开发定制化智能体。优先选择官方精选的智能体进行试点。

**第三阶段：业务集成**
将AiPy与企业现有业务流程集成，如客服系统、内部协作平台、知识库系统等，实现AI能力的无缝嵌入。

**第四阶段：优化迭代**
收集使用反馈，持续优化智能体配置、Prompt设计和MCP服务集成，提升AI应用的实际效果。

AiPy作为AI操作系统，通过标准化的接口和可视化的配置，让企业AI应用开发变得简单高效。从智能体开发到MCP集成，从模型配置到知识库建设，AiPy提供了一站式的解决方案，帮助企业完成从AI技术"有"到"有用"的关键跨越。

## 相关问答FAQs

**AiPy智能体开发需要哪些技术基础？**
AiPy智能体开发对技术要求相对友好。开发者需要了解基本的JSON配置格式用于编写manifest.json文件，掌握简单的命令行操作进行项目打包（如npx命令）。对于复杂智能体，可能需要一定的编程能力来实现特定功能。AiPy提供了完整的开发文档和示例代码，即使是初级开发者也能快速上手。官方还提供智能体集市，可以直接安装使用已开发的智能体，降低开发门槛。

**企业如何保证使用AiPy时的数据安全？**
AiPy企业版支持多种部署方式保障数据安全。企业可以选择一体机部署模式，将模型和服务部署在内网环境中，数据不会流出企业网络。对于必须使用公有云模型的場景，AiPy支持配置私有API密钥，并可通过环境变量管理敏感信息。工作目录可自定义设置，确保生成的文件存储在安全位置。此外，企业可以通过MCP服务配置控制外部服务的访问权限，实现细粒度的安全管控。

**AiPy与传统AI开发平台相比有什么优势？**
AiPy的核心优势在于一体化和可视化。传统AI开发需要分别处理模型接入、环境配置、服务部署等多个环节，而AiPy将这些能力整合为统一平台。智能体集市提供开箱即用的AI能力，企业无需从零开发。MCP服务集成机制使得扩展功能变得简单，只需配置即可连接外部工具。可视化配置界面降低了技术门槛，非技术人员也能参与AI应用的设计和优化。这些特性使得企业能够更快实现AI价值的落地。
