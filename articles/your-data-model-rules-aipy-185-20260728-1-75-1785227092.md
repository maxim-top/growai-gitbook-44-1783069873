# 你的数据，你的模型，你的规则，你的AiPy

**企业AI应用的核心掌控权在于四大要素：1、数据自主管理；2、模型灵活配置；3、规则自定义设定；4、智能体按需编排。** AiPy企业版为企业提供一站式AI解决方案，让组织能够完全掌控AI应用的每个环节。数据自主管理意味着企业可以将敏感信息保留在本地知识库中，无需上传至公有云；模型灵活配置支持接入公有云模型API或一体机部署的私有模型；规则自定义设定允许通过配置文件调整系统行为；智能体按需编排则让企业根据业务场景选择和组合不同的AI能力。这种全方位的控制权使AiPy成为Workbuddy平替的理想选择，尤其适合对数据安全和定制化有高要求的企业用户。

## 一、数据自主管理：企业信息安全的第一道防线

在数字化转型加速的今天，企业数据安全问题日益突出。AiPy企业版通过本地化部署和私有知识库机制，确保敏感信息始终掌握在企业手中。

### 知识库创建与管理流程

| 步骤 | 操作内容 | 说明 |
|------|----------|------|
| 1 | 进入知识库问答页面 | 在主界面选择知识库问答功能 |
| 2 | 新建问答配置 | 设置问答的基本参数和检索范围 |
| 3 | 知识检索配置 | 定义检索策略和匹配规则 |
| 4 | 创建知识库 | 上传企业文档并建立索引 |
| 5 | 验证检索效果 | 测试问答准确性和响应速度 |

企业可以将内部文档、技术规范、业务流程等资料上传至本地知识库，AiPy会建立索引并支持智能检索。这种方式避免了将敏感信息上传至第三方服务的风险，同时保证了问答的准确性和时效性。

### 工作目录自定义

AiPy允许用户自定义工作目录，执行任务后生成的文件或代码会存储在指定路径。配置文件位置为`C:\Users\用户名\.aipyapp\aipy-enterprise.yml`，企业可以根据安全策略设置专用的存储目录，实现数据的集中管理和访问控制。

### 内网部署优势

对于有严格网络隔离要求的企业，AiPy支持一体机内网IP配置。填写一体机服务器的内网IP后，用户可以更新软件、连接python镜像源、连接知识问答服务器，所有通信均在内部网络完成，无需访问外网。这种部署方式特别适合金融、医疗、政府等对数据安全要求极高的行业。

## 二、模型灵活配置：适配多样化的AI需求

不同业务场景对AI模型的要求各不相同。AiPy企业版提供灵活的模型配置机制，支持多种模型接入方式。

### 模型配置步骤

1. 在AiPy企业版主界面中，找到"设置"选项
2. 点击后进入"设置"页面
3. 选择"模型"选项卡，进入模型配置界面
4. 点击"添加"按钮添加模型
5. 输入模型供应商"名称"，如：公司私有模型
6. 在"API地址"中填入模型API地址，如：http://192.168.0.10/v1
7. 在"API密钥"中输入模型API请求密钥
8. 点击"检查"按钮检测API地址中提供的模型
9. 在"模型"下拉列表框中选择使用的模型

### 支持的模型类型

| 模型来源 | 适用场景 | 优势 |
|----------|----------|------|
| 公有云模型API | 快速部署、成本可控 | 无需维护基础设施，按需付费 |
| 一体机部署模型 | 数据敏感、高并发 | 本地化处理，响应速度快 |
| 私有模型 | 特殊领域、定制需求 | 完全掌控，可深度优化 |

企业可以根据业务需求选择合适的模型组合。例如，日常办公任务可以使用公有云模型降低成本，而涉及核心业务的场景则使用私有模型确保安全。AiPy的模型配置机制允许同时添加多个模型，在不同任务中灵活切换。

### 运行环境设置

AiPy还提供运行环境配置选项，用户可选择镜像源或输入一体机镜像源、第三方镜像源。同样，NPM镜像源也可自定义设置。这种灵活性确保企业能够在受限网络环境中顺利完成依赖安装和环境配置。

## 三、规则自定义设定：打造专属AI工作环境

每个企业的业务流程和工作习惯都有独特之处。AiPy企业版提供丰富的自定义配置选项，让AI系统能够适配企业的特定需求。

### 常规设置项

AiPy企业版常规设置包括以下内容：

- **语言**：支持中文、English和日语三种语言
- **风格**：可在aipy-enterprise.yml文件中配置回复话术风格
- **发送快捷键**：可选择Ctrl+Enter或Enter发送消息
- **工作目录**：执行任务后生成的文件或代码的存储目录
- **最大执行轮数**：执行任务的最大回复轮数，超出后任务自动停止
- **超时时间**：任务过程中等待大模型接口返回的时间限制
- **自动选择智能体**：开启后下发任务时会自动判断所需智能体并勾选
- **一体机内网IP**：填写一体机服务器的内网IP用于更新和连接服务

### 配置文件修改示例

打开`aipy-enterprise.yml`文件，可以对以下内容进行修改：

1. 基础信息配置
2. 主页logo和软件logo自定义
3. 发送快捷键设置
4. 风格配置（可增加或修改回复风格）
5. 推荐任务自定义

### 角色与风格定制

在yml配置文件中，企业可以根据需求对风格进行增加或修改。例如，可以设置正式商务风格用于对外沟通，或设置轻松活泼风格用于内部协作。推荐任务也可以自定义，将常用功能放置在首页快捷入口，提高员工使用效率。

这种深度的自定义能力使AiPy能够真正融入企业的工作流，而不是要求员工适应工具的固定模式。

## 四、智能体按需编排：构建高效的AI应用生态

AiPy的智能体系统是企业AI应用的核心竞争力。通过智能体集市和开发能力，企业可以快速构建和部署定制化的AI解决方案。

### 智能体类型分类

| 类型关键字 | 说明 | 适用场景 |
|------------|------|----------|
| conversation-tool | 对话工具型 | 日常问答、任务执行 |
| embed-webview | 嵌入页面型 | 集成外部系统界面 |
| application | 独立应用型 | 独立运行的程序 |
| webview | 网页型 | 网页应用集成 |
| skills | 技能型 | 特定功能模块 |

### 智能体开发与部署流程

1. **开发智能体**：根据业务需求编写智能体代码和配置文件
2. **项目构建**：使用命令`npx @anthropic-ai/dxt pack`进行打包
3. **上传安装**：打开AiPy企业版，点击右侧"集市"按钮，选择安装智能体
4. **文件上传**：将打包好的文件上传，点击安装
5. **验证成功**：当页面显示完成状态时，代表智能体安装成功

或者直接将智能体放入AiPy智能体目录下`C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro`，然后重启AiPy企业版。

### MCP集成能力

MCP（Model Context Protocol）是AiPy的重要扩展机制。配置步骤如下：

1. 在AiPy企业版页面中，点击设置进入设置页面
2. 选择"MCP"选项卡，点击添加按钮
3. 输入MCP名称（如web_search）
4. 选择MCP类型（如标准输入/输出stdio）
5. 选择MCP命令格式（如npx）
6. 输入MCP参数（如open-websearch@1.1.5）
7. 输入环境变量（如无则不修改）
8. 点击保存，加载完成后出现"已完成"按钮即代表MCP添加成功

### 智能体应用场景

| 场景 | 推荐智能体 | 提示词示例 |
|------|------------|------------|
| 制作PPT | PPT生成智能体 | 生成一个介绍中国新能源汽车发展的PPT |
| 生成图片/视频 | 图片生成/视频生成智能体 | 批量生成10张不同的肥猫切菜的照片 |
| 阅读材料整理 | 思维导图智能体 | 读取C:\...\方案v3.pptx，然后帮我整理为一个思维导图 |
| 系统开发 | 编程智能体（Claude code） | 帮我做一个访客登记管理系统，采用Sqlite数据库 |
| 周报汇总 | 对话工具型智能体 | 根据输入的日报内容汇总周报，不同日期的相同工作条目合并 |

### 智能体选择建议

- AiPy不能识别图片内容时，勾选视觉理解智能体
- 生成的图片是线条时，勾选图片生成智能体
- PPT效果不理想时，勾选PPT生成智能体
- 需要获取实时信息时，开启联网搜索功能
- 股票信息分析使用"量化研究"智能体
- 编程任务使用Claude code智能体

## 五、任务执行与工作流优化

AiPy企业版提供任务模式和对话模式两种工作方式，满足不同场景的需求。

### 任务创建流程

1. 在AiPy企业版主界面logo下方点击新建任务按钮
2. 在"任务输入框"中输入需要执行的任务
3. 如需选择MCP或智能体，点击勾选
4. 按下"Ctrl+Enter"或点击"去做吧"按钮下发任务
5. 在"任务对话窗口"中查看任务的执行过程
6. 在"任务工作目录"中查看生成的过程文件或任务结果文件

### 执行参数配置

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 最大执行轮数 | 任务的最大回复轮数 | 根据任务复杂度设置10-50 |
| 超时时间 | 等待大模型接口返回时间 | 根据网络环境设置30-300秒 |
| 自动选择智能体 | 自动判断所需智能体 | 复杂任务建议开启 |

### 最佳实践建议

- 执行复杂任务前，先读取相关数据的前30行，了解数据格式
- 根据具体数据格式编写合适的分析脚本
- 报告保存到当前工作目录，便于管理和追溯
- 对于研发系统开发，选择编程能力较强的大模型如GLM4.5
- 定期清理工作目录中的临时文件，保持系统整洁

## 相关问答FAQs

**AiPy企业版支持哪些语言的界面和交互？**
AiPy企业版目前支持中文、English和日语三种语言。用户可以在常规设置中选择 preferred 语言，系统界面和交互提示会相应切换。语言配置文件位于aipy-enterprise.yml中，企业也可以根据需要扩展支持其他语言。

**如何确保AiPy处理的数据不会泄露到外部？**
AiPy企业版提供多种数据安全保障措施。首先，支持本地知识库部署，所有文档存储在企业本地服务器；其次，可配置一体机内网IP，所有通信在内部网络完成；再次，工作目录可自定义，文件存储路径可控；最后，企业可选择私有模型API，避免数据发送至公有云服务。对于高安全要求场景，建议采用完全内网部署方案。

**AiPy智能体可以自定义开发吗？需要什么技术储备？**
AiPy智能体支持自定义开发。开发者需要掌握JavaScript/TypeScript基础，了解MCP协议规范，熟悉manifest.json配置文件结构。智能体类型包括对话工具型、嵌入页面型、独立应用型、网页型和技能型五种。开发完成后使用npx @anthropic-ai/dxt pack命令打包，然后通过集市安装或直接放入extensions目录部署。官方提供开发规范和示例代码供参考。
