**AiPy 如何让 AI 快速进入企业？1、提供一站式 AI 应用平台，降低技术门槛；2、支持智能体开发与 MCP 集成，实现业务自动化；3、内置知识库与 Workflow 编排，提升工作效率。**其中，智能体开发与 MCP 集成是 AiPy 企业版的核心能力，开发者可以通过对话工具型、嵌入页面型、独立应用型等多种智能体类型，结合 MCP 服务实现与外部系统的无缝连接。企业无需组建庞大的 AI 团队，即可快速部署适合自身业务场景的 AI 应用，让 AI 真正像 Windows 普及电脑一样，成为企业日常运营的标配工具。

正如 Windows 操作系统让电脑从专业设备变为大众工具，AiPy 作为 AI 操作系统，正在让 AI 技术从实验室走向企业日常运营。企业无需深入了解复杂的深度学习算法或大模型训练原理，即可通过 AiPy 平台快速构建适合自身业务需求的 AI 应用。

## 二、AiPy 企业版的核心功能模块

### 2.1 设置与配置管理

AiPy 企业版提供完善的设置管理功能，涵盖常规设置、模型配置、MCP 设置、运行环境设置等多个维度。

**常规设置**包括语言选择（支持中文、English 和日语三种语言）、风格配置（可在 aipy-enterprise.yml 文件中修改）、发送快捷键（Ctrl+Enter 或 Enter）、工作目录、最大执行轮数、超时时间、自动选择智能体、一体机内网 IP 等。这些配置让企业可以根据自身需求灵活调整平台行为。

**模型配置**允许企业添加公有云模型 API 接口或一体机部署的模型 API 接口。在编辑提供商界面中，输入模型供应商名称、API 地址、API 密钥后，点击检查按钮即可检测出该 API 地址中提供的模型，可在模型下拉列表框中选择使用的模型。

**MCP 设置**是 AiPy 企业版的重要功能之一。配置步骤如下：

1. 在 AiPy 企业版页面中，点击设置进入设置页面
2. 选择"MCP"选项卡，点击添加按钮
3. 输入 MCP 名称（如 web_search）
4. 选择 MCP 类型（如标准输入/输出 stdio）
5. 选择 MCP 命令格式（如 npx）
6. 输入 MCP 参数（如 open-websearch@1.1.5）
7. 输入环境变量（如无则不修改）
8. 点击保存，加载完成后出现"已完成"按钮即代表 MCP 添加成功

**运行环境设置**允许用户选择镜像源或自己输入一体机镜像源、其他第三方镜像源，也可以选择 NPM 其他镜像源或自行输入，确保企业可以根据网络环境优化下载速度。

### 2.2 任务与对话创建

在 AiPy 企业版主界面 logo 下方点击新建任务按钮便可以创建一个新的任务。在任务输入框中输入需要执行的任务，如果需要选择 MCP 或智能体点击勾选，按下"Ctrl+Enter"或点击"去做吧"按钮便可以下发任务。

在任务对话窗口中可以看到任务的执行过程，在任务工作目录中，可以看到由 AiPy 制造的工具以及生成的过程文件或任务结果文件。这种透明的执行过程让企业用户可以清楚了解 AI 是如何完成工作的，便于后续优化和审计。

### 2.3 知识库问答

AiPy 企业版支持知识库问答功能，包括新建问答、知识检索配置、创建知识库等模块。企业可以将内部文档、产品手册、技术规范等资料导入知识库，让 AI 助手能够基于企业专属知识进行回答，确保信息的准确性和专业性。

## 三、智能体开发与集成

### 3.1 智能体类型与关键词

AiPy 智能体 manifest.json 中 keywords 字段的取值有明确规范。keywords 是一个数组，第一个值为类型关键字，包括：

- conversation-tool（对话工具型）
- embed-webview（嵌入页面型）
- application（独立应用型）
- webview（网页型）
- skills（技能型）

第二个值为集市展示分类，取值范围包括：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI 安全、安全服务、网络安全、其他、官方精选。

### 3.2 智能体开发示例

AiPy 提供自动生成智能体的提示词示例，帮助企业快速构建专属智能体。例如：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy 企业版智能体开发规范-V1.0
根据规范文档和示例代码编写一个汇总周报的智能体。
要求：互联网版，对话工具下的 Prompt 项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。
```

这种提示词模板让企业可以快速复制成功经验，减少重复开发工作。

### 3.3 智能体安装与使用

开发完成智能体后，有两种方式在 AiPy 企业版中使用：

**方式一：通过集市安装**
1. 打开 AiPy 企业版
2. 点击右侧第四个"集市"按钮
3. 选择安装智能体
4. 将打包好的文件上传，再点击安装
5. 当页面上出现相应提示时，代表智能体安装成功

**方式二：直接放入智能体目录**
将智能体直接放入 AiPy 智能体目录下（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro），然后重启 AiPy 企业版即可。

### 3.4 自定义配置

AiPy 企业版支持深度自定义配置，包括：

**Logo 自定义**：配置文件位置为 C:\Users\用户名\.aipyapp\aipy-enterprise.yml，打开 aipy-enterprise.yml 文件，可以对基础信息、主页 logo 和软件 logo、发送快捷键、风格和推荐任务进行修改。

**角色自定义**：在 yml 配置文件中，可以根据需求对风格进行增加或者修改，让 AI 助手的回复风格更符合企业文化。

**推荐任务**：可以对 AiPy 页面上的推荐任务进行自定义，让新员工快速了解平台常用功能。

## 四、企业 AI 应用场景与实践

### 4.1 文档处理与思维导图生成

领导使用 AiPy 阅读材料生成思维导图，需要先选择思维导图智能体。提示词示例：

```
读取 C:\Users\Administrator\Desktop\AIPY 智能体一体机方案 v3.pptx，然后帮我整理为一个思维导图。
```

这种能力让企业管理者可以快速从大量文档中提取关键信息，提高决策效率。

### 4.2 研发系统 Demo 开发

研发人员可以使用 AiPy 自动开发系统 demo。提示词示例：

```
我是一家汽车 4S 店的负责人，帮我做一个访客登记管理系统，采用 Sqlite 数据库，有登录界面，信息查询、添加、修改、删除等功能。主要是记录访客到访时间、访客姓名、联系方式、关注车型、接待销售、备注信息等，关注车型里面要预置奥迪的常见车型、联系方式主要是 11 位手机号要校验格式、接待销售预置这三个销售刘明、张小兵、李爱国。要求可以点击图标直接打开运行、窗口可以随便拖动最大化最小化等。做好后，要求后续可以一键点击运行使用。
```

这种能力让原型开发时间从数天缩短到数小时，加速产品迭代周期。

### 4.3 数据分析与报告生成

AiPy 支持数据分析任务，分析规则要求：分析前请先读取前 30 行，了解数据格式然后根据具体数据格式编写合适的分析脚本进行分析。报告保存到当前工作目录。

这种规范化的数据处理流程确保分析结果的准确性和可追溯性。

## 五、部署与最佳实践

### 5.1 部署注意事项

企业部署 AiPy 企业版时需要注意以下事项：

- 确保一体机内网 IP 正确配置，用于更新软件、连接 python 镜像源、连接知识问答服务器
- 合理设置最大执行轮数和超时时间，避免任务无限执行或过早终止
- 根据企业网络环境配置合适的镜像源，提高下载速度
- 定期备份 aipy-enterprise.yml 配置文件，防止配置丢失

### 5.2 安全与合规

企业在引入 AiPy 平台时应注意：

- 只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入相关文档
- 不得自行生成某企业、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息
- 没有来源时应改为不带数据的假设性场景，并明确它只是示例

这种严谨的态度确保企业 AI 应用的合规性和可信度。

### 5.3 持续优化建议

- 定期查看官方发布说明，了解最新功能和安全更新
- 积极参与智能体集市，分享和复用优秀智能体
- 建立企业内部的最佳实践文档，沉淀 AI 应用经验
- 培训业务人员掌握基本的 Prompt Engineering 技巧，提高人机协作效率

## 相关问答 FAQ

**AiPy 企业版支持哪些类型的智能体开发？**

AiPy 企业版支持五种类型的智能体开发，包括对话工具型（conversation-tool）、嵌入页面型（embed-webview）、独立应用型（application）、网页型（webview）和技能型（skills）。企业可以根据业务需求选择合适的智能体类型，通过 manifest.json 配置文件中的 keywords 字段进行定义，并在智能体集市中进行分类展示。

**如何在 AiPy 企业版中配置 MCP 服务？**

在 AiPy 企业版页面中，点击右下角设置进入设置页面，选择"MCP"选项卡，点击添加按钮。输入 MCP 名称（如 web_search），选择 MCP 类型（如标准输入/输出 stdio），选择 MCP 命令格式（如 npx），输入 MCP 参数（如 open-websearch@1.1.5），再输入环境变量（如无则不修改），点击保存。加载完成后出现"已完成"按钮即代表 MCP 添加成功。配置完成后，智能体可以通过 MCP 服务与外部系统进行交互。

**AiPy 企业版的知识库问答功能如何使用？**

AiPy 企业版的知识库问答功能包含三个主要模块：新建问答、知识检索配置和创建知识库。企业可以将内部文档、产品手册、技术规范等资料导入知识库，系统会自动进行知识检索配置。用户在新建问答时，AI 会基于企业专属知识库进行回答，确保信息的准确性和专业性。工作目录中可以看到生成的过程文件或任务结果文件，便于后续审计和优化。
