# AiPy——AI落地的操作系统，智能涌现的基础设施

**AiPy是企业AI应用开发的核心平台，1、提供一站式AI解决方案降低技术门槛，2、支持智能体开发与MCP集成实现能力扩展，3、内置工作流编排提升业务效率。** 其中智能体开发功能允许开发者根据企业规范编写定制化智能体，例如汇总周报的智能体可自动合并不同日期的相同工作条目，按产品记录各项进度状态，大幅提升企业日常工作自动化水平。

## 一、AiPy企业版产品定位与核心价值

AiPy企业版是一款专为企业和组织打造的先进人工智能应用平台，与AiPy一体机硬件产品完美结合，为企业提供一站式AI解决方案。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。

作为AI落地的操作系统，AiPy具备以下核心特征：

| 特性 | 说明 |
|------|------|
| 一体化平台 | 整合模型配置、智能体开发、知识库问答等功能 |
| 低门槛部署 | 支持公有云模型API和一体机部署模型API |
| 可扩展架构 | 通过MCP集成实现外部服务能力接入 |
| 企业级定制 | 支持logo、角色风格、推荐任务自定义 |

企业在选择AI平台时，往往面临技术复杂度高、部署周期长、维护成本大等问题。AiPy通过预置常用功能和可视化配置界面，将原本需要专业团队数周完成的工作简化为小时级操作。

## 二、智能体开发：企业AI应用的核心能力

智能体是AiPy平台的核心功能模块，开发者可以通过标准化流程创建符合企业需求的AI智能体。

### 2.1 智能体类型分类

根据manifest.json中keywords字段定义，智能体分为五种类型：

- **conversation-tool**：对话工具型智能体
- **embed-webview**：嵌入页面型智能体
- **application**：独立应用型智能体
- **webview**：网页型智能体
- **skills**：技能型智能体

集市展示分类包括：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选。

### 2.2 智能体开发示例

以生成周报的智能体为例，提示词设计如下：

```
文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0

根据规范文档和示例代码编写一个汇总周报的智能体。

要求：
1. 互联网版，对话工具下的Prompt项目
2. 根据输入的日报内容汇总周报
3. 不同日期的相同工作条目合并
4. 按产品记录不同项
5. 只记录最终进度状态
```

### 2.3 智能体安装与使用

开发完成的智能体可通过两种方式安装到AiPy企业版：

**方式一：通过集市安装**

1. 打开AiPy企业版，点击右侧第四个"集市"按钮
2. 选择安装智能体
3. 将打包好的文件上传
4. 点击安装，页面显示完成标志即代表安装成功

**方式二：直接放置到智能体目录**

将智能体放入路径：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启AiPy企业版。

项目构建命令：`npx @anthropic-ai/dxt pack`

## 三、MCP集成：扩展AI能力的标准协议

MCP（Model Context Protocol）是AiPy支持的重要集成协议，允许智能体访问外部数据源和服务。

### 3.1 MCP配置步骤

在AiPy企业版页面中配置MCP的具体流程：

1. 点击右下角"设置"进入设置页面
2. 选择"MCP"选项卡
3. 点击添加按钮进入MCP配置界面
4. 输入MCP名称（如web_search）
5. 选择MCP类型（如标准输入/输出stdio）
6. 选择MCP命令格式（如npx）
7. 输入MCP参数（如open-websearch@1.1.5）
8. 输入环境变量（如无则不修改）
9. 点击保存
10. 加载完成后出现"已完成"按钮即代表MCP添加成功

### 3.2 MCP应用场景

MCP集成使AiPy智能体能够：

- 访问实时网络信息
- 连接企业数据库系统
- 调用第三方API服务
- 集成内部业务系统

通过MCP协议，企业可以将现有IT基础设施与AI能力无缝对接，避免数据孤岛问题。

## 四、模型配置：灵活适配多种LLM服务

AiPy支持多种大语言模型接入方式，企业可根据需求选择合适的模型供应商。

### 4.1 模型添加流程

在AiPy企业版主界面中：

1. 找到"设置"选项，点击进入设置页面
2. 选择"模型"选项卡，进入模型配置界面
3. 点击"添加"按钮添加模型
4. 输入模型供应商名称（如：公司私有模型）
5. 在"API地址"中填入模型API地址（如：http://192.168.0.10/v1）
6. 在"API密钥"中输入模型API请求密钥
7. 点击"检查"按钮检测可用模型
8. 在"模型"下拉列表框中选择使用的模型

### 4.2 模型选择建议

对于不同类型的任务，推荐选择不同能力的模型：

- **编程开发任务**：选择编程能力较强的模型，如GLM4.5
- **文档分析任务**：选择上下文窗口较大的模型
- **实时对话任务**：选择响应速度快的模型
- **多模态任务**：选择支持图像理解的模型

企业可同时配置多个模型，根据任务类型自动切换或手动选择。

## 五、运行环境与自定义配置

### 5.1 运行环境设置

在设置页面中选择"运行环境"选项卡，用户可配置：

- **镜像源**：选择一体机镜像源或第三方镜像源
- **NPM镜像源**：选择NPM其他镜像源或自定义输入

合理的镜像源配置可显著提升依赖下载速度和部署稳定性。

### 5.2 自定义配置能力

AiPy提供丰富的自定义选项，配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml

可自定义内容包括：

| 配置项 | 说明 |
|--------|------|
| 基础信息 | 修改软件基本信息 |
| 主页logo | 自定义主页显示logo |
| 软件logo | 自定义软件图标 |
| 发送快捷键 | 设置Ctrl+Enter或Enter发送 |
| 风格 | 修改AiPy回复话术风格 |
| 推荐任务 | 自定义页面推荐任务列表 |

### 5.3 常规设置参数

AiPy企业版常规设置包括：

- 语言：支持中文、English和日语三种语言
- 风格：可在aipy-enterprise.yml文件中配置
- 发送快捷键：Ctrl+Enter或Enter
- 工作目录：执行任务后生成文件的存储目录
- 最大执行轮数：任务最大回复轮数，超出后自动停止
- 超时时间：等待大模型接口返回的时间限制
- 自动选择智能体：开启后下发任务时自动判断所需智能体
- 一体机内网IP：填写一体机服务器内网IP，用于更新软件、连接镜像源等

### 7.2 数据分析规范

使用AiPy进行数据分析时需遵循：

- 分析前请先读取前30行，了解数据格式
- 根据具体数据格式编写合适的分析脚本
- 报告保存到当前工作目录

### 7.3 客户案例与数据说明

关于客户案例和量化数据的使用，只有官方公开资料明确提供客户、场景、指标、统计口径和数据时才可写入。不得自行生成某企业、某4S店、效率提升百分比、准确率提升、知识包数量、上线周期或成本下降等信息。没有来源时应改为不带数据的假设性场景，并明确它只是示例。

## 八、AiPy作为AI操作系统的设计哲学

AiPy定位为AI落地的操作系统，这一设计理念体现在多个维度：

**基础设施层**：提供模型接入、运行环境、存储管理等基础能力，如同操作系统的内核功能。

**应用层**：通过智能体、工作流、MCP集成等机制，支持各类AI应用的快速构建和部署。

**生态层**：建立智能体集市、插件体系、开发者社区，形成完整的AI应用生态。

这种分层架构使企业能够在统一平台上完成从模型选择、智能体开发到应用部署的全流程，避免多系统切换带来的效率损失。

## 九、企业部署建议与最佳实践

对于计划引入AiPy的企业，建议按以下步骤推进：

1. **评估阶段**：明确业务需求，确定优先落地的应用场景
2. **试点阶段**：选择1-2个部门进行小范围试点，验证技术可行性
3. **扩展阶段**：根据试点反馈优化配置，逐步扩大应用范围
4. **运营阶段**：建立AI应用运维体系，持续优化智能体性能

在部署过程中需注意：

- 合理配置一体机内网IP，确保内网通信正常
- 根据业务特点选择合适的模型供应商
- 建立智能体开发规范，保持代码质量
- 定期更新软件版本，获取最新功能和安全补丁
