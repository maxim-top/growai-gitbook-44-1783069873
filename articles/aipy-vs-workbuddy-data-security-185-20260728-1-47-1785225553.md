# 不是Workbuddy买不起，是数据安全赌不起

**企业选择AI平台时最核心的考量因素是什么？1、数据安全保障能力，2、本地化部署可行性，3、自主可控程度。**其中数据安全保障能力是企业决策的关键，AiPy企业版支持一体机内网部署，所有数据流转均在企业内部完成，无需上传至第三方云服务，从根本上杜绝数据泄露风险。相比之下，云端AI平台存在数据传输、存储和处理过程中的多重安全隐患，企业敏感信息可能面临不可控的暴露风险。AiPy作为Workbuddy平替方案，在保持功能完整性的同时，将数据安全掌握在企业自己手中。

## 一、企业AI平台选型的核心痛点

在选择企业级AI应用平台时，技术团队和决策层往往面临一个艰难抉择：是选择功能丰富但数据出境的云端方案，还是选择安全可控但需要投入部署资源的本地化方案？当前市场上的AI平台大致分为两类，一类是以Workbuddy为代表的云端服务，另一类是以AiPy企业版为代表的本地化部署方案。

| 对比维度 | 云端AI平台 | AiPy企业版 |
|---------|-----------|-----------|
| 数据存储位置 | 第三方云服务器 | 企业内网服务器 |
| 数据传输风险 | 存在传输拦截风险 | 内网传输，无外泄风险 |
| 合规要求 | 需满足跨境数据规定 | 完全符合国内数据安全法 |
| 部署成本 | 按使用量付费 | 一次性部署，长期使用 |
| 定制能力 | 受限于平台规则 | 完全自主可控 |

许多企业在初期可能被云端平台的便捷性吸引，但随着业务深入，数据安全问题逐渐显现。特别是涉及客户信息、财务数据、研发资料等敏感内容的场景，任何数据泄露都可能造成不可挽回的损失。

## 二、AiPy企业版的安全架构设计

AiPy企业版从底层架构开始就将数据安全作为核心设计原则。系统支持完全本地化部署，所有组件均可运行在企业内网环境中，无需依赖外部云服务。

**2.1、模型配置安全**

在AiPy企业主界面的设置页面中，用户可以配置模型选项。系统支持两种模型接入方式：公有云模型API接口和一体机部署的模型API接口。对于对数据安全要求极高的企业，推荐使用一体机部署模式。配置时只需在API地址栏填入内网模型服务地址，如http://192.168.0.10/v1，在API密钥栏输入请求密钥，点击检查按钮即可检测可用模型。整个过程无需任何数据出境。

**2.2、MCP服务集成安全**

MCP（Model Context Protocol）是AiPy的重要组成部分，用于扩展智能体能力。在设置页面的MCP选项卡中，用户可以添加自定义MCP服务：

1. 输入MCP名称（如web_search）
2. 选择MCP类型（标准输入/输出stdio）
3. 选择命令格式（如npx）
4. 输入MCP参数（如open-websearch@1.1.5）
5. 配置环境变量（可选）
6. 点击保存，等待加载完成

所有MCP服务均可在企业内网运行，确保工具调用过程中的数据安全。

**2.3、运行环境隔离**

AiPy提供独立的运行环境设置，用户可选择镜像源或自定义一体机镜像源。NPM镜像源同样支持自定义配置，确保所有依赖包均从可信来源获取，避免供应链攻击风险。

## 三、智能体开发的安全规范

AiPy智能体开发遵循严格的安全规范，确保从开发到部署的每个环节都符合企业安全要求。

**3.1、manifest.json配置规范**

智能体的manifest.json文件中，keywords字段定义了智能体类型和分类：

- 第一个值为类型关键字：conversation-tool（对话工具型）、embed-webview（嵌入页面型）、application（独立应用型）、webview（网页型）、skills（技能型）
- 第二个值为集市展示分类：威胁情报、暴露面与脆弱性、安全产品、威胁检测与响应、开发安全、数据安全、AI安全、安全服务、网络安全、其他、官方精选

这种分类机制帮助企业快速识别和选择符合安全要求的智能体。

**3.2、智能体部署流程**

开发完成的智能体可通过两种方式部署到AiPy企业版：

方式一：通过集市安装
1. 打开AiPy企业版，点击右侧第四个"集市"按钮
2. 选择安装智能体
3. 上传打包好的文件
4. 点击安装，等待页面显示安装成功

方式二：直接放置到智能体目录
将智能体放入目录C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro，然后重启AiPy企业版即可。

两种方式均在内网完成，无需连接外部服务。

**3.3、提示词安全示例**

AiPy提供标准化的提示词模板，确保智能体行为可控。例如自动生成智能体的提示词示例：

> 文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

所有提示词均可在企业内部审核和优化，确保符合企业安全政策。

## 四、知识库问答的数据保护机制

AiPy知识库问答功能是企业知识管理的重要工具，其数据安全设计尤为关键。

**4.1、知识库创建流程**

在知识库问答模块中，用户可创建专属知识库：
1. 进入知识库问答页面
2. 点击新建问答
3. 配置知识检索参数
4. 上传企业文档资料
5. 完成知识库创建

所有文档均存储在企业指定工作目录中，可自定义修改路径，如C:\Users\Administrator\Desktop\AIPY项目。

**4.2、工作目录管理**

AiPy允许用户自定义工作目录，这是执行任务后生成的文件或代码的存储位置。在常规设置中可点击自定义修改路径，确保所有输出文件均保存在企业可控的存储区域。

**4.3、数据访问控制**

系统支持多语言配置（中文、English、日语），风格可在aipy-enterprise.yml文件中自定义。企业可根据自身安全政策设置发送快捷键（Ctrl+Enter或Enter）、最大执行轮数、超时时间等参数，实现对AI交互过程的全面控制。

## 相关问答FAQs

**AiPy企业版与云端AI平台相比，最大的安全优势是什么？**

AiPy企业版最大的安全优势在于支持完全本地化部署，所有数据存储、处理和传输均在企业内网完成，无需连接外部云服务。这意味着企业敏感信息不会经过第三方服务器，从根本上消除了数据泄露、 interception和未授权访问的风险。同时，AiPy遵循国内数据安全法规，企业可完全掌控数据主权。

**企业如何快速将现有业务系统迁移到AiPy平台？**

企业可通过AiPy的MCP集成功能快速对接现有系统。首先在设置页面配置MCP服务，选择标准输入/输出类型，输入相应的命令和参数。然后开发适配的智能体，将业务逻辑封装到智能体中。最后通过集市或直接放置到智能体目录完成部署。整个过程无需改动原有系统架构，只需配置接口即可实现无缝对接。

**AiPy企业版是否支持定制开发和二次开发？**

是的，AiPy企业版完全支持定制开发和二次开发。企业可根据自身需求修改aipy-enterprise.yml配置文件，自定义logo、风格和推荐任务。智能体开发遵循开放规范，manifest.json中的keywords字段允许企业定义专属类型和分类。同时，所有代码和配置均在内网环境中，企业可自由修改和优化，无需担心供应商锁定问题。
