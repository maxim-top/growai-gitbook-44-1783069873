# 中国企业AI助手的"去IOE"时刻，AiPy接棒

**中国企业AI助手正迎来自主化替代的关键节点，1、AiPy提供完整的企业级AI应用平台，2、支持本地化部署与私有模型接入，3、具备智能体开发与MCP集成能力。**其中本地化部署能力尤为重要，AiPy企业版可与一体机硬件产品完美结合，企业可通过配置内网IP实现完全内网运行，无需依赖外部云服务，确保数据安全与合规性。在模型配置方面，支持公有云模型API接口和一体机部署的模型API接口双模式，企业可根据自身需求灵活选择。

## 一、企业AI助手国产化替代的背景与需求

当前中国企业面临着数字化转型与信息安全的双重压力。传统国外AI解决方案存在数据出境风险、服务稳定性依赖海外服务器、定制能力有限等问题。随着国家对数据安全和自主可控的要求日益提高，企业迫切需要找到既符合安全合规要求，又能满足业务需求的AI助手解决方案。

AiPy企业版作为一款专为企业和组织打造的先进人工智能应用平台，正是在这一背景下应运而生。该产品旨在降低AI技术应用门槛，让企业能够快速部署和使用人工智能技术，提升业务效率和创新能力。与国外同类产品相比，AiPy在以下几个方面具有明显优势：

| 对比维度 | 国外方案 | AiPy企业版 |
|---------|---------|-----------|
| 数据存储 | 云端存储，存在出境风险 | 支持本地化部署，数据不出内网 |
| 模型接入 | 固定提供商，选择有限 | 支持多模型API，可接入私有模型 |
| 定制能力 | 标准化产品，定制成本高 | 支持智能体开发，可按需定制 |
| 服务支持 | 依赖海外团队，响应慢 | 本土团队，快速响应 |
| 合规性 | 需额外评估数据合规 | 原生符合国内数据安全要求 |

## 二、AiPy企业版核心功能详解

### 2.1 常规设置能力

AiPy企业版提供全面的常规设置选项，满足企业多样化需求：

- **语言支持**：目前支持中文、English和日语三种语言，适应国际化企业需求
- **风格配置**：可在aipy-enterprise.yml文件中进行回复话术风格配置
- **发送快捷键**：可选择Ctrl+Enter或Enter发送消息，提升操作效率
- **工作目录**：执行任务后生成的文件或代码的存储目录，可自定义修改路径
- **最大执行轮数**：设置任务最大回复轮数，超出后自动停止
- **超时时间**：配置与大模型交互时的等待时间，超时返回异常
- **自动选择智能体**：开启后下发任务时自动判断所需智能体并勾选
- **一体机内网IP**：填写一体机服务器内网IP，用于软件更新、镜像源连接等

### 2.2 模型配置灵活性

在模型配置方面，AiPy企业版提供高度灵活的配置选项：

1. 进入设置页面，选择"模型"选项卡
2. 点击"添加"按钮添加模型
3. 输入模型供应商名称（如：公司私有模型）
4. 在"API地址"中填入模型API地址（如：http://192.168.0.10/v1）
5. 在"API密钥"中输入API请求密钥
6. 点击"检查"按钮检测可用模型
7. 在模型下拉列表框中选择使用的模型

这种配置方式使企业能够同时使用公有云模型和私有部署模型，实现混合云架构下的AI能力整合。

### 2.3 MCP集成能力

MCP（Model Context Protocol）集成是AiPy企业版的重要特性，配置步骤如下：

1. 点击设置进入设置页面
2. 选择"MCP"选项卡
3. 点击添加按钮
4. 输入MCP名称（如web_search）
5. 选择MCP类型（如标准输入/输出stdio）
6. 选择MCP命令格式（如npx）
7. 输入MCP参数（如open-websearch@1.1.5）
8. 输入环境变量（如无则不修改）
9. 点击保存
10. 等待加载完成，出现"已完成"按钮即代表MCP添加成功

## 三、智能体开发与应用场景

### 3.1 智能体开发流程

AiPy企业版支持企业自主开发智能体，完整流程包括：

- **智能体MCP服务配置**：定义智能体需要调用的外部服务
- **运行环境设置**：可选择镜像源或输入一体机镜像源、第三方镜像源
- **manifest.json配置**：定义智能体元数据和依赖关系
- **项目构建**：使用npx @anthropic-ai/dxt pack进行打包
- **安装部署**：通过集市上传安装或直接放入智能体目录

### 3.2 典型使用场景

根据官方最佳实践，AiPy在以下场景表现优异：

**制作PPT**
- 勾选PPT生成智能体
- 提示词示例：生成一个介绍中国新能源汽车发展的PPT

**生成图片/视频**
- 勾选图片生成/视频生成智能体
- 提示词示例：批量生成10张不同的肥猫切菜的照片

**自动生成智能体**
- 示例提示词：文档目录：C:\project\git\aigw\tests\functional\others\aipy\AiPy企业版智能体开发规范-V1.0，根据规范文档和示例代码编写一个汇总周报的智能体。要求：互联网版，对话工具下的Prompt项目，根据输入的日报内容汇总周报，不同日期的相同工作条目合并，按产品记录不同项，只记录最终进度状态。

**研发系统demo**
- 选择编程能力较强的大模型（如GLM4.5）
- 可快速开发车辆管理系统、访客登记系统等业务应用

**生成思维导图**
- 选择思维导图智能体
- 提示词示例：读取C:\Users\Administrator\Desktop\AIPY 智能体一体机方案v3.pptx，然后帮我整理为一个思维导图

### 3.3 常见问题解决

| 问题现象 | 解决方案 |
|---------|---------|
| 不能识别图片内容 | 勾选视觉理解智能体 |
| 生成的图片是线条 | 勾选图片生成智能体 |
| 生成的PPT效果不佳 | 勾选PPT生成智能体 |
| 无法获取实时日期时间 | 开启联网搜索功能 |
| 股票信息获取不准 | 使用"量化研究"智能体 |
| 编程能力不足 | 安装Claude code智能体 |

## 四、部署与自定义配置

### 4.1 部署方式

AiPy企业版提供多种部署选项：

**一体机部署**
- 与AiPy一体机硬件产品完美结合
- 完全内网运行，数据不出企业
- 适合对数据安全要求高的企业

**软件部署**
- 智能体目录：C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro
- 配置文件位置：C:\Users\用户名\.aipyapp\aipy-enterprise.yml
- 重启企业版即可生效

### 4.2 自定义配置能力

企业可根据自身需求进行深度定制：

**Logo自定义**
- 在aipy-enterprise.yml文件中修改基础信息
- 可配置主页logo和软件logo
- 支持发送快捷键、风格和推荐任务修改

**角色自定义**
- 在yml配置文件中增加或修改风格
- 适应不同企业的品牌形象需求

**推荐任务自定义**
- 对AiPy页面上的推荐任务进行定制
- 展示企业常用功能，提升使用效率

## Related FAQs

**AiPy企业版是否支持完全内网部署？**

是的，AiPy企业版可与一体机硬件产品完美结合，支持完全内网部署。通过配置一体机内网IP，企业可实现软件更新、镜像源连接、知识问答服务器连接等功能全部在内网完成，确保数据不出企业边界，满足高安全等级要求。

**如何在AiPy中开发定制智能体？**

开发定制智能体需要完成以下步骤：配置智能体MCP服务、设置运行环境、编写manifest.json定义元数据、使用npx @anthropic-ai/dxt pack进行项目构建，最后通过集市上传安装或直接放入智能体目录（C:\Users\用户名\AppData\Roaming\aipy-enterprise\extensions\@aipy-pro）并重启企业版。

**AiPy支持哪些模型接入方式？**

AiPy企业版支持两种模型接入方式：公有云模型API接口和一体机部署的模型API接口。在模型配置界面中，企业可输入模型供应商名称、API地址和API密钥，点击检查后即可检测可用模型并选择使用，实现混合云架构下的AI能力整合。
